# AI 短剧生产底座 · 使用手册

> 7 个 skill + CLI 执行层组成生产 harness。**上传剧本 + 飞书链接 → 全套生产资产 + 自动生成**。聊天只产生草案，写入飞书必须经你确认。

---

## 一、总览：流水线

```
上传小说章节（或成品剧本）+ 飞书链接
  → harness 绑定 workspace（只读）
  → ① drama-initializer          剧本设定 + 角色档案        → 写入飞书三张表
  → ② drama-asset-generation 角色/场景/道具版式化出图        → 触发出图
  → 逐集滚动：
    → ③ novel-to-drama           小说章节 → 剧本（1 章 = 1 集）→ 写入剧本表
    → ④ drama-asset-extraction   剧本+小说 → 角色/场景/道具资产（一句 ≤50 字描述）→ 写资产表 → 按依赖出图 + 场景一致性检查
    → ⑤ drama-segment-generation       资产绑定+拆分镜+依赖+视频提示词 → 写入分镜表 → 触发配音+视频
（ai-drama-harness 编排全程；人在 4 个确认点介入）
```

逐集阶段用当前章小说原文补长相、空间与道具细节（剧本里的外貌/性格细节常被压缩丢失），每个资产给一句 ≤50 字描述；无小说原文时只用剧本，库里已有的资产直接复用。

## 二、怎么开始

### 项目放哪（一个剧本一个文件夹）

- 默认推荐路径：`C:\Users\Heart\PycharmProjects\vomin_studio\workspace\{剧名}`，workspace 根目录下并存多个剧本
- 你也可以指定任意路径；初始化时 harness 会把实际路径列进确认清单
- 路径会自动写入飞书「系统设置」表（项目路径/剧名/创建时间），之后只给飞书链接也能定位到本地项目

### 方式 A — 给飞书链接 + 上传剧本（推荐）

> "飞书链接: https://xxx.feishu.cn/base/XxxYyyZzz
> 剧本：（上传 .txt / .md / .docx / .pdf / 飞书文档）"

harness 自动解析链接、发现/补全表结构、按默认规则（或你指定的路径）创建 workspace、拉取已有数据，并写回系统设置。

### 方式 B — 只有剧本，从零开始

> "剧本：（上传剧本文件）"

harness 先通读剧本、产出初始化草案给你确认，**确认后才会新建飞书多维表格和本地 workspace 并写入数据**，不会一上来就建空表。

> 只有一句话想法、没有剧本文件时无法启动：初始化技能只处理现成剧本，不替你原创剧本。

## 四、节点依赖（谁等谁）

```
上传小说章节 / 剧本
  └→ ① drama-initializer ── 剧本设定 / 资产库 / 角色档案
            ├→ ② 资产图（角色四视角 / 场景四视角资料图 / 道具双视角）→ generate 出图
            └→ 逐集（每集依次）：
                 ③ novel-to-drama：小说 → 剧本 → 剧本表（小说章节/小说内容/初版剧本）
                 ④ drama-asset-extraction：读本集剧本 + 小说原文 → 角色/场景/道具清单（≤50 字描述）→ 写资产表（已有复用）→ 按依赖出图 → 场景一致性检查
                 ⑤ drama-segment-generation（读 当前集±1集 剧本 + 三张资产表做绑定）：
                    → 分段 → 依赖场景/角色/道具 → 视频提示词
                    → 缺资产先补 → generate 配音+视频
```

**关键**：
- 小说章节由你上传，**严格 1 章 = 1 集**：原文逐字存入剧本表「小说内容」，转化后的剧本存「初版剧本」，抽资产以剧本定"有什么"、小说原文补"长什么样"，拆分镜只读转化后的剧本；若上传的是成品剧本，则直接存「初版剧本」
- 资产提取可以重复跑：每次都先读三张资产表，同名标复用、不重复插行；写入只写新建项
- 分镜和视频提示词由同一个技能一次完成
- **拆分镜只读取"当前集 + 前 1 集 + 后 1 集"共 3 集**（`read --table 剧本表 --episode N --context 1`，默认不含小说原文），用于把握角色心境、场景布局和人物调度；禁止一次读入全部剧本，避免上下文膨胀导致输出变差

## 五、4 个确认点（你的活）

**铁律：聊天归聊天，写入归写入。** 你在对话里提意见、否定、讨论，harness 只会改草案；任何对飞书的写入、修改、生成，都会先列出"本次将执行的动作清单"，你回复"确认/写入/执行"后才动手。

| # | 确认什么 | 方式 | 确认后 |
|---|---|---|---|
| 1 | 剧本设定 + 角色档案 | 对话确认 | 建表（方式B）+ 写入三张表 |
| 2 | 角色形象图 | 飞书审核 | 确认/返工 |
| 3 | 分镜与视频提示词（逐集） | 对话确认 | 补资产 + 写分镜表 + 生成 |
| 4 | 视频成片（逐集） | 飞书审核 | 确认/返工 |

- **对话确认**：回复"确认"写入，"修改：意见"只改草案不写入，"重做"重新生成草案
- **飞书审核**：在飞书查看图片/视频，返工的改状态为"返工"并填备注，然后回复"继续"
- **返工重生成也要确认**（要花生成预算）
- **只读操作不要确认**：读取表格、预览提示词展开随时可以

## 六、素材锚定语法（角色 / 场景 / 道具怎么挂图）

3.0 格式：参考图挂在【资产锁定】的条目里，正文用"编号+名称"引用；一段 = 一次生成 = 分镜表一行（段 ID `ep01_p01`）。

**1. 资产锁定**（`编号｜名称：补充内容`，锚点放末尾）：

```text
【参考图映射】图1=S01出租屋；图2=R01张三；图3=P01行李箱
场景：【S01｜出租屋：{资产库：出租屋}】
角色：【R01｜张三：{资产库：张三}】
道具：【P01｜行李箱：24 寸硬壳，{资产库：行李箱}】
```

- `{资产库：名}` / `{资产库：名}` / `{资产库：名}`：移除标记，并按顺序把图传给模型；
- **【参考图映射】** 把 图N 与资产对齐：编号从 1 连续、顺序 = 条目出现顺序，**带图道具也要列**；
- 补充内容写在锚点前（`24 寸硬壳，{资产库：行李箱}`）；展开时 `：】` / `，】` 会自动收干净。

**2. 正文**：写成 `R01张三扶住门框`，不写裸名、不加【】。

其他可引用素材：

```text
{素材库：素材ID}            任意素材（图/视频）
{剧本分镜表：ep01_p03}      上一段成片（动作衔接，能不用就不用）
{sheetName:rowId}           通用形式：表名 + 行主键（中英文冒号均可）
```

- 角色/场景必须已在库且素材已生成；道具没出图就只写文字、不挂锚点
- 生成前用 `python cli.py expand <workspace> --shot ep01_p01` 预览展开结果与素材清单

**资产库**：存放反复出现或需要单独出图的关键道具（行李箱、蛋糕、四件套……）。一行一个道具，字段：`道具ID / 道具类型 / 道具描述 / 关联集数 / 生成提示词 / 文件路径 / 出图状态`。录入后可用 `python cli.py generate <workspace> --target 资产库:行李箱` 出参考图；空表也能跑，没有行的道具只写文字。

## 七、CLI 命令速查

| 命令 | 作用 | 是否需确认 |
|---|---|---|
| `python cli.py init-from-url <URL> [路径] --name 剧名` | 绑定已有飞书表格（路径省略用 workspace\剧名） | 否（仅写系统设置引导项） |
| `python cli.py init [路径] --name 剧名` | 从零建表+workspace（路径省略用 workspace\剧名），自动写系统设置 | **是** |
| `python cli.py set-path <路径>` | 迁移目录后更新系统设置中的项目路径 | 否（仅写路径） |
| `python cli.py read <路径> --table 表名` | 读取表数据（JSON） | 否 |
| `python cli.py read <路径> --table 剧本表 --episode 5 --context 1` | 只读第 4/5/6 集（分镜输入，默认不含小说原文；加 `--with-novel` 才带原文） | 否 |
| `python cli.py migrate-schema <路径> --dry-run` | 预览存量表迁移计划（剧集表→剧本表、补字段、补缺失表） | 否 |
| `python cli.py migrate-schema <路径>` | 执行存量表迁移（含补齐「资产库」等缺失标准表） | **是** |
| `python cli.py write <路径> --table 表名 --data '<JSON>'` | 写入数据（upsert） | **是** |
| `python cli.py generate <路径> --target 资产库:林砚` | 生成指定资产 | **是** |
| `python cli.py generate <路径>` | 批量生成待生成分镜（按各段 timeline 真实秒数出片，配音从角色档案取音色） | **是** |
| `python cli.py generate <路径> --tts-only` | 仅配音（本项目 `tts.enabled=false`，已停用） | **是** |
| `python cli.py generate <路径> --target 生图工作台:all` | 批量生成工作台里所有未完成任务（只填提示词即可） | **是** |
| `python cli.py workbench <路径>` | 同上；说「生图工作台现在开始工作」时执行 | **是** |
| `python cli.py preflight <路径> --episode N` | 生产态资产校验（文件存在 + 扩展名与真实格式一致），不过不许调模型 | 否 |
| `python cli.py push <路径>` | 推送到飞书 | **是** |
| `python cli.py pull <路径>` | 从飞书拉取 | 否 |
| `python cli.py expand <路径> [--shot ID]` | 预览提示词展开 | 否 |
| `python cli.py status <路径>` | 查看状态和预算 | 否 |

> **生图工作台用法**：在飞书「生图工作台」新建一行，**只填「提示词」就能出图**——提示词里可以写 `{资产库：陈诚}`、`{资产库：陈诚公寓门口}` 引用素材。
> - 任务名留空 → 自动取提示词首行前 20 字
> - 模型 / 分辨率 / 画面比例 → 都是**下拉选择**；留空走默认（模型 `ark.image_model`、分辨率 `2K`、比例 `16:9`）
> - 比例换算：2K+16:9 = `2048x1152`，2K+9:16 = `1152x2048`；分辨率直接写 `1024x768` 时按写的来
> - **场景资料板**选 `22:9`（6600×2700 同比例）：4K+22:9 = `3360x1374`（面积上限），成品需超分到 6600×2700
> - 跑：`python cli.py workbench <路径>`（或说「生图工作台现在开始工作」）
> - **续生**：新建一行，提示词里写 `{生图工作台：上一行任务名}` 即可把上一张图当参考图继续改。要续生就**必须填任务名**。

> **视频模型怎么定**：优先级 = 分镜行 `模型` 字段 > `workspace.yaml` 的 `ark.video_model`。
> - 默认 `doubao-seedance-2-5-260628`，**2.5 才支持长段（最长 30 秒）**
> - `video_model_fast`（`doubao-seedance-2-0-fast-260128`）只在 `ark.allow_fast_model: true` 且该段没有配音参考时才启用；默认关闭，避免长段被静默降级
> - 成片画幅取 `ark.default_ratio`，本项目应为 `16:9`

## 八、核心设计原则

1. **确认后写入**：对话中产生的一切都只是草案，飞书写入/生成必须逐次确认
2. **小说原文不动**：章节原文逐字进剧本表「小说内容」；改编只发生在「初版剧本」，且不改剧情事实
3. **三层拆分**：剧本 → 角色档案（唯一标准源）→ 生成提示词
4. **只补新增**：每集依赖清单比对资产库，新增才补生成
5. **一场景一图 + 逐集增量**：一个场景只出一张图，随集抽取，库里已有的场景直接复用；出图后过一致性检查再进分镜
6. **画风全局继承**：资产图、视频提示词的画风一律取剧本设定
7. **一致性基准**：角色四视角设定图是后续所有画面的人脸标准

## 十、常见问题

**Q：我在聊天里说"把主角改成 30 岁"，会自动改飞书吗？**
A：不会。harness 只改草案并重新给你看，同时列出将写入的内容，你回复"确认"才写入。

**Q：每一次小修改都要确认吗？**
A：是的。可以在一轮里把多条修改意见一次说完，harness 汇总更新后只确认一次。

**Q：同一场景在好多集出现？**
A：只生成一次，后续集复用（分镜依赖清单去重，初始化时场景名已归一化）。

**Q：想从中间开始？**
A：可以。比如已确认设定，直接说"拆分镜第3集"即可。

**Q：怎么跳过确认？**
A：启动时说"全自动/不用确认"，harness 跳过对话确认（#1 #4），但飞书图片/视频审核（#2 #3 #5）保留，因为图片/视频必须人眼检查。

**Q：上传的剧本不完整怎么办？**
A：只初始化已有的集数，缺失集标"待编写"，不会替你续写。
