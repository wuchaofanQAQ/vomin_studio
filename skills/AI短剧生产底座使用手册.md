# AI 短剧生产底座 · 使用手册

> 9 个 skill + CLI 执行层组成全自动 harness。一句话想法 + 飞书链接 → 全套生产资产 + 自动生成。人只在关键节点做确认。

---

## 一、总览：全自动流水线

```
飞书链接 + 一句话想法
  → harness 自动初始化 workspace
  → ① story-developer           设定+全集大纲        → 写入飞书·剧本设定表
  → ② character-bible-extractor  角色档案（8模块）    → 写入飞书·角色库 + 角色档案
  → ③ character-three-view-prompt 角色出图提示词      → 触发出图
  → ④ scene-image-prompt         场景出图提示词       → 触发出图
  → ⑤ episode-generator          分集剧本（逐集）
  → ⑥ storyboard-generator       分镜+依赖清单        → 写入飞书·剧本分镜表
  → ⑦ battle-fx-storyboard       战斗特效分镜         → 合并到分镜表
  → ⑧ video-shot-prompt          视频提示词           → 触发配音+视频生成
（ai-drama-harness 编排全程；人在 7 个确认点介入）
```

---

## 二、怎么开始

### 方式 A — 给飞书链接（推荐）

> "飞书链接: https://xxx.feishu.cn/base/XxxYyyZzz
> 想法: 外卖员重生回10年前打脸前老板的短剧，30集"

harness 会自动解析链接、发现/补全表结构、创建 workspace、拉取已有数据。

### 方式 B — 从零开始

> "剧名: 重生打脸
> 想法: 做个都市重生逆袭短剧，30集"

harness 会先和你聊完剧本设定，确认满意后再自动创建飞书多维表格 + 本地 workspace 并写入数据。不会一上来就建空表。

## 四、节点依赖（谁等谁）

```
① 设定+大纲（源头，必须先）
   ├→ ② 角色档案
   │      └→ ③ 三视图（吃角色档案+画风）→ generate 出图
   ├→ ④ 核心场景（吃设定画风，可并行）→ generate 出图
   └→ ⑤ 写剧本（吃①设定+①大纲+②核心角色档案）
           └→ ⑥ 分镜 → ⑦ 战斗分镜 → ⑧ 视频提示词 → generate 出视频
```

**关键**：
- 写剧本（⑤）**不依赖**场景图（④）
- 核心角色档案（②）是写剧本的真正前提

## 五、7 个确认点（你的活）

| # | 确认什么 | 方式 | 之后 |
|---|---|---|---|
| 1 | 剧本设定和大纲 | 对话确认 | 写入飞书·剧本设定 |
| 2 | 角色档案 | 对话确认 | 写入飞书·角色库 |
| 3 | 角色形象图 | 飞书审核 | 确认/返工 |
| 4 | 核心场景图 | 飞书审核 | 确认/返工 |
| 5 | 分集剧本 | 对话确认 | 交给分镜 skill |
| 6 | 分镜脚本 | 对话确认 | 写入飞书·分镜表 |
| 7 | 视频成片 | 飞书审核 | 确认/返工 |

- **对话确认**：回复"确认"继续，"修改: 意见"调整，"重做"重来
- **飞书审核**：在飞书中查看图片/视频，返工的改状态为"返工"，然后回复"继续"

## 六、CLI 命令速查

| 命令 | 作用 |
|---|---|
| `python cli.py init-from-url <URL> <路径>` | 从飞书链接创建 workspace |
| `python cli.py init <路径> --name 剧名` | 从零创建 workspace + 飞书表 |
| `python cli.py read <路径> --table 角色库` | 读取表数据（JSON） |
| `python cli.py read <路径> --table 角色档案` | 读取角色完整8模块档案 |
| `python cli.py write <路径> --table 角色库 --data '<JSON>'` | 写入数据（upsert） |
| `python cli.py generate <路径> --target 角色库:林砚` | 生成指定资产 |
| `python cli.py generate <路径>` | 批量生成所有待生成分镜 |
| `python cli.py generate <路径> --tts-only` | 仅配音 |
| `python cli.py push <路径>` | 推送到飞书 |
| `python cli.py pull <路径>` | 从飞书拉取 |
| `python cli.py status <路径>` | 查看状态和预算 |

## 七、核心设计原则

1. **全自动编排**：harness 通过 CLI 读写飞书 + 触发生成，人只在确认点介入
2. **三层拆分**：剧本 → 角色档案(唯一标准源) → 生成提示词
3. **只补新增**：每集依赖清单比对资产库，新增才补生成
4. **场景两段式**：核心场景提前出 5~8 张定画风；剧情场景随集去重补生成
5. **画风全局继承**：三视图、场景、续集、视频的画风一律取剧本设定
6. **一致性锚点**：角色三视图是后续所有画面的人脸标准

## 八、角色档案 8 模块

| 模块 | 内容 | 角色档案表字段 | 谁用 |
|---|---|---|---|
| A 基本信息 | 角色名/定位/身份/关系 | `basic_info` | harness、episode-generator |
| B 风格层 | 画风/主色调/气质 | `style_desc` | 三视图、特效、视频 |
| C 音色层 | 音色/语速/口音 | `voice_desc` | 配音、TTS |
| D 外貌层 | 年龄/脸型/五官/发型/身体/服装 | `appearance` | 三视图出图 |
| E 性格层 | 性格/动机/弱点/说话风格 | `personality` | 写剧(对白不OOC) |
| F 战斗层 | 战斗风格/招式/阶段状态/特效 | `battle_desc` | 打斗特效、视频 |
| G 标志性表达 | 经典动作/台词/道具 | `signature_expr` | 写剧、分镜、特效 |
| H 标注交接 | 来源集数/缺失清单/资产状态 | `notes` | harness |

> 角色库存精简版（外貌+音色+生图参数），角色档案存完整 8 模块。两表以角色名关联。

## 九、常见问题

**Q：先出核心场景才能写第一集吗？**
A：不用。写剧本只需设定+大纲+核心角色档案。

**Q：同一场景在好多集出现？**
A：只生成一次，后续集复用（分镜依赖清单去重）。

**Q：想从中间开始？**
A：可以。比如已有剧本，直接说"建角色档案"或"拆分镜"即可。

**Q：harness 是不是完全不用手动操作？**
A：除了 7 个确认点需要你回复"确认"或在飞书审核，其余一切自动。

**Q：怎么跳过确认？**
A：启动时说"全自动/不用确认"，harness 跳过文本确认（#1 #2 #5 #6），保留飞书图片/视频审核（#3 #4 #7）。
