# AI 短剧生产底座 · 使用手册

> 6 个 skill + CLI 执行层组成生产 harness。**上传剧本 + 飞书链接 → 全套生产资产 + 自动生成**。聊天只产生草案，写入飞书必须经你确认。

---

## 一、总览：流水线

```
上传剧本 + 飞书链接
  → harness 绑定 workspace（只读）
  → ① drama-initializer          剧本设定 + 剧集 + 角色档案 → 写入飞书四张表
  → ② character-three-view-prompt 角色三视图提示词          → 触发出图
  → ③ scene-image-prompt          场景空镜提示词             → 触发出图
  → ④ storyboard-prompt（逐集）   拆分镜+依赖解析+视频提示词 → 写入分镜表 → 触发配音+视频
（ai-drama-harness 编排全程；人在 5 个确认点介入）
```

character-bible-extractor 作为可选深化技能，用于补全初始化阶段的角色档案。

## 二、怎么开始

### 项目放哪（一个剧本一个文件夹）

- 默认推荐路径：`C:\Users\Heart\PycharmProjects\vomin_studio\workspace\{剧名}`，workspace 根目录下并存多个剧本
- 你也可以指定任意路径；初始化时 harness 会把实际路径列进确认清单
- 路径会自动写入飞书「系统设置」表（项目路径/剧名/创建时间），之后只给飞书链接也能定位到本地项目

### 方式 A — 给飞书链接 + 上传剧本（推荐）

> "飞书链接: https://xxx.feishu.cn/base/XxxYyyZzz
> 剧本：（上传 .txt / .md / .docx / .pdf / 飞书文档）"

harness 自动解析链接、发现/补全表结构、按默认规则（或你指定的路径）创建 workspace、拉取已有数据，并写回系统设置。

### 方式 B — 只有剧本，从零开始

> "剧本：（上传剧本文件）"

harness 先通读剧本、产出初始化草案给你确认，**确认后才会新建飞书多维表格和本地 workspace 并写入数据**，不会一上来就建空表。

> 只有一句话想法、没有剧本文件时无法启动：初始化技能只处理现成剧本，不替你原创剧本。

## 四、节点依赖（谁等谁）

```
上传剧本
  └→ ① drama-initializer ── 剧本设定 / 剧集表（含完整原文）/ 角色库 / 角色档案
            ├→ ② 角色三视图（吃角色档案+画风）→ generate 出图
            ├→ ③ 核心场景（吃场次列表+画风）→ generate 出图（可并行）
            └→ ④ 逐集 storyboard-prompt（只读 当前集±1集）：
                 读 剧本设定+角色档案+前1集+本集+后1集
                 → 拆分镜 → 依赖场景 → 依赖角色 → 视频提示词
                 → 新增角色/场景先补②③ → generate 配音+视频
```

**关键**：
- 剧本由你上传，初始化时逐集原文完整存入剧集表，不再从大纲自动写分集剧本
- 分镜和视频提示词由同一个技能一次完成
- **拆分镜只读取"当前集 + 前 1 集 + 后 1 集"共 3 集**（`read --table 剧集表 --episode N --context 1`），用于把握角色心境、场景布局和人物调度；禁止一次读入全部剧集，避免上下文膨胀导致输出变差

## 五、5 个确认点（你的活）

**铁律：聊天归聊天，写入归写入。** 你在对话里提意见、否定、讨论，harness 只会改草案；任何对飞书的写入、修改、生成，都会先列出"本次将执行的动作清单"，你回复"确认/写入/执行"后才动手。

| # | 确认什么 | 方式 | 确认后 |
|---|---|---|---|
| 1 | 剧本设定 + 剧集 + 角色档案 | 对话确认 | 建表（方式B）+ 写入四张表 |
| 2 | 角色形象图 | 飞书审核 | 确认/返工 |
| 3 | 核心场景图 | 飞书审核 | 确认/返工 |
| 4 | 分镜与视频提示词（逐集） | 对话确认 | 补资产 + 写分镜表 + 生成 |
| 5 | 视频成片（逐集） | 飞书审核 | 确认/返工 |

- **对话确认**：回复"确认"写入，"修改：意见"只改草案不写入，"重做"重新生成草案
- **飞书审核**：在飞书查看图片/视频，返工的改状态为"返工"并填备注，然后回复"继续"
- **返工重生成也要确认**（要花生成预算）
- **只读操作不要确认**：读取表格、预览提示词展开随时可以

## 六、素材锚定语法（提示词里怎么引用角色/场景）

分镜视频提示词分两层：**锚定段 + 正文**。

**1. 锚定段（CLIP 开头）**：每个引用独占一行，写清"是谁/什么角色/什么场景"，按顺序编号：

```
## [参考素材锚定]
{角色库：张三} 图1：张三，男主角，28岁外卖员，黑色短发、左眉骨伤疤，黑色冲锋衣
{场景库：出租屋} 图2：出租屋，张三住处，筒子楼一居室，室内·夜·雨，冷蓝调
{剧本分镜表：ep01_s01} 视频1：上一镜成片，张三门口动作衔接
```

**2. 正文**：直接用角色名/场景名（如"张三扶住门框""出租屋窗外冷蓝光"），**不再出现 `{}`**；长相服装由参考图控制。

其他可引用素材：

```
{素材库：素材ID}            任意素材（图/视频）
{sheetName:rowId}           通用形式：表名 + 行主键（中英文冒号均可）
```

- CLI 展开时标记移除、映射说明保留，图1/图2/视频1 按编号作为参考图/参考视频随 API 传递
- 只写一个光秃秃的 `{角色库：张三}` 而不说明是谁，不合格；角色/场景必须已在库且素材已生成
- 生成前可用 `python cli.py expand <workspace> --shot ep01_s01` 预览展开结果与素材清单

## 七、CLI 命令速查

| 命令 | 作用 | 是否需确认 |
|---|---|---|
| `python cli.py init-from-url <URL> [路径] --name 剧名` | 绑定已有飞书表格（路径省略用 workspace\剧名） | 否（仅写系统设置引导项） |
| `python cli.py init [路径] --name 剧名` | 从零建表+workspace（路径省略用 workspace\剧名），自动写系统设置 | **是** |
| `python cli.py set-path <路径>` | 迁移目录后更新系统设置中的项目路径 | 否（仅写路径） |
| `python cli.py read <路径> --table 表名` | 读取表数据（JSON） | 否 |
| `python cli.py read <路径> --table 剧集表 --episode 5 --context 1` | 只读第 4/5/6 集（分镜输入，禁止全量读剧集） | 否 |
| `python cli.py write <路径> --table 表名 --data '<JSON>'` | 写入数据（upsert） | **是** |
| `python cli.py generate <路径> --target 角色库:林砚` | 生成指定资产 | **是** |
| `python cli.py generate <路径>` | 批量生成待生成镜头 | **是** |
| `python cli.py generate <路径> --tts-only` | 仅配音 | **是** |
| `python cli.py push <路径>` | 推送到飞书 | **是** |
| `python cli.py pull <路径>` | 从飞书拉取 | 否 |
| `python cli.py expand <路径> [--shot ID]` | 预览提示词展开 | 否 |
| `python cli.py status <路径>` | 查看状态和预算 | 否 |

## 八、核心设计原则

1. **确认后写入**：对话中产生的一切都只是草案，飞书写入/生成必须逐次确认
2. **剧本原文不动**：上传剧本逐集完整进剧集表，只做提取、不做改编
3. **三层拆分**：剧本 → 角色档案（唯一标准源）→ 生成提示词
4. **只补新增**：每集依赖清单比对资产库，新增才补生成
5. **场景两段式**：核心场景提前出 5~8 张定画风；剧情场景随集去重补
6. **画风全局继承**：三视图、场景、视频提示词的画风一律取剧本设定
7. **一致性锚点**：角色三视图是后续所有画面的人脸标准

## 九、角色档案 8 模块

| 模块 | 内容 | 角色档案表字段 | 谁用 |
|---|---|---|---|
| A 基本信息 | 角色名/别名/定位/身份/关系/出场集数 | `basic_info` | 分镜 |

| D 外貌层 | 年龄/脸型/五官/发型/身体/服装/标志特征 | `appearance` | 三视图出图 |

## 十、常见问题

**Q：我在聊天里说"把主角改成 30 岁"，会自动改飞书吗？**
A：不会。harness 只改草案并重新给你看，同时列出将写入的内容，你回复"确认"才写入。

**Q：每一次小修改都要确认吗？**
A：是的。可以在一轮里把多条修改意见一次说完，harness 汇总更新后只确认一次。

**Q：同一场景在好多集出现？**
A：只生成一次，后续集复用（分镜依赖清单去重，初始化时场景名已归一化）。

**Q：想从中间开始？**
A：可以。比如已确认设定，直接说"拆分镜第3集"即可。

**Q：怎么跳过确认？**
A：启动时说"全自动/不用确认"，harness 跳过对话确认（#1 #4），但飞书图片/视频审核（#2 #3 #5）保留，因为图片/视频必须人眼检查。

**Q：上传的剧本不完整怎么办？**
A：只初始化已有的集数，缺失集标"待编写"，不会替你续写。
