# 资产判定细则

## 1. 什么进资产

只收**要出图**的东西：后续分镜会引用、需要跨镜头保持同一外观的。

| 收 | 不收 |
|---|---|
| 有名字/有台词/有明确动作或被指认的人物 | 只在台词里被提一句的人 |
| 本集实际发生的空间（场头地点 + 时间） | 只在回忆里说到的地名 |
| 反复出现、推动剧情、角色会拿起来的道具 | 一次性桌面陈设、背景家具 |
| 会跨镜头保持一致的服装/配饰（校服、婚服、伤疤） | 每场都换的日常衣服 |
| ≥3 个同类无台词个体（群像） | 虚焦背景人群 |
| 有固定形态、需要一致的法术/法相/生物 | 每帧都在变的粒子光效 |

判据一句话：**分镜里会不会写它的名字、会不会拿它做动作、会不会被观众记住**。三条都不占，就不建。

## 2. 场景：合并与拆分

先定"空间"，再定"光影"。

**合并**（同一场景）：
- 同一地点、同一时段、没有实体隔断；
- 开放式厨房与客厅（无门无墙）算同一空间；
- 同一场戏里镜头在屋里来回，不拆。

**拆分**（不同场景）：
- 被实体墙/门隔开：客厅 / 卧室 / 卫生间；
- 光影不同：`出租屋（日）` / `出租屋（夜）` / `出租屋（黄昏）`；
- 闪回、不同年代、明显不同装修；
- 室内外切换（门内 / 走廊）。

**命名**：地点名 + 全角括号光影后缀；**不含 `·`**（会被当分隔符）。名字一旦写进资产库就不再改；要改就是新建一行。

## 3. 角色：归并与分身份

- **别名归一**：`诚诚`、`哥哥`、`林女士` 指同一人时归到主名；别名写进档案 `basic_info`。
- **同一人不同形态**：年龄（`陈诚` / `陈诚 12岁`）、变身、重病妆、婚服，外观差到需要另一张图时才拆；拆了就是两个资产，提示词各自写。
- **不出现的不建**：只被提到、没有出镜的角色，不进资产库（台词需要声音时由 `角色档案` 的音色负责，不需要图）。
- **群像**：≥3 个同类、无个体台词、只需要一个整体外观（迎亲队、保镖、围观人群）→ 一行群像，`char_type=群像`，提示词写人数、服色、队形。

## 4. 道具：收与不收

**收**：
- 反复出现（行李箱、手机、水杯）；
- 推动剧情（生日蛋糕、母亲的遗物、合同）；
- 角色会拿起来做动作（钥匙、刀、外卖袋）；
- 需要外观一致才能连戏（伤疤、纹身、特定包装）。

**不收**：
- 背景家具、墙面挂画、一次性餐具；
- 每场都在但没人碰的杂物；
- 只写"一个杯子"、没有任何特征、也不会再出现的。

**写法**：尺寸 + 材质 + 颜色 + 使用痕迹（`24 寸黑色硬壳，拉杆拉出三十厘米，箱角磨损`）。同类只建一个（所有手机 = `手机`），除非外观明确不同（`沈幼怡的手机` / `陈诚的手机` 屏幕内容不同时才拆）。

## 5. 服装 / 配饰

默认不单独建资产——服装写在角色描述里。只有下面情况才单独建：
- 服装是剧情道具（婚纱、校服、囚服）；
- 同一角色在本集换装且两套都要出图；
- 服装有标志性细节（刺绣、破洞、血迹）需要跨镜头一致。

## 6. 用小说补细节的边界

| 可以 | 不可以 |
|---|---|
| 补房间布局、材质、颜色、固定陈设 | 新增剧本里没有的场景/角色/道具 |
| 补角色长相、发型、服装、体态 | 改剧本里的身份、关系、年龄、场次归属 |
| 补道具的外观、尺寸、磨损 | 把比喻、情绪、心理写成画面 |
| 补光线、天气、气味转成的可见氛围 | 把人物动作、剧情写进场景图 |

冲突时**以剧本为准**（场景名、时间、谁在场、做了什么），小说只补"长什么样"。两边都没写 → `未指定`，列进 `missing`，不猜。

## 7. 复用与改名

| 情况 | 动作 |
|---|---|
| 同名 + 已出图 | 复用，`status=复用`，描述不动 |
| 同名 + 未出图 | 补齐描述，`status=新建` |
| 同名但要换光线/陈设 | 新建带后缀的名字，旧资产保留 |
| 名字不同但确认是同一物 | 合并到库里的名字，在说明里写"原名 X 并入 Y" |
| 拿不准 | 列"待确认"，不擅自合并 |

## 8. 未指定怎么写

- 缺失项写 `未指定`，并在 `missing` 里给出"缺什么、影响哪张图、建议怎么补"。
- 不要用"大概是""应该是"填空；不要为了凑满描述编造细节。
