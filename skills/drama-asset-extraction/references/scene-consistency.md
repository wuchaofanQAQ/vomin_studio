# 出图后场景一致性检查（门禁）

场景图出图后、进入分镜视频生成前逐张比对。**任一条不过，先修图，不得往下生成。**

## 一、什么时候检查

- 每张场景图出图后，对照该场景的**描述**逐条比对；
- 重抽或局部重绘后**重新比对**，不沿用上次结论；
- 同一空间的光影变体（`出租屋（日）` / `出租屋（夜）`）互相比对共享元素。

## 二、硬指标

| 检查项 | 通过标准 | 不通过处理 |
|---|---|---|
| 入口位置与开门方向 | 与描述一致 | 重抽，不将就 |
| 地面材质与分界 | 材质、颜色、分界线一致 | 重抽或局部重绘 |
| 功能区与门窗方位 | 左右/前后不反转 | 重抽 |
| 光源方向 | 主光方向与描述一致 | 改描述重抽 |
| 色调 | 同一时空统一 | 调色或重抽 |
| 共享元素 | 跨场景的门/窗/五金外观一致 | 改描述重抽 |
| 无人无字 | 无人物、无文字、无水印 | 重抽 |

## 三、报告格式

| 场景 | 对照 | 入口 | 地面 | 功能区/门窗 | 光源 | 色调 | 共享元素 | 结论 |
|---|---|---|---|---|---|---|---|---|
| 出租屋（夜） | 描述 | ✓ | ✓ | ✓ | ✓ | ✓ | — | 通过 |
| 出租屋（日） | 描述 + 夜版 | ✓ | ✗ 地面分界缺失 | ✓ | ✓ | ✓ | ✓ | **不通过：重抽** |

## 四、不通过怎么办

1. 写明哪一条、哪个场景、差在哪；
2. 先改描述：把没遵守的部分写得更具体（比如"玄关与客厅同铺浅木地板，无分界"）；
3. 重抽（`generate` 花预算，先列清单确认）；
4. 重抽后**重新比对**，不沿用上次结论；
5. 修图期间，依赖这些场景的分镜不得生成视频。

## 五、结果回写

| 结果 | `出图状态` | `一致性检查` |
|---|---|---|
| 全过 | `已通过` | `通过` |
| 任一不过 | `需重抽` | `不通过` |
| 未查 | `已出图` | `未检查` |
