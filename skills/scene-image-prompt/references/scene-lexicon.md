# 场景类型/氛围词表 + 三层景深写法

## 场景类型 → 画风词

| 场景类型 | 画风词（追加） |
|---|---|
| 现代都市 / 办公楼 / 街道 | 电影级写实，自然光影，真实材质 |
| 古代宫殿 / 庭院 / 市集 | 写实古风，考究古建细节，柔和光影 |
| 仙侠洞府 / 云雾山峦 | 半写实仙侠风，云雾缭绕，灵光点缀 |
| 科幻都市 / 舱内 / 实验室 | 赛博朋克/科幻风，霓虹光效，金属质感 |
| 废墟 / 战场 / 荒原 | 冷硬写实，荒凉氛围，高对比光影 |
| 温馨居室 / 咖啡厅 | 清新明亮写实，柔和暖光，通透感 |

## 三层景深写法

每层给出具体内容，避免空泛：

- **前景**：贴近镜头的物件（散落道具/花草/柱栏/积水…）
- **中景**：场景主体（建筑/机器/人物活动区/主景观）
- **背景**：远景氛围（天空/远景建筑/雾/光晕）

固定句式：
> 画面分为清晰的前景、中景、背景三层景深：前景是__，中景主体是__，背景是__，层次分明。

## 构图规则（全局）

- **16:9 横版**
- **主体占画面约 3/4**，留约 1/4 空旷空间（为角色叠加留位）
- 留空位置说明方向（右侧/上方/中央），避免 AI 无处安放
- **纯空镜无人物**，无文字水印
