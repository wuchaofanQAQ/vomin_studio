## 九宫格机位词表（固定 ①~⑨，必须全部使用；每机位必须双锚点）

符号约定：**P0** = 摄影主轴站位端锚点（通常主入口/门洞），**P1** = 主轴朝向端锚点（主背景墙/主窗），**M** = 主体锚点；"左/右"一律以"站 P0、面朝 P1"为基准。

| # | 机位 | 站位锚点（摄影机位置，必须紧靠已锁定实体） | 朝向锚点（光轴对准的已锁定实体） | 高度/焦段 |
|---|---|---|---|---|
| ① | 全局高位俯视 | 空间几何中心正上方（M 正上方、略偏 P0） | 垂直向下并向 P1 倾斜，覆盖 P0—P1 全轴与各区域 | 45°—65° 俯角 / 24mm wide |
| ② | 正面广角主视角 | 紧靠 P0 朝室内一侧的边缘 | 沿主轴对准 P1，M 居中；前景 P0 边界、中景 M、背景 P1 | 约1.5m / 24—28mm |
| ③ | 左前方 45° 视角 | P0 端主轴左手侧区域内，紧靠该区域锚点物件的具体一侧 | M 靠 P0 一端的左前角，向 P1 延伸；前景左手侧锚点、中景 M、背景 P1 | 约1.5m / 28mm |
| ④ | 右前方 45° 视角 | P0 端主轴右手侧区域内，紧靠该区域锚点物件的具体一侧 | M 靠 P0 一端的右前角，向 P1 延伸；前景右手侧锚点、中景 M、背景 P1 | 约1.5m / 28mm |
| ⑤ | 核心电影主机位 | M 靠 P0 一侧的具体锚点（如 M 前茶几边缘/过道） | M 正面中心，背景 P1；前景 M 前方最近锚点、中景 M | 1.4—1.6m / 28—35mm cinematic |
| ⑥ | 反打视角 | M 与 P1 之间、紧靠 M 背面（≈⑤的朝向锚点） | 机位⑤的站位锚点（朝 P0）；前景 M 背面、中景中间锚点、背景 P0 | 约1.5m / 35mm |
| ⑦ | 场景内部向外视角 | 最深处功能区内部的具体锚点（台面内侧/吊柜下/门框内） | M 与 P0 方向；前景功能区构件、中景过渡锚点、背景 M 与 P0 | 功能区高度 / 28mm foreground framing |
| ⑧ | 侧面横向空间视角 | 一侧墙的具体锚点（门/窗/墙角旁） | 光轴垂直主轴，对准对面侧墙的具体锚点；沿光轴排列各锚点 | 约1.5m / 35mm |
| ⑨ | 低机位/特殊高度 | 与⑤同站位锚点，或另行明确写出的锚点（禁止悬空） | M 正面与 P1；前景低位锚点、中景 M、背景 P1 | 0.8—1m / 35mm |

> 表中每个锚点在产出时必须替换为 `<SPACE MAP>` 中已命名的真实实体（如"紧靠原木餐桌靠 P0 一侧的桌角"），P0/P1/M 只是占位符，不允许直接出现在最终提示词里。

## 同一空间锁定写法（<LOCK> 必写要素）

- **同一空间、同一套建筑结构、同一套家具/道具、同一时间、同一光线条件**，摄影机移动、环境不变。
- **所有锁定关系不允许改变**：空间结构、家具摆放位置、门窗位置与朝向、墙面地面材质、家具材质、色调、光源方向与色温。
- 九个面板之间禁止物品移动、增减、换位、变形或改色。

固定句式：
> 本场景板为同一个真实空间的九个机位拍摄，不是九个不同场景，也不是九种重新设计……摄影机可以移动，环境不允许改变；所有锁定关系不允许改变……

## 空间锚点写法（<SPACE MAP>，必须极致细节）

0. **摄影主轴（最先写，全部方位的唯一参照系）**：用三个已锁定实体定义——站位端锚点 P0（通常主入口/门洞）、朝向端锚点 P1（主背景墙/主窗）、主体锚点 M；并写明 P0 左手侧、右手侧各是什么区域与锚点。没有主轴，"左/右/前/后"全部不成立。
1. **核心空间锚点**：A 区域 / B 区域 / C 区域分别是什么；按主轴基准写明左侧/右侧/前方/后方/中央分别有什么固定物体。
2. **物品与区域位置关系**：**逐项列出画面出现的每一个物件**（沙发、餐桌、入户门、窗户、柜体、床、书桌、厨房台面、走廊门、灯、装饰物等），写清彼此相对位置与参照物（如"布艺沙发位于客厅中央偏右、正对电视墙"）。**一个物件都不能漏**。
3. **门/窗朝向清单**：每个门写明位置+开向（朝内/朝外、铰链侧），每扇窗写明位置+朝向（朝哪个方向、对应哪面墙）。
4. **光源位置清单**：光源数量、每个光源的位置/类型（自然光/人造光）/色温/照射方向/对哪些物件形成高光与阴影。

固定句式：
> 摄影主轴（全部方位的唯一参照系）：从站位端锚点 P0__，朝向朝向端锚点 P1__，主体锚点 M 为__；所有"左/右/前/后"以摄影机站在 P0、面朝 P1 为基准：P0 左手侧为__，右手侧为__。
> 核心空间锚点：A 区域为__，B 区域为__，C 区域为__。左侧__，右侧__，前方__，后方__，中央__。
> 物品与区域位置关系：- __：位于__、__。
> 门/窗朝向清单：- __门：__位置、__开向；- __窗：__位置、__朝向。
> 光源位置清单：- __（主光源）：__位置、__类型、__色温、__照射方向、对__形成高光/阴影。

## 机位双锚点写法（<PANELS>，每个机位缺一不可）

每个机位按同一公式写：

> **编号+机位名：摄影机站在【站位区域】、【站位锚点：紧靠/背靠/位于哪个已锁定实体的哪个位置】，高度 X 米；镜头朝向【朝向区域】、【朝向锚点：光轴对准哪个已锁定实体】；前景为【锚点】、中景为【锚点】、背景为【锚点】。焦段。**

硬性规则：

1. **禁止裸方位词**："左前方/右前方/左侧/右侧/深处/正面/对面"不得单独出现，必须绑定 `<SPACE MAP>` 已命名的区域与实体锚点；"左/右"一律以主轴（站 P0 面朝 P1）为基准。
2. **锚点必须来自 `<SPACE MAP>`**：站位锚点与朝向锚点都必须是已锁定的家具、门、窗、墙面、台面、过道、墙角等实体；空间中找不到现成锚点时，先在 `<SPACE MAP>` 补入该实体（如墙角、立柱、过道），再写机位，禁止临时编造。
3. **三层画面锚点**：每机位写清前景/中景/背景各是什么锚点，使画面内容可被空间地图逐项验证。
4. **对称关系用锚点表达**：⑥ 反打 ⑤ → ⑥ 的站位锚点 ≈ ⑤ 的朝向锚点、⑥ 的朝向锚点 = ⑤ 的站位锚点；③ 与 ④ 分居 P0 端主轴左右两侧；⑧ 的光轴与主轴垂直，两端锚点都要写明。
5. 严禁出现"移动到场景左前方""放置在场景最深处""位于场景左侧"这类无法定位的句子——看到即判定为错误，必须改写为双锚点句式。

## 完全对应校验（必执行）

- 提示词产出后，将 `<SPACE MAP>` 每一项（**摄影主轴 P0/P1/M**、每个物件位置/门开向/窗朝向/光源位置）**逐项回查**九个机位描述与质量约束。
- **逐机位回查双锚点**：每个机位是否都写全了"站位区域 + 站位锚点 → 朝向区域 + 朝向锚点 + 前景/中景/背景"；锚点是否都能在 `<SPACE MAP>` 中找到；机位间对称关系（⑤/⑥ 反打、③/④ 对称、⑧ 垂直主轴）是否成立。
- 任一物件或机位在提示词中缺失、含糊（只写"可见沙发"未写位置关系、只写"左前方"未给锚点）、或各面板描述相互矛盾 → **该提示词即为错误**，必须修正后重新输出。
- 输出说明中附一句校验声明：如"已逐项核对：沙发/餐桌/入户门/窗/光源位置与锁定清单完全对应；九个机位的站位锚点与朝向锚点均取自 SPACE MAP、无悬空方位词、无矛盾"。

## 构图规则（全局）

- **16:9 横版，3×3 九宫格**（3 行 3 列九个面板），白色间隙分隔，无重叠无裁切。
- 每个面板内**主体占约 3/4**，留约 1/4 空旷空间（为角色叠加留位）。
- **纯空镜无人物**，无文字水印。
- 九面板光影方向一致、色温一致、材质一致（同一空间同一光线条件的机位变换）。
