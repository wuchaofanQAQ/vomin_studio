# 场景类型与氛围词表

## 场景类型 → 画风词

| 场景类型 | 画风词（追加） |
|---|---|
| 现代都市 / 办公楼 / 街道 | 电影级写实，自然光影，真实材质 |
| 现代居室 / 客厅 / 玄关 / 厨房 | 现代简约家装，干净明亮，原木/暖白/布艺质感，柔和自然光 |
| 古代宫殿 / 庭院 / 市集 | 写实古风，考究古建细节，柔和光影 |
| 仙侠洞府 / 云雾山峦 | 半写实仙侠风，云雾缭绕，灵光点缀 |
| 科幻都市 / 舱内 / 实验室 | 赛博朋克/科幻风，霓虹光效，金属质感 |
| 废墟 / 战场 / 荒原 | 冷硬写实，荒凉氛围，高对比光影 |
| 温馨居室 / 咖啡厅 | 清新明亮写实，柔和暖光，通透感 |

画风以剧本设定为准。场景空镜写全画面清晰，不写浅景深。

## 四个视角

**P0** = 站位端（通常是门洞），**P1** = 朝向端（通常是主窗或主背景墙），**M** = 主体。家具位置用北/南/东/西写进 `<SPACE MAP>`，四个视角共用这一份。

| 视角 | 机位 |
|---|---|
| 正视图 | 站在 P0 旁，面朝 P1，高度约 1.5 米，24–28mm。画面左侧是面朝 P1 时的左手侧墙。 |
| 反打图 | 站在 M 与 P1 之间的主轴上，面朝 P0，高度约 1.5 米，28–35mm。画面左侧是面朝 P1 时的右手侧墙，画面右侧是当时的左手侧墙。镜头后方不入画。消失点是 P0。 |
| 45°俯视 | 在 M 上方略偏 P0，向 P1 俯约 45°，24mm。 |
| 90°垂直俯视 | 楼板拆掉后的户型图。镜头在 M 正上方，垂直 90° 向下，24mm。天花不入画，墙只是平面边界，家具是俯视轮廓。画面上缘是 P1，下缘是 P0，左缘是面朝 P1 时的左手侧墙。 |
