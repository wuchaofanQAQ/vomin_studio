# 场景类型与氛围词表

## 场景类型 → 画风词

| 场景类型 | 画风词（追加） |
|---|---|
| 现代都市 / 办公楼 / 街道 | 电影级写实，自然光影，真实材质 |
| 现代居室 / 客厅 / 玄关 / 厨房 | 现代简约家装，干净明亮，原木/暖白/布艺质感，柔和自然光 |
| 古代宫殿 / 庭院 / 市集 | 写实古风，考究古建细节，柔和光影 |
| 仙侠洞府 / 云雾山峦 | 半写实仙侠风，云雾缭绕，灵光点缀 |
| 科幻都市 / 舱内 / 实验室 | 赛博朋克/科幻风，霓虹光效，金属质感 |
| 废墟 / 战场 / 荒原 | 冷硬写实，荒凉氛围，高对比光影 |
| 温馨居室 / 咖啡厅 | 清新明亮写实，柔和暖光，通透感 |

画风以剧本设定为准。场景空镜写全画面清晰，不写浅景深。

## 全景基准图机位

**P0** = 站位端（通常是门洞），**P1** = 朝向端（通常是主窗或主背景墙），**M** = 主体。家具位置用北/南/东/西写进 `<SPACE MAP>`。

**当前模式（懒加载·单基准图）**：每个场景默认只生成一张**全景基准图**，不生成其他视角图。机位按以下标准（即 drama-episode-analyzer 写入 `description` 的【基准图机位】）：

| 场景类型 | 全景基准图机位 |
|---|---|
| 室内（客厅/卧室/书房/病房/办公室等，占 90%） | 机位高 **1.5 米**平视（不仰不俯）；**45° 斜角**，站在房间一个角落外侧看向对角（画面同时纳入该角相邻两面墙与核心陈设）；**35mm** 小广角 |
| 室外常规（街道/别墅大门/停车场/医院门口） | 平视，45° 斜侧，35mm，略微拉开距离拍到主体建筑 + 周边环境 |
| 室外狭长（走廊/地下通道） | 可偏 **30°**，不正对通道深处（避免隧道视觉） |
| 特殊固定机位（监控视角/固定窗边） | 单独改相机；其余一律用默认标准 |

> 下方「正视图 / 反打图 / 45°俯视 / 90°垂直俯视」为遗留多视角机位表，**当前不使用**，仅保留供参考。
