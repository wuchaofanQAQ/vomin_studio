# 场景提示词组装蓝图（单视角版）

用于豆包 seedream 文生图，单条中文 prompt，每条提示词对应**一个视角一张图**。按固定段落顺序组装，段落间以换行分隔，标签区块结构（标签名保持英文字母，内容使用中文）。

---

## 标签区块结构

整条提示词由 6 个标签区块组成，按固定顺序排列：

```
<HEADER>
单视角场景声明（场景名+视角类型+画面规格）
</HEADER>

<STYLE LOCK>
从剧本设定画面风格提取的画风锁定（中文）
</STYLE LOCK>

<LOCK>
空间一致性总锁定（必写，见下）
</LOCK>

<SPACE MAP>
空间锚点 + 物品/区域位置关系 + 门/窗朝向 + 光源位置（必写，见下）
</SPACE MAP>

<CAMERA>
单个摄影机位描述（必写，见下）
</CAMERA>

<QUALITY>
纯空镜无人物 + 质量约束（必写，见下）
</QUALITY>
```

---

## 1. `<HEADER>` — 开头声明

声明本图的画面规格、场景名称和视角类型。**每个视角的 HEADER 不同**：

**正视图：**
```
<HEADER>
16:9横版单视角场景空镜图，{场景名}正面全景，纯空间无角色。
</HEADER>
```

**反打图：**
```
<HEADER>
16:9横版单视角场景空镜图，{场景名}反打回望全景，纯空间无角色。参考 {场景库：场景名·正视图（默认）}。参考图只提供已入画家具的外形、材质和颜色。消失点是 P0。P0 另一侧母版没拍到的空间按文字生成。
</HEADER>
```

**45°俯视斜角：**
```
<HEADER>
16:9横版单视角场景空镜图，{场景名}45°俯视斜角全景，纯空间无角色。参考 {场景库：场景名·正视图（默认）} 为场景母版，保持完全一致的空间结构与物件。
</HEADER>
```

**90°垂直俯视：**
```
<HEADER>
16:9横版单视角场景空镜图，{场景名}户型图，楼板拆掉后的垂直俯视，纯空间无角色。参考三张同一场景不同角度图为场景母版。
</HEADER>
```

## 2. `<STYLE LOCK>` — 统一风格锁定

从剧本设定的画面风格字段读取（或按场景类型从 `scene-lexicon.md` 词表选择），翻译为中文后填入，锁定全场景统一画风。**所有视角共享同一段 STYLE LOCK**。示例：

```
<STYLE LOCK>
现代都市风格（韩式真人影视剧质感）：场景干净明亮现代，真人影视剧质感，全画面清晰，墙体门窗与家具边界可读，禁止浅景深背景虚化，空间比例真实，材质精致真实（暖白墙面原木地板原木家具布艺），现代简约家装与城市建筑质感，自然光与柔和布光，轻微胶片颗粒不过度锐化，色彩明快通透低饱和暖调，拒绝破旧斑驳锈蚀脏乱年代感；现代都市生活剧，夏末暖色温馨日常基调，清新明亮，不要暗黑或赛博朋克风。
</STYLE LOCK>
```

## 3. `<LOCK>` — 空间一致

**正视图：**

```
<LOCK>
同一个空间、同一套家具、同一时间、同一光线。
本图确立已入画家具的外形、材质与位置。没拍到的区域以 SPACE MAP 文字为准。
</LOCK>
```

**反打、45°、90°：**

```
<LOCK>
同一个空间、同一套家具、同一时间、同一光线，仅摄影机位置不同。
已入画家具的外形、材质、位置与母版一致。母版没拍到的区域以 SPACE MAP 文字为准。
</LOCK>
```

## 4. `<SPACE MAP>` — 空间锚点 + 物品/区域位置关系 + 门/窗朝向 + 光源位置（★ 必写，必须极致细节）

各视角共用场景库 `description`，直接作为 `<SPACE MAP>`，不改写方位。不写"摄影机身后""画面左侧"。

写法：
1. **主轴**：P0、P1、M，以及面朝 P1 时的左手侧墙、右手侧墙。这是墙的固定称呼，不是画面左右。
2. **分区**：A/B/C 区各在哪面墙。
3. **物件**：逐个写位置。正视图看不到、反打才露出的空间标注"正视图不入画"。
4. **门窗**：位置和开向。
5. **光源**：位置、自然光或灯、色温、照射方向（用北/南）。

固定写法模板：

```
<SPACE MAP>
摄影主轴（世界坐标，不随当前机位改变）：站位端锚点 P0 为【如北侧客厅门洞】，朝向端锚点 P1 为【如南墙客厅大窗】，主体锚点 M 为【如布艺沙发与矮茶几】。轴线从 P0 指向 P1。站在 P0、面朝 P1 时，左手侧墙为【西墙 + 区域 + 锚点】，右手侧墙为【东墙 + 区域 + 锚点】。

核心空间锚点：A 区域【如东墙厨房区】，B 区域【如西墙餐厅区】，C 区域【如中轴偏南的客厅区】。P0 以北【固定物体】，P1 以南【固定物体】，中轴【主要家具】。

物品与区域位置关系（逐一列出画面中的每个物件）：
- 【物品1，如布艺沙发】：位于【区域/方位】、【相对参照物关系】
- 【物品2，如原木餐桌】：位于【区域/方位】、【相对参照物关系】
- 【物品3，如入户门】：位于【区域/方位】、【门扇朝向：朝内/朝外、铰链侧】
- 【物品4，如客厅大窗】：位于【区域/方位】、【窗户朝向：朝哪个方向、对应哪面墙】
- 【物品5…】：逐项列出画面中出现的所有物品/区域（含灯、装饰物等，不遗漏）

门/窗朝向清单：
- 【门1，如入户门】：【位置】+【朝向/开向】
- 【窗1，如客厅窗】：【位置】+【朝向】
- 【门2/窗2…】：逐项列出

光源位置清单：
- 【光源1，如客厅大窗】：【位置】+【类型：自然光】+【色温：傍晚暖光】+【照射方向】+【对哪些物件形成高光/阴影】
- 【光源2，如吊灯】：【位置】+【类型：人造光】+【色温】+【照射范围】
- 【光源3…】：逐项列出画面中出现的所有光源
</SPACE MAP>
```

写完后核对物件、门窗、光源与 description 一致，并和 `<CAMERA>` 不矛盾。镜头后方的物件只留在 `<SPACE MAP>`，不写进画面左右。

## 5. `<CAMERA>` — 一个机位

一条提示词只写一个机位。画面左侧、画面右侧必须带墙名和物件。站位和朝向用 `<SPACE MAP>` 里已有的门、窗、墙、家具。

**正视图：**

```
<CAMERA>
正面全景：摄影机站在 P0【门洞】旁、朝向 P1 的一侧，高度约1.5米，面朝 P1【主窗】，光轴对准 M。P0 在镜头后方，不入画。
前景：【靠近镜头的地面或家具】；
中景：【M】；
背景：【P1】。
画面左侧是面朝 P1 时的左手侧墙【墙名 + 物件】；画面右侧是右手侧墙【墙名 + 物件】。
24—28mm lens。
</CAMERA>
```

**反打图：**

```
<CAMERA>
反打回望：摄影机站在 M 与 P1 之间的主轴上，高度约1.5米，面朝 P0。P1 和镜头后方的物件不入画。
画面左侧是面朝 P1 时的右手侧墙【墙名】，从 P1 到 P0 为【物件】。
画面右侧是面朝 P1 时的左手侧墙【墙名】，从 P1 到 P0 为【物件】。
前景：【M】；中景：【M 与 P0 之间】；背景：【P0】。
P0 另一侧母版没拍到的空间按文字生成。消失点是 P0，不出现 P1 的窗景。
28—35mm lens。
</CAMERA>
```

**45°俯视斜角：**

```
<CAMERA>
45°俯视斜角全景：摄影机位于空间几何中心上方（M 正上方、略向 P0 偏移），镜头向 P1 方向倾斜约 45°，光轴覆盖主轴两侧全部区域。
画面中 P0 在下缘、P1 在上缘，各区域与锚点的平面位置关系清晰可辨。
要看到地面/桌面的平面分布与走道动线。
24mm wide angle，architectural overview。
</CAMERA>
```

**90°垂直俯视：**

```
<CAMERA>
户型图：镜头在 M 正上方，垂直 90° 向下。楼板和天花已拆掉，不入画。墙体只作为平面边界，家具是俯视轮廓，能看清地面上的位置和走道。
画面上缘是 P1，下缘是 P0。左缘是面朝 P1 时的左手侧墙，右缘是右手侧墙。
24mm，top-down floor plan。
</CAMERA>
```

## 6. `<QUALITY>` — 纯空镜 + 质量约束

```
<QUALITY>
纯空镜场景，画面无任何人物，无文字，无水印，无标注线框；16:9横版单图；全画面清晰，墙体、门窗与家具边界可读，禁止浅景深背景虚化；光影方向与色温与 SPACE MAP 锁定一致；场景主体占画面约四分之三，留出约四分之一空旷空间（为角色叠加留位）；高清，细节丰富，透视准确，禁止夸张透视、禁止鱼眼畸变。
</QUALITY>
```

## 修正规则

- 用户改某要素 → 只替换对应段落（`<STYLE LOCK>` / `<SPACE MAP>` / `<CAMERA>`），重新输出整条 prompt。
- 若需要画面带文字（如招牌、海报）→ 在空间锚点段用中文引号标注文字内容，如"招牌上写着"某某公司""。
- 一旦摄影主轴（P0/P1/M）或任何锚点物件发生增删、移位 → 必须连带重写 `<CAMERA>` 中引用该锚点的站位/朝向描述，并重做完全对应校验，禁止只改 `<SPACE MAP>` 不改 `<CAMERA>`。
- 画面左侧、画面右侧必须带墙名和物件。反打面朝 P0 时，左侧是面朝 P1 时的右手侧墙，右侧是当时的左手侧墙。
