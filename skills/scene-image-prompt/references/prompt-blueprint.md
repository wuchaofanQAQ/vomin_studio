# 场景提示词组装蓝图

用于豆包 seedream 文生图，单条中文 prompt。按固定段落顺序组装，段落间以逗号/分号衔接，不出现"段落标题"。

## 组装顺序

1. **场景类型段** — 室内/室外、具体地点
2. **主体物段** — 场景中心主体（建筑/山/街道/装置…）
3. **时代风格段** — 从剧本设定继承的画风
4. **环境氛围段** — 光线（日/夜/黄昏）、天气、色调
5. **三层景深段** — 明确前/中/背景（★ 核心）
6. **构图规格段** — 16:9 横版、主体占 3/4、留 1/4
7. **质量约束段** — 纯空镜无角色、无文字、高清

## 关键句式（必须包含）

三层景深 + 构图（固定写法）：

> 画面分为清晰的前景、中景、背景三层景深：前景是__，中景主体是__，背景是__，层次分明。场景主体占画面约四分之三，右侧/上方留出约四分之一空旷空间，无人物。

无角色约束（固定写法）：

> 纯空镜场景，画面中没有任何人物，无文字，无水印。

## 完整示例

输入场景描述：
> 《暗夜追缉》第3集雨夜追捕场景，废弃厂房，冷调。

产出的 seedream 提示词：

> 废弃厂房内部，锈蚀的钢梁与倒塌的机器残骸为主体物，破败工业风，冷蓝色调，雨夜光线昏暗，地面积水反光。画面分为清晰的前景、中景、背景三层景深：前景是散落的锈铁管与积水，中景主体是矗立的钢梁与废弃机床，背景是远处漏光的破损墙洞，层次分明。场景主体占画面约四分之三，右侧留出约四分之一空旷空间，无人物。电影级写实，冷硬光影，16:9 横版构图，纯空镜场景，画面中没有任何人物，无文字，无水印，高清，细节丰富。

## 修正规则

- 用户改某要素 → 只替换对应段落，重出整条 prompt。
- 若需要画面带文字（如招牌、海报）→ 在主体物段用中文引号标注文字内容，如"招牌上写着"某某公司""。
