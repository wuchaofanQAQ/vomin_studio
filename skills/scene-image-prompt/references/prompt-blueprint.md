# 场景提示词组装蓝图（3×3 九宫格版）

用于豆包 seedream 文生图，单条中文 prompt。按固定段落顺序组装，段落间以换行分隔，标签区块结构（标签名保持英文字母，内容使用中文）。

---

## 标签区块结构

整条提示词由 5 个标签区块组成，按固定顺序排列：

```
<HEADER>
16:9横版3×3九宫格多机位场景板设定图，白色间隙间隔，3行3列九个面板，每面板为同一场景空间从不同固定机位拍摄的视角；面板之间以清晰白色间隙分隔，无重叠、无裁切。
</HEADER>

<STYLE LOCK>
从剧本设定画面风格提取的画风锁定（中文）
</STYLE LOCK>

<LOCK>
同一空间总锁定（必写，见下）
</LOCK>

<SPACE MAP>
空间锚点 + 物品/区域位置关系 + 门/窗朝向（必写，见下）
</SPACE MAP>

<PANELS>
九个固定机位逐一描述（必写，见下）
</PANELS>

<QUALITY>
纯空镜无人物 + 质量约束（必写，见下）
</QUALITY>
```

---

## 1. `<HEADER>` — 开头声明

固定内容，不需要改动：

```
<HEADER>
16:9横版3×3九宫格多机位场景板设定图，白色间隙间隔，3行3列九个面板，每面板为同一场景空间从不同固定机位拍摄的视角；面板之间以清晰白色间隙分隔，无重叠、无裁切。
</HEADER>
```

## 2. `<STYLE LOCK>` — 统一风格锁定

从剧本设定的画面风格字段读取（或按场景类型从 `scene-lexicon.md` 词表选择），翻译为中文后填入，锁定全场景统一画风。示例：

```
<STYLE LOCK>
现代都市风格（韩式真人影视剧质感）：场景干净明亮现代，真人影视剧质感，浅景深背景虚化，空间比例真实，材质精致真实（暖白墙面原木地板原木家具布艺），现代简约家装与城市建筑质感，自然光与柔和布光，轻微胶片颗粒不过度锐化，色彩明快通透低饱和暖调，拒绝破旧斑驳锈蚀脏乱年代感；现代都市生活剧，夏末暖色温馨日常基调，清新明亮，不要暗黑或赛博朋克风。
</STYLE LOCK>
```

## 3. `<LOCK>` — 同一空间总锁定（★ 核心纪律，必须逐字保留）

这不是九个不同场景，也不是九种重新设计，而是**同一个空间、同一套建筑结构、同一套家具/道具、同一时间、同一光线条件**，由摄影机移动到九个不同位置进行拍摄。**摄影机可以移动，环境不允许改变；所有锁定关系不允许改变**（空间结构、家具摆放、门窗朝向、材质、色调、光源全部锁定）。

固定写法（必写）：

```
<LOCK>
本场景板为同一个真实空间的九个机位拍摄，不是九个不同场景，也不是九种重新设计：
同一个空间、同一套建筑结构、同一套家具与道具、同一时间、同一光线条件，由摄影机移动到九个不同固定位置进行拍摄。
摄影机可以移动，环境不允许改变；所有锁定关系不允许改变：空间结构、家具摆放位置、门窗位置与朝向、墙面地面材质、家具材质、色调、光源方向与色温全部锁定，九个面板之间禁止任何物品移动、增减、换位、变形或改色。
</LOCK>
```

## 4. `<SPACE MAP>` — 空间锚点 + 物品/区域位置关系 + 门/窗朝向 + 光源位置（★ 必写，必须极致细节）

**作用**：让 AI 明确"这是一套建筑里的同一空间"，九个面板共享同一张空间地图。**锚点关系必须做到非常细节：画面中出现的每一个物件都要写入对应关系，且提示词产出的空间关系必须与锁定关系完全对应——缺一项、含糊一项、或与其他面板矛盾一项，该提示词即为错误。**

写法：
1. **摄影主轴（★最先写，全部方位的唯一参照系）**：用三个已锁定实体定义一条有方向的轴线——站位端锚点 **P0**（摄影机起点，通常为主入口/门洞）、朝向端锚点 **P1**（主背景，通常为主背景墙/主窗）、主体锚点 **M**（场景中心主体）。明确写出："摄影主轴为从【P0】朝向【P1】，主体锚点 M 为【M】；本提示词所有'正面/左侧/右侧/前方/后方'均以摄影机站在 P0、面朝 P1 为基准；P0 左手侧为【区域+锚点】、右手侧为【区域+锚点】。" 没有主轴，后续任何方位词与机位描述都不成立。
2. **核心空间锚点**：A 区域 / B 区域 / C 区域分别是什么；按主轴基准写明左侧/右侧/前方/后方/中央分别有什么固定物体
3. **所有画面出现的物品与区域的对应位置关系**：**逐个列出画面中出现的每一个物件**（沙发、餐桌、入户门、窗户、柜体、床、书桌、厨房台面、卫生间、走廊门、灯、装饰物等），写明它们彼此的相对位置与参照物（如"布艺沙发位于客厅中央偏右、正对电视墙；原木餐桌紧邻厨房台面、位于沙发左侧；入户门在玄关尽头右侧，门扇朝内开"）
4. **每个门的朝向、每扇窗的朝向**：逐一写明（如"入户门朝内开，门扇在右侧铰链；客厅大窗朝向东南，位于沙发正对面的墙面"）
5. **光源位置（★必写）**：光源数量、每个光源的位置（在哪个区域/哪个墙面/哪个方向）、光源类型（自然光/灯）、色温（暖/冷）、照射方向、对哪些主要物件形成高光/阴影

固定写法模板：

```
<SPACE MAP>
摄影主轴（全部方位的唯一参照系）：从站位端锚点 P0【如客厅门洞】朝向朝向端锚点 P1【如南墙客厅大窗】，主体锚点 M 为【如布艺沙发与矮茶几】；本提示词所有"正面/左侧/右侧/前方/后方"均以摄影机站在 P0、面朝 P1 为基准：P0 左手侧为【区域+锚点，如B区餐桌与原木餐桌】，P0 右手侧为【区域+锚点，如A区开放式厨房台面】。

核心空间锚点：A 区域【如厨房区】，B 区域【如餐厅区】，C 区域【如客厅区】。左侧【固定物体/建筑】，右侧【固定物体/窗户】，前方【固定物体】，后方【固定物体】，中央【主要家具/装置】。

物品与区域位置关系（必须全部一致出现于九宫格各面板，逐一列出画面中的每个物件）：
- 【物品1，如布艺沙发】：位于【区域/方位】、【相对参照物关系】
- 【物品2，如原木餐桌】：位于【区域/方位】、【相对参照物关系】
- 【物品3，如入户门】：位于【区域/方位】、【门扇朝向：朝内/朝外、铰链侧】
- 【物品4，如客厅大窗】：位于【区域/方位】、【窗户朝向：朝哪个方向、对应哪面墙】
- 【物品5…】：逐项列出画面中出现的所有物品/区域（含灯、装饰物等，不遗漏）

门/窗朝向清单：
- 【门1，如入户门】：【位置】+【朝向/开向】
- 【窗1，如客厅窗】：【位置】+【朝向】
- 【门2/窗2…】：逐项列出

光源位置清单：
- 【光源1，如客厅大窗】：【位置】+【类型：自然光】+【色温：傍晚暖光】+【照射方向】+【对哪些物件形成高光/阴影】
- 【光源2，如吊灯】：【位置】+【类型：人造光】+【色温】+【照射范围】
- 【光源3…】：逐项列出画面中出现的所有光源
</SPACE MAP>
```

**完全对应校验（组装完成后必须执行）**：将 `<SPACE MAP>` 中的每一项（摄影主轴、每个物件位置/门开向/窗朝向/光源位置）逐项回查 `<PANELS>` 各机位描述与 `<QUALITY>`，任何一项在九宫格各面板中缺失、含糊（如只写"可见沙发"而未写位置关系）、或相互矛盾，该提示词即为**错误**，必须修正后重新输出。

## 5. `<PANELS>` — 九个固定机位（★ 必写，机位编号固定，每个机位必须双锚点）

先写一句跨面板一致性总锁定（与 `<LOCK>` 呼应），再按 ①~⑨ 顺序逐一描述。

**机位双锚点强制格式（每个机位缺一不可）**：

> **编号 + 机位名：摄影机站在【站位区域】、【站位锚点：紧靠/背靠/位于哪个已锁定实体的哪个位置】，高度 X 米；镜头朝向【朝向区域】、【朝向锚点：光轴对准哪个已锁定实体】；前景为【锚点】、中景为【锚点】、背景为【锚点】。焦段。**

纪律：

- **禁止裸方位词**："左前方 / 右前方 / 左侧 / 右侧 / 深处 / 正面 / 对面"等词不得单独出现，必须绑定 `<SPACE MAP>` 已命名的区域与实体锚点。"左 / 右"一律以主轴（站 P0 面朝 P1）为基准。
- **站位锚点与朝向锚点必须是 `<SPACE MAP>` 已锁定的实体**（家具、门、窗、墙面、台面、过道等），禁止临时编造锚点；场景中找不到现成锚点时，必须先在 `<SPACE MAP>` 补入该实体（如墙角、立柱、过道）再写机位。
- 每机位写清**前景 / 中景 / 背景**三层锚点，使画面内容可被空间地图验证。
- 对称机位用锚点表达：⑥ 反打 ⑤ → ⑥ 的站位锚点 ≈ ⑤ 的朝向锚点、⑥ 的朝向锚点 = ⑤ 的站位锚点；③ 与 ④ 分居 P0 端主轴左右两侧；⑧ 的光轴与主轴垂直、两端锚点都要写明。

占位符模板（P0/P1/M 与左右锚点从 `<SPACE MAP>` 代入）：

```
<PANELS>
九个面板必须严格为同一空间的九个机位视角：空间结构、家具摆放、门窗位置与朝向、地面墙面材质、光源方向完全一致，禁止各面板生成不同的空间布局。全部机位的"左/右/前/后"以摄影主轴（站在 P0、面朝 P1）为唯一基准。

① 全局高位俯视：摄影机位于空间几何中心正上方（主体 M 正上方、略向 P0 一侧偏移），镜头垂直向下并向 P1 方向倾斜约45°—65°，光轴覆盖 M 与 P0—P1 主轴两侧的全部区域；前景/中景/背景体现为各区域与锚点的平面位置关系，作为场景空间地图。24mm wide angle，architectural overview。

② 正面广角主视角：摄影机站在【P0 所在区域】、紧靠【P0 锚点朝室内一侧的边缘】，高度约1.5米；沿主轴朝向【P1 所在区域】、光轴对准【P1 锚点，M 居中】；前景为【P0 边界构件，如门框/门洞】，中景为【M】，背景为【P1】。24—28mm lens。

③ 左前方45°视角：摄影机站在【P0 端主轴左手侧区域】、紧靠【该区域具体锚点的哪一侧/背靠什么】，高度约1.5米；朝向【M 所在区域】、光轴对准【M 靠 P0 一端的左前角，向 P1 延伸】；前景为【左手侧锚点物件】，中景为【M】，背景为【P1】。28mm lens。

④ 右前方45°视角：摄影机站在【P0 端主轴右手侧区域】、紧靠【该区域具体锚点的哪一侧/背靠什么】，高度约1.5米；朝向【M 所在区域】、光轴对准【M 靠 P0 一端的右前角，向 P1 延伸】；前景为【右手侧锚点物件】，中景为【M】，背景为【P1】。28mm lens。

⑤ 核心电影主机位：摄影机站在【M 靠 P0 一侧的具体锚点，如 M 前茶几边缘/M 前方过道】，高度约1.4—1.6米；朝向【M 正面与 P1】、光轴对准【M 正面中心】；前景为【M 前方最近锚点】，中景为【M】，背景为【P1】，自然电影构图，不做夸张广角。28—35mm cinematic lens。

⑥ 反打视角：摄影机站在【M 与 P1 之间、紧靠 M 背面/背靠 P1 的具体锚点】，高度约1.5米；朝向【P0 所在区域】、光轴对准【机位⑤的站位锚点】；前景为【M 背面，如沙发靠背】，中景为【M 与 P0 之间的锚点】，背景为【P0】，与机位⑤严格180度空间连续性，可验证两镜头属同一物理空间。35mm lens。

⑦ 场景内部向外视角：摄影机站在【最深处功能区内部的具体锚点，如台面内侧/吊柜下方/门框之内】，朝向【M 与 P0 所在区域】；前景为【功能区内部构件，如台面/门框/设备边缘】，中景为【功能区与 M 之间的锚点】，背景为【M 与 P0】。28mm lens，foreground framing。

⑧ 侧面横向空间视角：摄影机站在【一侧墙的具体锚点，如某门/窗/墙角旁】，高度约1.5米；光轴垂直于摄影主轴，朝向【对面侧墙的具体锚点】横向拍摄；画面沿光轴方向依次排列【锚点1、锚点2、M、锚点3】，突出家具门窗区域的距离与排列。35mm lens。

⑨ 低机位/特殊高度视角：摄影机站在【与机位⑤相同的站位锚点，或另行明确写出的锚点】，高度约0.8—1米；朝向【M 与 P1】、光轴对准【M 正面】；前景为【低位锚点，如茶几边缘/桌面】，中景为【M】，背景为【P1】，建筑比例真实，不使用夸张仰拍。35mm lens。
</PANELS>
```

> 每个机位都要把 `<SPACE MAP>` 的锁定关系落到画面上：前景/中景/背景写的是"该机位真实应看到的锚点"，写完后逐机位反查这些锚点在空间地图中的位置是否成立。

## 6. `<QUALITY>` — 纯空镜 + 质量约束

固定内容，不需要改动：

```
<QUALITY>
纯空镜场景，九个面板均无任何人物，无文字，无水印，无标注线框；16:9横版3×3九宫格布局，白色间隙分隔清晰；九个面板光影方向一致、色温一致、材质一致，为同一空间同一光线条件的机位变换；场景主体占各面板画面约四分之三，留出约四分之一空旷空间（为角色叠加留位）；高清，细节丰富，透视准确，禁止俯视顶视图以外的夸张透视、禁止鱼眼畸变。

```

<STYLE LOCK>
