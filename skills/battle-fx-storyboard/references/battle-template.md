# 战斗分镜条目模板 + 战斗运镜/节奏词表 + 示例

## 战斗分镜条目模板

```
镜头N｜时间线(秒)｜镜头焦点调度｜动作描述｜特效描述｜人物锁定｜环境锁定｜状态标注
```

## 战斗运镜词表

| 运镜 | 战斗用途 |
|---|---|
| 快速推镜 | 冲刺/突袭，逼近紧张感 |
| 快速拉镜 | 拉开距离/暴露大场面 |
| 环绕移镜 | 对峙/绕圈周旋 |
| 手持微晃 | 贴身搏斗/混乱感 |
| 慢镜 | 关键一击、大招、暴走瞬间 |
| 固定机位 | 招式起手/蓄力 |
| 极低仰拍 | 膝盖以下/积水高度仰拍，巨物从上方俯压，压迫感 |
| 荷兰角 | 画面倾斜15度，每次格挡倾斜加剧，回正=要反击了 |
| 急速环绕 Orbit | 战斗中高速绕圈，制造紧迫感 |
| 震颤定格 | impact瞬间镜头猛震+短暂停格，增强打击感 |
| 快速正反打 | 攻防交替急速切换，攻击→受击→反击 |

## 战斗节奏词表

- 攻防交替：近身→特写→拉开→反打（循环）
- 关键一击：慢镜 + 特效爆发的特写
- 大招/暴走：全程特效 + 慢镜 + 颜色突变
- 收招：固定机位，定格战果
- 物理反馈递进：第1击表面凹陷/碎裂 → 第2击躯干扭曲/后仰 → 第3击被轰飞/倒地
- 英雄镜头：侧面低角度仰拍 + 蓄力→爆发动作链 + 甩完定格一拍

## 完整示例

输入：剧本《燃魂》战斗戏，主角"阿火"（暴走状态，火焰特效，红色光效）对战"冰刃"（寒冰特效，蓝色）。

输出战斗分镜（节选）：

| 镜头 | 时间线 | 镜头焦点调度 | 动作描述 | 特效描述 | 人物锁定 | 环境锁定 | 状态标注 |
|---|---|---|---|---|---|---|---|
| 1 | 00:00–00:02 | 全景·环绕移镜 | 两人对峙，阿火压低身形，冰刃横刀 | 无 | 阿火vs冰刃 | 竞技场 | 常态 |
| 2 | 00:02–00:04 | 近景·手持微晃 | 阿火突进，拳击冰刃防御 | 拳风带火星 | 阿火 | 竞技场 | 常态 |
| 3 | 00:04–00:06 | 特写·慢镜 | 冰刃挥刀，寒气凝刃 | 寒冰特效·蓝色 | 冰刃 | 竞技场 | 蓄力 |
| 4 | 00:06–00:09 | 全景·快速拉镜 | 阿火暴走，火焰爆发，红蓝对冲 | 火焰爆发·红变暗红 | 阿火vs冰刃 | 竞技场 | **暴走** |
| 5 | 00:09–00:11 | 特写·固定 | 阿火重拳击中冰刃，火花四溅 | 火焰冲击波 | 阿火→冰刃 | 竞技场 | 暴走 |
| 6 | 00:11–00:13 | 中景·固定 | 冰刃后仰，阿火收招，火焰渐熄 | 火焰渐弱 | 阿火 | 竞技场 | 回常态 |

## 修正规则

- 用户改某镜头 → 只改该镜头，其余不变；时间线改动需重排后续秒数。
- 新增招式/特效 → 需回填到角色档案 F 模块，保证全剧一致。
