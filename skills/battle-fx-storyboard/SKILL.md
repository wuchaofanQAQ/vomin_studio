# Battle Fx Storyboard

## Overview

把剧本里的**打斗/战斗/特效场景**拆成"可直接生成画面/视频"的战斗特效分镜。它吃角色档案的 **F战斗层（战斗风格/招式/阶段状态/特效）+ G标志性表达层（经典动作/台词）**，保证每个动作戏镜头的招式、特效、角色状态都锁定一致，不漂移。

## 战斗特效分镜条目格式（每镜头）

```
镜头N｜时间线(秒)｜镜头焦点调度｜动作描述｜特效描述｜人物锁定｜环境锁定｜状态标注
```

| 字段 | 含义 |
|---|---|
| 时间线(秒) | 本镜头起止秒 |
| 镜头焦点调度 | 景别 + 运镜（战斗用快速运镜/手持晃动/慢镜）|
| 动作描述 | 具体招式/攻防动作（引用角色档案战斗招式）|
| 特效描述 | 本镜头伴随的特效（火焰/雷电/光效/粒子…）|
| 人物锁定 | 出手角色 + 受击角色 |
| 环境锁定 | 场景名（引用场景资产）|
| 状态标注 | 该角色当前阶段状态（常态/暴走/残血），对应档案里的颜色/特效变化 |

## Workflow

### Step 1 — 加载输入

读齐：**战斗戏剧本片段** + **出场角色档案**（F/G 模块）+ **场景资产**。缺任一则要求提供。

### Step 2 — 提取战斗要素

从剧本 + 角色档案提取：
- 交手双方（人物锁定）
- 各用的**战斗招式**（来自档案 F）
- 阶段状态变化（是否暴走/升级，颜色/特效按档案）
- 战斗**特效**（火焰/雷电/寒冰/光效…按档案）
- 经典台词是否在战斗中触发（来自档案 G）

### Step 3 — 逐镜头产出

按格式输出每个战斗分镜。**战斗分镜铁律**：
- **动作戏节奏快**：单镜头 1~3 秒，攻防交替用正反打
- 招式名必须用档案里的战斗招式，不临时编新招
- 特效必须用档案里该角色/该阶段的特效与颜色，不漂移
- 慢镜/特写留给"关键一击"和"大招"（暴走状态）
- 结尾镜头给收招/战果

### 战斗镜头专业规则（必读 `references/fight-clip-rules.md`）

- **打斗不是回合制** — 每个动作的结束状态直接是下一个动作的起始状态，零停顿。攻防交织，不是A打完B再打
- **巨物也极速** — Boss/巨型角色不因体型大就慢，挥击/重拳/乱抓都是极速
- **拳拳到肉有物理反馈** — 每次击打双方有物理反馈，且反馈递进（第1击表面凹陷→第2击躯干扭曲→第3击被轰飞）
- **镜头快切+急速运镜** — 战斗不能只6个Shot，需要更多快剪镜头，每镜运镜不同
- **压迫感镜头** — 极低角度仰拍、前景遮挡、荷兰角制造失衡感、巨物占画面70%+
- **震颤定格** — 每次impact镜头猛震前推+短暂定格，不是一直晃，是打中那一下震一下定一下

### Step 4 — 输出与说明

输出战斗分镜表，附 2–3 行说明：交手双方、用了哪些档案招式/特效、阶段状态变化、新增需补的资产（如有）。

## References

- `references/fx-scheduling.md` — 特效调度规则（阶段状态/颜色/特效一致性）

## Automated Mode (Harness Integration)

当被 `ai-drama-harness` 调用时，额外输出结构化 JSON，供 harness 合并到剧本分镜表。

### 读取输入

```bash
python cli.py read $WS --table 角色库
python cli.py read $WS --table 角色档案
python cli.py read $WS --table 剧本分镜表
```

### JSON 输出格式

````
```json:structured-output
{
  "shots": [
    {
      "shot_id": "ep01_s05",
      "episode": 1,
      "shot_number": "S05",
      "dialogue": "",
      "description": "林砚侧身躲避，反手一拳...",
      "prompt": "{角色库:林砚}侧身闪避，反击一拳...",
      "status": "待生成"
    }
  ],
  "dependencies": {
    "new_scenes": [],
    "new_characters": []
  }
}
```
````

harness 将战斗分镜通过 `python cli.py write --table 剧本分镜表` 合并到主分镜表。
