# 角色档案初始化抽取规则（Step 4）

初始化阶段从全剧剧本中**一次性抽取全部角色**，产出角色库（精简版）+ 角色档案（6 模块初版）。逐集分析阶段如发现新角色，由 `novel-to-character-assets` 补充完整档案。初始化要为全剧角色建立基线，避免逐集临时加人导致人设漂移。

## 一、抽取范围

1. 有对白或有动作的角色全部抽取，含重要配角；纯背景群演（"路人""保镖"无台词无动作）可只登记到角色库，角色档案标"龙套"
2. **跨集汇总**：同一角色的要素要从其出场的所有集中汇总，不能只看某一集
3. **别名归一**：同一角色的昵称、称呼、外号（如"三哥""林总"）统一映射到正式角色名，在 `basic_info` 中列出别名

## 二、6 模块（与飞书角色档案表一致）

| 模块 | JSON key | 抽取要点 |
|---|---|---|
| A 基本信息 | `basic_info` | 角色名/别名/定位（主角/反派/重要配角/配角/龙套）/身份/出场集数/人物关系 |
| B 风格层 | `style_desc` | 画风基调（从剧本设定继承）、主色调、气质；剧本未写明时随设定一起标"推断" |
| C 音色层 | `voice_desc` | 性别、年龄感、音色、语速、口音/方言；供 TTS |
| D 外貌层 | `appearance` | 年龄/脸型/五官/发型/身材/标志性特征（伤疤/纹身/道具）/常驻服装；**供三视图出图** |
| E 性格层 | `personality` | 性格、动机、弱点、说话风格（用台词举例）；供写剧本防 OOC |
| F 战斗层 | `battle_desc` | 战斗风格/招式/阶段状态/特效；非战斗题材或无相关描写标"未指定" |

> 经典动作/口头禅、来源集数与缺失项不落表（「标志性表达」「标注交接」两列已删除），只写进分析说明。

## 三、角色库（精简版，与生图/TTS 直接对接）

```json
{
  "name": "张三",
  "char_type": "核心",
  "appearance": "28岁亚洲男性，方脸，黑色短发，左眉骨伤疤，黑色冲锋衣"
}
```

- 角色库**不写** `gen_prompt`（三视图提示词由 `character-three-view-prompt` 生成）

## 四、抽取铁律

1. **缺失标"未指定"，不臆造**：剧本没写年龄/音色/战斗风格，不许脑补，只在 `notes` 缺失清单中列出
2. **标志性特征必须保留**：伤疤、纹身、独眼、固定道具等是一致性锚点，一个都不能漏
3. **关系网要闭合**：`basic_info` 中写清与谁对立/结盟/情感/上下级，供分集和分镜使用
4. **信息来源标注**：每条关键描述尽量能指回集数（如"第3集自述曾是雇佣兵"）
5. **画风全局继承**：B 模块画风统一取自剧本设定的画面风格，各角色不另起炉灶
6. 详细字段模板可对照 `novel-to-character-assets/references/bible-template.md`
