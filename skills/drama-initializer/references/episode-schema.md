# 剧集拆分规则（Step 3）→ 剧集表

把上传剧本逐集拆分为**剧集表**行。剧集表是后续"逐集滚动生产"的索引：分镜、视频、配音全部按集号挂接。

## 一、拆分原则

1. **以剧本既有分集为准**：剧本有明确集边界（第X集/EPX）时严格照切，不重新划分。
2. **无分集标记时**：按"完整钩子闭环"切分——每集一个核心事件、结尾一个钩子；切分结果逐集列给用户确认。
3. **原文完整保留**：`script` 字段放该集**完整原文**（含场次标题、动作描写、对白），不做任何改写。
4. **不编造未提供的集**：用户只给了 N 集就只产出 N 集；后续集在表中留空（状态"待编写"），不替用户续写。

## 二、每集字段（与飞书剧集表一一对应）

| JSON key | 飞书字段 | 内容要求 |
|---|---|---|
| `episode` | 集数（主键，数字） | 1, 2, 3...，从 1 开始连续 |
| `title` | 集名 | 用剧本原集名；无集名则按核心事件起一个 10 字内标题，标注"拟名" |
| `core_event` | 核心事件 | 一句话：本集发生了什么（谁做了什么/结果如何） |
| `characters` | 出场角色 | 本集全部出场角色名，顿号分隔；名字必须与角色库一致 |
| `prev_hook` | 上集钩子 | 本集开场承接的上集悬念；第 1 集留空 |
| `end_hook` | 结尾钩子 | 本集结尾的悬念/反转/威胁（短剧生命线，没有钩子要明确提示） |
| `scenes` | 场次列表 | 本集场次，逐条"地点·时间/内外景·日/夜"，分号或换行分隔 |
| `script` | 完整剧本 | 该集**原文全文**，逐字保留 |
| `status` | 状态 | 初始化固定填 `"草稿"`（用户确认后由 harness 改为"已确认"） |

## 三、场次列表写法

```
1. 出租屋·内·夜（雨）
2. 写字楼大堂·内·日
3. 街边·外·黄昏
```

场次名就是后续场景库的主键来源，**全剧同一场景必须用完全相同的名字**（如"出租屋"不要一会儿写"张三的家"）。发现剧本中同景异名时，在初始化阶段统一并在说明中列出"名称归一化对照表"。

## 四、钩子检查（短剧铁律）

逐集检查结尾钩子，在说明中汇报：
- 有明确钩子 → 摘录钩子一句话
- 结尾平淡无钩子 → 标"⚠ 无钩子，建议补"，但**不擅自改写原文**，只给修改建议
- 上集钩子与本集开头要能咬合；不咬合的地方列出

## 五、输出粒度

- 每集字段都要能被下游直接消费：`core_event` 不写对白，`characters` 只写名字，`scenes` 只写场景头
- 剧本中的对白、动作细节全部留在 `script` 原文中，不重复抄到其他字段
