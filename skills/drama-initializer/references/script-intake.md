# 原文接收与通读规则（Step 1）

用户上传的小说章节/剧本是初始化的唯一事实来源。先通读、再产出，严禁没读全就开写。

## 一、接收形式

- 文件：`.txt` / `.md` / `.docx` / `.pdf` / 飞书文档链接（按平台能力读取全文）
- 文本：直接粘贴的剧本正文
- 可能是：小说章节（首批若干章）、完整全剧剧本、多集剧本合集、单集剧本 + 大纲、或剧本 + 人物小传混合文档

## 二、通读时必须建立的结构索引

| 索引项 | 识别方式 | 处理 |
|---|---|---|
| 剧名 | 文件名 / 封面 / 标题行 | 缺失则请用户补充，不擅自命名（可给 2-3 个备选） |
| 集数边界 | "第X章""第X集""EPX"等分隔标记 | **严格 1 章 = 1 集**，按标记切分；无标记时按场次/钩子节奏切分并标注"自动切分待确认" |
| 场次边界 | "场景：""地点+时间""内/外景""日/夜" | 仅作理解，场次列表由 novel-to-script 逐集产出 |
| 角色名 | 对白行的人物名（如"张三："）、动作描述中的人名 | 汇总全角色名单，统一别名/称呼到正式名 |
| 时空设定 | 剧本中的时代、地点、世界观规则陈述 | 提取到剧本设定 |
| 画风线索 | 剧本中的风格说明、对标作品、导演备注 | 提取到画面风格；没有则按题材推断并标注 |

## 三、通读后的完整性检查（缺项一次问清）

只追问**剧本中确实缺失、且会影响下游生产**的项，合并为一次提问：

1. **集数与单集时长**：未分章/分集或未注明时长 → 确认实际集数；时长默认 2 分钟/集（标注默认）
2. **画面比例/平台调性**：竖屏 9:16 还是横屏 16:9 → 默认竖屏 9:16（标注默认）
3. **画风基调**：剧本未写明 → 按题材给推断方案（如都市重生→电影级写实冷色调），明确标注"推断，待确认"
4. **原文完整度**：只上传了部分章节？明确已覆盖到第几章，未提供的章节不编造、不续写（剧本表由 novel-to-script 逐章产出，本技能不写）

## 四、铁律

1. **原文只读不改**：本技能只读取并归纳原文，不改写、不缩写、不"润色"；原文逐字留存由 novel-to-script 写入剧本表的 `小说内容` 字段完成
2. **不臆造**：剧本没有的设定（人物年龄、世界观规则、画风）一律标注"未指定/推断"，不写成既定事实
3. **区分事实与推断**：产出中用"【原文】/【推断】/【默认】"标注信息来源，末尾汇总
4. **超长剧本分段读**：按集/按场次读取，避免遗漏；角色要素要跨集汇总，防止单集人设漂移
5. **用户的额外说明优先**：用户随剧本给出的修改要求/设定说明，优先级高于剧本原文，但要标注"用户补充"
