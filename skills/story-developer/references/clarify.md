# 澄清问题清单

从用户的模糊想法起步，先识别缺口，再按下面顺序**一次性追问**（合并成一次提问，不要逐条轰炸）。

## 必须澄清的核心项

1. **题材/类型**：都市、古装、仙侠、悬疑、科幻、甜宠…
   - 缺 → 问：你想做哪个题材？
2. **核心设定/亮点**：核心冲突、金手指、世界观亮点是什么
   - 缺 → 问：这部戏最抓人的点是什么？（金手指/逆袭/复仇/穿越…）
3. **主角身份与人设方向**：主角是谁、职业、性格倾向
   - 缺 → 问：主角大致是什么人设？
4. **集数与时长**：目标多少集、单集多久
   - 缺 → 默认 30 集 × 2 分钟/集（短剧常见规格），并标注为默认
5. **基调**：爽、虐、甜、燃、悬疑…
   - 缺 → 由题材惯例推断并标注默认

## 规则

- 用户若只给一句创意（如"想拍个外卖员逆袭的短剧"），可先用题材惯例搭建骨架，再把"核心设定/主角人设"作为唯一必答项追问，其余默认。
- 未答项一律标注"默认设定"，不擅自当作已确认事实。
