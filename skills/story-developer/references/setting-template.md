# 剧本设定文档模板（剧集圣经 Bible）

按以下完整结构输出剧本设定。每一节都要具体、可被下游 skill 消费；标注 ★ 的字段会直接喂给下游 skill，务必写清。

## A. 项目定位层

### 1. 剧名与卖点
- **剧名**：吸引人的短剧名（可给 2~3 个备选）
- **一句话卖点（logline）**：一句话讲清"谁 + 遇到什么 + 有什么爽/虐/甜点"

### 2. 题材类型与定位
- 题材类型（细分到二级，如"都市 + 重生 + 逆袭""古装 + 宅斗"）
- **受众定位**：给谁看（性别/年龄层/圈层）
- **平台调性**：竖屏短剧 / 横屏网剧（影响画面比例，★ 竖屏走 9:16，横屏走 16:9）
- **对标作品**：参考的已知剧/风格（帮助理解画风与节奏）

### 3. 基调
- 情绪基调（爽/虐/甜/燃/悬疑/搞笑…，可多个）
- 甜虐程度 / 爽点浓度

## B. 剧情层

### 4. 剧情简介
- **一句话简介**（用于推荐位/海报）
- **300 字简介**（完整讲清故事）
- 世界观设定（时代/背景/世界规则/金手指规则，**必须自洽闭合**，列出"能做到什么 + 不能做到什么"）

### 5. 主线与冲突
- 主冲突 / 核心矛盾
- 主角目标（外部目标 + 内心需求）
- 对抗力量（反派 / 障碍 / 命运）

### 6. 故事大纲
- **剧情弧线**：激励事件 → 中点转折 → 低谷 → 高潮 → 结局（标注所在集数）
- **全集剧情大纲**：逐集"核心事件 + 出场角色 + 集末钩子"

## C. 角色层

### 7. 角色设定
- **主要角色清单**：每个角色"名字 + 一句话定位 + 核心动机"（详细档案交 `character-bible-extractor`）
- **人物关系网**：谁和谁对立/结盟/情感线
- 角色成长弧线（可选）

## D. 风格与表达层（★ 直接驱动出图/出片）

### 8. 画面风格
- **画风基调**：电影级写实 / 日系动漫 / 半写实古风 / 水墨国风 / 赛博朋克…
- **主色调倾向**：冷/暖/暗/亮，以及主打色
- **光影基调**：写实自然光 / 戏剧化布光 / 高对比 / 柔和
- **质感关键词**：真实皮肤质感 / 干净线条 / 纸张质感…
- **参考画面**：1~2 部对标作品的具体视觉方向

> 此节直接喂给 `character-three-view-prompt` 和 `scene-image-prompt` 的画风词表，务必写清。

### 9. 音乐与声音基调（可选）
- 配乐风格、环境声方向

## E. 节奏层

### 10. 剧本节奏
- 单集时长、目标集数
- **钩子密度**：每集几个钩子、爽点频率
- 整体节奏定位：快节奏爽点密集 / 慢热铺垫 / 前快后稳
- 关键节奏节点分布（前 3 集留人点、中点反转点等）

## F. 看点与传播层

### 11. 剧本看点 / 爽点清单
- **核心看点**：本剧最抓人的 3~5 个点
- **爽点类型**：打脸 / 逆袭 / 复仇 / 甜宠 / 悬念 / 扮猪吃虎…
- 每集建议的看点节奏

### 12. 话题与传播点（可选）
- 可发酵的社交话题、金句、名场面方向

## 输出规则

- 逐节输出，节节完整；不适用项标"无/默认"。
- 末尾注明：哪些项来自用户想法、哪些是默认设定、哪些待用户确认。
- ★ 字段（画面风格、平台调性）是下游 skill 的关键输入，缺失要提示补全。
