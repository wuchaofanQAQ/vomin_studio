# 全集剧情大纲模板

## 剧情弧线（总纲）

按四幕划分，标注节点集数：
- 激励事件（第 1 幕起点）
- 中点转折（约 1/2 处）
- 低谷（约 3/4 处）
- 高潮（倒数第 2 集）
- 结局（最后 1 集）

每段写 1 句：剧情方向 + 情绪走向。

## 分集大纲

逐集一行，短剧格式：

```
第X集｜核心事件一句话｜出场角色｜集末钩子一句话
```

### 短剧分集铁律

1. **每集结尾必须有钩子**（悬念/反转/威胁/诱惑），否则观众流失——这是短剧的生命线。
2. 单集节奏：**开场 5 秒抓人 → 中段一个推进/爽点 → 结尾留钩**。
3. 每集只推进一个核心事件，不贪多。
4. 集与集之间要有"连续追剧"的牵引（上一集钩子 → 本集解决并埋新钩）。

## 粒度要求

- 分集大纲**只写事件与角色，不写对白、不写机位**。
- 每集粒度以"能被 episode-generator 扩写成完整分集剧本"为准。
- 明确标注出场角色名，方便角色档案对齐。

## 结构标注（建议在分集大纲中标注）

在剧情弧线和分集大纲中，建议标注以下叙事节点的位置：

| 节点 | 位置（占总集数比例） | 功能 |
|---|---|---|
| **激励事件** Inciting Incident | ~10-15%（如30集剧第3-4集） | 打破日常平衡、启动故事 |
| **第一情节点** Plot Point 1 | ~25%（第一幕末） | 主角被迫上路/做出不可逆决定 |
| **中点转折** Midpoint | ~50% | 伪胜利或伪失败，方向性误判 |
| **第二情节点** Plot Point 2 | ~75%（第二幕末） | 最大危机/最低谷，跌入绝望 |
| **高潮** Climax | ~85-90% | 核心冲突正面对决 |
| **结局** Resolution | ~95-100% | 新平衡/余韵 |

### 情绪曲线设计

每集和全剧都应有情绪曲线：铺垫→升温→爆发→回落。
- 不要全程高潮（观众会疲劳）
- 不要全程平叙（观众会走神）
- 张弛交替：文戏蓄势 → 爆发点宣泄 → 短暂回落 → 下一轮蓄势
- 每集小三幕：开场建置+钩子→中段加压/推进→结尾反转/悬念
