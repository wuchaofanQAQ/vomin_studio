# 导演级逐镜自检改写（写完每段后必跑）

> 来源：《自检提示词专用》。与 `core-principles.md` 的 18 项硬审计分工不同：**18 项审计是交付闸门（查合规）；本文件是改写轮（查"能不能拍出来"）。** 先改写，再跑 `check_storyboard.py` 和 18 项审计。

## 怎么做

把自己同时当成：导演、动作导演、摄影指导、剪辑师、视效指导、物理动作指导、AI 视频提示词工程师。把摄影机放到写定的位置，逐镜检查这份提示词能否生成**空间连续、动作清楚、速度准确、物理反馈可信、摄影机合理**的画面。

**输出方式（硬要求）**

- 发现问题**直接改进该镜头正文**；不向用户解释发现了什么，不输出检查报告，不列修改建议。
- 修正**融入镜头本身**，保留一镜一自然段，不因自检拆出大范围分行分段、不另列"优化说明"。
- 改的是给 Seedance 2.5 用的提示词，不是写给用户看的解释。
- 改动不得改剧情、核心动作、台词和用户明确要求（见 `core-principles.md` 第 2、17 条）。
- 可用手段：调整运镜、精简动作、改变景别、调整时间分配、修正物理反馈、删除穿帮元素、补环境互动、修正空间方向、修正比例、优化切镜点、强化速度感、重新设计不成立的镜头。
- 优先**正向画面描述**；只有某个错误极易发生、正向写法不足以消除歧义时，才补极少量否定约束（`check_storyboard.py` 的负向词检查是提醒，不是绝对禁令，见文末）。

## 16 项逐镜检查

### 01 摄影机与运镜
起始位置、与主体距离、焦段与景别是否匹配；运动方向、路径、速度是否明确且真实可执行；能否在镜头时长内完成；结束位置能否接下一镜。
- 推进、跟拍、环绕、甩镜、俯冲、上摇、下摇、伴飞，**都必须有实际空间路径**。
- 高速环绕人物：摄影机是**与人物共同前进的同时改变相对方位**，不是围着高速人物原地转圈。
- 快速甩镜写明**甩动方向和最终落点**。
- 高速飞行镜头可有适量气流微震、轻微横滚、惯性反馈，但摄影机保持专业可控。
- 运镜太复杂、时间内做不完，**主动简化**为更清楚、更有力量的单一运动。

### 02 速度感
"高速"必须从画面看出来，不能只靠"高速、极速、迅猛"。速度感 = **空间视差 + 摄影机相对速度 + 环境反馈 + 人物姿态变化**：
- 近处景物快速穿过画面，中距离降低，远景相对稳定；
- 摄影机追赶、超过、落后或绑定主体；人物与目标距离持续变化；
- 高速擦镜产生短促方向性模糊；
- 头发、衣摆、尘土、树叶、水雾、云雾有明确方向的速度反馈；
- 主体人物的身体和脸尽量保持可读。

若所谓高速镜头只是人物在背景上平移，**重新设计该镜的摄影机、前景和环境运动**。

### 03 人物动作与姿态
姿态只保留决定画面正确的关键信息：身体朝向，直立/前倾/后仰/侧倾，双手主要位置，双腿或支撑脚关系，视线方向。不写成人体参数表。
关键动作必须写姿态变化：加速前后的身体倾角、脚寻找借力点、被撞击后的重心变化、落地时腿部吸收冲量、挥剑时身体与武器的运动关系。
前后镜姿态连续：不能上一镜右脚在前、下一镜无过程变成完全不同状态；切镜可省略过程时，**新镜第一帧仍须符合运动惯性**。

### 04 动作链完整性
**接近 → 接触 → 受力 → 压缩/形变 → 发力/释放 → 后续运动**。
- 脚没踩到支撑点，不得改变运动方向；
- 攻击没接触目标，对方不得被击飞；
- 落地不能脚刚出现身体就已站稳；
- 载具受冲击不能没有受力过程就改变姿态。

观众必须看懂：**力量从哪来 → 作用在哪 → 产生什么结果**。

### 05 物理反馈与受力反馈
踩踏、落地、撞击、借力、挥砍、推拉、爆发、大型物体运动、高速经过环境——**人物自身、接触物、环境三者都要有对应反馈**。
- 脚踩岩石：腿部短促压缩 → 鞋底与岩面接触 → 岩面按力量产生灰尘/碎石/裂纹 → 腿部回弹离开。
- 人落飞机：腿部吸收垂直冲量 → 冲量作用于机体 → 飞机出现符合大型飞行器惯性的短促姿态变化 → 摄影机与驾驶舱人物同步受惯性 → 飞机恢复稳定。
- **反馈强度与力量一致**：轻点轻反馈，重踏明显反馈。
- 巨大结构破坏：裂纹 → 错位 → 失稳 → 断裂 → 坠落/倾倒 → 二次碰撞。环境结果不得凭空发生。

### 06 环境互动
人物、车辆、生物、特效不能像图层贴在背景上。主体经过时，**足够近的环境**要有反馈：
高速掠过竹林 → 最近竹叶向运动反方向短暂伏动并回弹；高速贴水 → 水面出现方向一致的波纹、水雾或尾流；高速掠过地面 → 草叶、灰尘、细碎物受气流影响；穿过云雾 → 最近云丝产生明显相对运动与局部扰动；脚踩岩面 → 灰尘、碎石、裂纹从真实接触点产生。
反馈**集中在真正受影响的区域**，不让整个场景同时响应。

### 07 镜头可见范围与穿帮（最高优先级之一）
逐镜重新确认焦段、景别、机位、摄影机朝向、主体距离，再查每个元素是否真可能进入画面：
- 脚部特写不写表情和上半身动作；
- 面部近景不写脚底接触细节；
- 300 米高空俯拍不写眼神和细小手部动作；
- 驾驶舱近景不无缘无故看到完整飞机外形；
- 侧面大全景只有当前空间能合理进入画面的元素。

检查是否混入：上一/下一场景元素、当前空间不存在的人物、当前镜头不可能看到的道具、没有剧情来源的额外角色/建筑/动物/载具/特效。**不该出现的直接删除；不靠加否定词补救，把正文改成只描述正确存在的画面。**（详见 `camera-space-and-visibility.md` 第 3 节。）

### 08 空间连续性
前后镜是否同一连续空间：人物往哪个方向移动、目标在人物哪个方向、人物在目标前后上下哪个位置、距离缩短还是扩大、高度上升还是下降、切镜后运动轴线是否突然反转。
追逐戏：追赶者始终朝目标运动；人物不无原因瞬间跨几十米；目标不在左右之间无理由跳变。越轴、方向反转、巨大位置变化必须靠明确的摄影机运动、动作或切镜逻辑让观众理解。

### 09 尺度与比例
统一参考资产给出的尺寸关系。同一主体在连续镜头中不忽大忽小；人物与大型载具同框保持明显尺度差；远处自然变小、近处按透视放大；**不为构图方便错误缩小载具或巨兽**。尺度靠人物参照、环境参照、景别、透视持续保持。（数字写法见 `physics-and-scale.md` 第 6 节。）

### 10 镜头时长与动作密度
当前时长是否真能完成提示词里的全部动作：
- 0.5 秒镜头只承担**一个极清楚的动作**；
- 1 秒左右不同时完成多个复杂动作链和复杂运镜；
- 2~3 秒可承担较完整的运动，仍需明确主要任务。

塞太多就**删次要动作或移给相邻镜头**。前段高速剪辑尤其要保持动作迅速，不要因描述过多让模型把每个动作慢悠悠展示。

### 11 切镜与运动惯性
高速段优先在**动作仍具运动速度时切**：脚刚蹬离岩面 → 切大全景看人物射出；人物即将经过摄影机 → 切另一个高速机位；摄影机高速甩动 → 借运动模糊切换场景。
切入的下一镜须继承上一镜的**运动方向、身体惯性、速度等级、人物当前状态**；不能每切一次镜人物就从静止重新开始。

### 12 慢镜头
慢镜必须承担一个值得看清的动作：接触瞬间、受力传递、结构开始破坏、重要动作姿态、关键情绪瞬间。写明**看什么**；结束后**明确恢复正常速度**，恢复时动作惯性继续存在；慢镜不是拖延时长的手段。（升格每段次数在整体基准声明。）

### 13 资产连续性
人物服装/发型、武器、载具、生物、场景是否持续一致；连续镜头里有无服装突变、武器换手或消失、载具结构变化、发型改变、角色数量变化、物体出现在错误位置。资产锁定只保留真正重要的连续性约束，不在每镜重复大量资产描述。

### 14 光线与时间连续性
同一连续场景内：太阳方向、人物主光方向、阴影方向、天气、天空颜色、时间段不能无故跳变（上一镜顺光下一镜完全逆光、上一镜晴天下一镜阴天、同一连续动作里太阳位置明显跳变）。不同场景可改变时间和光线，但要在合理切镜后完成转换。（机位换边时补本镜光向，见 `shot-richness-and-pitfalls.md`。）

### 15 画面重点
逐镜问：**这个镜头的唯一主要任务是什么？** 建立环境 / 展示姿态 / 看清借力 / 表现速度 / 展示目标距离 / 表现受力 / 表现反应 / 完成视觉揭示。短镜头只承担一个；内容太多，保留最重要的，其余交给前后镜头。

### 16 最终镜头
有结尾大景、人物定格或海报式收尾时，重点重写最后一镜，必须明确：主体在画面的位置与占比；前/中/远景；人物姿态；环境层次；光线方向；摄影机最终位置与最后如何减速；**最后一帧的具体构图**。不能只写"摄影机后拉，画面唯美"，要写真正停下来的那一帧。最后一镜须形成独立可用的结束画面，并与【本段终态】一致。

## 最终优化原则

**主动删除**：重复描述、无意义参数、当前镜头看不见的信息、对生成没帮助的抽象形容词、过多否定约束、与镜头主要任务无关的内容。
**主动加强**：运镜路径、速度参照、人物与摄影机相对运动、动作连续性、接触过程、受力传递、环境反馈、空间连续性、尺度关系、切镜惯性、最终画面构图。

## 与本 skill 其他规则的衔接

| 事项 | 处理 |
|---|---|
| 一镜一自然段 | 自检改写后仍是一镜一自然段（对白另起一行是唯一例外），不新增"摄影机：""速度："之类栏目 |
| `{}` 锚点块、【资产名】、无代词 | 改写时保持；新增的任何主体指称仍写【资产名】 |
| 时间码 / 0.5 秒格 / 首尾相接 | 调整时间分配后必须重新核对，改完跑 `check_storyboard.py` |
| 台词逐字、语速 ≤5.3 字/秒 | 删动作、改时长时不得动台词；窗口变短导致语速超限，改镜头分配而不是删字 |
| 负向词检查 | 脚本对镜头正文的「不要/禁止/切勿…」仍会报错；确属"极易发生且正向无法消歧"的少量约束，改用**正向可见元素集合**表达（"画面中只有两人：【A】与【B】"）而非否定句 |
| 对用户的输出 | 交付里**不附逐镜自检报告**；只保留交付摘要里的 `18 项硬审计` 结论一行和真实完成的检查（见 `core-principles.md` 第 24 条） |
