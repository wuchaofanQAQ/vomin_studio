# 镜头空间、可见边界与切镜重建

> 来源：《剧本转提示词》3.0 的「镜头坐标系 / 当前可见边界 / 切镜重建」与 4.2 的「先建场景再设计镜头 / 当前镜头可见性 / 镜头语言」，已按本 skill 的 `{}` 锚点块 + 【资产名】体系改写。写镜头前先答"摄影机在哪、能拍到什么"，再动笔。

## 1. 先建场景，再设计镜头

把场景当成有体积、出入口和高差的空间，写【本段初始空间】前先确认：

1. **稳定地标**：地面、楼层、墙顶、屋檐、平台、门洞、栏杆、道路、水岸。"门上城楼""相邻墙顶""城门下"是三个不同位置，不能混写。
2. **站位要落到支撑面**：人站在哪里、踩在哪里、朝向哪里、从哪里出入、退路在哪。
3. **多张场景图分工**：哪张给建筑正面，哪张给向外视野，哪张只给局部或材质。**相反方向的图不能叠成同一背景**；局部图不能承担大面积景（局部码头图不承担江面），平视外观图不能当已知俯视平面图。
4. **图外空间沿资产补全**：沿可见的材质、尺度、墙线、地形逻辑补，并在【本段现场生成】写清"取用层（取哪张图的什么）+ 重建层（补什么）"。推断只解决怎么拍，不新增地标、不改资产已确认的结构。
5. **世界方向轴**：优先"城内/城外、门口/室内、来路/目的地"这类易懂关系，有依据再用东南西北。**画左画右由当前机位推导，反打之后不得照抄上一镜的画左画右。**
6. **身体左右与画面左右分开**：持握手、伤痕侧别按角色身体写，不随换机位交换。
7. **资产改朝向**：写主体在三维空间里转向哪个地标、机位在哪一侧、可见哪一面，保持同一骨架与非对称细节；已朝向目标就直接建立该初态，剧情需要转身才写转身过程，不用含糊的"反过来"。

## 2. 屏幕坐标系：位置与朝向都绑定当前画面

主体、道具、特效在当前镜头可见时，优先用 **画左 / 画右 / 画面中央 / 画上 / 画下 / 前景 / 中景 / 后景** 写位置，必要时补"贴近画框边缘""从画右后景进入画左前景""被画左前景人物遮挡一部分"。

| 差（孤立方向词） | 好（绑定摄影机） |
|---|---|
| 【A】看向前方 | 【A】上半身朝画右偏转，视线落向画右上方画外 |
| 【A】转向身后 | 【A】背对镜头向画面上方后景走去 |
| 【A】朝他走去 | 【A】从画左中景横移到画面中央前景，停在【B】身前约两步 |
| 【A】看向【B】（B 位置未建立） | 【A】位于画左前景，侧身看向画右中景的【B】（仅当 A、B 同时可见） |

- **A 看向 B** 只在 A、B 同时可见且位置已建立时写。B 在画外，只写 A 看向哪个**画面方向**，不顺带写 B 的画外动作。
- **过肩**写清谁的肩背在前景、另一人在哪侧哪层：`【A】的右肩虚化占据画右前景，【B】位于画左中景，正面朝向【A】`。确实出现后肩/耳侧/后脑/衣领才称"过肩"，没有身体前景就称**干净反打**。

## 3. 当前镜头只描述当前可见画面

每镜写完后做三步（内部做，不写进提示词）：

1. **列三个集合**：当前**可见集**（实体/局部/反射/可辨投影进入画框）、当前**可听集**、**画外因果集**。
2. **逐句核对**视觉正文里出现的每个人名、物名、身体部位，是否真的在可见集里。画外人物**写出名字就可能被模型生成出来**。
3. **问一句**："摄影机在这个景别、角度、遮挡下，能否同时拍到我写的全部内容？"不能，就拆镜。

规则：

- 画外信息只以摄影机能接收的形式出现，并标来源方向：`画右画外传来金属坠地声`；画外对白写 `角色·画外声`（见 `dialogue-and-audio.md`）。**不得描述画外角色的姿态、表情、受力或特效状态。**
- 单人近景保持干净；陪同角色只有承担叙事或空间功能时才进前景/后景。定场大景已交代的人物，不必在每个后续近景里陪衬。
- 近景只有女主时，可写她的表情、肩颈、手部、视线方向，以及画外传来的声音；**不能同时写画外妖怪"张口、挥爪"**。要表现妖怪，要么切到妖怪镜头，要么改成能容纳双方的景别，要么让摄影机摇移/横移后"揭示"它入画。
- 句子一旦越过当前镜头的可见边界，立即拆镜：保留当前主体镜头，再写"切镜头，"进入另一主体，新镜头重新写景别、机位/运镜、画面位置和当前状态。

### 示例（两镜头）

锚点块照常使用 `{}`，镜头正文只用【资产名】：

```
【参考素材锚点】
{角色库：女主} 图1：【女主】，主角，修行者
{角色库：妖怪} 图2：【妖怪】，岩石巨妖
{场景库：城市上空} 图3：【城市上空】主场景，外景·日，云层之下的城市

【镜头01｜0-2s｜女主察觉异动】
开镜，近景固定机位，【女主】占据画面中央，只保留头肩与胸口以上，身后【城市上空】的城市后景浅景深虚化；【女主】原本平视画面前方，画右上方画外传来一声低沉咆哮后眉骨下压、下颌微抬，视线转向画右上方画外，右侧鬓发被由右向左掠过的气流推向画左，镜头停在眼神上。

【镜头02｜2-4s｜妖怪警告】
切镜头，低机位近景并缓慢前推，【妖怪】的岩石脸位于画面中央前景，庞大头部挤满画面上半部，【城市上空】两侧云雾被它的体积压向画框边缘；【妖怪】面朝镜头下方张口，低频声压从画面中央向前景扩散，近处薄云先向左右分开，摄影机随声压向后短促低幅震动一次后回稳。
【对白 2.5-3.5s】妖怪，愤怒地：退下。
```

要点：镜头 01 只保留【女主】与【妖怪】的**画外声音**；【妖怪】的可见状态和台词放到镜头 02。

## 4. 切镜后状态必须重建

主体在运动中切镜，或离开画面后再次出现，当前镜头必须**重新写清此刻可见的**：位置、朝向、姿势、运动方式、速度趋势、手脚状态、持握道具、视线。

- 不要只写"继续飞行""仍然站着""保持原姿势"，这些词后面必须补足当前可见状态。
- **描述范围服从景别**：全景能看全身，写站立/悬浮高度、身体轴线、双腿、双手、重心、衣发方向；近景看不到腿脚，就不写腿脚，只写头部、肩颈、手部、表情。
- 状态变化写**原因与时点**：`冲击抵达胸口的一瞬，【B】上身先向画右后仰，重心随后越过右脚，左脚被惯性拖离地面`。不让姿势、朝向、道具、速度无因跳变。
- 切镜只改观察位置，不重开已完成的动作；每次切出，记下下一镜要用的状态，下一镜从同一进度接起（见 `shot-grammar.md` 动作链衔接）。

## 5. 景别决定信息精度

| 景别 | 写什么 |
|---|---|
| 远景 | 整体路径、轮廓、群体运动 |
| 全景 | 全身、支撑、间距 |
| 中景 | 头身手势 |
| 近景 | 脸与可见道具 |
| 特写 | 只聚焦局部 |

极远景中的小人影，不同时写清表情与手指。屋顶遮住的地方、墙后的人、画框外的腿脚，不能靠文字"透视"出现；需要看见，就改真实机位或另切镜头。

## 6. 运镜：起幅、经过、落幅

- 摄影机每次移动写**起点 → 路径 → 终点 → 结束构图**，路径经过真实空间。连续移动与硬切分开写，每次实际切镜新建镜号。
- 一个短镜头以**一个主要运镜**为主，不无因堆叠多种运镜。固定机位也要明写"固定"。
- 分别核对起幅、经过、落幅：**稍后才入框的脸、手、后景，不能写成从头可见**；同速跟拍与主体逼近等相对运动要同时成立。
- 源文只规定起幅景别时，后续可在镜内通过真实运镜、变焦或跟焦改变观察范围，写清落幅与入框时机；明确锁定全程景别的要求照常保留。镜内改构图要解决遮挡与视锥问题，不是单纯把景别名称改大。
- **高空俯拍**：先确定机位在哪个地标上方、镜轴朝哪一面，以及屋顶/墙体/人体造成的遮挡。要垂直 90 度俯拍时，写镜轴垂直地面、以地面平面关系组织画面、地平线在取景之外，并按已知布局重建从上方可见的屋顶、石块顶面或道路，不能把平视图直接倾斜贴入。

## 7. 文戏的镜头语言

- 以建立关系的大景或克制双人镜头起步，再用**干净正反打、真实过肩、必要反应镜头**承载对白。
- 双方目线与对话轴一致，摄影机主要留在轴的一侧；需要越轴，先用连续移动或重新定场让关系可见。
- 双人镜头用于共同反应、递物、接触、关系变化；对白长或空间含混时用全景/大全景重建关系，但**不机械地每几秒插一个大景**，也不把所有对白塞进同一双人中景。
- 脸部表演要有真实光源（窗外天光、前檐开口、火光、月光、地面反射），保留眼神、鼻梁、嘴唇、面部轮廓；背影与剪影按该镜意图保持，不为露脸任意换机位。
- 文戏优先稳定中景、近景、过肩、缓推、轻微横移、焦点转移；写目光方向、呼吸、停顿、手指/嘴角微动、人物间距。**不强加环绕、甩镜、爆炸特效或无动机抖动**。
- 保留原剧本的切镜；新增切镜必须带来新的观察信息或节奏职责，不为"炫酷"反复重放同一动作。
