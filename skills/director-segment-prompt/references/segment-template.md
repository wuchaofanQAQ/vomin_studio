# 段落模板

## 文档头（整集一份）

```
{剧名} 第{N}集
Seedance 2.5 导演级视频提示词
逐段使用
每个生成段从本段资产锁定开始，连同整体基准、初始空间、全部镜头与本段终态一起提交。镜头时间码均从本段零秒开始；同一场景分为连续两段时，按各段写明的初态和终态衔接。
资产绑定
参考图标签与本段资产锁定中的名称对应。角色图提供面容与体态，场景图提供地貌、建筑和材质；镜头中的角度、光线与动态按正文建立。{特效资产，如刀气、鱼群、护罩}按各镜的空间路径、层次、遮挡与环境作用生成连续动态。
待补资产
【{名称}】。后文已写入对应动作及外形基准，补图后按同名绑定。
分段索引
第01段  {标题}  {X}秒
第02段  ...
```

"待补资产"只在确有缺图时出现，且必须保证正文里已写出该资产的形制基准（见 continuity-and-anchoring.md）。

## 单段骨架

```
第NN段  {场景｜事件标题}
本段总时长 {X}秒  时间范围 0-{X}s

{场景库：{空间名}} 图2：【{资产名}】主场景，{时空}，{结构色调}（需局部写 {场景库：{空间名}·局部·部位}）
{剧本分镜表：{上一段ID}} 视频1：上一段成片，承接终态姿态（需要动作衔接时才写）
【本段资产锁定】
【A】、【B】、【场景】、【道具/特效】
【本段现场生成】
...
【本段整体基准】
...
【本段初始空间】
...
【镜头01｜0-3s｜标题】
...
【对白 0.5-3s】角色：台词
【镜头02｜...】
...
【本段终态】
...
```

标题格式：多场景/动作段用"地点｜事件"（如"皇宫大殿｜质问杨广"）；单一空间奇观段用"地点 事件"（如"深海海沟 千米刀气下斩"）。

## 各块写法

### 【参考素材锚点】

- 给 CLI 展开素材用，**整段里唯一允许出现 `{}` 的地方**；CLI 展开时移除标记、保留"图N：…"说明，素材按图1/图2/视频1 顺序随 API 传入。
- 每个出镜角色、每个场景（含空镜）各一行；不写长相服装细节，由参考图锚定。
- 图片 `图1…图N`、视频 `视频1…` 连续编号，一素材一段内只声明一次。
- 没出图的资产不进锚点块。完整规则见 `asset-binding-and-cli.md`。

### 【本段资产锁定】

- 只列名字，顿号分隔，名称与参考图标签逐字一致。
- 同一角色的不同阶段/版本分别列出并写全称（`【杨广 中年版】`、`【北极熊，披风版】`）。
- 顺序：主角 → 配角 → 群体 → 场景 → 道具/特效。
- 本段只出现一次的临时群演（如"六名隋代士卒"）也列，因为要用它的服甲形制扩人数。

### 【本段现场生成】

三类句式，按需组合：

1. **取图建空间**：`取【陈诚公寓门口】的浅米灰地砖、白墙与深灰防盗门，建立门外约半米宽的站立区。`
2. **沿资产补全**：`沿【隋朝皇宫大殿】可见梁柱、地板、帘幕和丹陛补全朝向正门的反向空间。`
3. **按形制扩量**：`数百名隋军沿六名隋代士卒的服甲形制现场生成`、`取【八名隋代男女劳役】体貌衣料扩为十六名役夫，人数包含【隋末跛脚男性役夫】`。

> **引用图必须写【资产名】**，且该资产必须已在本段【本段资产锁定】里。禁止写"走廊图""厨房图""上一段那张图"这类泛称——它既不是库内行标识，也不会被 `expand` 识别。需要用到第二张场景图时，把它加进锚点块与资产锁定。

凡资产里没有的东西，在这里**给出尺寸与承重**：`成人掌心可握的金属酒杯`、`足以承托巨型熊的低矮加宽厚木食案，粗壮短腿稳压木地板`、`茶盏大小以手掌托住为准`。

特效物（刀气、护罩）在这里重建为**有体积的形状**：`有薄厚的竖直月牙刃面；凸刃朝正下方，两尖向上回收，刃面长轴沿海沟纵向`。

### 【本段整体基准】

固定顺序（缺项可省）：

1. 画风+年代：`写实电影，隋代历史场景与东方修仙表演。` / `写实东方高武，阴天柔光保持人物眼神与刀斧轮廓清楚。`
2. 光源：`清晨天光从临江侧上方落来，侧光勾亮人物面缘，岩面反光托住眼神。`
3. 风/气流主方向：`中等山风从内陆斜吹向江心，衣袖、衣摆、细草与新生雾丝具有一致主方向。`
4. 声音层次：`风声、水声和远处船木轻响形成层次。` 对白戏写"现场声音以台词、空殿轻混响、衣料、酒杯撞地和脚步为主"。
5. 角色状态：`姜颜只使用【姜颜】身份`、`姜颜本段全程以既有老者外貌行动，身法却轻快精确`、`皇帝全段使用【杨广 中年版】`。
6. 本段专属规则：
   - 一击类：`刀气为同一击，只从本段右手下斩产生一次。`
   - 量化类：`整体弧刃跨度约三千米，厚度相对跨度很薄。`
   - 动作类：`高速打击在接触瞬间完成，观众从对手被掀离地面及泥土落点读到力度，后续镜头承接同一动作。`
   - 节奏类：`缴械从察觉到刃停在颈侧是一串约四秒的连续快动作…刃停之后让院中风声与呼吸形成静场。`
   - 慢放：`转身揭示使用一次短升格，行走及对白回正常速度。`（升格全片只在个别段出现，用则声明次数）
7. **对白段固定句**（有台词的段，附在整体基准末尾，原样使用）：

> 本段总时长按剧本锁定；对白在动作与反应中连贯说出，切镜作为连续声桥，同句换景别时声音持续。短反应与视线变化发生在说话过程中。

### 【本段初始空间】

必须包含，缺一不可：

- **世界轴**：`内陆平原—崖缘—崖下近岸—广阔江心`、`殿门与龙椅位于同一主轴两端`。
- **每个主体**：位置（距某物多远）、朝向、相对他人的偏移。距离用步、臂、米、人宽、半个头等可测量单位。
- **未入画者的位置**：`韩擒虎与军阵在两人身后的内陆平原`、`殿门方向位于姜颜身后约九米处`。
- **开镜机位**：`开镜摄影机位于临江一侧悬空、与杨广胸面平齐，朝内陆取他的正面；姜颜处于本镜左侧画外。`
- **对话轴与机位侧**：`双人谈话轴连接姜颜与杨广，主要机位位于该轴同一侧。`
- **后续要发生的位移终点**：`她起飞经过栏杆上方和敞口外的天空`、`抛掷落区是前方外侧空草坡`、`酒杯稍后落在龙椅所在平台的前部地面`。

### 【镜头NN｜起止｜标题】

- 编号两位，标题 4~12 字，概括镜头功能（"借雾与犹疑""金属杯撞地翻滚"）。
- 时间码格式 `0-1.5s`：以秒为单位，**最小单位 0.5 秒**，起止都必须是 0.5 的整数倍。
- 正文写法见 shot-grammar.md。

### 【本段终态】

一段话，写：主体位置/姿态/手持物 + 环境残留 + 尚未发生的事。示例：

> 唯一一道三千米级弧刃已经轰入海沟并继续向地底深入；下斩线两侧岩层崩开，悬沙和碎块仍翻涌。姜颜右手持出鞘刀、刀鞘在左腰，尚未再次挥斩。

> 姜颜以直立姿态飞向街外天空并远去，衣摆拖在身后；杨广停在栏内靠前位置，仰望同一方向。成年巨型白毛北极熊仍留在后部食案，继续进食。
