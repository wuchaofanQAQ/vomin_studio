# 迭代修复手册

## 迭代医生原则

1. 失败后**一次只改 1~2 个变量**。
2. **保留成功部分**，不整段重写。
3. 每轮修改后必须重新过 `preflight-checklist.md`，不能跳过。
4. 用户修正某一镜或某一段 → 只改它和因终态/初态衔接受影响的后续段；依赖变化时同步更新依赖清单。

本 skill 不写 NEGATIVE。下表的"修复"一律用**正向写法**把画面写对，需要排除某种现象时写成"画面中只有……""始终为同一……"。

## 常见问题修复表

| 问题 | 修复 |
|---|---|
| 掉帧、画面卡顿 | 降低手持/摇晃幅度，改固定或轻推；把"疾速摇"换成"短弧绕行后收稳"；缩短该镜窗口里的动作量 |
| 角色复制、人数不对 | 在整体基准/现场生成里**写死人数**（"画面中只有两人：姜颜与杨广"）；每个镜头开头写出镜人数；群体写"取…扩为 N 名，人数包含【某某】" |
| 动作被跳过 | 先保核心镜头完整，合并次要镜头；窗口 <1 秒的镜头只放一个动作 |
| 特效颜色偏差（如偏蓝紫） | 在形制基准里写明目标色（"暗金刃面，深红底色"），不写"别偏蓝" |
| 格挡/命中没有物理反馈 | 补推退、飞溅、震动：冲击后一次短震，写幅度、方向、衰减（见 `physics-and-scale.md`） |
| 表情过多、过度 | 删除所有情绪词，改写成 2~3 个肌肉动作；按人设推演克制程度 |
| 翻滚/转向方向错 | 明确写方向词（向后、向画右、顺时针），并写落点 |
| 演出不匹配人设 | 写之前通读角色档案；同一角色不同场景演出可不同 |
| 色调不一致 | 同场景统一色调；整体基准锁定光源和色温，逐镜头检查是否矛盾 |
| 景别与描述不符 | 逐镜检查：镜头拍不到的不写（中景不写脚趾） |
| 比喻污染 | 删除"像……""如……"，直接写视觉事实 |
| 画面假、没有活人感 | 环境动态不足：每镜补 3~4 个（空气 + 光 + 物体/水） |
| 肤色与环境色不匹配 | 补光-表面交互：光源照到哪、色温混合、反射光来源 |
| 动作僵硬、像人偶 | 只写了一个部位：补全身动力学链 |
| 画面空、元素少 | 补前景/中景/背景/空气层 |
| 人与环境没有物理交互 | 补接触面：脚踩、手扶、衣摆扫过物体 |
| 台词与口型/时长对不上 | 查语速（≤5.3 字/秒），拆镜或延长窗口；检查对白时间码落在镜头窗口内 |
| 对白在切镜处断掉 | 补整体基准末尾的"连续声桥"固定句；镜头里写"画外声音接完后半句时…" |
| 段与段衔接跳变 | 对照上一段【本段终态】逐项复述到本段【初始空间】，必要时加视频1 做动作衔接 |
| 一击重复发生 | 整体基准写"同一击，只从本段某处产生一次"，镜头里用"承接同一次…" |

## 成功经验

**方法**
1. 用户/导演给了详细镜头设计时，执行者的职责是翻译成 Seedance 能吃的文本，不自己编镜头。
2. 多轮迭代，每轮只改 1~2 个变量。
3. 冲突自查是硬门——每次改完都要重过。

**写作技术**
4. **每镜运镜尽量全不同**——重复运镜是模型偷懒的信号。
5. **动词要狠**："猛然翻起"，不是"缓慢起身"。
6. **物理细节每镜不重复、有递进**：第一镜写扬尘，第二镜写碎石弹跳，第三镜写余震衰减。
7. 每条规则都针对真实踩过的坑，不堆套话。

**角色演出**
8. 演出是推演结果，不是死规矩——同一角色在不同场景应有不同表现。
9. 角色之间演出要分化：三人面对同一件事，反应各不相同（一人僵住，一人后退，一人盯着看）。

## 写作前确认

- [ ] 用户/导演是否已给出镜头设计？没有，先问要。
- [ ] 每镜运镜是否尽量不同？
- [ ] 动词够狠吗？
- [ ] 物理细节每镜有递进吗？
- [ ] 角色演出是否匹配人设、彼此分化？
- [ ] 导演意图卡是否先于写作完成？
