# 完整分集剧本模板

按以下结构输出一集完整剧本。

## 集信息

- 集数 / 剧名
- 本集核心事件（一句话）
- 出场角色（列名）
- 承接的上一集钩子（一句话）
- 本集结尾新钩（一句话）

## 开场（0–5 秒）

- 快速抓住观众的场景 + 一句有冲击力的对白/动作
- 短剧原则：不得慢热铺垫

## 主体（若干场次）

按场景逐场展开，每场格式：

```
场次｜地点/时间｜出场角色
[动作/环境描述]
角色：对白
（情绪/反应标注）
```

- 每场写清：环境、动作、对白、情绪
- 单集推进一个核心事件 + 一个中段爽点/反转
- 对白符合角色档案中的性格（不OOC）

## 结尾（钩子）

- 最后一场必须留下悬念/反转/威胁/诱惑
- 明确写出"下一集钩子"一句话，供 episode-generator 连续续写

## 画面导演提示（为分镜做铺垫）

每场写完对白/动作后，可附 1-2 行画面导演提示（可选但推荐），帮助后续分镜 skill 更好地拆镜头：

- **情绪氛围**：这场戏要观众感到什么？（如：压迫、温馨、紧张、孤独）
- **关键画面**：这场戏最该被"看到"的一个画面是什么？（如：雨中独站、手握碎照片、两人背对背）
- **光影/色调暗示**：这场戏的光影基调（如：逆光剪影、低调暗影、暖色温馨、冷蓝压抑）
- **节奏标注**：快节奏（短镜头快切）/ 慢节奏（长镜头蓄势）/ 爆发（情绪高潮）

### Show Don't Tell 自查

写完每场戏对照：
- [ ] 有没有角色用台词直白说出自己的心理活动？→ 改用动作/道具/沉默表达
- [ ] 信息传递是通过"告诉"还是"呈现"？→ 尽量呈现
- [ ] 有没有潜台词空间？→ 角色嘴上说的和真实想法之间有没有缝隙
