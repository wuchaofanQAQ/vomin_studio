# 续写一致性自查清单

续写剧集最容易出现"剧情断钩、人设漂移、风格突变"三类问题。出稿前按此自查。

## 剧情承接

- [ ] 本集开头已回收上一集钩子
- [ ] 本集推进了分集大纲中该集的事件（未跑偏到别的集）
- [ ] 本集结尾留了新钩，且与大纲下一集衔接
- [ ] 未引入大纲外的新设定（如确需，须标注待确认）

## 角色一致性

- [ ] 每个出场角色外形符合角色档案（未擅自改服装/发型）
- [ ] 对白符合角色性格，未OOC（脱离人设）
- [ ] 标志性特征（道具/伤疤/口头禅）延续

## 画风/语气一致

- [ ] 基调（爽/虐/甜/悬疑）与剧本设定一致
- [ ] 与已有剧集的文风、节奏保持一致

## 单集质量

- [ ] 开场 5 秒抓人
- [ ] 单集推进一个核心事件 + 至少一个中段爽点/反转
- [ ] 结尾有钩子
