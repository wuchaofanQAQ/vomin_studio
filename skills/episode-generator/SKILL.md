# Episode Generator

## Overview

在"剧本设定 + 剧情大纲 + 角色档案 + 已有剧集"的约束下，滚动生成**下一集（或连续多集）的完整分集剧本**。核心职责是：忠实承接已有剧情的钩子与走向，同时保持角色一致性、画风一致性。

## Workflow

### Step 1 — 加载上下文

续写前必须读齐（缺则要求用户提供）：

1. **剧本设定**（世界观/画风/主线）
2. **全集剧情大纲**（尤其目标集的"分集大纲 + 集末钩子"）
3. **角色档案**（目标集出场角色的档案）
4. **已有剧集**（上一集结尾，确认上集留下的钩子）

只读目标集所需内容，不重读整本（控制体积）。

### Step 2 — 承接与设定本集

- 确认上一集钩子，本集**开头必须回收它**
- 对照分集大纲，锁定本集核心事件 + 出场角色
- 从角色档案对齐每个出场角色的外形与性格（不漂移）

### Step 3 — 生成完整分集剧本

按 `references/episode-template.md` 输出完整剧本：场次 + 对白 + 动作 + 情绪 + 节奏。铁律：

- 单集节奏：**开场 5 秒抓人 → 中段一个推进/爽点 → 结尾留新钩**
- 每集结尾必须有钩子，为下一集留牵引
- 对白符合角色性格（依据角色档案），不OOC（脱离人设）
- 动作/场景描述具体到可被后续"分镜 skill"拆解

编剧专业规则（提升剧本品质）：
- **Show, Don't Tell** — 用动作、画面、道具呈现信息，不让角色用台词说出心理活动。不写"他很紧张"，写"他反复点烟、手在抖、咖啡凉了没喝"
- **潜台词** — 角色嘴上说A，真正想表达B。镜头/动作要把B藏在A的缝隙里，不直白外露
- **情绪曲线** — 每集情绪不是平的：铺垫→升温→爆发→回落。吵架戏前先有一段平静铺垫，爆发后留一个沉默余韵
- **节奏张弛** — 文戏用长场景慢蓄势，动作戏/高潮用短场景快推进，快慢交替比一味快更有力
- **导演思维** — 场景描述不只写"发生了什么"，同时给出画面暗示（氛围/光线/道具特写），方便后续分镜直接拆解

### Step 4 — 输出与说明

输出完整分集剧本，附 2–3 行说明：承接了哪个钩子、本集推进了哪个剧情节点、结尾留了什么新钩。

## 批量规则

- 若要求续写多集，逐集生成，每集基于"上一集刚生成的结尾钩子"继续，保证连续。
- 支持"先出大纲级简版 → 确认后扩写成完整剧本"的两段式（视用户需要）。

## References

- `references/episode-template.md` — 完整分集剧本模板（必读）
- `references/consistency-check.md` — 续写一致性自查清单

## Automated Mode (Harness Integration)

当被 `ai-drama-harness` 调用时，本 skill **不输出结构化 JSON**（分集剧本是纯文本产物，不直接写入飞书表）。harness 将完整剧本文本作为下游 storyboard-generator 的输入上下文。

### 读取输入

```bash
python cli.py read $WS --table 剧本设定
python cli.py read $WS --table 角色库
python cli.py read $WS --table 角色档案
```

### 输出规范

正常 markdown 输出即可。确保包含：
- 集数标注
- 出场角色列表
- 上集钩子承接 + 本集结尾新钩
- 场次列表（场景名明确标注）
