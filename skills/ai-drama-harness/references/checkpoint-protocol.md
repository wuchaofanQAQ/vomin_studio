# 确认点标准流程

harness 全流程共 7 个确认点。每个确认点暂停等待用户输入，再继续下一步。

## 确认点一览

| # | 标题 | Phase | 确认方式 | 产出类型 |
|---|---|---|---|---|
| 1 | 剧本设定 | A1 | 对话确认 | 设定+大纲文本 |
| 2 | 角色档案 | A2 | 对话确认 | 角色档案文本 |
| 3 | 角色形象 | A3 | 飞书审核 | 角色形象图 |
| 4 | 核心场景 | A4 | 飞书审核 | 场景参考图 |
| 5 | 分集剧本 | B1 | 对话确认 | 单集剧本文本 |
| 6 | 分镜脚本 | B2 | 对话确认 | 分镜表文本 |
| 7 | 视频成片 | B3 | 飞书审核 | 视频+配音 |

## 对话确认模板（#1 #2 #5 #6）

```
--- 确认点 {N}: {标题} ---

{产出摘要：显示关键内容，如设定核心要素 / 角色列表 / 剧本梗概 / 分镜数量}

请确认：
  "确认" → 继续下一步
  "修改: <意见>" → 按意见调整后重来本步骤
  "重做" → 全部重新生成本步骤
```

### 处理逻辑

- **"确认"**: 将产出写入飞书（如尚未写入），进入下一步
- **"修改: XXX"**: 将修改意见追加到 skill 输入中，重新调用该 skill
- **"重做"**: 不带额外约束，重新调用该 skill

## 飞书审核模板（#3 #4 #7）

```
--- 确认点 {N}: {标题} ---

已生成 {数量} 个{资产类型}并推送到飞书。
请在飞书中查看并审核：
- 通过 → 保持"待审核"或改为"通过"
- 返工 → 将状态改为"返工"并填写审核备注

审核完成后回复"继续"。
```

### 处理逻辑

- **"继续"**: 
  1. 执行 `python cli.py pull $WS` 拉取最新状态
  2. 检查是否有"返工"状态的记录
  3. 有返工 → 读取审核备注，调整参数后重新生成，再次推送
  4. 无返工 → 进入下一步

## 跳过确认

如果用户在启动时说"全自动/不用确认/跳过确认"，harness 跳过所有对话确认点（#1 #2 #5 #6），但保留飞书审核点（#3 #4 #7），因为图片/视频必须人眼检查。
