# 场景空间设计文档模板

drama-episode-analyzer 为每个场景产出的结构化空间设计，写入场景库 `description` 字段。这就是各视角共用的 `<SPACE MAP>`。scene-image-prompt 直接复用，不再改写方位。不写"摄影机身后""画面左侧""P0 左手侧"。

## 格式规范

description 字段使用**紧凑文本格式**，`\n` 分隔模块，每个模块以 `【模块名】` 开头。不使用 Markdown 格式（description 是数据字段，不是文档）。

## 6 模块结构

### 1. 【场景基础】

```
【场景基础】{室内/室外}·{具体地点}，{风格（继承剧本设定）}，{光线时段}·{天气}·{色调}，{墙面材质}+{地面材质}+{家具材质}
```

示例：
```
【场景基础】室内·现代都市小户型出租屋，当代写实风，夜间·雨天·冷蓝调，水泥墙面+复合木地板+廉价板式家具
```

### 2. 【功能区】

```
【功能区】A区={功能}（{相对主轴方位}）B区={功能}（{方位}）C区={功能}（{方位}）
```

- 按空间自然分区命名（不超过 4 个区）
- 方位用北/南/东/西。需要左右墙时，写成"面朝 P1 时的左手侧墙（西墙）"

示例：
```
【功能区】A区=书桌工作区（西墙，面朝P1时的左手侧墙）B区=床铺休息区（东墙，面朝P1时的右手侧墙）C区=门厅（北墙，P0）
```

### 3. 【摄影主轴】

```
【摄影主轴】P0={锚点名}（{北/南/东/西}） → P1={锚点名}（{北/南/东/西}） M={主体名}。轴线从 P0 指向 P1。面朝 P1 时，左手侧墙是{东墙或西墙}，右手侧墙是{对面墙}
```

选择原则：
- **P0**（站位端）：角色最常进出的位置，通常为主入口/门洞
- **P1**（朝向端）：空间纵深终点，通常为主背景墙/主窗
- **M**（主体）：角色互动最多的物件/区域
- 剧本暗示的"镜头方向"优先

示例：
```
【摄影主轴】P0=入户门（北墙） → P1=窗台（南墙） M=书桌与办公椅。轴线从北指向南。面朝 P1 时，左手侧墙是西墙，右手侧墙是东墙
```

### 4. 【物件清单】

```
【物件清单】{物件1}：{区域}，{相对主轴方位}，{与邻近物件关系}；{物件2}：...
```

- **逐一列出**场景中每个物件（家具、电器、装饰物、固定结构）
- 每个物件必须写明：所在区域（A/B/C）、北/南/东/西、与最近物件的位置关系
- 正视图站在 P0 旁朝向 P1，拍不到的物件标注"正视图不入画"
- 从剧本动作中发现物件（角色"坐在沙发上"→ 有沙发；"从冰箱里拿啤酒"→ 有冰箱）
- 未在剧本中出现但空间合理必备的物件也要列出（如出租屋必有入户门即使剧本未提）

示例：
```
【物件清单】书桌：A区，西墙，桌面有笔记本电脑和外卖盒；办公椅：书桌东侧，面朝书桌；单人床：B区，东墙，床头朝北；衣柜：东墙，床尾与南墙窗台之间；入户门：北墙正中，门扇朝室内开，铰链在东侧，正视图不入画；窗台：南墙正中，窗户朝南
```

### 5. 【门窗】

```
【门窗】{门/窗1}：{位置}，{朝向/开向}，{铰链侧/类型}；{门/窗2}：...
```

- 每个门：位置 + 开向（朝内/朝外）+ 铰链侧
- 每扇窗：位置 + 朝向 + 类型（推拉/平开）

示例：
```
【门窗】入户门：北墙正中，朝内开，右侧铰链；窗户：南墙正中，朝南，推拉式
```

### 6. 【光源】（★必填）

```
【光源】{光源1}（{角色}）：{位置}，{类型}，{色温}，{照射方向/范围}，{光影效果}；{光源2}：...
```

- 光源角色：主光 / 补光 / 氛围光
- 类型：自然光 / 人造光
- 必须写明对哪些物件形成高光/阴影

示例：
```
【光源】窗外路灯（主光）：南墙窗户外，自然光，冷白，从南向北照入，照亮书桌台面和床脚，在衣柜西侧形成长条阴影；书桌台灯（补光）：书桌靠北端，人造光，暖黄，照亮台面，与南窗冷光形成冷暖对比
```

## 完整示例

场景：出租屋（来自剧本描述"张三在出租屋醒来，坐在书桌前看手机，走到窗前看窗外的雨"）

```
【场景基础】室内·现代都市小户型出租屋，当代写实风，夜间·雨天·冷蓝调，水泥墙面+复合木地板+廉价板式家具
【功能区】A区=书桌工作区（西墙，面朝P1时的左手侧墙）B区=床铺休息区（东墙，面朝P1时的右手侧墙）C区=门厅（北墙，P0）
【摄影主轴】P0=入户门（北墙） → P1=窗台（南墙） M=书桌与办公椅。轴线从北指向南。面朝 P1 时，左手侧墙是西墙，右手侧墙是东墙
【物件清单】书桌：A区，西墙，桌面有笔记本电脑和外卖盒；办公椅：书桌东侧，面朝书桌；单人床：B区，东墙，床头朝北，床上有凌乱被褥；床头柜：床头北侧，靠东墙，放手机和水杯；衣柜：东墙，床尾与南墙窗台之间；入户门：北墙正中，门扇朝室内开，铰链在东侧，正视图不入画；鞋架：北墙，入户门西侧，正视图不入画；窗台：南墙正中，窗台上放几本旧书和烟灰缸
【门窗】入户门：北墙正中，朝室内开，铰链在东侧，正视图不入画；窗户：南墙正中，朝南，推拉式，窗外可见对面楼房和路灯
【光源】窗外路灯（主光）：南墙窗户外，自然光，冷白，从南向北照入，穿过雨滴在地面投下斑驳光影，照亮书桌台面和床脚，在衣柜西侧形成长条阴影；书桌台灯（补光）：书桌靠北端，人造光，暖黄，照亮台面和键盘，与南窗冷光形成冷暖对比；走廊灯光（透光）：北墙入户门门缝，暖白，正视图不入画
```

## 室外场景补充说明

室外场景的 6 模块同样适用，但有差异：
- **功能区**：按空间自然分区（如"街道主路""人行道""店铺外立面"）
- **摄影主轴**：P0 通常为角色进入画面的方向，P1 为角色前进方向的远景
- **物件清单**：包含固定建筑物、路灯、车辆、摊位等
- **门窗**：改为"出入口/通道"清单（如"小巷入口""店铺门面"）
- **光源**：以自然光为主（太阳方位、时间段），辅以路灯/霓虹灯等
