# 场景空间设计文档模板

drama-episode-analyzer 为每个场景产出的结构化空间设计，写入场景库 `description` 字段。这就是全景基准图共用的 `<SPACE MAP>`。scene-image-prompt 直接复用，不再改写方位。不写"摄影机身后""画面左侧""P0 左手侧"。

## 格式规范

description 字段使用**紧凑文本格式**，`\n` 分隔模块，每个模块以 `【模块名】` 开头。不使用 Markdown 格式（description 是数据字段，不是文档）。

## 8 模块结构

### 1. 【场景基础】

```
【场景基础】{室内/室外}·{具体地点}，{风格（继承剧本设定）}，{光线时段}·{天气}·{色调}，{墙面材质}+{地面材质}+{家具材质}
```

示例：
```
【场景基础】室内·现代都市小户型出租屋，当代写实风，夜间·雨天·冷蓝调，水泥墙面+复合木地板+廉价板式家具
```

### 2. 【功能区】

```
【功能区】A区={功能}（{相对主轴方位}）B区={功能}（{方位}）C区={功能}（{方位}）
```

- 按空间自然分区命名（不超过 4 个区）
- 方位用北/南/东/西。需要左右墙时，写成"面朝 P1 时的左手侧墙（西墙）"

示例：
```
【功能区】A区=书桌工作区（西墙，面朝P1时的左手侧墙）B区=床铺休息区（东墙，面朝P1时的右手侧墙）C区=门厅（北墙，P0）
```

### 3. 【摄影主轴】

```
【摄影主轴】P0={锚点名}（{北/南/东/西}） → P1={锚点名}（{北/南/东/西}） M={主体名}。轴线从 P0 指向 P1。面朝 P1 时，左手侧墙是{东墙或西墙}，右手侧墙是{对面墙}
```

选择原则：
- **P0**（站位端）：角色最常进出的位置，通常为主入口/门洞
- **P1**（朝向端）：空间纵深终点，通常为主背景墙/主窗
- **M**（主体）：角色互动最多的物件/区域
- 剧本暗示的"镜头方向"优先

示例：
```
【摄影主轴】P0=入户门（北墙） → P1=窗台（南墙） M=书桌与办公椅。轴线从北指向南。面朝 P1 时，左手侧墙是西墙，右手侧墙是东墙
```

### 4. 【物件清单】

```
【物件清单】{物件1}：{区域}，{相对主轴方位}，{与邻近物件关系}；{物件2}：...
```

- **逐一列出**场景中每个物件（家具、电器、装饰物、固定结构）
- 每个物件必须写明：所在区域（A/B/C）、北/南/东/西、与最近物件的位置关系
- 全景基准图（45° 斜角机位，见【基准图机位】）拍不到的物件标注"全景基准图不入画"
- 从剧本动作中发现物件（角色"坐在沙发上"→ 有沙发；"从冰箱里拿啤酒"→ 有冰箱）
- 未在剧本中出现但空间合理必备的物件也要列出（如出租屋必有入户门即使剧本未提）

示例：
```
【物件清单】书桌：A区，西墙，桌面有笔记本电脑和外卖盒；办公椅：书桌东侧，面朝书桌；单人床：B区，东墙，床头朝北；衣柜：东墙，床尾与南墙窗台之间；入户门：北墙正中，门扇朝室内开，铰链在东侧，全景基准图不入画；窗台：南墙正中，窗户朝南
```

### 5. 【门窗】

```
【门窗】{门/窗1}：{位置}，{朝向/开向}，{铰链侧/类型}；{门/窗2}：...
```

- 每个门：位置 + 开向（朝内/朝外）+ 铰链侧
- 每扇窗：位置 + 朝向 + 类型（推拉/平开）

示例：
```
【门窗】入户门：北墙正中，朝内开，右侧铰链；窗户：南墙正中，朝南，推拉式
```

### 6. 【光源】（★必填）

```
【光源】{光源1}（{角色}）：{位置}，{类型}，{色温}，{照射方向/范围}，{光影效果}；{光源2}：...
```

- 光源角色：主光 / 补光 / 氛围光
- 类型：自然光 / 人造光
- 必须写明对哪些物件形成高光/阴影

示例：
```
【光源】窗外路灯（主光）：南墙窗户外，自然光，冷白，从南向北照入，照亮书桌台面和床脚，在衣柜西侧形成长条阴影；书桌台灯（补光）：书桌靠北端，人造光，暖黄，照亮台面，与南窗冷光形成冷暖对比
```

### 7. 【画面分层】（★必填）

```
【画面分层】前景={有哪些物件/人物层次}；中景={有哪些物件/活动层次}；远景={有哪些物件/空间层次}；画面由近及远依次为{...}，形成{纵深/层次关系}
```

- **必须写清三个景深层次各有什么**，以及它们的前后遮挡、画面布局关系
- 这是描述的重中之重：分镜（storyboard-prompt）直接据此设计镜头站位、人物调度、构图纵深
- 前景通常是靠近机位、可遮挡的物件（椅背、桌角、柜边、门框）；中景是主要活动区；远景是空间纵深的终点（窗台、背景墙、走廊尽头）

示例：
```
【画面分层】前景=办公椅椅背与床脚（画面右下角）；中景=书桌台面、键盘与外卖盒，单人床中段；远景=南墙窗台、窗外路灯与对面楼剪影；画面由近及远依次为椅背→书桌→窗台，形成明显纵深
```

### 8. 【基准图机位】（★必填）

```
【基准图机位】室内基准图：机位高1.5米平视，45°斜角置于{本场景角落}位看向对角{角落}，35mm小广角；画面纳入{本角落}相邻的两面墙与核心陈设
```

每个场景只有一个**全景基准图**，不生成其他视角图。机位按统一的相机参数标准为本场景选一个具体角落/朝向（见下方「相机参数标准」）。

示例（矩形客厅，四角 A/B/C/D，相机放靠近 A 角位置看向对角 C）：
```
【基准图机位】室内基准图：机位高1.5米平视，45°斜角置于A角位看向对角C，35mm小广角；画面同时看见A角相邻的两面墙，沙发、茶几、门窗均落入画面
```

## 相机参数标准（全景基准图）

每个场景默认只生成一张**全景基准图**，机位按以下标准设定（只写进【基准图机位】，不额外生成多视角图）。

**室内场景（占 90% 短剧场景：客厅、卧室、书房、病房、办公室）**

- 机位高度：**1.5 米**，成年人平视高度（不仰、不俯；仰俯留给分镜镜头）
- 水平角度：**45° 斜角**，站在房间一个角落外侧，看向对角。例：矩形客厅四角 A/B/C/D，相机放靠近 A 角位置看向对角 C；画面里同时看见【A 相邻的两面墙】，沙发、茶几、门窗这些核心陈设都落在画面内
- 镜头焦距：**35mm**（小广角）

**室外场景（街道、别墅大门、停车场、医院门口）**

- 常规外景：平视，45° 斜侧，35mm，略微拉开距离，拍到主体建筑 + 周边环境。例：别墅大门基准图，斜着拍大门，同时拍到一部分院墙和门前空地，不是正对着大门
- 狭长外景（走廊、地下通道）：可稍微偏 **30°**，不要正对着通道深处（正对通道容易产生隧道视觉，机位很难复用）

**特殊固定机位场景（监控视角、固定窗边机位）**

- 只有这类特殊固定机位场景才单独改相机；其余一律用上面的默认标准。

## 完整示例

场景：出租屋（来自剧本描述"张三在出租屋醒来，坐在书桌前看手机，走到窗前看窗外的雨"）

```
【场景基础】室内·现代都市小户型出租屋，当代写实风，夜间·雨天·冷蓝调，水泥墙面+复合木地板+廉价板式家具
【功能区】A区=书桌工作区（西墙，面朝P1时的左手侧墙）B区=床铺休息区（东墙，面朝P1时的右手侧墙）C区=门厅（北墙，P0）
【摄影主轴】P0=入户门（北墙） → P1=窗台（南墙） M=书桌与办公椅。轴线从北指向南。面朝 P1 时，左手侧墙是西墙，右手侧墙是东墙
【物件清单】书桌：A区，西墙，桌面有笔记本电脑和外卖盒；办公椅：书桌东侧，面朝书桌；单人床：B区，东墙，床头朝北，床上有凌乱被褥；床头柜：床头北侧，靠东墙，放手机和水杯；衣柜：东墙，床尾与南墙窗台之间；入户门：北墙正中，门扇朝室内开，铰链在东侧，全景基准图不入画；鞋架：北墙，入户门西侧，全景基准图不入画；窗台：南墙正中，窗台上放几本旧书和烟灰缸
【门窗】入户门：北墙正中，朝室内开，铰链在东侧，全景基准图不入画；窗户：南墙正中，朝南，推拉式，窗外可见对面楼房和路灯
【光源】窗外路灯（主光）：南墙窗户外，自然光，冷白，从南向北照入，穿过雨滴在地面投下斑驳光影，照亮书桌台面和床脚，在衣柜西侧形成长条阴影；书桌台灯（补光）：书桌靠北端，人造光，暖黄，照亮台面和键盘，与南窗冷光形成冷暖对比；走廊灯光（透光）：北墙入户门门缝，暖白，全景基准图不入画
【画面分层】前景=办公椅椅背与床脚（画面右下角）；中景=书桌台面、键盘、外卖盒与单人床中段；远景=南墙窗台、窗外雨景与对面楼剪影；画面由近及远依次为椅背→书桌→窗台，形成明显纵深
【基准图机位】室内基准图：机位高1.5米平视，45°斜角置于北墙入户门旁位看向对角南窗，35mm小广角；画面纳入北墙相邻的东墙与西墙，书桌/床/窗台均落入画面
```

## 场景抽取规则（是否新增场景）

drama-episode-analyzer 在逐集抽取场景时，按下述两条规则判定是否新建一个场景行（详见 `drama-episode-analyzer/SKILL.md` 的「场景抽取规则」专节）：

1. **空间连通性**：区域间被**实体墙/门阻挡、不互通** → 2 个独立场景（客厅与卧室、客厅与卫生间各算一个）；**互通** → 1 个场景（客厅与开放式厨房互通 = 1 个；封闭式厨房有墙/门阻挡 = 2 个）。
2. **光影/时刻**：同一空间不同时刻、光影不同 → 拆分为不同场景行（`出租屋·夜` 与 `出租屋·日` 是两个场景行），场景名需体现时刻/光影。

## 室外场景补充说明

室外场景的 8 模块同样适用，但有差异：
- **功能区**：按空间自然分区（如"街道主路""人行道""店铺外立面"）
- **摄影主轴**：P0 通常为角色进入画面的方向，P1 为角色前进方向的远景
- **物件清单**：包含固定建筑物、路灯、车辆、摊位等
- **门窗**：改为"出入口/通道"清单（如"小巷入口""店铺门面"）
- **光源**：以自然光为主（太阳方位、时间段），辅以路灯/霓虹灯等
- **画面分层**：前景=近处行道树/车辆/栏杆等；中景=主体建筑/人物活动区；远景=街景尽头/天际线
- **基准图机位**：室外基准图按「相机参数标准」——平视 45° 斜侧拉开距离拍到主体+环境；狭长外景偏 30° 不正对深处
