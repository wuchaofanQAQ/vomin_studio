# 角色档案字段模板（Character Bible · 完整版）

每个角色一份。逐字段抽取，缺失标"未指定"，不臆造。标注每个模块的**下游消费方**，确保字段可落地。

## A. 基本信息

- **角色名**
- **定位**：主角 / 反派 / 关键配角 / 龙套
- **出场集数范围**：第 X–Y 集
- 身份（职业 / 社会角色）
- 性别
- 关系定位（与主角/其他角色的关系）

> 消费方：harness 编排、storyboard-prompt。

## B. 风格层（一致性基调，★ 必须与剧本匹配）

- **画风基调**：从剧本设定继承（电影级写实/日系动漫/古风水墨/赛博…）——必须与剧本设定一致，不另行发挥
- **主色调倾向**：角色专属配色（如冷蓝 / 暖金），用于统一出图与特效
- **整体气质**：一个词概括（冷峻/飒/温润/痞…）

> 消费方：character-three-view-prompt（三视图画风）、scene 特效、视频一致性。

## C. 音色层（配音/口播用）

- **音色描述**：男/女、年龄段、音质（低沉/清亮/沙哑/磁性…）
- **语速与语气**：快/慢、冷/热、口头习惯
- **口音/方言**（如有）

> 消费方：配音 / 口播生成、TTS。

## D. 外貌层（出图用，★ 喂给三视图）

**脸部细节**
- 年龄 / 年龄段
- 脸型（方/圆/瓜子/长脸…）
- 头发（发色、长度、造型、发质）
- 眼睛（眼型、瞳色、眉形）
- 鼻子（高/直/小巧…）
- 嘴巴（唇形、厚薄）
- 肤色（白/小麦/深…）

**身体**
- 体型（身高比例、胖瘦）
- 体态（挺拔/佝偻/慵懒…）
- 肩宽 / 身形特征

**服装与配饰**
- 上装 / 下装 / 外套（款式、颜色、材质）
- 配饰（饰品、眼镜、帽子、手套、项链…）
- 标志性特征（伤疤、纹身、胎记、道具、独特穿着）——**一致性锚点，必写**

> 消费方：character-three-view-prompt（4张照片直接据此生成）。

## E. 性格层（写剧/对白用）

- 性格（外向/内敛/暴躁/冷静…多维度）
- 动机 / 目标（外部目标 + 内心需求）
- 弱点 / 软肋
- 说话风格（简短/话痨/阴阳怪气…）

> 消费方：storyboard-prompt（角色演出与对白不 OOC）。

## F. 战斗层（打斗/特效用，★ 动作戏专用）

- **战斗风格（常规）**：整体打法定位（近身格斗/远程/法术/敏捷/坦克…）+ 武器（如有）
- **战斗招式**：常用招式清单（命名 + 动作描述）
- **阶段状态**：不同阶段/状态对应的视觉变化——
  - 常态 → 颜色/形态
  - 暴走/变身/升级 → 颜色/光效/特效变化
  - 受伤/残血 → 视觉表现
- **特效特征**：招式伴随的特效（火焰/雷电/寒冰/能量光/粒子…）
- **战斗姿态**：起手式、蓄力、爆发等标志性姿态

> 消费方：打斗/特效分镜、视频生成（动作与特效一致性）。

## G. 标志性表达层（角色记忆点）

- **经典动作**：标志性动作/手势/习惯动作（如撩发、转刀、扶眼镜…）
- **经典台词**：口头禅 / 金句 / 标志性台词（含语气）
- **标志性道具**：随身物件（如有）

> 消费方：storyboard-prompt（台词、动作、道具）、视频特效。

## H. 标注与交接

- **来源集数**：从第几集抽取
- **缺失项清单**：明确列出"未指定"项，提醒后续补齐
- **资产状态**：三视图是否已生成 / 档案是否待更新

**交接映射**：
- 外貌(D) + 风格(B) → `character-three-view-prompt`
- 性格(E) + 台词(G) → `storyboard-prompt`（分镜演出与台词）
- 战斗(F) + 特效(F) → `storyboard-prompt`（打斗/特效镜头）、视频生成
- 音色(C) → 配音/TTS
