# 改编的方法：先看懂，再动笔

这份文档是 `SKILL.md` 的展开，不是另一套规则。它回答三个问题：

1. 拿到一段原文（可能跨几章），先看什么？
2. 怎么判断这一集该用什么结构？
3. 写完之后，怎么知道它是“戏”还是“说明”？

---

## 一、小说和剧本是两种东西

| 小说 | 剧本 |
|---|---|
| 可以告诉读者“她心里像被针扎了一下” | 只能让人看见她的手在抖 |
| 时间可以自由跳 | 时间就是屏幕上的秒 |
| 作者可以解释因果 | 观众自己从行为里推因果 |
| 读者可以停下来想 | 观众随时会划走 |
| 篇幅不设限 | 60~120 秒 |

所以改编不是“缩写”，是三次翻译：

### 1. 时间翻译

小说里的“六年”“从小”“后来”“那天之后”，在剧本里必须变成一个**现在时的动作或物证**：

- 六年 → 他手机里一张没删的旧照片，或一扇从不让人进的卧室门。
- 从小 → 一只用了很多年的旧碗，或一句“你小时候也这样”。
- 后来 → 不解释，让观众从现在的状态倒推。

闪回可以用，但它是**最后手段**，不是默认手段。一个物证能说清的，不要用闪回。

### 2. 心理翻译

小说的心理描写分三档：

- **信息、立场、决定** → 可以留成 OS。
- **身体感觉、情绪、观察、犹豫** → 转成动作、表情、镜头里的细节。
- **比喻、形容、作者的评论** → 删。

不要逐句翻译心理。一段 200 字的心理，落到剧本里可能只有一句 OS 加一个动作。

### 3. 因果翻译

小说可以写“因为从小到大，母亲都偏心弟弟，所以她不再相信任何人”。剧本不能这么写。剧本要让人看见：

- 一个具体的偏心事件（现在时）。
- 她的一个选择（不是“她决定不信人”，而是“她把递过来的钱推回去”）。
- 这个选择的代价。

**因果要变成选择，选择要付代价。**

## 一之一、阅读窗口与取材区间（不是一章一集）

**章是原文的切分，集是戏的切分。** 改编时先有“这一集要什么”，再回原文截取。

### 阅读窗口

- 从上一集结束句往后读，默认 2~3 章。
- 本集明显跨更多章，就继续读，直到找到：一个完整的问题、2~5 个 turn、一个能接的钩子。
- 窗口可以比本集用到的范围大；多读是为了判断“在哪切”，不是为了全拍。
- 不读全书；也不只读一章。

### 取材区间

- 用两句原文定位：**起始句 → 结束句**。
- 可以从某章中段开始、到另一章中段结束；不需要“整章”。
- 结束句要选在“下一集能直接接”的位置：动作完成、问题抛出、门关上/打开、话说一半。
- 区间写进剧本抬头 `原文区间：`，并写进交稿说明。

### 章号是结果

先定区间，再从区间反推 `对应原小说章节`：

- 从第 2 章中段到第 4 章前段 → `2,3,4`。
- 只用第 5 章一部分 → `5`。
- 不要求从 1 开始，也不要求连续；用了哪几章写哪几章。

### 反例

- “第 1 集拍第 1 章，第 2 集拍第 2 章”——这是章节的惯性，不是戏的结构。
- “这章还有两场没拍，再加一集”——如果那两场不构成一个独立问题，应该并进这一集或删掉。
- “这章拍完了，所以这一集结束”——如果结尾没有钩子，这一集不成立，回窗口重切。

## 二、五本账的用法

### 1. 故事发动机

不是“这一段讲了什么”，是“这一集谁在要什么，为什么现在要，失败会怎样”。

一个可用的测试：**把主角的目标换掉，这一集还成立吗？** 如果换成任何目标都成立，说明这一集没有发动机，只有事件。

### 2. 人物筹码

短剧里的人物不是靠“性格”立住的，是靠**筹码**：

- 他有什么别人要的？
- 他怕失去什么？
- 他敢做到哪一步？

一场戏里，筹码必须移动。一个人求另一个人，如果对方没有理由拒绝，这场戏就没有张力；如果对方有理由拒绝，但他偏偏答应了，观众就想知道他为什么。**筹码移动的那一刻，就是戏眼。**

### 3. 信息差

信息差是短剧最便宜的戏剧性。三个基本盘：

- **观众知 / 角色不知**：观众替角色紧张。适合危机、背叛、身份揭穿前的铺垫。
- **角色知 / 观众不知**：观众想知道他到底瞒了什么。适合悬疑、复仇、双面人。
- **A 知 / B 不知**：看谁先露底。适合对峙、谈判、感情博弈。

一集只选一个主引擎，不要三个一起转。三个一起转，观众一个都记不住。

### 4. 情绪账

短剧不是“情绪一直高”，是“憋—放—再憋—再放”。

- 先让观众憋：她被拒之门外、他被当众羞辱、真相说不出口。
- 再给一个落点：门开了、巴掌落下了、那句话终于说出口。
- 落点之后马上开新账：门开了，但“你爸呢”把暖意变成审问。

**只有憋没有放，观众会弃剧；只有放没有憋，观众会麻。**

### 5. 不可替代的场景

每本小说都有几场“读者就是为了这个才看下去”的戏。改编的第一优先级是保住它们，第二优先级才是删减。

判断标准：**把这场删掉，读者会不会觉得“这本书白看了”？** 会，就是名场面；不会，就是可删的解释性场景。

名场面不能只复述。要重新设计：

- 观众先看到什么，后看到什么？
- 谁在场，谁不在场？
- 这场结束时，观众多知道了什么？
- 有没有一个可以被记住的动作/物件/台词？

## 三、结构菜单详解

结构不是情节，是**信息和压力的排列方式**。同一个故事，换一种结构，观众的感受完全不同。

### 1. 对峙

**适用**：摊牌、认亲、逼问、分手、谈判、审问。

**戏眼**：谁先眨眼；谁握着对方要的东西；谁可以随时走却没有走。

**陷阱**：两个人吵得很凶，但谁也没有得到/失去什么。修法：给一方一个对方要的筹码，让让步有代价。

### 2. 揭秘

**适用**：身世、背叛、证据、悬疑、双面人。

**戏眼**：最后一块拼图；或者观众比角色先知道，看着角色往坑里走。

**陷阱**：靠角色口述资料推进。修法：让揭示带来一个即时的后果——有人必须当场做出反应，或者一个关系当场破裂。

### 3. 倒计时

**适用**：救人、赶车、手术、拆迁、限期、最后一通电话。

**戏眼**：最后一秒的代价；为了赶上，主角失去了什么。

**陷阱**：倒计时是假的，人物不真的失去。修法：让时间真的拿走一样东西——机会、信任、一个人的命。

### 4. 闯关

**适用**：求职、比赛、寻人、复仇、升级、连续打脸。

**戏眼**：用不同的方式过同一类关；每一次过关都带出一个更大的问题。

**陷阱**：重复同一种阻碍，观众第三关就疲劳。修法：换阻碍的性质（人→规则→时间→自己），不要只换对手。

### 5. 关系推进

**适用**：甜宠、暧昧、姐妹、母子、搭档、日常。

**戏眼**：一个越界的小动作——多看一眼、递一次东西、替对方挡一句。

**陷阱**：没有变化，变成日常流水账。修法：每一场让信任/权力/亲密度移动一格，哪怕只移动一格。

### 6. 多方博弈

**适用**：家族、宫斗、商战、群像、多方谈判。

**戏眼**：谁背叛了谁；谁在说谎；谁手里的信息最值钱。

**陷阱**：人物太多，观众记不住。修法：一场只给两到三方，每方一个明确的当场目标；其余人留在画外。

### 7. 重复变奏

**适用**：打脸、重生、日常、训练、循环、复仇。

**戏眼**：最后一次的不同；同一个动作，这次有了新的意义。

**陷阱**：重复没有升级。修法：每次重复必须改变一个变量——对象、代价、旁观者、主角的态度。

### 8. 情绪爆点

**适用**：葬礼、分手、认错、告别、崩溃、久别重逢。

**戏眼**：那句说不出口的话；那个终于落下的动作。

**陷阱**：只有情绪，没有选择。修法：让角色在两种痛苦里选一个——说出来会毁掉关系，不说会毁掉自己。

### 9. 发现-选择

**适用**：伦理困境、复仇、亲情、身份、秘密。

**戏眼**：选择的代价；两个坏选项里，他选了哪个。

**陷阱**：发现太容易，选择没有代价。修法：让发现本身需要付出代价（偷看、背叛、撒谎），让选择不可逆。

### 10. 荒诞反差

**适用**：喜剧、沙雕、反套路、黑色幽默。

**戏眼**：错位的尊严——一个很认真的人在一个很荒唐的处境里。

**陷阱**：只有梗，没有人物。修法：给荒唐的人一个真实的欲望，让观众笑完之后有点心疼。

### 结构可以组合

一集里可以“对峙 + 揭秘”，也可以“倒计时 + 发现-选择”。但**一集只选一个主结构**，其余是配角。主结构太多，观众不知道自己在看什么。

## 四、按题材选发动机（起点，不是答案）

| 题材 | 常用主结构 | 常用信息差 | 小心 |
|---|---|---|---|
| 甜宠 / 暧昧 | 关系推进 | 他喜不喜欢我 / 她有没有别人 | 不要靠误会拖十集 |
| 复仇 / 打脸 | 闯关 + 重复变奏 | 观众知 / 反派不知 | 不要每集都靠新反派 |
| 悬疑 / 身份 | 揭秘 + 倒计时 | 角色知 / 观众不知 | 不要靠角色口述线索 |
| 家庭 / 亲情 | 对峙 + 情绪爆点 | A 知 / B 不知 | 不要用“都是为了你好”解释一切 |
| 职场 / 商战 | 多方博弈 + 闯关 | A 知 / B 不知 | 不要人物太多 |
| 古装 / 宫斗 | 多方博弈 + 揭秘 | 观众知 / 角色不知 | 不要靠下跪、扇耳光推进 |
| 喜剧 / 沙雕 | 荒诞反差 + 重复变奏 | 观众知 / 角色不知 | 不要只有梗没有人物 |
| 治愈 / 日常 | 关系推进 + 重复变奏 | 角色知 / 观众不知 | 不要没有变化 |

这张表只是起点。真正决定结构的，是这一集的问题、阻力和观众在等什么，不是题材标签。

## 五、失败模式：症状 → 真正的问题 → 怎么修

| 症状 | 真正的问题 | 怎么修 |
|---|---|---|
| 每集都从门铃/手机消息/走路开始 | 依赖原文顺序，没有“晚进” | 从冲突的结果开始，原因后面补 |
| 每场都在吵，但没有输赢 | 没有筹码转移 | 给一方一个对方要的东西，让让步有代价 |
| 反转很多，但不惊喜 | 没有埋信息，或反转不改关系 | 前面埋一个细节，反转后让它重新有意义 |
| OS 很多，但人物不立体 | OS 在解释，不在行动 | 删复述，留决定；把情绪改成动作 |
| 台词很漂亮，但不像人话 | 书面语、金句癖 | 读出声，改短句，一集只留 1~2 句金句 |
| 观众看不懂谁是谁 | 人物没有可辨认的欲望/动作 | 给每人一个当场目标和一个标志动作 |
| 情绪上不去 | 主角没有付出代价，没有选择 | 堵死退路，让他在两个坏选项里选 |
| 结尾不想看下一集 | 钩子不是本集后果，或没有新问题 | 用“欠/瞒/逼/失/变”重写 |
| 节奏拖 | 一场里有多个 turn，或解释太多 | 拆场，删解释 |
| 节奏碎 | 信息换得太勤，没有一场待够 | 让一场戏升级，不要每两秒换一个信息 |
| 像小说朗读 | 大量 OS/旁白/形容词 | 转成动作、台词、物件 |
| 像小品 | 只有对话，没有空间/动作/物件 | 加走位、道具、身体 |
| 人物 OOC | 台词/行为不符合筹码和底线 | 回到人物账本，重写这场 |
| 前后矛盾 | 状态没跟 | 列状态表：门、手、衣、伤、屏幕、时间 |
| 场景像布景 | 空间没有权力关系 | 用门/窗/出口/座位安排人 |
| 结尾靠新人物/新车祸 | 钩子作弊 | 用本集已经点燃的火 |
| 每集都像上一集 | 结构复制 | 换空间/视角/时间/胜负中的一个 |
| 观众提前猜到 | 进场太早，信息给太全 | 从最晚的切入点进，留一手 |

## 六、AI 腔的十个症状

大模型写剧本，最容易写出“很像剧本、但没有人味”的东西。逐条自查：

1. **每句都像金句**：排比、对仗、警句密度过高。真人有话说不出的时候。
2. **滥用“不是……而是……”**：一次是锋刃，三次是口头禅。
3. **用形容词代替动作**：“气氛凝固”“空气里全是压迫感”——拍不出来。
4. **所有人都说同一种聪明话**：不同年龄、职业、阶层的人，词汇和句长应该不同。
5. **OS 解释主题**：“原来，有些门一旦关上，就再也打不开了。”——这是作者，不是人物。
6. **每场都停在意味深长的沉默**：沉默用多了，就是没有戏。
7. **每场都下雨/逆光/慢动作**：氛围不能代替事件。
8. **人物没有具体生活**：没有工作、没有账单、没有手上的活。具体的生活细节，比十句心理更立得住。
9. **台词没有对象感**：像独白，不像在跟对面的人说话。每句台词都要有一个“我要你……”的潜台词。
10. **结尾都用旁白总结**：“他不知道，这一切才刚刚开始。”——删掉，让画面自己说。

修法：读出声；删掉三成修饰；给每个人一个具体的动作/物件；让至少一个人说错话、说废话、说不出口。

## 七、一个完整的思考示例

> 示例素材来自本项目第 1 集。它展示的是**判断过程**，不是供套用的模板。

### 原文（节选）

> 门铃响，短促又怯生。陈诚码字正到关键处，眉头一拧，扯了扯领口，大裤衩拖鞋啪嗒啪嗒蹚过客厅，一把拽开门。热浪糊脸。门口站着个女孩，安静得不像活人，目光死死盯着自己的鞋尖。

### 五本账

**故事发动机**：陈诚想安安静静码字、不想被沈家再拖累；沈幼怡想进门、想被收留。阻力是陈诚对沈家的旧怨。失败的话，她无处可去；他则要再一次被“沈家”绑住。

**人物筹码**：陈诚有房子、有门、有“说不”的权力；沈幼怡有“沈幼怡”这个名字（对陈诚是旧疤）、有陈诚他妈发来的消息、有“沈家”的钱和身份。她怕被赶走；他怕被再次拖累。

**信息差**：观众不知道“沈幼怡”三个字对陈诚意味着什么；陈诚不知道她为什么来；沈幼怡不知道她妈和陈诚的过去。主引擎选“A 知 / B 不知”的博弈，副引擎是“角色知 / 观众不知”的悬念。

**情绪账**：先憋（她被拒、门关上），再心疼（她在门外站了一个小时），最后给一点暖（他开门），但马上用“你爸呢”把暖意变成审问。钩子是“你爸呢”——不是新事件，是本集刚打开的门带来的新问题。

**不可替代的场景**：手机屏幕抵在门缝里；“沈幼怡”三个字让陈诚变脸；门关上后她没走。这三场必须保留。

### 集问题

**他会不会让她进门？**

### 结构

**对峙 + 揭秘**。主结构是对峙（门里门外，两个人互相要东西），副结构是揭秘（她的名字揭开他的旧疤）。

### Turn

1. 他拒绝（“找错了吧”）。
2. 她亮出名字（手机屏幕）——他发现她是谁。
3. 他关门——他选择不认。
4. 他发现她没走——他的选择被动摇。
5. 他开门，但用“你爸呢”把收留变成审问——关系变了，但没变好。

### 场表（内部）

| 场 | 地点/时间 | 谁想要什么 | 谁挡 | 转移 | 戏眼 | 出口状态 |
|---|---|---|---|---|---|---|
| 1 | 门口/日 | 她想进门 | 他不想认 | 她亮名字，他变脸 | 手机屏幕抵在门缝 | 门关上 |
| 2 | 玄关/日 | 他想让她走 | 她站着不动 | 他发现她没走 | 猫眼里的浅蓝色 | 他开门 |
| 3 | 门口/日 | 他想要答案 | 她说不出口 | 她用手机答 | “妈妈说，给你发过信息了” | 他得知她妈发过消息 |
| 4 | 玄关/日 | 他想维持距离 | 她进来了 | 沈崇山的消息 | “你哥哥会照顾好你的” | 他气笑，关系变成“照顾” |

### 剧本（第一场片段，只示范写法）

```text
剧名：养妹失策，社恐妹妹占有欲爆棚
第1集　如果你不想要我，我可以走
对应原小说章节：1
原文区间：第1章「门铃响，短促又怯生」→ 第1章「你哥哥会照顾好你的」
预估时长：约 88 秒｜4 场

1．外景　陈诚公寓门口　日
人物：沈幼怡、陈诚
备注：八月末下午两点，地表四十度，热浪贴地
本场预估：约 28 秒

△ 门开一条缝，陈诚堵在缝里，头发被汗黏在额角。
陈诚（不耐烦）：「找错了吧？」
△ 门外，沈幼怡的手还悬在门铃上，没来得及收回。
△ 浅蓝碎花裙的后背湿了一片，行李箱立在右脚边，拉杆拉出三节。
△ 陈诚的视线从她脸上扫到行李箱，又扫回来。
△ 沈幼怡没抬头，从书包侧袋抽出手机，屏幕转过来。
（字幕·手机）我是沈幼怡。
△ 陈诚盯着那行字，门缝里的半张脸僵住。
陈诚（OS，压着火）：「沈幼怡。这三个字，是我亲手捂了六年的旧疤。」
△ 门要合上。沈幼怡伸手，把手机抵在门缝里。
△ 门停住。
（音效）门轴响了一声。
△ 门合上。
（音效）门锁「咔」一声。
```

### 复盘

1. **晚进**：原文从门铃开始，剧本从门开一条缝开始。门铃已经响过，观众从“找错了吧”进入冲突，不需要看她走路、抬手。
2. **物证**：行李箱、湿透的后背、没撕膜的手机，替代了“她从外地来、她很有钱、她很紧张”的解释。
3. **OS 只在 turn 上**：第一场只留一句 OS——“沈幼怡。这三个字……”。它同时承担信息（他认识她）和态度（旧疤）；删掉它，观众就不懂他为什么变脸。门口那点“嫌烦”，交给动作和台词，不用 OS 再说一遍。
4. **钩子是本集的后果**：第三场门开了，但“你爸呢”把“收留”变成“审问”；第四场沈崇山的消息再把“照顾”变成交易。下一集可以直接从这笔账开始，不需要新事件。
5. **Step A 没有镜头术语**：没有景别、机位、运镜。此时编剧只决定观众看见什么、听见什么、什么时候知道；镜头在 Step B 才加（见 `cut-format.md`）。

## 八、续集怎么接

不要用“章”当进度条。用上一集抬头的 `原文区间` 结束句定位；没有区间，就用剧本的**最后一场/最后一个动作**回原文对。

1. 读上一集剧本全文（`read --table 剧本表 --episode N-1`），先看抬头的 `原文区间` 结束句；找不到，再看最后 3~5 个动作/台词。
2. 拿最后几行去对小说原文，找到它对应的**最后一句原文**。
3. 续集从这句之后开始读窗口：不重复、不跳漏。
4. 上一集的钩子必须在第一场被接住：回答它、推进它，或让它变得更糟。
5. `对应原小说章节` 由本集的原文区间反推；一章用了一半也写该章。

**不要用“上一集用了第 1 章，这一集就用第 2 章”来推进。** 一章可以拆成三集，三章也可以并成一集。进度以“剧本已经拍到哪一句”为准。

### 重做已有集

- 旧 `对应原小说章节` 不是范围，只是上一版的结果。
- 用户只说“重做一下”时，先问清范围；不要拿旧字段猜。
- 用户提到具体情节/台词，先在原文里定位这句，再定起点/终点；不要凭旧章号找。
- 先问清楚：重做的是结构、时长、取材范围，还是某几场？
- 默认起点仍是 N-1 的结束句；终点由新要求决定，可能比旧版更远或更近。
- 用户点名“从第 5 章开始重做”，以用户为准；读第 5 章及前后各 1 章确认边界。
- 重写后必须更新 `原文区间` 和 `对应原小说章节`；旧值只用来对比“改了什么”。
- 新范围与 N+1 集重叠或跳空，先报告，等用户确认再写。
- 重做后旧分镜/提示词作废，提示下游重跑，不要沿用。

## 九、几条我自己的判断

这些不是规则，是我写短剧时反复验证过的判断。它们可以商量，但不能不知道。

1. **短剧卖的是“未结算的账”**。观众留下来，不是因为事件多，是因为有一笔账没结：谁欠谁、谁瞒谁、谁还没低头。每集结一点，再开一笔。
2. **观众记不住事件，记得住反应**。一巴掌只有半秒，反应有三秒。把时间给反应，不要给解释。
3. **人物不是性格，是筹码**。他说自己善良没用；他在能拿走对方一切的时候选择不收，才有用。
4. **信息差是免费的戏剧性**。大多数改编失败，不是因为不会写台词，是因为让所有人太快知道了所有事。
5. **场是权力转移**。谁能让谁留下、谁能让谁闭嘴、谁可以转身走——一场戏结束时，这个答案必须变。
6. **钩子要长在本集身上**。凭空扔一个新车祸，是收买；本集的选择带来一个无法回避的后果，才是钩子。
7. **重复是短剧的语法**。同一句话第二次说、同一扇门第二次开、同一碗面第二次端上来——观众会自己比较。用得好，比新事件有力。
8. **代价是情节的燃料**。主角得到任何东西，都要失去一点什么。没有代价的胜利，观众不信。
9. **节奏是呼吸，不是快**。一直高，观众会麻；一直低，观众会走。憋—放—再憋—再放。
10. **结尾要改写本集的意义**。好的钩子让观众重新理解刚才看到的一切；坏的钩子只是宣布“还有下一集”。
11. **改编忠于效果，不忠于句子**。读者爱这本小说，是因为某个瞬间的感觉，不是因为某句话的顺序。保住那个感觉，句子可以让路。
12. **不要用“高级”掩盖“不清楚”**。观众看不懂，就是没写清。留白是观众能自己补上；含糊是观众补不上。
