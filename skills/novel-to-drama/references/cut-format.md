# 切镜头版格式（Step B：给视频模型的预处理剧本）

> 本文件只管 Step B。Step A（常规剧本）的格式见 `format.md`。
> 一句话：**Step A 让人看懂戏，Step B 让模型看得懂怎么拍。** 两步之间只许加"怎么拍"，不许改"发生了什么"。

---

## 0. 为什么分两步

- 写戏时想镜头，两头都做不好：结构会被景别牵着走，镜头会被台词挤没。
- Step A 定的是**问题、turn、钩子、台词**；Step B 定的是**切点、景别、构图、光、运镜、环境互动、声音**。
- 两步产物必须**事件、台词、场序完全一致**。差异只允许出现在镜头切分与描写上。
- **台词逐字不动**。Step B 里想改台词，回 Step A 改完再转，不要在转换时偷偷改。

## 1. 产物与去向

| 步骤 | 文件 | 写到哪 |
|---|---|---|
| Step A 常规剧本 | `drafts/epNN_script_plain.md` | 只在本地，用来对比、返工 |
| Step B 切镜头版 | `drafts/epNN_script.md` | 剧本表 `初版剧本`（这份才是下游 B1 的输入） |

> 重做一集时，两个文件都要重出；只改 Step B 会造成"台词和文件对不上"。

## 2. 骨架

```text
剧名：养妹失策，社恐妹妹占有欲爆棚

第1集　如果你不想要我，我可以走

对应原小说章节：1

原文区间：第1章「门铃响得跟做贼似的」→ 第1章「照顾？谁给他的脸？」

预估时长：约 118 秒｜6 场｜48 镜

强制一致：沈幼怡的手机｜字号顶满屏幕

强制一致：行李箱｜拉杆三节全出

1．外景　陈诚公寓走廊　日

人物：陈诚、沈幼怡

备注：八月末下午两点，走廊尽头的窗开着，热浪贴地，蝉声不停

本场预估：约 20 秒

切镜头，沈幼怡胸部以上近景，门刚拉开一条缝，门外的白光把沈幼怡半张脸压暗；一只手还悬在门铃面板上方，指尖离圆钮约两厘米。

陈诚（画外，门内，不耐烦）：「找错了吧？」

切镜头，陈诚胸部以上近景，门缝只开一指宽，陈诚堵在缝里，额头碎发被汗黏成一缕；门内没开灯，走廊的光只勾亮半张脸。

……

（字幕·手机）我是沈幼怡。

（音效）门轴响了一声。

……

（本集完）
```

要点：

1. 抬头比 Step A 多两样：`｜N 镜`、若干条 `强制一致：`。
2. **一个镜头 = 一行，`切镜头` 顶格写在行首**。换镜就换行，新起一行：
   - 不许把新镜头接在上一镜的句末（`…门关上了。切镜头，陈诚近景，…` ✗）；
   - 不许加列表符号（`- 切镜头，…`、`1. 切镜头，…`、`> 切镜头，…` 全 ✗）；
   - 不许一行写两个 `切镜头`（下游按行切镜，第二镜会被整行吞掉）。
3. **每行之间空一行**（抬头、场头、镜头、台词、字幕、音效都一样）——缺空行检查器会报错。**源文件分行不等于看上去分行**：Markdown 预览和飞书会把连续的行并成一大段，行还在，看起来却像没换行。空行才是"真的另起一行"。
4. 台词、`（字幕…）`、`（音效）` 各自单独一行，属于它**上面最近的那一镜**。
5. **不再写 `△` 行**：动作全部进镜头。
6. 场头的 `人物：` / `备注：` / `本场预估：` 与 Step A 相同。
7. 台词换了归属镜头时，**只许改括号里的发声方位**（`陈诚（画外，门内，不耐烦）`），说话人与台词文本一个字不动；`--compare` 会逐句核对。

## 3. 一镜怎么写

句式（顺序固定，缺的可以省，顺序不换）：

```text
切镜头，[景别 + 机位/角度]，[主体名字][动作或状态]，[前景/后景与遮挡]，[本镜光]，[运镜与落幅]。
```

### 3.1 景别先起笔

写能核对画面边界的量词，不写"近一点""大一点"：

| 用 | 不用 |
|---|---|
| `胸部以上近景`、`腰部以上中景`、`面部特写`、`手部特写`、`贴地特写`、`过肩中景`、`门内反打近景`、`俯拍全景` | `近景`（单写也行，但不如前者可核对）、`特写镜头`、`拉近一点` |

### 3.2 主体写名字，不写代词

`沈幼怡`、`陈诚`；身体局部要归属：`沈幼怡的指尖`、`陈诚的喉结`、`行李箱的拉杆`。

下游 B1 按名字绑资产，代词会让它把动作挂到别人身上。

### 3.3 一个人的近景/中景/特写可以并成一镜

**同一主体、中间没有切点**，就在一行里把起幅落幅写清：

```text
切镜头，陈诚由胸部以上近景轻推到面部特写，视线从屏幕上抬起来，落到门外；眼睑收窄，喉结滚了一下，嘴唇闭着。
```

**有切点就拆两镜**：机位换边、主体换人、时间跳过、信息换层（脸→手、人→屏）。

### 3.4 一镜只给一件事

1~2 秒的镜头只放"一个动作 + 一个落幅"。不要在一行里写"拉开→转身→坐下→说话"，模型只会给你第一个动作。

## 4. 按需写：先问这一镜需要什么

**没有"每镜必须写几项"这种规矩。** 全篇只有一条判断标准：

> **删掉这句，模型会不会自己编一个别的、或者看错？** 会编就写；不会就删。

写得多不等于写得好。堆满描写会让模型抓住错的重点；该写的地方写透一句，比四句泛泛的形容有用。

### 4.1 格式地基（这不是描写要求，是解析要求）

| 项 | 为什么 | 例 |
|---|---|---|
| `切镜头，` 顶格 + 景别 | 解析器按它切镜 | `胸部以上近景` |
| 主体写名字 | 下游靠名字绑资产，代词会挂错人 | `沈幼怡`，不写"她" |
| 一个可见变化 | 否则这一镜没有信息，等于空转 | `睫毛在颧骨上压出一小片影，视线没动` |

### 4.2 内容项：按戏决定

| 项 | 什么时候值得写 | 什么时候可以不写 |
|---|---|---|
| 运镜（起点→落幅） | 揭示、压迫、跟随、情绪推近，或要让观众**发现**画框外的东西 | 固定镜不用写"镜头固定"；这一镜不需要运动就不写。**但整集一处运镜都没有，通常是没想镜头** |
| 动作速度/力度 | 快慢本身就是戏：急停、回弹、慢慢松手、猛地一拽；不写会变成匀速 | 静态反应、纯空镜、道具特写 |
| 本镜光 | 换机位、换空间、换时间，或光本身在说话（屏幕光、逆光） | 同侧连续镜，光没变 |
| 前景/后景分层 | 过肩、门缝、有遮挡、双人关系 | 干净正面的单人反应 |
| 构图 | 窥视、错位、画左画右的力量对比 | 一般对白镜 |
| 环境互动（风、热浪、汗、水汽、尘、蝉声） | 环境在推动戏（这一集的热就是压力） | 室内静场 |
| 声音 | 有信息量的声音：门锁、钥匙串、手机震、水声 | 无信息的底噪 |
| 道具状态（拉杆几节、膜撕没撕） | 道具是证人，状态会漂 | 道具不入镜 |
| 微表情（物理化） | 这一镜要让观众读出人物在忍/在装/在退 | 群像、远景、纯动作 |
| 强制一致项 | 见第 5 节：对象入镜的那几镜 | 对象不入镜 |

### 4.3 质量优先，不是产量优先

- **镜数、字数、每镜几项细节，都不是指标。** 25 镜每镜都对，好过 40 镜一半空转。
- **一镜一件事。** 一镜里塞三件事，模型只会给你第一件，剩下的自己编。
- **该停就停。** 一个反应给足两秒，比切三个半秒的反应更有力。
- **写不准就别写。** 不准的细节模型会照着编，比不写更糟；宁可留白，让它按资产图和上下文补。
- **每集重排一次节奏**：把"这镜为什么存在"回答不出来的镜头，删或并。

## 5. 强制一致项

### 5.1 为什么要有

视频模型记不住"上一集这个手机字号是最大号"。凡是**一眼能认出来、又能被模型随手改掉**的东西，都要写成清单，并在每次入镜时**原样复写同一句**。

> 这是整份文档里**唯一"缺了就报错"的描写规则**；其余（运镜、速度、光、构图、环境互动）全是按需。它管的不是文笔，是**前后两镜会不会变成两个东西**。

### 5.2 怎么写

抬头一行一条：

```text
强制一致：<对象>｜<每次入镜都必须原样出现的短语>
```

- `<对象>`：剧本里**原样出现**的那个称呼，写到不会误伤别人：`沈幼怡的手机`、`行李箱`、`书包`。不要写光秃秃的 `手机`——陈诚的手机一入镜也会被要求写这一句；也不要写“道具”“场景”。
- `<短语>`：一句具体的、拍得到的描写（`字号顶满屏幕`、`白底黑字`、`箱侧机场行李条没撕`），不写形容词（"很大""很旧""挺新的"）。
- 一个对象有两条互不相关的特征，分两行写。
- 短语要求**同一句原样复写**，不要换个说法——换说法模型就当成新东西。

### 5.3 收什么、不收什么

| 收 | 不收 |
|---|---|
| 模型爱乱改的状态：字号、膜、拉杆、鞋码、伤、水渍、门开几度 | 服装、发型、长相、场景风格——由资产图锁定 |
| 反复出现、观众会当成记号的物 | 一次性的环境描写 |
| 主角身上会漂移的身体细节（疤、痣、手伤） | 情绪、性格、关系 |

### 5.4 检查

`check_script.py --mode cut` 会逐镜核对：**对象入镜而短语缺失 → 报错**。判断依据是"这一镜里有没有出现对象字符串"，所以对象名写具体（见 5.2）。

确实入镜但拍不到那面（手机在兜里、屏幕朝下），在该镜写 `（不入屏）`，降为警告。

## 6. 集内一致性

写完通读一遍，这几样不许漂：

- **空间**：门开几度、谁在门里谁在门外、行李箱在左脚边还是右脚边。
- **光**：同一场只有一个光向；换机位就补一句"光从哪来"。
- **道具**：拉杆几节、膜撕没撕、鞋脱了没、箱子靠哪面墙。
- **身体**：汗、红印、发抖、呼吸——上一镜有，下一镜不能突然没有。
- **时间**：`两点十一` 这类明确时间全集只出现一次，前后不能矛盾。
- **服装**：换装必须写清在哪一镜换的。

## 7. 不要写

- 时间码（`00:00-00:05`）、段号（`ep01_p01`）、`【第NN段｜…】` —— 那是 B1（`drama-segment-generation`）的事。
- 资产锚点 `{资产库：手机}`、`R01陈诚` —— B1 才编号。
- 焦段、光圈、快门、胶片型号、英文参数、负向词。
- 情绪形容词：`紧张`、`气氛凝重`、`眼神复杂` —— 换成肌肉、呼吸、视线、手上的动作。
- 作者评论、主题解释、旁白式总结。

## 8. 从 Step A 转到 Step B 的顺序

1. 通读 Step A，圈出本集**必须让观众看清的 3~5 个瞬间**（名场面、道具特写、屏幕字、关键反应）。
2. 抽**强制一致项**，先写进抬头——不要边写边想。
3. 逐场在草稿上列镜头表：`场号｜镜号｜景别｜主体｜这一镜给的唯一信息`。信息重复的镜合并。
4. **从名场面倒推**：先排那几镜，再用过肩、反打、插入镜把前后接上。
5. 按镜写描述：景别 → 主体动作 → 前景/后景 → 本镜光 → 运镜落幅。
6. 台词逐条从 Step A 搬进来，**一个字不改**，落在真正发声的那一镜。
7. 自检：强制一致、光向、道具状态、时间、代词；跑 `check_script.py --mode cut --compare <Step A 文件>`。
8. 交付：剧本表写切镜头版；Step A 留在 `drafts/` 备查。

## 9. 常见错例

| 错 | 为什么错 | 改 |
|---|---|---|
| `切镜头，陈诚看着她。` | 没有景别、没有细节 | `切镜头，陈诚胸部以上近景，视线从沈幼怡脸上移到那块屏幕上，眉骨压下去一点。` |
| `切镜头，她低头打字。` | 代词、过程性动作、没有手机特征 | `切镜头，沈幼怡胸部以上近景，拇指一个字一个字地戳；屏幕白底黑字，字号顶满屏幕。` |
| `切镜头，屏幕特写。` | 只有一个词，模型自己编屏 | `切镜头，沈幼怡的手机屏幕正面特写，白底黑字，字号顶满屏幕，一行只放得下七八个字；屏幕的光打在沈幼怡下颌上。` |
| 一镜写"拉开→转身→坐下→说话" | 一镜多事，模型只拍第一件 | 拆成 3 镜，每镜"一个动作 + 一个落幅" |
| `…门关上了。切镜头，陈诚近景，…` | 新镜头接在上一行句末，按行解析会漏掉 | 门关上的动作收进上一镜，另起一行写 `切镜头，陈诚近景，…` |
| `- 切镜头，陈诚近景，…` | 列表符号占行首，`切镜头` 不在行首解析不出 | 去掉 `-`，`切镜头` 顶格 |
| 一行里塞两个 `切镜头` | 第二镜会被整行吞掉 | 换行，一镜一行 |
| 整场一行接一行、中间不空行 | 源文件是分行的，但 Markdown/飞书预览会并成一段，看着像没换行 | 每行之间空一行（抬头也算） |
| `切镜头，陈诚近景，他关上门。` | 没有速度/力度，模型给你匀速关门 | `切镜头，陈诚近景，反手一带，门板撞上门框，门框上的浮灰震下来一层。` |
| `切镜头，陈诚腰部以上中景，侧过身让出半个门洞。` | 让身这段就该慢，不写就变成利落让步 | `…侧过身，半秒后才让出半个门洞，肩膀还挡着。` |
| 全场都写"镜头固定" | 运镜偷懒，戏不动 | 揭示/压迫镜至少给一个轻推或横移，并写落幅 |
| 沈幼怡的手机入镜却没写字号 | 强制一致项缺失，每镜字号都不一样 | 补 `字号顶满屏幕` |
| 换到门内反打，光还写走廊日光 | 光向漂移 | 补 `门内客厅冷光落在门槛上` |

## 10. 交付前清单

- [ ] 与 Step A 逐场对过：事件、台词、场序一致，台词一字未改
- [ ] 每镜独立一行、`切镜头` 顶格在行首；没有一行两个镜头、没有接在句末、没有列表符号
- [ ] 每行之间空一行（抬头、场头也算；不空行 Markdown 预览与飞书会并段）
- [ ] 每镜都有 `切镜头，` + 景别 + 名字 + 一个可见变化
- [ ] 没有 `△` 行、没有代词、没有时间码/段号/锚点/焦段
- [ ] 强制一致项每条都在对应镜头出现；确实不拍的标了 `（不入屏）`
- [ ] 运镜、动作速度、光、构图、环境互动：该写的写了，没有硬凑；固定镜没有为了对称补一句运镜
- [ ] 换机位/换空间的镜，该补的本镜光补了没有
- [ ] 道具状态、汗/伤/时间全集没有漂移
- [ ] 删一句还看得懂的地方，删了吗？（写多了比写少了更伤模型）
- [ ] 抬头 `｜N 镜` 与正文镜头数一致
- [ ] `python skills/novel-to-drama/scripts/check_script.py <文件> --mode cut --compare <Step A 文件>` 零错误
