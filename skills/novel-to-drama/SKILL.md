# 小说转初版剧本

## 定位

输入小说原文，输出**可直接开拍的初版剧本**（只到剧本为止）。

- **不改剧情**：顺序、台词、事件、因果一律照原文。只决定"怎么拍"。
- **不写镜头编号**：没有「镜头 01」。每一刀都写成「切镜头，……」。
- **每场带秒数**：场标题写成「一、地点｜日｜外｜（54s）」，正文里不写秒数、不写时间轴。
- **不另立空间／光／人物头**：这些都写进分镜正文里，跟着画面走。
- **删戏不删字**：为了压进 90 秒，可以整场砍、整句砍，但留下来的每句台词、每句心里话必须逐字照原文，一个字都不改。
- **只产出「初版剧本」**：落到剧本表的 `初版剧本` 字段；分镜设计稿、提示词都不在本 skill 的范围。

---

## 零、节奏（抖音 / 红果推流标准）

剧本先满足节奏，再谈文采。四条硬指标：

1. **开头 3 秒即爆点**：第 1 场第 1 刀就是冲突本身——有人被拦在门外、有人被当面质问、有人把东西砸了。禁止用环境、天气、空镜、走路、"门铃响了"起势。
2. **5 秒一个爽点，但一刀只给 1.5~3 秒**。这两件事必须分开：
   - **爽点**是观众获得新信息/情绪爆发的间隔，约 5 秒一次；
   - **一刀**（切镜头）是画面单位，**1.5~3 秒**，一个爽点通常由 **2~3 刀**完成。
   - 举例：她掏手机亮屏（一个爽点，5 秒）＝ 手伸进袋子 2s ＋ 屏幕亮起 3s，是两刀，不是一刀 5 秒。
   - 一刀 5 秒只在三种情况成立：长台词必须一口气说完、连续运镜、情绪停顿（沉默/对视）。
   - 90 秒一集大约 **35~50 刀**；如果一集只有 18~20 刀，说明刀太长。
3. **剧情完整、易懂、不拖沓**：一集讲清一件小事（谁想要什么、被谁挡住、最后怎么落），观众不看前情也能看懂。重复的解释、来回的客套、无信息量的过场全部砍掉。
4. **每集结尾必留钩子**：最后 3~5 秒给出一个新问题或新威胁（一句没说完的话、一个不该出现的人、一条刚弹出的消息）。本集的事收住，下一集的因埋下。

**时长**：**60~120 秒之间**，落在区间里就算合格。90 秒只是中间值，**不是指标**。

- 时长由内容决定：18 个爽点就 90 秒，15 个就 75 秒，20 个就 100 秒。**先数爽点，再算时长**；
- **不许为凑时长加水**。常见的注水有四种，一个都不许：
  1. 把一个动作拆成两刀（扔拖鞋 / 穿上）；
  2. 加没有信息的空镜（空调叶片、冷雾、尘埃）；
  3. 加重复的反应镜头（愣住、眨眼、沉默）；
  4. 把一句台词拆成两句；
- **长了也行**：内容真撑得住就拍满，别为压到 90 砍掉关键台词或翻转。
- 交付时报告"这一集几个爽点、多少秒"，不报告"是否到了 90 秒"。

**单场上限 25~30 秒**：一场只装它自己的爽点，凑不到就不凑，超过 30 秒就拆场或压刀。

- 一场戏的估时按「三、第 2 步」里的「怎么估时长」算；
- 全片总时长落在区间内才交付；
- 超了：先删无信息量的刀，再合并同空间、同时段的场，最后砍次要支线，**不许删关键台词、不许加速对白硬塞**；
- 短了就短了：只要开头爆点、5 秒一个爽点、结尾钩子成立，60 秒也算合格，**不必硬补到 90**。真要补，只能补有信息量的戏（原文里被砍掉的动作或台词），不补空镜、不补重复反应。

## 零之二、分集规划（小说怎么切成集）

**小说与集没有固定对应**，只服务节奏。四种切法都合法：

| 切法 | 什么时候用 |
|---|---|
| 一章 = 一集 | 该章本身就是一个完整事件 + 一个钩子，正好 90 秒 |
| 一章 = 多集 | 该章信息量大、事件多，一个 90 秒装不下 |
| 多章 = 一集 | 几章都在推同一件事，单独成集太薄 |
| 章内切分 | 高潮在中段，前半集结尾要留钩子，就从中间切开 |

**唯一约束**：每集 60~120 秒、开头 3 秒爆点、5 秒一个爽点、集与集之间连贯。

规划步骤：

1. 先读本次要用的章节，标出每个「事件 + 反转 + 钩子」的位置，不要一章一章硬切；
2. 列分集表（内部用，不进表格）：集号｜覆盖原文起止句｜事件｜钩子；
3. 每集独立起终态，结尾留钩子，下一集开头重新交代时间、地点、人物状态；
4. 上一集的钩子必须在下一集被接住；
5. 回填 `对应原小说章节`——**只写纯数字**，逗号分隔，按升序：`1`、`1,2`、`2`。不许出现「第1章」「1-2」「第2章 后半」这类写法，一个汉字都不许有。一集只用了某章的一部分，也仍然只写该章数字。

## 零之三、写续集前，先确认上一集讲到哪

`对应原小说章节` 只告诉"用了哪几章"，**它不能告诉你那一章用了多少**。写第 N 集（N>1）时，必须自己判断：

1. **读上一集的初版剧本全文**（`python cli.py read <WS> --table 剧本表 --episode N-1`），重点看最后 3~5 刀；
2. **拿最后几刀去对小说原文**，找到它对应的**最后一句原文**——是台词就找那句台词，是动作就找那个动作；
3. **续集从这句之后开始**，不许重复上一集用过的内容，也不许跳过没拍的原文；
4. 字段只作粗定位：字段写 `1`，但上一集可能只用了第 1 章前半，续集仍在这一章里接着走，字段也仍然写 `1`；
5. 拿不准时，把上一集最后一场和小说对应段落并排列出来，逐句对齐，不要靠猜。

**不要用"章"当进度条**。一章可以用成两集，也可以半章加半章凑一集；进度以剧本已经拍到哪一句为准。

## 零之四、交稿前必须自己通读一遍

写完不算完。**从头到尾当读者读一遍，不是当作者检查格式。**

1. 整段粘出来，从头读到尾，中间不许跳；
2. 每读到一处停顿，问三句：这里我知道这是谁吗？我知道他为什么这么做吗？我知道刚才发生了什么吗？
3. 卡住的地方记下来，**至少找三处**；找不到三处，说明读得不够狠；
4. 逐处补接口——补的是一句话或一个细节，不是加一场戏。

最容易卡住的五处：

| 位置 | 会卡在哪 | 补什么 |
|---|---|---|
| 闪回 | 突然跳到另一个时空，不知道是谁的记忆 | 首刀写「他记得的那个××岁」，或用同构物件转场 |
| 代称 | 「妈妈说」——她的妈还是他的妈 | 让他掏出自己的手机，屏上是「妈」发来的消息 |
| 身份 | 「沈家」是谁、凭什么有钱 | 一个物证：她手里那台膜还没撕的新手机 |
| 来历 | 她为什么提着箱子站在这儿 | 一个细节：箱侧还贴着没撕的机场行李条 |
| 动机 | 他为什么问「你爸呢」 | 闪回里让那个男人可辨（细框眼镜、深灰西装） |

## 零之五、交代过的状态要跟到底

凡是第一次交代过、并且会持续存在的状态，之后**每次出现都要复述**。

| 状态 | 第一次 | 之后每次出现 |
|---|---|---|
| 屏幕字号 | 白底黑字，字号被调到最大，一行只放得下七八个字 | 白底黑字，字号还是那么大，一行还是七八个字 |
| 门 | 门开十厘米 | 门开一掌半／门已合拢、锁舌到位 |
| 手上的东西 | 她把手机举在胸前 | 手机还在手里，屏幕朝门内 |
| 衣着伤况 | 浅蓝碎花裙后背湿了一片 | 后背那片湿痕又深了两度 |
| 箱子 | 立在右脚边，拉杆三节全出 | 箱子还在原地，轮子没动 |

规矩：

- 每出现一次，至少带一个状态词（大小、开合、在谁手里、朝向、干湿）；
- **写可感的量，不写术语**：别写"字号顶到两侧"，写"一行只放得下七八个字"；别写"浅景深"，写"她脸清楚、背后的走廊糊成一片"；别写"高光比"，写"人脸一半亮一半黑"；
- 状态变了，写清是什么时候变的（他关门前／她转身时）；
- 不许写"和刚才一样""照旧"——读者不记上一刀。

## 零之六、每一刀能不能被看懂

逐刀问四件事，答不上来就补：

1. **是谁**——每一只手、每一个背影、每一个局部都要点名到人，不许用「一只手」「另一只手」「两个背影」「那个人」。

| 禁止 | 改成 |
|---|---|
| 一只手抓起白瓷碗 | 陈诚他爸的手（成年男人，宽厚、指节粗、手背浮筋、虎口一层薄茧）抓起白瓷碗 |
| 另一只手伸进画面 | 十二岁的陈诚伸进画面一只手（比他爸那只小一圈，指节细，手背没有肉，能看清细青筋） |
| 两个背影往外走 | 陈诚他妈拎着深棕软皮包、穿浅色外套，跟一个穿深灰西装、戴细框眼镜的高个男人一前一后往外走 |

2. **什么样**——衣服、发型、物件材质、新旧、颜色，至少给一个能认出来的特征；
3. **在哪**——什么屋子、光从哪来、人站在门里还是门外；
4. **结果**——这一刀结束时，画面停在什么状态。

判据：没看过小说的人只看这一刀的文字，能不能复述出"发生了什么"。复述不出来，就是没写清。

## 一、五条硬规则

1. **可见性**：摄影机拍不到的不写。心理、评价、比喻一律转成动作、生理细节、环境反馈。
2. **一场一空间**：一场 = 一个空间 + 一段连续时间。换地方另起一场。空间的方位、距离、光源，在本场开头那几刀里交代清楚，不单独列块。
3. **一切切换都得写**：景别变了、机器动了、视角换了，都写成一句「切镜头」。特写和近景之间尤其不能省。
4. **因果链**：发力、接触、受力反馈、环境响应、机位反馈，全部落到具体细节。
5. **资产唯一**：场景 S、角色 R、道具 P、特效 FX 全篇统一编号，同一资产同一个号；本场没出现的不塞。

## 二、第 1 步：资产提取

通读原文，列出重复出现的视觉实体：

- 场景 S：S01 走廊、S02 玄关、S03 客厅
- 角色 R：R01 陈诚、R02 沈幼怡（附固定外貌、服装）
- 道具 P：P01 她的手机、P02 行李箱
- 特效 FX：FX01 热浪扭曲、FX02 闪回颗粒、FX03 猫眼鱼眼

只收"拍得到的实体"。

---

## 三、第 2 步：分场

一场一个标题，格式固定：

```text
一、陈诚公寓走廊｜日｜外｜（54s）
二、陈诚公寓玄关｜日｜内｜（11s）
三、陈诚公寓客厅｜日｜内｜（19s）
```

场标题只写：序号、地点、日/夜、内/外、**本场预估时长（秒，写在圆括号里）**。不写空间说明、不写光影说明、不写人物表——这些进正文。

### 怎么估时长

一场的时间＝这一场所有刀的时间相加。单刀按下表算，台词并进它所属的那一刀，不叠加：

| 景别 | 基准 |
|---|---|
| 全景 | 3.2s |
| 中景 | 2.8s |
| 近景 | 2.6s |
| 过肩／反打 | 2.6s |
| 主观 | 3.0s |
| 特写 | 2.2s |

- 刀内描述超过 60 字，加 0.4s；超过 90 字，加 0.8s（内容多，镜头要更长）。
- 台词按 **5.3 字/秒** 折算，每句再加 0.3s 的呼吸；一句话最短 1.2s。
- 一刀里既有画面又有台词时，取二者较大值，**不要相加**。
- 每场四舍五入到整秒；全片结尾写一行 `全片约 XXXs（X 分 X 秒），共 N 场。`

时长是估出来的，用来判断节奏和集长，不进正文，也不决定真实拍摄。

**交付门槛**：全片总时长必须落在 **60~120 秒**。不在区间内就必须重切，不许交付。

## 四、第 3 步：写剧本（核心）

### 4.1 每一刀都是「切镜头，……」

正文不分镜头号，一行一刀，句式固定：

```text
切镜头，陈诚近景，……
切镜头，沈幼怡特写，……
切镜头，全景，……
切镜头，过肩，……
切镜头，反打，……
切镜头，主观（陈诚的眼睛），……
```

- 第一刀通常是**全景**，在描述里把空间交代掉：画左是什么、画右是什么、人站在哪、离门多远、光从哪来。
- 之后每一刀都写：谁、什么景别、在做什么、镜头怎么动。
- 同一场里，同一组人物不要连着三次用同一个景别。

### 4.2 台词与 OS 逐字保留，紧跟它所属的那一刀

原文里说出口的每一句、心里想的每一句，都要原样落进分镜，**一句不删、一字不改、不合并**。写法是：先写这一刀的画面，另起一行、顶格写台词或 OS。

```text
切镜头，陈诚近景，他把门又推开半掌，人横过来挡住大半门洞，下巴朝门外下方抬了一下。

陈诚（不耐，问得随意，尾音落平）：「找错了吧？」

切镜头，陈诚近景，他没动，视线在她脸上停住，眉头皱起来。

陈诚（OS，压着火气，嫌烦）：「谁啊，这时候敲门。」
```

规矩：

- **顶格写**：台词、OS、屏幕字都从行首开始，不缩进、不加空格。
- **前后空一行**：台词和它上面那刀、下面那刀之间各留一个空行，别粘在一起。
- **说话人写名字**，不许写"他""她"。
- **OS 标在括号最前面**：`（OS，情绪）`。心理活动一律走 OS，不转成旁白，也不删。
- **格式**：`角色（怎么说）：「台词」`。名字直接写，不加【】，括号写"怎么说"，冒号全角。
- **括号三段式**：①情绪打底 ②发声方式 ③必要的气息或口型。三段加起来通常十五到二十五个字，一句就够，不堆。
- **情绪词必须能指导表演**：演员看到就能做表情，含糊的一律换掉。

| 含糊（演员不知道怎么做） | 具体（能演） |
|---|---|
| 小心 | 拘谨、戒备、怯 |
| 怅然 | 意外、羡慕、发酸 |
| 复杂 | 说清是哪两种，如「又气又舍不得」 |
| 有情绪 | 删掉，改写成具体动作 |
| 状态不对 | 这种评语不写 |

| 段 | 可用词 |
|---|---|
| 情绪 | 不耐、恼怒、克制、压抑、轻蔑、讥诮、怨怼、发苦、发沉、沉痛、负气、嘴硬、冷淡、急且冲、气结、如释重负、紧张、郁结、心下一沉、存疑、迟疑、局促、自嘲 |
| 发声 | 压低、短促、慢半句、一句一顿、尾音往上、尾音落平、每字落定、逐字清楚、气多声少、咬着字、狠声 |
| 气息与口型 | 喘息、咬牙、牙关咬住、哭腔、气息轻落 |

不用口语词：没好气、别扭、赌气、发怵、掂量、发狠、闷、烦、小声、松口气。

参考写法：

```text
陈诚（不耐，语气冲）：「进不进？中暑了我可没钱送你去医院。」
陈诚（压到最低，慢半句，气多声少）：「你爸呢？」
陈母（电话里，声音低下来，少见地认真）：「诚诚。妈求你了。」
```

- **OS 写在括号里**：`角色（OS，情绪，发声方式）：「…」`，OS 两个字放在括号最前面。
- **OS 一律第一人称**：OS 是角色心里的原话，说「我」，不说「他／她」。
  | 原著的第三人称叙述 | 不能直接当 OS | 改成 |
  |---|---|---|
  | 这三个字，是他亲手捂了六年的旧疤 | 角色不会管自己叫"他" | 「这三个字，是我亲手捂了六年的旧疤。」 |
  | 什么破事？他妈答应的，关他屁事 | 同上 | 「什么破事？他妈答应的，关我屁事！」 |
  | 跟她想象中的哥哥家不太一样 | 同上 | 「跟我想象中的哥哥家不太一样。」 |
  - 改代词不算改字；除了代词，其他字照原文。
  - 有的第三人称句子改成第一人称会很别扭，那就不要当 OS 用，改写成可见动作或直接删。
- **OS 不出口**：写 OS 的那一刀，人物嘴唇是闭着的，画面里不要有说话的嘴型。
- **画外声音写方位**：`画外声音来自画左外近处，角色（…）：「…」`。
- **括号只回答"怎么说"**：情绪、发声、气息。
  - 不写**原因/情境**："被门铃打断""因为心虚""想到刚才那一幕"——这些是画面和上下文的事，括号里不出现。
  - 不写**动作**："眼睛看着地上""目光收回去""先短笑一声""骂给自己听"——写进画面那一刀。
  - 不写**动机解释**："底子是怕""气的是自己"——直接写情绪本身（怕、自嘲）。

- **标点照原文**，只允许为语气微调句读，字不能动。
- **顺序照原文**：谁先说、谁后说，分镜里不许调。
- **屏幕上的字**（短信、打字、微信）单独写成：

```text
切镜头，手机屏幕特写，白底黑字，字号被调到最大，一行字顶着两侧。
屏幕上打着——「我是沈幼怡。」
```

- **台词和 OS 都必须有人在场**：说这句话、想这句话的人，必须在同一场里出现。

### 4.3 空间写在第一刀里，之后靠"位置"维持

```text
切镜头，全景，走廊从画左的电梯口向画右的楼梯窗延伸，地砖上落着一块硬边的光斑；
她站在画右三分之一，箱子在右脚边，拉杆拉出三节；门在画左中段，门框右缘一拳处是门铃面板，
左下贴着一张歪掉的 901。门里没光，黑成一块。
```

后面每一刀，只要机位换了边，就补一句位置：

```text
切镜头，反打，机位到了门外——她在画右，门在画左，他只剩缝里那半张脸。
```

### 4.4 光影跟着画面走，只写核实过的

- **有光源才写**：正午的窗、门缝、屏幕、台灯、走廊顶灯。
- **写方向和落点**：从哪来、打在谁身上、哪里沉进暗部。
- **同场不许矛盾**：这场是正午顶灯，就不能冒出月光。
- **不要每刀都写**：一场写三到五次，写在光真正决定画面的那几刀。

```text
切镜头，沈幼怡近景，日头从她背后压过来，正脸落在半暗里，只有额角一线亮；
睫毛在颧骨上压出一小片影。
```

### 4.5 运镜写在句子里，标方向

```text
切镜头，沈幼怡手部近景，机位向画左横移半步，跟着她的手。
切镜头，陈诚特写，缓慢推近，推到只剩睫毛。
切镜头，中景，跟着他起身，机位上摇到肩高。
切镜头，全景，绕着他转小半圈，转到侧后方。
切镜头，近景，机位后退，把他整个人退进画框。
```

推、拉、跟、摇、移、环绕，六个动作任选，但**每次都要写清往哪个方向、跟谁**。

### 4.6 震动写方向与幅度

不许只写"镜头一震"：

```text
切镜头，门板近景，门板合拢，机位向右横震约两指宽，随即回稳。
切镜头，地面特写，瓷碗砸下，机位短促下颠半个指宽。
切镜头，拳头特写，砸在门板上，画面向内侧抖了一下，幅度不超过画宽百分之一。
```

方向 + 幅度 + 回稳，三样缺一不可。

### 4.7 景别之间不许跳

- 近景 → 特写：写「切镜头，特写」，或「特写，推近」。
- 特写 → 全景：写「切镜头，全景」，并补一句人退到画面哪一侧。
- 反打 → 主观：写「切镜头，主观（谁的眼睛）」，交代他此刻看向哪。
- 过肩与反打要成对：先过肩看对方，再反打回来。

### 4.8 主观镜头必须点名

```text
切镜头，主观（陈诚的眼睛），门缝只有十厘米宽，她整个人被切在缝里，先露鞋尖，再露裙摆。
```

不点名等于废镜。

## 五、镜头语言速查

| 想表达 | 用什么 |
|---|---|
| 交代空间、人物关系 | 全景（固定或横移） |
| 两人对峙、距离感 | 过肩 → 反打 |
| 情绪落点、眼神变化 | 近景（可推近） |
| 关键细节（手指、钮、屏幕） | 特写 |
| 他在看什么 | 主观（点名是谁的眼睛） |
| 压迫感 | 推近 |
| 被抛下、孤立 | 拉远／后退 |
| 跟着走、跟着手 | 跟随 |
| 打量、审视 | 环绕小半圈 |
| 空间层次 | 过肩带前景，反打带后景 |

## 六、自检

- [ ] 交稿前从头到尾读过一遍，并找出至少三处「观众会卡住」的地方，已补接口
- [ ] 交代过的持续状态（屏幕字号、门开度、手上的东西、衣着伤况）每次出现都复述了
- [ ] 每一刀都答得出「是谁、什么样、在哪、结果」；没看过小说的人读得懂
- [ ] 剧情、台词、顺序与原文一致，没加戏没删戏
- [ ] 原文每句台词、每句 OS 都在，逐字没改，紧跟所属镜头，说话人写了名字
- [ ] 每句 OS 都是第一人称（说「我」），没有把原著第三人称叙述直接搬进来
- [ ] 写 OS 的那一刀，人物嘴唇是闭着的，画面里没有说话的嘴型
- [ ] 台词写成"角色（情绪＋发声方式＋气息）"；OS 写成"角色（OS，…）"；画外写了方位
- [ ] 括号里没有走位和景别
- [ ] 每个情绪词都能直接指导表演（不写小心、怅然、复杂这类含糊词）
- [ ] 台词、OS 上下各空一行
- [ ] 台词、OS、屏幕字全部顶格，没有缩进也没有空格
- [ ] 屏幕文字写成「屏幕上打着——」
- [ ] 没有「镜头 1」「镜头 2」这类编号，每一刀都是「切镜头，……」
- [ ] 场标题带「（Ns）」，正文里没有秒数和时间轴
- [ ] 全片总时长落在 60~120 秒之间（不追求 90，也不为凑数加水）
- [ ] 每一刀都带新信息；没有拆动作、没有空镜、没有重复反应
- [ ] `对应原小说章节` 只写了纯数字（如 `1`、`1,2`），没有任何汉字
- [ ] 续集从上一集最后一句原文之后开始，没有重复、没有跳漏
- [ ] 上一集的钩子在这一集被接住，人物情绪与状态接得上
- [ ] 开头 3 秒是冲突本身，不是环境或过场
- [ ] 平均每 5 秒一个爽点，没有连续 10 秒的平段
- [ ] 单刀 1.5~3 秒；一集 35~50 刀（超过 3.5 秒的刀都有明确理由：长台词/连续运镜/停顿）
- [ ] 结尾 3~5 秒留了钩子
- [ ] 场标题只有「序号、地点、日/夜、内/外」，没有空间／光／人物块
- [ ] 第一刀把空间交代清楚（画左、画右、人的站位、光的来向）
- [ ] 每次景别变化都写了切法，特写与近景之间没有跳
- [ ] 主观镜头点了名；过肩与反打成对
- [ ] 运镜标了方向；震动写了方向与幅度
- [ ] 机位换边之后补了位置交代
- [ ] 光影有来源、同场不矛盾、没有每刀都写
- [ ] 没有比喻、没有心理描写、没有"电影感""氛围感"

## 七、示例（原文一段 → 剧本一场）

**原文**：门铃响，短促又怯生。陈诚码字正到关键处，眉头一拧，扯了扯领口，大裤衩拖鞋啪嗒啪嗒蹚过客厅，一把拽开门。热浪糊脸。门口站着个女孩，安静得不像活人，目光死死盯着自己的鞋尖。

```text
一、陈诚公寓走廊｜日｜外｜（12s）

切镜头，全景，走廊从画左的电梯口向画右的楼梯窗延伸，净宽一米六，浅米灰地砖上落着一块硬边的光斑；她站在画右三分之一，酒红行李箱在右脚边、拉杆拉出三节，浅灰书包挂右肩；门在画左中段，门框右缘一拳处是门铃面板，左下贴着一张歪掉的 901。门里没光，黑成一块。

切镜头，沈幼怡近景，右手食指悬在门铃上方半寸，停住，没有再往上抬。

切镜头，门铃特写，指腹压下去，钮面陷进两毫米，回弹，灰被蹭掉一道；铃声只响一下，短促，怯生，尾音被门板吃掉。

切镜头，门内全景（机位不动），键盘被推开的轻响，接着是拖鞋底拍木地板，由远及近，声音穿过门板时闷了一层。
陈诚（OS，被打断的火，低声嘀咕）：「谁啊，这时候敲门。」

切镜头，陈诚手部近景，机位向画左横移半步，跟着那只手：右手从领口上松开，抓住门把往下压，指节泛白。

切镜头，过肩，从他的右肩后拍她。门只开了十厘米，门缝竖着，她整个人被切在缝里——只剩黑皮鞋尖、浅蓝裙摆、行李箱一角。

切镜头，过肩推近，机位沿门缝推近半步，缝一点点变宽，先露鞋尖，再露裙摆，最后露出睫毛；热浪在缝口压出一层透明的抖。

切镜头，反打，机位到了门外——她在画右，门在画左，他只剩缝里那半张脸，另半边沉在黑里，日头把门板下缘照出一道亮边。
陈诚（不耐烦，问得随意）：「找错了吧？」

切镜头，沈幼怡近景，她没有抬头，也没有说话，眼睛钉在自己鞋尖上，睫毛动了一下。
```

这一场做了四件事：全景交代空间；近景接特写交代动作；过肩推近完成从"看不见"到"看见"；反打把机位交到门外，并用一句位置交代把左右钉住。
