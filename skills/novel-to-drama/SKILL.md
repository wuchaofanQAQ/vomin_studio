# 小说转分镜

## 定位

输入小说原文，输出**按场划分的分镜稿**。

- **不改剧情**：顺序、台词、事件、因果一律照原文。只决定"怎么拍"。
- **不写镜头编号**：没有「镜头 01」。每一刀都写成「切镜头，……」。
- **不写时长**：不出现秒数、时间轴。
- **不另立空间／光／人物头**：这些都写进分镜正文里，跟着画面走。
- **台词与 OS 都保留**：原文引号里的每句台词、每句心里话，原样写进分镜，一句不删、一字不改。

---

## 一、五条硬规则

1. **可见性**：摄影机拍不到的不写。心理、评价、比喻一律转成动作、生理细节、环境反馈。
2. **一场一空间**：一场 = 一个空间 + 一段连续时间。换地方另起一场。空间的方位、距离、光源，在本场开头那几刀里交代清楚，不单独列块。
3. **一切切换都得写**：景别变了、机器动了、视角换了，都写成一句「切镜头」。特写和近景之间尤其不能省。
4. **因果链**：发力、接触、受力反馈、环境响应、机位反馈，全部落到具体细节。
5. **资产唯一**：场景 S、角色 R、道具 P、特效 FX 全篇统一编号，同一资产同一个号；本场没出现的不塞。

---

## 二、第 1 步：资产提取

通读原文，列出重复出现的视觉实体：

- 场景 S：S01 走廊、S02 玄关、S03 客厅
- 角色 R：R01 陈诚、R02 沈幼怡（附固定外貌、服装）
- 道具 P：P01 她的手机、P02 行李箱
- 特效 FX：FX01 热浪扭曲、FX02 闪回颗粒、FX03 猫眼鱼眼

只收"拍得到的实体"。

---

## 三、第 2 步：分场

一场一个标题，格式固定：

```text
一、陈诚公寓走廊｜日｜外｜（54s）
二、陈诚公寓玄关｜日｜内｜（11s）
三、陈诚公寓客厅｜日｜内｜（19s）
```

场标题只写：序号、地点、日/夜、内/外、**本场预估时长（秒，写在圆括号里）**。不写空间说明、不写光影说明、不写人物表——这些进正文。

### 怎么估时长

一场的时间＝这一场所有刀的时间相加。单刀按下表算，台词并进它所属的那一刀，不叠加：

| 景别 | 基准 |
|---|---|
| 全景 | 3.2s |
| 中景 | 2.8s |
| 近景 | 2.6s |
| 过肩／反打 | 2.6s |
| 主观 | 3.0s |
| 特写 | 2.2s |

- 刀内描述超过 60 字，加 0.4s；超过 90 字，加 0.8s（内容多，镜头要更长）。
- 台词按 **5.3 字/秒** 折算，每句再加 0.3s 的呼吸；一句话最短 1.2s。
- 一刀里既有画面又有台词时，取二者较大值，**不要相加**。
- 每场四舍五入到整秒；全片结尾写一行 `全片约 XXXs（X 分 X 秒），共 N 场。`

时长是估出来的，用来判断节奏和集长，不进提示词，也不决定真实拍摄。

## 四、第 3 步：写分镜（核心）

### 4.1 每一刀都是「切镜头，……」

正文不分镜头号，一行一刀，句式固定：

```text
切镜头，陈诚近景，……
切镜头，沈幼怡特写，……
切镜头，全景，……
切镜头，过肩，……
切镜头，反打，……
切镜头，主观（陈诚的眼睛），……
```

- 第一刀通常是**全景**，在描述里把空间交代掉：画左是什么、画右是什么、人站在哪、离门多远、光从哪来。
- 之后每一刀都写：谁、什么景别、在做什么、镜头怎么动。
- 同一场里，同一组人物不要连着三次用同一个景别。

### 4.2 台词与 OS 逐字保留，紧跟它所属的那一刀

原文里说出口的每一句、心里想的每一句，都要原样落进分镜，**一句不删、一字不改、不合并**。写法是：先写这一刀的画面，另起一行、顶格写台词或 OS。

```text
切镜头，陈诚近景，他把门又推开半掌，人横过来挡住大半门洞，下巴朝门外下方抬了一下。

陈诚（不耐，问得随意，尾音落平）：「找错了吧？」

切镜头，陈诚近景，他没动，视线在她脸上停住，眉头皱起来。

陈诚（OS，压着火气，嫌烦）：「谁啊，这时候敲门。」
```

规矩：

- **顶格写**：台词、OS、屏幕字都从行首开始，不缩进、不加空格。
- **前后空一行**：台词和它上面那刀、下面那刀之间各留一个空行，别粘在一起。
- **说话人写名字**，不许写"他""她"。
- **OS 标在括号最前面**：`（OS，情绪）`。心理活动一律走 OS，不转成旁白，也不删。
- **格式**：`角色（怎么说）：「台词」`。名字直接写，不加【】，括号写"怎么说"，冒号全角。
- **括号三段式**：①情绪打底 ②发声方式 ③必要的气息或口型。三段加起来通常十五到二十五个字，一句就够，不堆。

| 段 | 可用词 |
|---|---|
| 情绪 | 不耐、恼怒、克制、压抑、轻蔑、讥诮、怨怼、发苦、发沉、沉痛、负气、嘴硬、冷淡、急且冲、气结、如释重负、紧张、郁结、心下一沉、存疑、迟疑、局促、自嘲 |
| 发声 | 压低、短促、慢半句、一句一顿、尾音往上、尾音落平、每字落定、逐字清楚、气多声少、咬着字、狠声 |
| 气息与口型 | 喘息、咬牙、牙关咬住、哭腔、气息轻落 |

不用口语词：没好气、别扭、赌气、发怵、掂量、发狠、闷、烦、小声、松口气。

参考写法：

```text
陈诚（不耐，语气冲）：「进不进？中暑了我可没钱送你去医院。」
陈诚（压到最低，慢半句，气多声少）：「你爸呢？」
陈母（电话里，声音低下来，少见地认真）：「诚诚。妈求你了。」
```

- **OS 写在括号里**：`角色（OS，情绪，发声方式）：「…」`，OS 两个字放在括号最前面。
- **OS 不出口**：写 OS 的那一刀，人物嘴唇是闭着的，画面里不要有说话的嘴型。
- **画外声音写方位**：`画外声音来自画左外近处，角色（…）：「…」`。
- **括号只回答"怎么说"**：情绪、发声、气息。
  - 不写**原因/情境**："被门铃打断""因为心虚""想到刚才那一幕"——这些是画面和上下文的事，括号里不出现。
  - 不写**动作**："眼睛看着地上""目光收回去""先短笑一声""骂给自己听"——写进画面那一刀。
  - 不写**动机解释**："底子是怕""气的是自己"——直接写情绪本身（怕、自嘲）。

- **标点照原文**，只允许为语气微调句读，字不能动。
- **顺序照原文**：谁先说、谁后说，分镜里不许调。
- **屏幕上的字**（短信、打字、微信）单独写成：

```text
切镜头，手机屏幕特写，白底黑字，字号被调到最大，一行字顶着两侧。
屏幕上打着——「我是沈幼怡。」
```

- **台词和 OS 都必须有人在场**：说这句话、想这句话的人，必须在同一场里出现。

### 4.3 空间写在第一刀里，之后靠"位置"维持

```text
切镜头，全景，走廊从画左的电梯口向画右的楼梯窗延伸，地砖上落着一块硬边的光斑；
她站在画右三分之一，箱子在右脚边，拉杆拉出三节；门在画左中段，门框右缘一拳处是门铃面板，
左下贴着一张歪掉的 901。门里没光，黑成一块。
```

后面每一刀，只要机位换了边，就补一句位置：

```text
切镜头，反打，机位到了门外——她在画右，门在画左，他只剩缝里那半张脸。
```

### 4.4 光影跟着画面走，只写核实过的

- **有光源才写**：正午的窗、门缝、屏幕、台灯、走廊顶灯。
- **写方向和落点**：从哪来、打在谁身上、哪里沉进暗部。
- **同场不许矛盾**：这场是正午顶灯，就不能冒出月光。
- **不要每刀都写**：一场写三到五次，写在光真正决定画面的那几刀。

```text
切镜头，沈幼怡近景，日头从她背后压过来，正脸落在半暗里，只有额角一线亮；
睫毛在颧骨上压出一小片影。
```

### 4.5 运镜写在句子里，标方向

```text
切镜头，沈幼怡手部近景，机位向画左横移半步，跟着她的手。
切镜头，陈诚特写，缓慢推近，推到只剩睫毛。
切镜头，中景，跟着他起身，机位上摇到肩高。
切镜头，全景，绕着他转小半圈，转到侧后方。
切镜头，近景，机位后退，把他整个人退进画框。
```

推、拉、跟、摇、移、环绕，六个动作任选，但**每次都要写清往哪个方向、跟谁**。

### 4.6 震动写方向与幅度

不许只写"镜头一震"：

```text
切镜头，门板近景，门板合拢，机位向右横震约两指宽，随即回稳。
切镜头，地面特写，瓷碗砸下，机位短促下颠半个指宽。
切镜头，拳头特写，砸在门板上，画面向内侧抖了一下，幅度不超过画宽百分之一。
```

方向 + 幅度 + 回稳，三样缺一不可。

### 4.7 景别之间不许跳

- 近景 → 特写：写「切镜头，特写」，或「特写，推近」。
- 特写 → 全景：写「切镜头，全景」，并补一句人退到画面哪一侧。
- 反打 → 主观：写「切镜头，主观（谁的眼睛）」，交代他此刻看向哪。
- 过肩与反打要成对：先过肩看对方，再反打回来。

### 4.8 主观镜头必须点名

```text
切镜头，主观（陈诚的眼睛），门缝只有十厘米宽，她整个人被切在缝里，先露鞋尖，再露裙摆。
```

不点名等于废镜。

## 五、镜头语言速查

| 想表达 | 用什么 |
|---|---|
| 交代空间、人物关系 | 全景（固定或横移） |
| 两人对峙、距离感 | 过肩 → 反打 |
| 情绪落点、眼神变化 | 近景（可推近） |
| 关键细节（手指、钮、屏幕） | 特写 |
| 他在看什么 | 主观（点名是谁的眼睛） |
| 压迫感 | 推近 |
| 被抛下、孤立 | 拉远／后退 |
| 跟着走、跟着手 | 跟随 |
| 打量、审视 | 环绕小半圈 |
| 空间层次 | 过肩带前景，反打带后景 |

## 六、自检

- [ ] 剧情、台词、顺序与原文一致，没加戏没删戏
- [ ] 原文每句台词、每句 OS 都在，逐字没改，紧跟所属镜头，说话人写了名字
- [ ] 写 OS 的那一刀，人物嘴唇是闭着的，画面里没有说话的嘴型
- [ ] 台词写成"角色（情绪＋发声方式＋气息）"；OS 写成"角色（OS，…）"；画外写了方位
- [ ] 括号里没有走位和景别
- [ ] 台词、OS 上下各空一行
- [ ] 台词、OS、屏幕字全部顶格，没有缩进也没有空格
- [ ] 屏幕文字写成「屏幕上打着——」
- [ ] 没有「镜头 1」「镜头 2」这类编号，每一刀都是「切镜头，……」
- [ ] 没有秒数、没有时间轴
- [ ] 场标题只有「序号、地点、日/夜、内/外」，没有空间／光／人物块
- [ ] 第一刀把空间交代清楚（画左、画右、人的站位、光的来向）
- [ ] 每次景别变化都写了切法，特写与近景之间没有跳
- [ ] 主观镜头点了名；过肩与反打成对
- [ ] 运镜标了方向；震动写了方向与幅度
- [ ] 机位换边之后补了位置交代
- [ ] 光影有来源、同场不矛盾、没有每刀都写
- [ ] 没有比喻、没有心理描写、没有"电影感""氛围感"

## 七、示例（原文一段 → 分镜一场）

**原文**：门铃响，短促又怯生。陈诚码字正到关键处，眉头一拧，扯了扯领口，大裤衩拖鞋啪嗒啪嗒蹚过客厅，一把拽开门。热浪糊脸。门口站着个女孩，安静得不像活人，目光死死盯着自己的鞋尖。

```text
一、陈诚公寓走廊｜日｜外｜（12s）

切镜头，全景，走廊从画左的电梯口向画右的楼梯窗延伸，净宽一米六，浅米灰地砖上落着一块硬边的光斑；她站在画右三分之一，酒红行李箱在右脚边、拉杆拉出三节，浅灰书包挂右肩；门在画左中段，门框右缘一拳处是门铃面板，左下贴着一张歪掉的 901。门里没光，黑成一块。

切镜头，沈幼怡近景，右手食指悬在门铃上方半寸，停住，没有再往上抬。

切镜头，门铃特写，指腹压下去，钮面陷进两毫米，回弹，灰被蹭掉一道；铃声只响一下，短促，怯生，尾音被门板吃掉。

切镜头，门内全景（机位不动），键盘被推开的轻响，接着是拖鞋底拍木地板，由远及近，声音穿过门板时闷了一层。
陈诚（OS，被打断的火，低声嘀咕）：「谁啊，这时候敲门。」

切镜头，陈诚手部近景，机位向画左横移半步，跟着那只手：右手从领口上松开，抓住门把往下压，指节泛白。

切镜头，过肩，从他的右肩后拍她。门只开了十厘米，门缝竖着，她整个人被切在缝里——只剩黑皮鞋尖、浅蓝裙摆、行李箱一角。

切镜头，过肩推近，机位沿门缝推近半步，缝一点点变宽，先露鞋尖，再露裙摆，最后露出睫毛；热浪在缝口压出一层透明的抖。

切镜头，反打，机位到了门外——她在画右，门在画左，他只剩缝里那半张脸，另半边沉在黑里，日头把门板下缘照出一道亮边。
陈诚（不耐烦，问得随意）：「找错了吧？」

切镜头，沈幼怡近景，她没有抬头，也没有说话，眼睛钉在自己鞋尖上，睫毛动了一下。
```

这一场做了四件事：全景交代空间；近景接特写交代动作；过肩推近完成从"看不见"到"看见"；反打把机位交到门外，并用一句位置交代把左右钉住。
