# 角色抽取规则与去漂移检查

角色档案跨多集抽取，最怕"人设漂移"（发色变、服装变、性格变）。按以下规则防漂移。

## 抽取规则

1. **同角色聚合**：先按角色名把所有出现段落聚合到一起，再统一抽取，不逐集单独抽。
2. **冲突处理**：多集描述不一致时——
   - 以外观第一次完整描述 + 剧本设定为准
   - 冲突项列出所有版本，标"多集表述不一致，取首现版"，提醒确认
3. **不臆造**：小说原文（及剧本）都没写的字段标"未指定"，不替作者脑补。小说为主、剧本兜底：两者冲突时以小说原文为准。
4. **继承全局画风**：画风基调一律从剧本设定继承，不从某集剧情推断。

## 去漂移检查清单（抽取后自查）

- [ ] 发色/发型/服装在各集引用一致
- [ ] 标志性特征完整无遗漏
- [ ] 性格与动机符合主线设定（不随单集情绪摆动）
- [ ] 画风基调与剧本设定一致
- [ ] 缺失项已标注、未擅自填充

## 版本与来源

- 档案末尾记录"抽取自哪些集、是否跨集一致、存在哪些冲突待确认"。
- 新增剧集后若角色有新外形/内核信息，更新档案并更新来源集范围。

## 逐集增量抽取注意

novel-to-character-assets 在 Phase B 逐集处理时，如发现新角色，需按上述规则从当前章**小说原文**抽取完整 8 模块档案（无小说原文时退回完整剧本）。由于逐集处理，同一角色可能在多集被重新遇到——已在角色库中的角色跳过，不重复抽取。
