# 资产生图（角色 / 场景 / 道具）

## 按资产类型出图（唯一分叉点）

同一张「资产库」，靠 **类型** 区分出图要求：

| 类型 | 版式 | 画面比例 | 模板来源 |
|---|---|---|---|
| 角色 | 四视角设定图：近景正/侧 + 全身正/背 | 16:9 | `asset_prompt.py --type 角色` |
| 场景 | 场景资料图（空间 + 光影） | 22:9 | `--type 场景` |
| 道具 | 双视角图：正偏侧 + 正面 | 16:9 | `--type 道具` |

提示词由「描述 + 模板」自动拼，不进表；出图后只回填 `文件路径`。

## 定位

把 `drama-asset-extraction` 产出的**文字描述**，按固定版式写成出图提示词，再触发 `generate` 出图。合并了旧的 `character-three-view-prompt`（三视图）与 `scene-board-image`（场景资料板）。

```text
资产库（描述 + 待出图状态）
  + 剧本设定（画风）
  → 按类型套版式 → gen_prompt
  → 确认 → write gen_prompt → generate → 出图后检查
```

**本 skill 只负责"怎么把描述变成图"**：选题、套版式、写提示词、出图、验收。资产有什么、叫什么，由 `drama-asset-extraction` 决定。

> **生图必须逐次确认**：每次调用 `generate`（包括重抽、补抽、换版式）之前，单独列出「资产名 / 版式 / 比例 / 张数」，等用户明确说"确认"再调用。没有确认就停在提示词草案，不许直接打接口。写 `gen_prompt` 也算写操作，一并列入确认清单。

## 三种版式（唯一合法格式）

### 角色 · 四视角设定图（16:9）

```text
角色四视角设定图，同一角色，四格布局：画面上三分之一，左侧为人物近景正视图，右侧为人物近景侧视图；画面下三分之二，左侧为人物全身正视图，右侧为人物全身背视图。浅净背景，画面内无任何文字。真人电影级写实质感，保留真实皮肤纹理与自然光影；四视角为同一人，五官、发型、服装、体型完全一致。
角色外观：{描述}
```

### 场景 · 四视角资料图（22:9）

```text
场景四视角资料图，同一空间：画面左侧至中部为大幅场景正视图，占画面 70% 以上；画面右侧 30% 区域从上到下依次排布同一空间的前、后、左、右四个机位视角的小图。主次清晰，电影级光影设计，真实，细腻，画面干净高质感，无人，画面内无任何文字。
场景：{描述}
```

### 道具 · 双视角图（16:9）

```text
道具双视角图，画面中只有这一件道具，没有人物、没有手、没有其它物品。左侧为道具的正偏侧视角，能看清体积与厚度；右侧为正面视角，与左侧同一件道具、同一比例。背景为{背景}，画面内无任何文字。电影级写实质感，{质感}。
道具：{描述}
```

**通用**：`{描述}` 就是库里那句 ≤50 字描述，原样代入，不扩写、不加剧情；画风只在末尾由全局设定追加，提示词里不堆"8K/超清"。

**道具背景必须二选一**：偏白/浅色/银色/透明/发光的道具用 `纯绿幕背景`（白底会吃掉轮廓），其余用 `纯白背景`。不许写"绿幕或白色"让模型自己挑；`asset_prompt.py build` 会按描述自动判定。

**道具质感默认光洁**：`{质感}` 默认是「表面光洁，无划痕、无破损，材质细节清晰」；只有描述里写了磨损/划痕/旧/破/锈/脏/裂/掉漆/褪色，才换成「保留描述中的使用痕迹与磨损」（写「无划痕」不算）。

## 工作流

### Step 0 — 读资产（只读）

```bash
python cli.py read $WS --table 资产库
python cli.py read $WS --table 资产库
python cli.py read $WS --table 资产库
python cli.py read $WS --table 剧本设定     # 画风/画幅
```

选定本批目标：指定资产名 / 本集 `dependencies` 用到的 / 全部 `待出图`。**没有描述的资产跳过**，先回 `drama-asset-extraction` 补描述。

### Step 1 — 套版式写提示词

按类型套上面对应模板，把描述代入 `{描述}`。可直接用脚本生成，保证格式一致：

```bash
python skills/drama-asset-generation/scripts/asset_prompt.py build --type 角色 --desc "18岁清瘦男生，黑色微卷中长发，白T黑短裤"
python skills/drama-asset-generation/scripts/asset_prompt.py build --type 场景 --desc "老式公寓走廊，浅灰地砖，深灰防盗门，西端窗光，白天，无人"
python skills/drama-asset-generation/scripts/asset_prompt.py build --type 道具 --desc "24寸黑色硬壳行李箱，拉杆拉出，箱角磨损"
```

写入对应表的 `gen_prompt`（资产库），写前先跑一致性校验：

```bash
python skills/drama-asset-generation/scripts/asset_prompt.py check --library $WS
```

### Step 2 — 列清单、确认、写入

清单要写：资产名、类型、版式、画面比例、张数、预估费用。

```bash
python cli.py write $WS --table 资产库 --data @characters.json
python cli.py write $WS --table 资产库 --data @scenes.json
python cli.py write $WS --table 资产库 --data @props.json
```

只写本批目标；`status=复用` 的资产不动。

### Step 3 — 出图

```bash
python cli.py generate $WS --target 资产库:陈诚
python cli.py generate $WS --target 资产库:陈诚公寓门口
python cli.py generate $WS --target 资产库:行李箱
```

一次只出一个资产，出完看一眼再下一个；不要把一批全提交完才验收。

### Step 4 — 出图后检查（见 `references/review-checklist.md`）

- **角色**：四个视角都在、同一人、上近景下全身、浅净背景、无文字、皮肤与光影真实；
- **场景**：左侧大图占 70% 以上、右侧四张小图方向齐全（前/后/左/右）、无人无文字、主次清楚；
- **道具**：左正偏侧、右正面、绿幕或白底、无文字、材质真实。

不合格 → 改提示词重抽（`generate` 花预算，先列清单确认），不要将就。

### Step 5 — 回写

`generate` 会自动回填 `文件路径` 与 `出图状态`；场景还要按 `drama-asset-extraction/references/scene-consistency.md` 过一致性检查，回写 `一致性检查`。

## 版式细则

- **角色**：四视角必须是同一人——脸型、五官、发型、发色、服装、鞋子全部一致；近景只到胸口，全身从头顶到脚底不裁切；背景浅净纯色，无任何文字、水印、logo。
- **场景**：正视图是主体，右侧四图是同一空间的机位变化（前=入口方向、后=反向、左/右=两侧墙），不是四个不同场景；无人、无文字、无标注；光影方向四个视角一致。
- **道具**：左侧正偏侧能看清体积与厚度，右侧正面看整体比例与五金；背景按颜色二选一（浅色用绿幕、其余用白底）；无人物、无文字、无 logo。
- 画面比例：角色 16:9 / 场景 22:9 / 道具 16:9；`generate` 按类型自动取。

## 不做的事

- 不改资产名、不改描述、不新增资产（那是 `drama-asset-extraction` 的事）。
- 不在提示词里写剧情、人物关系、情绪、镜头运动（这些是分镜的事）。
- 不写出图参数清单、不写 NEGATIVE 段；约束写成正向画面要求。
- 不跳过验收批量提交。
