# 三种版式的完整模板

> 唯一合法格式。`{描述}` 用库里那句 ≤50 字描述原样代入，不扩写、不加剧情。
> 画风由 `剧本设定` 在生成时追加，提示词里不重复"8K/超清/电影感"。

## 一、角色 · 四视角设定图

```text
角色四视角设定图，同一角色，四格布局：画面上三分之一，左侧为人物近景正视图，右侧为人物近景侧视图；画面下三分之二，左侧为人物全身正视图，右侧为人物全身背视图。浅净背景，画面内无任何文字。真人电影级写实质感，保留真实皮肤纹理与自然光影；四视角为同一人，五官、发型、服装、体型完全一致。
角色外观：{描述}
```

## 二、场景 · 四视角资料图

```text
场景四视角资料图，同一空间：画面左侧至中部为大幅场景正视图，占画面 70% 以上；画面右侧 30% 区域从上到下依次排布同一空间的前、后、左、右四个机位视角的小图。主次清晰，电影级光影设计，真实，细腻，画面干净高质感，无人，画面内无任何文字。

```

```text
场景四视角资料图，同一空间：画面左侧至中部为大幅场景正视图，占画面 70% 以上；画面右侧 30% 区域从上到下依次排布同一空间的前、后、左、右四个机位视角的小图。主次清晰，电影级光影设计，真实，细腻，画面干净高质感，无人，画面内无任何文字。
```

## 三、道具 · 双视角图（正偏侧 + 正面）

**比例 16:9**（`2048x1152`）

```text
道具双视角图，画面中只有这一件道具，没有人物、没有手、没有其它物品。左侧为道具的正偏侧视角，能看清体积与厚度；右侧为正面视角，与左侧同一件道具、同一比例。背景为{背景}，画面内无任何文字。电影级写实质感，{质感}。
道具：{描述}
```

示例：

```text
道具双视角图，画面中只有这一件道具，没有人物、没有手、没有其它物品。左侧为道具的正偏侧视角，能看清体积与厚度；右侧为正面视角，与左侧同一件道具、同一比例。背景为{背景}，画面内无任何文字。电影级写实质感，{质感}。
道具：24寸黑色硬壳行李箱，拉杆拉出，箱角磨损
```

要点：左侧能看体积与厚度，右侧正面看整体比例与五金。

**背景规则（必须二选一，不许写「绿幕或白色」让模型自己挑）**：

| 道具颜色 | 背景 | 理由 |
|---|---|---|
| 偏白、浅色、银色、透明、发光 | `纯绿幕背景` | 白底会把浅色道具吃掉，抠不出轮廓 |
| 其余颜色（深色、彩色） | `纯白背景` | 通用，干净 |

`asset_prompt.py build` 会按描述自动判定并代入 `{背景}`；判定词表：白色/米白/奶白/乳白/象牙/浅色/浅灰/浅蓝/浅粉/浅黄/浅绿/银/透明/玻璃/雪白/淡/发光。

**质感默认光洁**：`{质感}` 默认「表面光洁，无划痕、无破损，材质细节清晰」；描述里写了磨损/划痕/旧/破/锈/脏/裂/掉漆/褪色才换成「保留描述中的使用痕迹与磨损」。要一条新道具就写「表面光洁无划痕」，别只写「精致」——模型会把「真实使用痕迹」画成划痕。

## 四、负向约束怎么写

不写 NEGATIVE 段，把约束写成**正向画面要求**（模板里已含）：

| 想避免 | 写成 |
|---|---|
| 图里有字/水印 | `画面内无任何文字` |
| 背景杂乱 | `浅净背景`（角色）/ `纯白背景` 或 `纯绿幕背景`（道具，按颜色二选一） |
| 四视角不是同一人 | `四视角为同一人，五官、发型、服装、体型完全一致` |
| 场景四图变成四个场景 | `同一空间的前、后、左、右四个机位视角` |
| 有路人 | `无人` |
