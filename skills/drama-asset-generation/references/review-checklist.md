# 出图后验收清单

逐张看，不合格就改提示词重抽（重抽要花预算，先列清单确认）。不要批量提交完再一起看。

## 角色（四视角设定图）

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 四格齐全 | 上左近景正、上右近景侧、下左全身正、下右全身背，四格都在，没有少格或多格 |
| 2 | 同一人 | 四格脸型、五官、发型、发色一致；服装、鞋子一致 |
| 3 | 上近景下全身 | 近景到胸口以上；全身从头顶到脚底不裁切 |
| 4 | 背景 | 浅净纯色，无杂物、无渐变噪点 |
| 5 | 无文字 | 画面内没有文字、水印、logo、编号 |
| 6 | 质感 | 真人电影级写实，皮肤纹理与光影自然，不塑料、不磨皮过头 |
| 7 | 版式比例 | 上 1/3 下 2/3 大致成立，四格边界清楚（不要求画辅助线） |

## 场景（四视角资料图）

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 主次 | 左侧至中部是一张大正视图，占画面 70% 以上 |
| 2 | 四机位 | 右侧 30% 从上到下四张：前、后、左、右，方向确实不同 |
| 3 | 同一空间 | 四张小图是同一空间的机位变化，不是四个不同场景 |
| 4 | 光影一致 | 四张图的窗光方向、色温一致 |
| 5 | 无人无字 | 没有人物、文字、标注、箭头 |
| 6 | 画面 | 干净、真实、细腻，不过曝、不畸变 |
| 7 | 与描述一致 | 入口/地面/功能区/门窗与资产描述对得上（见 scene-consistency） |

## 道具（双视角图）

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 双视角 | 左侧正偏侧、右侧正面，两个视角都在 |
| 2 | 同一件 | 两个视角是同一件道具，尺寸比例一致 |
| 3 | 无人 | 画面里只有道具，没有人物、没有人手、没有支架 |
| 4 | 背景 | 浅色道具是纯绿幕、其余是纯白，干净可抠（不能两者都出现） |
| 5 | 无文字 | 没有文字、水印、logo、价签 |
| 6 | 材质 | 材质真实（金属、皮质、塑料分得清）；表面与描述一致——默认应光洁无划痕，写了磨损才允许有痕迹 |
| 7 | 与描述一致 | 尺寸、颜色、磨损与资产描述一致 |

## 不合格怎么办

1. 在清单里写明：哪个资产、哪一条不过、差在哪；
2. 优先改提示词：把没做到的版式要求写得更具体（比如"右侧四图必须都出现"）；
3. 重抽（`generate` 花预算，先确认）；
4. 重抽后重新逐条看，不沿用上次结论；
5. 场景图未过，依赖它的分镜不得进入视频生成。
