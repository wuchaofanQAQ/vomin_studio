# 改编规则（小说 → 短剧剧本）

## 一、总原则

改**表现形式**，不改**剧情事实**。观众只能看到和听到，所以凡是不能被镜头拍到或被声音表达的内容，都要转成可见/可听的东西。

## 二、叙述 → 可见动作

| 小说写法 | 剧本写法 |
|---|---|
| "他心里一沉" | 动作/表情：他的手指停在半空，喉结滚动 |
| "她觉得很委屈" | 红着眼眶别过脸，手攥紧衣角 |
| "屋里很破旧" | 写成场头的色调/陈设，或一个可见细节（墙皮剥落、漏雨的盆） |
| 过去经历的交代 | 优先用一个道具/对白点出；必要时短闪回 |

规则：
- 不写"感到""觉得""意识到"这类不可见动词，写可见的外在表现
- 每个动作句只描述一个可拍的动作，避免一句话塞多个转折
- 环境描写服务于动作，不单独大段铺陈

## 三、内心独白

1. 能用表情、动作、停顿表达的，不用独白
2. 确实需要（重生、系统、算计类题材常见）时，用少量旁白/OS，标注 `（OS）`，单句不超过 30 字
3. 连续 OS 不超过 2 句；超过就拆到动作与对白里
4. 原文的金句型心理描写，可保留为 OS，但不得改写含义

## 四、对白

- 保留原话的**信息和语气**，改成口语：短句、断句、一句一个信息点
- 一句台词尽量不超过 20 字；长段独白拆成与动作交错的多句
- 不替角色编造原文没有的关键信息；过渡性寒暄可适度删
- 说话人每句都要标出，供下游 TTS 匹配音色

## 五、删减与补写

**可删**：重复的心理描写、与主线无关的景物铺陈、冗长的背景介绍、已被动作取代的转述。

**可补**（必须标【补】并在说明里列出）：
- 让人物从 A 地走到 B 地的必要过渡动作
- 把转述变成现场所必需的最小场面

**禁止**：新增人物、新增事件、改变因果与结局、改写人物关系、替换原文的反转与悬念。

## 六、节奏（竖屏短剧）

- 开场 1~2 个场内进入核心冲突，不做长铺垫
- 一集一个核心事件，一个钩子
- 信息密度高，台词短促，动作连续
- 该有的细节（标志道具特写、关键环境、回忆闪回）保留，但用最短的篇幅

## 七、结尾钩子

每集结尾落在以下之一：悬念 / 反转 / 威胁 / 情绪爆点。

- 原章末本身有钩子 → 剧本结尾对齐该处，在其最强的一刻收
- 原章末平淡 → 在说明里标"⚠ 无钩子"，给出**建议**（例如把本章最后一个冲突点后移到结尾），**不擅自改剧情**

## 八、场次与场景命名

- 按"同一地点、同一时间、同一空间逻辑"合并为一场；换地点/换时间/闪回另起一场
- 场景名简短稳定，全剧一致（"出租屋"不要一会儿写"张三的家"）
- 同一空间光影不同要在名字里体现（`出租屋·夜` / `出租屋·日`），这与下游场景抽取的拆分规则一致
- 与场景库已有名字对齐；发现同景异名，列"名称归一化对照表"

## 九、改编边界提示

- 章节体量明显过大（可能超出短剧单集容量）或过小：只在说明里提示"建议拆/并"，**仍按 1 章 = 1 集转化**，由用户决定是否调整章节
- 原文敏感或不适合画面表现的内容：保留事实，用侧面表现，并在说明里标注处理方式
