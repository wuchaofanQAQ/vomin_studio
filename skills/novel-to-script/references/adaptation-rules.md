# 改编规则（小说 → 短剧剧本）

## 一、总原则

改**表现形式**，不改**剧情事实**。观众只能看到和听到，所以凡是不能被镜头拍到或被声音表达的内容，都要转成可见/可听的东西。

## 二、叙述 → 可见动作

| 小说写法 | 剧本写法 |
|---|---|
| "他心里一沉" | 动作/表情：他的手指停在半空，喉结滚动 |
| "她觉得很委屈" | 红着眼眶别过脸，手攥紧衣角 |
| "屋里很破旧" | 写成场头的色调/陈设，或一个可见细节（墙皮剥落、漏雨的盆） |
| 过去经历的交代 | 优先用一个道具/对白点出；必要时短闪回 |

规则：
- 不写"感到""觉得""意识到"这类不可见动词，写可见的外在表现
- 每个动作句只描述一个可拍的动作，避免一句话塞多个转折
- 环境描写服务于动作，不单独大段铺陈
- 动作行一律以 `△` 开头（中文影视剧本标记画面/动作的标准符号），对白、OS、字幕、音效行不加

## 三、内心独白

1. 能用表情、动作、停顿表达的，不用独白
2. 确实需要（重生、系统、算计类题材常见）时，用少量旁白/OS，标注 `（OS）`，单句不超过 30 字
3. 连续 OS 不超过 2 句；超过就拆到动作与对白里
4. 原文的金句型心理描写，可保留为 OS，但不得改写含义

## 四、对白

- 保留原话的**信息和语气**，改成口语：短句、断句、一句一个信息点
- 一句台词尽量不超过 20 字；长段独白拆成与动作交错的多句
- 不替角色编造原文没有的关键信息；过渡性寒暄可适度删
- 说话人每句都要标出，供下游 TTS 匹配音色

## 五、删减与补写

**可删**：重复的心理描写、与主线无关的景物铺陈、冗长的背景介绍、已被动作取代的转述。

**可补**（必须标【补】并在说明里列出）：
- 让人物从 A 地走到 B 地的必要过渡动作
- 把转述变成现场所必需的最小场面

**禁止**：新增人物、新增事件、改变因果与结局、改写人物关系、替换原文的反转与悬念。

## 六、节奏（竖屏短剧）

- 开场 1~2 个场内进入核心冲突，不做长铺垫
- 一集一个核心事件，一个钩子
- 信息密度高，台词短促，动作连续
- 该有的细节（标志道具特写、关键环境、回忆闪回）保留，但用最短的篇幅

## 七、结尾钩子

每集结尾落在以下之一：悬念 / 反转 / 威胁 / 情绪爆点。

- 原章末本身有钩子 → 剧本结尾对齐该处，在其最强的一刻收
- 原章末平淡 → 在说明里标"⚠ 无钩子"，给出**建议**（例如把本章最后一个冲突点后移到结尾），**不擅自改剧情**

## 八、场次与场景命名

- 按"同一地点、同一时间、同一空间逻辑"合并为一场；换地点/换时间/闪回另起一场
- 场景名简短稳定，全剧一致（"出租屋"不要一会儿写"张三的家"）
- 同一空间光影不同要在名字里体现（`出租屋·夜` / `出租屋·日`），这与下游场景抽取的拆分规则一致
- 与场景库已有名字对齐；发现同景异名，列"名称归一化对照表"

## 九、改编边界提示

- 章节体量明显过大（可能超出短剧单集容量）或过小：只在说明里提示"建议拆/并"，**仍按 1 章 = 1 集转化**，由用户决定是否调整章节
- 原文敏感或不适合画面表现的内容：保留事实，用侧面表现，并在说明里标注处理方式

## 十、屏幕与字幕（手机文字怎么拍）

短剧里"社恐不说话、全靠打字"是常见设定，手机就是角色的嘴。处理不好会出现三个问题：观众不知道谁的手机、TTS 把字幕当台词读、消息太长来不及看。

规则：

1. **字幕不是台词**：短信、微信、打字内容一律走字幕行，不进对白（下游 TTS 不配音，只做画面字幕）
2. **字幕不挂角色名**：写成 `（字幕·{谁}手机）内容`，不要写成 `沈幼怡：（屏幕字幕）…`——挂了名字就变成台词，TTS 会用她的音色念字幕
3. **必须写归属**：同一场出现两块屏时，动作行写明"谁的手机 + 朝向谁"
   - ✗ `陈诚：（盯着屏幕）一阵子是多久？`
   - ✓ `陈诚：（盯着自己的手机）一阵子是多久？`
   - ✗ `屏幕亮起来，一条消息推到最上面`
   - ✓ `沈幼怡掏出手机。屏幕亮起来，一条消息推到最上面`
4. **屏幕内容要短**：单条 ≤ 25 字。长消息拆成多条连弹，或只留最后一行（原文"他只看清最后一行"可直接照此处理）
5. **打字过程要可拍**：手指一个字一个字地戳、光标闪、删了重打、打完把屏幕转过去。**转屏动作不能省**——那是角色之间唯一的信息传递
6. **已读/未读、发出/收到**要能分清：谁的消息在谁的手机上，用 `（字幕·微信，陈诚手机）` 这类标注锁死

## 十一、可拍性检查（台词必须挂动作）

台词是声音，动作是画面。只有台词没有动作的段落，导演只能拍两张脸，节奏立刻塌。

每写一句台词，先回答三个问题：

1. 谁在说？（说话人和朝向）
2. 说给谁听？（对方在做什么反应）
3. 说完之后，画面发生了什么变化？（递出去、接过来、转过身、门关上）

做法：

- 台词前后各挂一个动作：`她把手机转过来，屏幕正对着陈诚的脸。` → 台词 → `陈诚的手停在门把上。`
- 递/接/举/怼/塞/收回/别开眼/攥紧/退半步，这些动词比形容词值钱
- 禁止裸动作：`盯着屏幕`、`看着手机`、`低头打字`——必须补"谁的、朝向谁、打完给了谁"
- 情绪不写形容词：不写"他很心疼"，写"他伸手把提手朝外翻了一下"

## 十二、量化节奏指标（红果标准）

做的是 2 分钟上下的竖屏短剧，密度用数字卡，不靠感觉。脚本 `scripts/check_script.py` 会逐项校验：

| 指标 | 标准 | 说明 |
|---|---|---|
| 剧本字数 | 1500~2500 | 低于 1500 基本撑不住 2 分钟 |
| 场数 | 5~8 | 超过 8 场说明场次没合并 |
| 可拆节拍 | ≥40 | 动作行 / 台词 / OS / 字幕 / 有效音效，各计 1 拍；约合 20~30 个镜头 |
| 台词句数 | 8~30 | 含画外音；原文对白稀少的章节可偏下限 |
| 声音总量 | 台词 + OS + 字幕 ≥ 12 | 防止"全是动作、没有声音信息" |
| OS | ≤5 | 只给主视角人物，连续不超 2 句 |
| 字幕 | 1~10 | 含时间地点、微信、屏幕字幕；消息型章节可到 10 |
| 单人无对白场 | ≤1 | 超过 1 个就并场或加对手戏 |
| 开场钩子 | 2 行内 | 正文前两行必须出现悬念或冲突 |
| 结尾钩子 | 1 | 每集必须有，落在最强的一刻 |

**节拍不够时怎么加**（按优先级）：

1. 把叙述句拆成连续动作（`她抬手` / `指尖停住` / `又按了一下`）
2. 把转述变成现场（电话内容 → 现场通话；回忆交代 → 短闪回）
3. 给对手反应镜头（他听到这句话时的动作，而不是旁白解释）
4. 补有效音效（门铃、拖鞋声、震动、水声），只补对剧情有信息量的

**禁止注水**：堆形容词、拉长环境描写、重复心理独白、加没有信息量的寒暄。宁可 1800 字全是戏，不要 2500 字一半是水。
