# 剧本格式（结构化场头）

`完整剧本` 字段按本格式排版。**场头是机器可解析的**：下游 `script-to-scene-assets` 的 Step 1 逐场扫描场头，提取场号、内外景、地点、时间、出场人物、关键动作、色调/特殊要求；`director-segment-prompt` 据场头确定每个镜头的环境锁定。场头缺项，下游抽场景就会出错。

## 一、整集结构

```
【第N集】集名

场1｜内景｜出租屋｜夜（雨）
出场人物：张三、李四
关键动作：张三翻出旧手机；李四推门而入
色调/特殊：冷蓝调，低饱和

（动作描述）
张三坐在床沿，手指抹过手机屏幕上的裂纹。

张三：（低声）这一天，我等了十年。
李四：（推门，喘气）你还有脸待在这儿？

场2｜外景｜街边｜夜
...
```

## 二、场头字段（逐场必写）

| 字段 | 写法 | 说明 |
|---|---|---|
| 场号 | `场1`、`场2`…集内连续 | 下游以此对应生成片段 |
| 内/外景 | `内景` / `外景` | 对应 INT / EXT |
| 地点 | 稳定的场景名 | 全剧同景同名；与场景库对齐 |
| 时间 | `日` / `夜` / `黄昏` / `清晨`，必要时加天气 | 光影不同要体现，如 `夜（雨）` |
| 出场人物 | 顿号分隔，角色库正名 | 含有台词或动作的角色，不含纯背景人群 |
| 关键动作 | 一行，列决定陈设与站位空间的动作 | 如"开门、坐沙发、望向窗外"——动作暗示空间结构，下游据此定锚点 |
| 色调/特殊 | 可选；如"闪回低饱和""外景强光热浪" | 闪回/特殊色调场景由此识别 |

## 三、场景拆分规则（与下游一致）

1. **空间连通性**：被实体墙或门隔开的区域是不同场景（客厅 / 卧室）；互通的是同一场景（客厅与开放式厨房）
2. **光影时刻**：同一空间不同时刻/光影拆开写，并在名字里体现（`出租屋·日` / `出租屋·夜`）；同空间只出现一种光影则不加后缀
3. **闪回**：独立一场，场头色调栏标明回忆色调

> 场头只负责**如实标出**地点与时间，场景的母版/主图/局部定义由 script-to-scene-assets 完成，此处不要设计空间结构。

## 四、正文写法

- **动作行**：现在时，写可见动作，一句一个动作
- **对白行**：`角色名：（语气/动作提示）台词`；语气提示只在必要时写
- **旁白/内心**：`角色名（OS）：台词`
- **画外音/电话声**：`角色名（画外）：台词`
- **音效/关键声音**：`（音效）手机震动声`，只写对剧情有意义的
- **字幕/时间跳转**：`（字幕）十年前`，单独成行

## 五、不要写进剧本的内容

- 镜头语言（景别、运镜、机位）——这是 `director-segment-prompt` 的工作
- 空间的方位设计（北/南/东/西、P0/P1）——这是 `script-to-scene-assets` 的工作
- 情绪形容词堆砌——写成可见动作

## 六、示例（节选）

```
【第1集】重生第一夜

场1｜内景｜出租屋｜夜（雨）
出场人物：张三
关键动作：张三从床上惊醒；翻身下床；走向窗边看雨
色调/特殊：冷蓝调，雨夜，窗外路灯冷白光

雨点敲在窗玻璃上。张三猛地坐起，大口喘气，额头全是汗。
他低头看自己的手——年轻、没有伤疤。
墙上的日历停在十年前的一天。

张三（OS）：我……回来了。

场2｜外景｜街边｜夜
出场人物：张三、李四
关键动作：张三冲出楼道；李四拦路
色调/特殊：路灯暖黄，湿地面反光

……
```

## 七、交付前检查

- 每场都有场号、内外景、地点、时间、出场人物
- 地点名与场景库一致
- 没有镜头语言、没有空间方位设计
- 每句对白都有说话人
- 结尾落在钩子上
