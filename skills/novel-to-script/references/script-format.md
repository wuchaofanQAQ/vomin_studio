# 剧本格式（大厂标准分场景剧本）

本文件是 `完整剧本` 字段的**唯一格式标准**。写之前先读一遍，写完用 `scripts/check_script.py` 验一遍。

格式参照国内影视/短剧通行的分场景剧本规范：**场头四要素 + 人物行 + △ 动作行 + 角色台词**。下游 `script-to-scene-assets` 逐场扫描场头抽场景，`director-segment-prompt` 据 △ 行拆镜头——格式错一处，下游就少一个锚点。

## 一、文件与抬头

```
剧名：养妹失策，社恐妹妹占有欲爆棚
第1集　如果你不想要我，我可以走
```

- 第一行 `剧名：` + 剧名（全剧一致）
- 第二行 `第N集` + **全角空格** + 集名
- 文件名：`ep{两位集号}_script.md`，如 `ep01_script.md`
- 抬头与第一场之间空一行

## 二、场头（每场三行）

```
1．外景　陈诚公寓门口　日
人物：沈幼怡、陈诚
备注：八月末下午两点，40℃白炽烈日，热浪扭曲空气，高光过曝
```

| 元素 | 写法 | 说明 |
|---|---|---|
| 场号 | `1．` 阿拉伯数字 + 全角句点 | 集内连续；**跨集不重复编号** |
| 内/外景 | `内景` / `外景` | 对应 INT / EXT |
| 地点 | 全角空格分隔 | 稳定的空间名，全剧同景同名，与场景库对齐 |
| 时间 | `日` / `夜` / `清晨` / `黄昏` / `深夜` | 特殊场次加全角括号，如 `日（闪回）`、`夜（雨）` |
| 人物 | `人物：A、B` | 顿号分隔，角色库正名；只列有台词或动作的人 |
| 备注 | `备注：…` | 可选。光线、色调、天气、特殊要求，供场景图与分镜参考 |

规则：

1. 场号、内外景、地点、时间之间用**全角空格**，不用 `｜`、`|`、逗号
2. 闪回场在时间后加 `（闪回）`，不单独占一列
3. 同一空间不同光影/时刻拆场（`陈诚公寓·客厅　夜` 与 `陈诚公寓·客厅　日` 是两场）
4. 被门/墙隔开的区域是不同空间（玄关客厅 / 卧室 / 洗手间），互通的开敞区域算同一空间

## 三、正文元素

| 元素 | 写法 | 说明 |
|---|---|---|
| 动作/画面 | `△动作描述。` | **顶格、以 △ 开头**，现在时，一句一个动作 |
| 对白 | `角色：台词` | 顶格，全角冒号；角色名用正名 |
| 内心独白 | `角色（OS）：台词` | 只给主视角，连续不超 2 句 |
| 画外音/电话 | `角色（画外）：台词` | 电话、门外、背后传来的声音 |
| 音效 | `（音效）门铃，短促一声` | 只写对剧情有信息量的 |
| 字幕 | 见第四节 | **不挂角色名** |
| 集尾 | `（本集完）` | 最后一行的固定收尾 |

## 四、字幕的三种写法

字幕**不是台词**：不参与 TTS 配音，只做画面文字。

| 类型 | 写法 | 示例 |
|---|---|---|
| 时间/地点 | `（字幕）六年前` | 跳转、闪回、时空交代 |
| 他人消息 | `（字幕·微信，{收件人}手机）内容` | `（字幕·微信，陈诚手机）幼怡今天下午一点到，记得开门。` |
| 本人打字 | `（字幕·{本人}手机）内容` | `（字幕·沈幼怡手机）谢谢哥哥。` |

规则：

1. **不挂角色名**。`沈幼怡：（屏幕字幕）…` 是错的——挂了名字就变成台词，TTS 会用她的音色念字幕
2. **先交代屏上有字**：动作行写到"屏幕上，一行字："再接字幕行，字幕不能凭空出现
3. **单条 ≤ 25 字**，超长拆成多条连弹或只留最后一行
4. **归属写死**：谁的手机；同场两块屏时尤其不能省
5. **转屏动作不能省**：把屏幕转过去、怼进门缝、举到他眼前——那是信息传递本身

## 五、排版硬规则

1. 场与场之间**空一行**；场头三行之间不空行
2. 正文行之间**不空行**（连续动作用多个 △ 行，一句一行）
3. 全部使用**全角标点**：`，。：；？！（）「」`
4. 不使用 Markdown 标记（`**`、`#`、`-`、代码块）——存进飞书会被当成字符
5. 不使用表情符号、页眉页脚、水印、页码
6. 动作行与台词行**顶格**，不缩进

## 六、禁止写进剧本的内容

- **镜头语言**——这是 `director-segment-prompt` 的工作：
  - 景别：`特写` `大特写` `近景` `中景` `全景` `远景` `过肩`
  - 运镜：`推` `拉` `摇` `移` `跟` `升降` `环绕` `手持` `转场`
  - 机位/角度：`俯拍` `仰拍` `平视机位` `鱼眼` `广角` `航拍` `第一人称视角`
  - 剪辑：`切` `淡入` `淡出` `叠化` `镜头切换` `分屏`
  - 改写方式：把镜头语言换成**角色动作**——`（特写）手机屏幕` → `△手机屏幕亮着。`
  - 注意：`推` `拉` `跟` `切` 作为动作动词正常使用（推门、拉上门、跟上、切到外卖页），只有当运镜术语时才禁
- **空间方位设计**（北/南/东/西、P0/P1）——这是 `script-to-scene-assets` 的工作
- **情绪形容词堆砌**——写成可见动作

## 七、完整示例

```
剧名：养妹失策，社恐妹妹占有欲爆棚
第1集　如果你不想要我，我可以走

1．外景　陈诚公寓门口　日
人物：沈幼怡、陈诚
备注：八月末下午两点，40℃烈日，热浪扭曲空气

△沈幼怡的手机屏幕亮着。一根手指一个字一个字地戳，屏幕上，一行字：
（字幕·沈幼怡手机）我是沈幼怡。
△沈幼怡站在门口，后背湿透了，汗顺着下巴滴到行李箱拉杆上。
△她抬手，指尖在门铃上停住，没敢按。
（音效）门铃，短促一声。
陈诚（画外）：谁啊？
△门开一条缝。
陈诚：（从门缝里打量她）找错了吧？
△门要合上。
△沈幼怡伸手，把手机怼进门缝里。
（字幕·沈幼怡手机）我是沈幼怡。
△门停住了。
陈诚（OS）：沈幼怡。这三个字，是他捂了六年的旧疤。

2．内景　陈诚公寓·玄关客厅　日
人物：陈诚、沈幼怡

△陈诚站在门口，没让开。
陈诚：你爸呢？
...

（本集完）
```

## 八、交付前自检

```bash
python skills/novel-to-script/scripts/check_script.py workspace/{剧名}/drafts/ep01_script.md
```

脚本会校验：抬头、场头格式、人物行、△ 标记、台词格式与说话人、集尾、字数/场数/节拍/OS/字幕/单人场、镜头语言禁词。**不通过不交付。**

手工再过一遍：

- [ ] 每场都有场号 / 内外景 / 地点 / 时间 / 人物
- [ ] 每行动作以 △ 开头；对白、OS、字幕、音效不带 △
- [ ] 每句台词都有说话人，且说话人在本场人物行里
- [ ] 每句台词都有可见动作承载
- [ ] 屏幕类台词写明设备归属，转屏动作不省
- [ ] 字幕按三种写法标注，且不挂角色名
- [ ] 无镜头语言、无 Markdown、无方位设计
- [ ] 前两行有钩子，结尾落在钩子上
- [ ] 以 `（本集完）` 收尾
