# 交付前自检（必须亲自通读 + 两轮核对 + 修正闭环）

> **铁律：必须亲自从头到尾读一遍全稿。**
> 脚本只查机械项（结构/时间/锚点/台词/密度），读一遍才查得出「这句话拍不拍得出来、和前一句冲不冲突」。
> 不允许用「校验 0 错」代替通读；不允许用「已检查三遍」代替具体修改；文本自检 ≠ 出片实测。

## 第零步：为什么要亲自读

脚本只能发现我编码进去的规则。历史上真实漏掉的问题：
- 2 秒的镜里写「十秒钟过去」；
- 同一段的近景里写画外角色「抬眼又垂下」，下一镜又写「她没抬头」；
- 门「从内侧拉开」却没写谁开的，模型会让门自己动；
- 近景里写后景是地砖，这个焦段根本拍不到；
- 目线写反：她在画左，视线却写「落向画右画外」。

这些问题格式全对、脚本全过。**只有人读能发现。**

## 第零步·二 — 图与备注对过了吗

- [ ] 每个入画资产，**都亲眼打开过它的图片**（不是只读了 `描述`）
- [ ] 图片里真实的长相、服装、家具摆放，和正文写的一致
- [ ] **没有把参考图的机位/构图当成剧情机位**（参考图是广角，不代表本段都广角）
- [ ] 能说清这个空间的门、窗、光源、主要家具朝向和轴线；说不清的地方已标待补或问过
- [ ] `备注` 对照过，但没有照抄：备注与图/剧本对不上时，是按自己的空间判断改的，并写明了依据
- [ ] 光影不匹配（图是白天、戏是傍晚）时，没有用文字硬压光，而是先补图

## 情绪落点 — 这场戏的劲儿给了吗

- [ ] 每一场能说出「谁想要什么、谁在挡、谁退了一步」
- [ ] 人物在藏的东西，有对应的镜头（躲视线 / 手部 / 呼吸 / 停顿），不是全靠台词
- [ ] 原文里最扎的那句或那个动作，没有在压缩时丢掉

## 六层逐镜过（每镜都要能答出来）

- [ ] 环境声逐个问过「这个空间真的有这个声源吗」；没有就不写，不拿「没有风」凑数
- [ ] 这一镜的**构图、光影、环境、音效**都能说出「怎么设计、为什么、表达什么」；说不出来的项就是没设计

- [ ] 景别＋机位：从多远、站哪儿看
- [ ] 调度：人和机位这一镜怎么动
- [ ] 表演：他在忍什么，身体哪一处泄漏了
- [ ] 环境：空间里有什么在动（热浪/灰尘/窗帘/地板）
- [ ] 环境音：这一镜能听见什么
- [ ] 光影：光从哪来、和上一镜比变了什么
- [ ] 切点**只在有意义时写**（动作未完/声音/出门框/眼神变化）；没有决定就不写，别每镜一个「切在」
- [ ] 终态：只写**切出瞬间的状态**（位置/朝向/持握/开门角度/道具），不重复末镜动作、不写「下一段…」——否则模型会把终态当成第二个镜头再演一遍
- [ ] 终态以「切出瞬间状态（不占时长、不另拍镜头）：」开头，模型才认得出它不是镜头

## 运镜专项（每镜过一遍，判据见 `camera-movement-and-lens.md`）

- [ ] 这一镜**结束时观众多知道什么**，说得出来；说不出来就退回固定镜头
- [ ] 人物路径与摄影机路径分开写过，不是一句"向前移动"
- [ ] 拍法认得出来：摇摄（原地转，有起止对象）/ 横移（机位侧移，有前景—远景相对位移）；俯仰（只改角度）/ 升降（改高度）；变焦（机位不动）/ 推近（机位靠近）
- [ ] 起始景别与落幅景别写清，且真的不同；渐变过程有时间支撑
- [ ] 推拉不是只有平面缩放：前景、中景、后景的投影关系有没有跟着变
- [ ] 环绕/跟拍写了持续转向与距离关系；新露出的侧脸、衣服、背景可信
- [ ] 焦点落在该看的信息上；移焦有清晰区域连续转移的过程，没有把两个主体都锁死为清晰
- [ ] "缓慢"有可观察参照（"在她抬眼的过程中开始，到表情稳定时停住"）
- [ ] **晃动/震动有四项**：幅度（占画高多少/几个指宽）、频率（每秒几次）、方向、来源（呼吸、脚步、门板、喷嚏）；写"手持/轻晃"等于没写
- [ ] 没有拿设备名代替路径（"稳定器/无人机/手持"必须补"镜头去哪"）
- [ ] 条件不打架：推近不锁人物大小、跟拍不锁距离、环绕不锁朝向、移焦不锁双清
- [ ] **运镜目标在起幅真的存在**：推近/拉远/摇向/绕到的东西，起幅时看得见吗？还没出现（比如手机还在包里）就改成"起幅固定，等它出袋的一瞬才推"
- [ ] **后景在机位前方**：机位在门外，后景就是门内；机位在门内，后景才是走廊。别把摄影机背后的空间写成后景
- [ ] **三层不硬套**：特写、插入镜（门铃钮、手机背面、屏幕）只写画框里有什么；只有真有纵深（门缝、过肩、走廊）才分前景/中景/后景
- [ ] **主体不叫"中景"**：人用【名】+画面位置；"中景"是景别或景深层，不是人物
- [ ] **画框外的看不见**：全景里看不清他眼睛、中景里看不见脚趾、近景里看不见墙脚——写之前先反算这个焦段能取到哪
- [ ] 是「眼神变了」还是「瞳孔缩、眼睑收窄、视线从眼睛移到下颌再钉回来、中途没眨」——后者才拍得出来
- [ ] 主观镜头点了名：写清是谁的眼睛（`【陈诚】主观视角`），不用「他」「他的视线」
- [ ] **视线移动有载体**：写"视线从 A 移到 B"时，画面里 B 真的出现吗？没出现就让镜头跟着移、或切主观，别只写眼球动
- [ ] **景别装得下这个动作**：胸以上拍不到腰胯、膝以上拍不到脚、近景拍不到鞋尖；装不下就换景别，不是改动作
- [ ] **视线写画外要两样东西**：画面方向（画左/画右/画外上/画外下）+ **空间参照**（门槛外她站的那一侧／走廊尽头那扇窗／阳台外）。只写"画外"没方向，只写"画左"模型仍不知道那里是什么
- [ ] 视线的左右与【本段初始空间】的轴线一致：她在画左，他就不能"往画右别开"；先定轴线，再写目线
- [ ] 接下一镜时，人物走向、视线方向、光线方向、行动轴线能对上

## 台词括号专项（每句台词过）

**四要素缺一不可**：音量（几成）＋语速（快/平/慢）＋停顿位置（哪个字或标点后停）＋尾音变化（上挑/下压/平落/拖长/切断）。

- [ ] 每句括号都回到原文那一段核过情绪：这一刻是疑惑 / 烦躁 / 惊 / 隐痛 / 关心，不是按人设套的
- [ ] 每句都有**音量**，写成几成，不是"大声/小声"
- [ ] 每句都有**语速**（快 / 偏快 / 平 / 慢）
- [ ] 每句都有**停顿位置**：哪个字、哪个标点后停半拍或一拍
- [ ] 每句都有**尾音**：上挑 / 下压 / 平落 / 拖长 / 切断
- [ ] 尾音与标点一致：`！`砸下、`？`上挑或平落、`……`拖长、`？！`先升后砸、`~`拖软上扬、`，`停半拍不换气、`。`收住平落
- [ ] 没有情绪判断冒充发声：`紧张地说`、`生气地说`、`高兴地说`、`委屈地`
- [ ] 没有内心状态：`心里咯噔`、`心想`、`暗想`、`脑海里`、`琢磨`、`暗自`
- [ ] 说话人在画外时，没写只有画面才看得见的动作（喉结、眼神、手势、表情）
- [ ] 声音与画面分工：括号写发声，镜头正文补可见动作（"说话时他脖子往前一梗"）或画外可听的声音

## 比喻与推断（每镜过）

- [ ] 正文里没有比喻："像……""似的""仿佛""如同""宛如"（台词原文里的比喻不动）
- [ ] 没有把推断当画面："像在门口站了很久""像怕被人发现""像后悔问了"——观众看不见"像"
- [ ] 没有一个动作被文学化："把回忆从眼睛里甩掉""被自己说出口的话绊了一下"
- [ ] 删掉比喻后，该镜**仍然有一个可拍的物理动作**顶着（不是删完就空）
- [ ] 正文里没有导演意图解释（"为了让…""成为唯一运动""纹丝不动""象征"）：模型只执行看得见的东西

## 现场生成与整体基准（每段过）

- [ ] 【本段现场生成】**分条列出**要重建的元素：`1.` `2.` `3.` 各占一行
- [ ] 只说要重建什么，**不写**"取自参考图""不再重建""取用层/重建层""没有独立参考图"这类来源说明
- [ ] 人物/道具的形制补充（谁的手、多大、什么材质、几颗钉子）写在这里，**不写进整体基准**
- [ ] 整体基准只写本段差异：时段、光比、光色、主体保持、尺度、声音、剪辑执行——不写具体物件构造
- [ ] 没有要重建的，现场生成写「无」

## 第一轮：材料与覆盖

逐项核对，缺一项不算过：

| # | 核对项 | 通过标准 |
|---|---|---|
| 1 | 段界 | 每段独立，段头 `[0s-总时长]`，镜号从 01 起 |
| 2 | 时长 | 每段 ≤30s、全片 ≤180s、镜头首尾相接无空隙 |
| 3 | 原切镜 | 剧本原有的切镜全部保留；新增切镜有叙事或节奏理由 |
| 4 | 事件 | 剧本事件、结果、因果无增删（只补机位/调度/表演/受力） |
| 5 | 台词 | 逐字、每句只在真正发声的位置出现一次 |
| 6 | 身份 | 角色是谁、什么关系、什么状态，与剧本一致 |
| 7 | 资产名称 | 与库内行逐字一致；锁定项在正文都有真实用途；正文标签都能在锁定区找到 |
| 8 | 待补状态 | 库里没有的单列「待补」，不编锚点、不伪装成已验收 |
| 9 | 用户最新要求 | 本轮用户新增的每条要求都落到具体镜头 |
| 10 | 字符与平台 | 单段 ≤12000 字；16:9 / 24fps / 时长符合平台 |
| 11 | 材料真读到 | 剧本、资产表、参考图确实读过；没读到的写「未读取」，不猜 |
| 12 | 旧项目残留 | 清掉上一版/上一集/旧格式的编号、称呼、场景名 |

同基础名冲突（如「客厅」与「客厅（夜）」）必须确认区分，不自造文件。

## 第二轮：逐镜模拟拍摄

在脑中把摄影机放到写定的位置，逐镜走一遍：

1. **机位与可见**：这个景别、角度、遮挡下，能看见写的全部内容吗？画外人物的名字有没有被写进正文？
2. **动作时间线**：位置 → 支撑 → 持握 → 动作来向 → 接触点 → 反冲 → 结果，是否都在时长内成立？
3. **接触先于结果**：谁先受力、谁后动，有没有写反。
4. **摄影机反馈**：抖动/后坐有来源吗，还是无因抖动。
5. **特效传播**：从哪发出、往哪走、占多大、什么时候消散。
6. **群众/群像**：数量、位置、是否持续行动，不是背景板。
7. **光影与声音**：光有来源吗？声音有方向、有远近层次吗？
8. **切镜终态**：切出瞬间谁在什么状态，下一镜能不能直接接上。
9. **大动作镜**：动作分句 ÷ 秒数，超过约 3 条/秒就拆镜或加时长。
10. **文戏镜**：目线方向、面部受光、停顿节奏、手指与呼吸。
11. **运镜是否成立**：起幅→落幅的取景真变了没有；人物与摄影机是不是各走各路径；推拉有没有变成平面缩放；环绕/跟拍的新露出区域可信不可信；接镜时走向、视线、光向、轴线对不对得上。

## 出片之后：镜头成立性验收（有生成结果时）

先看开头、中段、结尾，再整段播一遍，按 `camera-movement-and-lens.md` 第 14 节逐项过：起止景别、路径是否各自成立、遮挡与门窗位置是否连续、推拉是否只有平面缩放、焦点是否落在该看的信息、人物与道具一致性、接镜轴线。

**每次修改先处理最明显的一项**：路径错了先简化运动；侧脸/手部不一致补人物参考；拉远后房间重建错误补空间资产；节奏不对改用分段生成或后期剪辑。不要靠加"高级""电影感"去修补具体问题。文本自检 ≠ 出片实测，没出片不写"实测通过"。

## 内部检查表（至少覆盖）

剧情与对白完整 · 段界与时间轴 · 资产存在或清楚待补 · 别名绑定 · 每段独立 · 世界轴与屏幕轴一致 · 所在楼层与支撑可行 · 可见集合真实 · 景别与信息精度匹配 · 机位路径可通行 · 敌我明确 · 群像持续行动 · 尺度与占比一致 · 快动作可执行 · 接触先于结果 · 摄影机反馈有来源 · 特效在空间中真实运动 · 关键帧与变速连续 · 身份与变色连续 · 光影与声音有来源 · 正向表达 · 字符与平台限制 · 缺图处置 · 文件内容完整。

**数值必须记录对象、单位、来源与适用镜头**（如「肩背比直立头顶高约半米——第 1 段尺度参照」）。
**时间指代要核对**：正文里的「同时、随后、此时、片刻后」，是否与时间码一致。

## 修正闭环

发现问题后：

1. 改**实际提示词**，不改检查表；
2. 复检**受影响镜头和相邻衔接**（前镜终态、后镜起幅）；
3. 涉及**空间轴、角色身份、资产替换、世界尺度**的修改，回查该场**全部相关段落**；
4. 高风险项再做一轮**定向第三轮**；
5. 尚有剧情遗漏、台词变化、时间轴断裂、空间矛盾、关键身份冲突时，**不能宣告通过**；
6. 按授权待补的资产**单列**，不掩饰为已经验收。

## 高风险回归类型

按本项目**实际出现过**的类型抽检，不出现的类型不强加：

跨场景往返 · 正反图 · 复杂支撑（骑乘/悬空/攀爬） · 多主体快动作 · 巨物 · 群战 · 连续特效 · 多道攻击 · 变速关键帧 · 外观渐变。

## 独立审查

- 有独立审查能力时：让只拿到母版、剧本和资产的审查者试写代表段，再按同一标准查缺口。
- 没有时：**明确写「自查」**，不伪称盲测。
- 测试失败的条款，回改母版或提示词后复核。

## 武戏专项（有认可样本时）

必须实写本项目最难的代表段（连续近战 + 关键大招 + 收束），再逐镜对照样本，比较：动作路径与节拍、有效攻击密度、连续防反、实体受力、环境变化、特效体积与推进、尺度参照、切镜与机位反馈、美感与结果可读性。**不按字数或形容词数量评分**；样本里有效的功能被弱化就回改复检；不把素材本身的错误当优点复刻。

## 收到失败反馈时

1. 先记录**时间码与实际画面**；
2. 区分：明确可见的问题 / 可能原因 / 待验证假设；
3. 保留已成功的部分，按**自然动作节点**修复；
4. 解释原因时不虚构模型未公开的权重或算法。

## 交付写法

```text
自检：PASS（第一轮 12 项 + 第二轮 10 项 + 通读 67 镜）
```

失败时逐条写：

```text
#9 失败：p04 镜头05 写「十秒钟过去」，这个镜只有 2 秒。
修订：删掉「十秒钟过去」，改为「手臂开始发酸」；复检镜头04/06 衔接，无影响。
```

- 资产未就绪：记 `PENDING（预览）`，**不写 PASS**。
- 只有 `preflight` 0 问题、进入生产态，才能写 PASS 并调模型。
