# 对白与声音

## 对白行格式

对白**另起一行**，紧跟在它所属的镜头正文之后：

```
起-止，编号+名称（语气说）：『台词』（行首时间窗）
```

范本写法对照：

| 情形 | 写法 |
|---|---|
| 画内说话 | `【对白 0.5-3s】杨广：人有南北，国有南北吗？` |
| 带语气 | `【对白 00:04.90—00:06.30】杨广，得意地：姜先生，看到了吗？` |
| 带延续语气 | `【对白 00:06.30—00:08.90】杨广，从高处继续得意地说：朕用十个月就建好了东都洛阳，` |
| 画外声（带方位） | `杨广（身后偏侧画外声）：…` |
| 画外声（简写） | `李世民·画外声：…`、`姜颜·画外声：想不想学？` |
| 内心独白 | `姜颜 内心独白：这里，就是月宫吗？` |
| 末句收尾 | `杨广，得意地收尾：贯通南北。` |

## 括号里写什么：发声方式，不是情绪

括号是给模型的**表演指令**。模型读不懂"紧张地说""生气地说"，但读得懂**声音怎么出来**。写法是**两个槽位**，一条括号 **8~13 字**：

```text
【角色】（状态/动作，声音与语流的处理）：「台词」
```

| 槽位 | 写什么 | 例（取自已验收的参考稿） |
|---|---|---|
| **状态/动作** | 可演的身体状态、方位、动作：喘息、咬牙、突然开口、打断、坏笑、哭腔、从后方、由前方高处 | 撑枪喘息、突然开口、克制怒意、带着坏笑、从后方大喝 |
| **声音与语流** | 音量＋清晰度＋语速＋停顿＋尾音，用自然语 | 声音低而清楚、平直而压紧、逐字清楚、语句间带明确压迫停顿、尾句笃定落重、尾字落稳、短促、问句越到末尾越轻、气息轻落、拖长尾音 |

写之前心里过四件事——**音量、语速、停顿位置、尾音变化**——但落到纸上要合成一句人话，**不要写成参数表**（"音量六成、语速偏快、问号后停半拍"这种读起来像仪表盘，模型反而抓不住重点）。

**OS 另规矩**：行首写「内心独白，」，嘴唇状态在【本段整体基准】统一声明一次（「内心独白一律嘴唇闭合」），括号里不再重复。

**先回原文定位情绪**：写括号前回到小说那一段，确认这一刻是疑惑、烦躁、惊、隐痛还是关心——**不按人设外推**（人设是毒舌傲娇，不等于每句都在发火）。同一场戏里，开门前的烦躁和开门后的打量是两拍。

**不写情绪词**：愤怒、紧张、高兴、委屈一个都不出现；情绪由"状态＋声音"推导出来。全稿 61 条台词里，"愤怒地说"这类写法是 0 条。

> **标点归属**：字是剧本的，标点可以是分镜的。剧本只写「靠。」，模型读不出炸毛；分镜里改成「靠！」它才知道是脱口而出。**改标点不算改台词**，但改字算。

### 标点就是发声指令

| 标点 | 发声处理 |
|---|---|
| ！ | 音量抬高、语速快、尾音落重、字间不留缝 |
| ？ | 真问 → 尾音上挑；反问 / 冷淡 → 尾音落平 |
| ？！ | 先升到顶，再砸下来 |
| …… | 尾音拖住，气带完再收 |
| 。 | 音量收、尾音落平，字咬实 |
| ， | 停半拍、不换气 |
| ~ | 尾音拖软、上扬 |

**顺序**：先看标点定尾音 → 再按情绪定音量与语速 → 最后标停顿位置。同一句里两个标点（"？……""？！"）要分别给动作。

### 不能写的两类

| 不能写 | 为什么 | 改成 |
|---|---|---|
| 紧张地说 / 生气地说 / 高兴地说 / 难过地说 | 情绪判断，模型无法执行 | 音量六成、语速快、句号尾音往下砸 |
| 心里咯噔一下 / 心想 / 暗想 / 脑海里 | 内心活动，既看不见也听不见 | 倒吸一口气、音量五成、逗号后停半拍 |
| 喉结动了一下（人在画外） | 画外拍不到，模型会凭空补出这个人 | 音量二成、从牙缝里挤、尾音直接断 |
| 偷偷打量（该镜她不在画面） | 观众看不到她的打量 | 音量两成、语速慢、省略号拖住 |

### 画面配合

声音写进括号，可见动作写进镜头正文：`画外，【陈诚】的吸气顿了半拍`、`说话时他脖子往前一梗`。说话人在画外时，正文只能补**声音**与**画外动作的后果**，不写他的表情、手势、姿态。

## 时间码规则

1. 对白起止**必须落在所属镜头窗口内**。
2. 范本实测：对白起点平均晚于镜头起点约 0.1 秒、终点平均早于镜头终点约 0.14 秒，即**对白几乎铺满镜头**。长镜头里可留白（起点最晚约 1.25 秒、终点最早约 1.75 秒），那是给动作或停顿的。
3. 一个镜头一般一条对白；一句长话拆到多个镜头时，每个镜头里的片段以逗号或句号自然结尾（见下文"长句拆分"）。
4. 同一段内，对白时间码按时间排序，不重叠。

## 语速

| 项目 | 数值 |
|---|---|
| 中位语速 | 约 4.5 字/秒 |
| 上限 | 约 5.3 字/秒 |
| 实测范围 | 2.0~5.3 字/秒（慢速多为带停顿或情绪压低的句子） |

计算：去掉标点后的汉字数 ÷ 对白时长。超过 5.3 就拆镜、延长窗口或删字。

校验示例：`姜颜：多谢。`（2 字）窗口 0.65 秒 → 3.1 字/秒；`杨广，得意地：姜先生，看到了吗？`（8 字）窗口 1.4 秒 → 5.7 字/秒，偏上限，应加长窗口。

## 长句拆分

一句长台词拆给多个镜头时：

- 在**逗号处**断，前一镜以逗号收（"朕用十个月就建好了东都洛阳，"），后一镜接续；
- 听话人的反应镜头插在中间，说话人声音以"从画外高处连续说"续上；
- 收尾镜头标"收尾"。

范本第20段：杨广的三句宏愿拆在镜头 05（说话人）→ 06（听话人，画外高处连续说）→ 07（说话人，收尾）。

## 画外声

画外声（说话人不在画面内）要写**方位与距离**，并在听话人的镜头里写**声音来向**。方位 = 画面方向 + 空间参照，两样都要：

- `杨广的声音从画外高处落下，带空殿轻余响`
- `镜头轻推，画外声音从对面连续传来`
- `画外声音从面前方向连续传来`
- 台词括号里的视线/声音同理：`（抬眼压向门槛外她那侧、语气发硬地说）`，不是 `（抬眼压向画外、…）`

## 内心独白

- 对白行标"内心独白"，并**明确嘴型与声源**：`陈诚 内心独白（嘴唇不动，画外声）：……`。只写"内心独白"不写嘴型，模型可能让人物开口说话。
- 整体基准写："内心独白清楚，外部空间静寂"或"内心独白清晰可辨"，让环境声退到背景。
- 画面里人物不开口：镜头正文写"嘴唇闭合"，不要写嘴部说话动作；表演用喉结、眨眼、视线承担。

## 连续声桥

多镜头对白的**声音不随切镜中断**。有对白的段，整体基准末尾附固定句（原样复制）：

> 本段总时长按剧本锁定；对白在动作与反应中连贯说出，切镜作为连续声桥，同句换景别时声音持续。短反应与视线变化发生在说话过程中。

镜头里配合：说话人切到听话人时，不重新起句，写"画外声音接完后半句时，她的眉眼停了一瞬"。

## 对白之外的声音

声音层次写在整体基准，一句话列出本段的现场声：

- 自然声：风声、水声、林风、院中风声与呼吸
- 动作声：脚步、衣料、兵器碰击、落地闷响、酒杯撞地、咀嚼
- 空间声：空殿轻混响、低频水声的厚重包围感、厚水中延续的冲击轰鸣与石块碎裂余响
- 静场：重大动作之后留一段只有风声/呼吸的静场（"刃停之后让院中风声与呼吸形成静场，再进入授艺文戏"）

镜头里需要强调声音时，直接写出声音事件：`发出一声清亮撞响`、`低沉冲击轰鸣与石块碎裂余响在厚水中延续`。

**声音要闭环**：整体基准声音层次里列出的每种声音，都要在至少一个镜头里作为声音事件出现（如 `（音效）拖鞋拍地两下`）；镜头标题里提到的声音（如"门缝与拖鞋声"）正文必须有对应写法，否则标题和正文对不上。

## 台词与字幕

提示词里**只写台词内容**，不写字幕样式。台词保持剧本原文，标点按原文，不润色。

## 屏幕文字是画面内容，不是字幕

手机、平板、电脑屏幕上的字**由模型生成在画面里**，写进镜头正文，不是后期字幕。

| 写什么 | 怎么写 |
|---|---|
| 界面 | `聊天软件单聊界面，白底，顶部联系人昵称栏，底部输入框` / `会话列表` |
| 气泡方向 | 自己发的是右侧绿色气泡，收到的是左侧灰色气泡 |
| 文字内容 | 用「」括起原文：`右侧绿色气泡「我是沈幼怡」` |
| 打字过程 | `输入框里逐字敲出文字，光标在字尾闪动` |

规则：

- **不要写「内容留白」「后期贴字」**——留白就真的什么都不显示
- 屏幕文字**不进 `dialogue`、不发声**；打字声/震动声用（音效）承担。本项目不做 TTS，对白由视频模型原生发声
- 只有时间卡、地点卡这类非剧情文字才用 `（字幕）`，标「字卡，后期叠加」
- 同一条气泡在画面停留不超过 2 秒，长消息拆成多条弹出
