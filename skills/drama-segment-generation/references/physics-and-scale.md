# 物理化、因果、量化

核心原则：**每一句都写成摄影机能拍到的东西**。情绪、力度、尺度都翻译成可见的物理状态。

## 1. 情绪物理化

| 想表达 | 不写 | 写 |
|---|---|---|
| 犹豫 | 他很犹豫 | 微微侧首，将目光转向画外斜前方，眼神凝住片刻 |
| 压抑的怒 | 他压着怒气 | 脸绷紧、下颌前送、杯中酒液在停住的杯内轻晃一下 |
| 冷 | 她眼神冰冷 | 眸光越来越冷，嘴唇合紧，颈肩保持挺直 |
| 震惊 | 众人震惊 | 两名女性同时肩头一缩、眼神一怔，薄纱随收身局部一颤 |
| 自信 | 他很自信 | 在栏内上前一步并站住，头稍抬，望向画外天空 |
| 孤寂 | 太空很孤寂 | 星点稀疏且微弱，外部空间静寂，只有内心独白清楚 |
| 讥讽收回 | 她不再讥讽 | 眉眼停了一瞬，原有讥意从嘴角缓缓收回，视线仍在同一对面方向 |

对白前的语气标注放在对白行（见 dialogue-and-audio.md），画面里写生理与姿态。

## 2. 先后因果

用"先…随后…""…的同时…""…时立即…"把动作排成因果链：

- `杯沿先撞在深色地板上，发出一声清亮撞响，杯身弹起翻转一回，再侧躺着向前滚出一小段；残酒沿地板向前泼成断续水痕。`
- `先离座再向平台前沿迈一步`
- `右手握柄开始拔刀，刀柄沿鞘轴斜前移` → `右手迅速抽出剩余刀身，一条青白反光沿金属刃口掠过` → `刀尖从鞘口完全脱出`

每个物体至少写一个**承重/支撑**事实，避免漂浮感：`盘底始终有实际支撑`、`食案短腿承重、桌面随咬拉只轻微受震`、`三头熊的脚掌与后躯各有真实支撑`。

## 3. 惯性滞后

主体动作先发生，附属物后发生，形成"迟半拍"：

- `回头时鬓发迟半拍顺肩侧滑动`
- `衣摆下端迟半拍离地`
- `衣摆和发尾被惯性猛拉向来路；杨广发梢与衣袖随后被余风带动`
- `发尾与裙摆稍后划出一条柔长弧线，随她第一步迈向前方继续后扬`
- `余风使衣袖最后一摆，场面收稳`

适用：转头、转身、起步、起飞、急停、落地。静止对白镜头不要滥用。

## 4. 0.2 秒爆发窗口

速度极快的一瞬，用**绝对时间码窗口**钉死，而不是形容词：

- `从这一姿态在14.35—14.55的0.2秒内猛烈向栏外前方疾掠出画`
- `前缘在0.2秒内从高处轰至沟底`

写法：先静（直立、悬停、蓄势）→ 窗口内爆发 → 之后写惯性与余波。窗口必须落在该镜头的时间码之内。

## 5. 短震量化

命中、起飞、落地、撞地之后加一次摄影机反馈，**写幅度、方向、衰减**：

- `发生一次约画宽百分之二的横向短震后回稳`
- `在下斩爆发点猛向下顿挫约画高2%`
- `首次撞地时摄影机短促向下震动约画高百分之一，立刻回稳`
- `摄影机在冲击抵达时猛震上抬约画高4%，紧接两次快速左右短摆，随后震幅迅速衰减，主命中线一直留在画中`

规则：幅度随冲击量级递增（1%~2% 小物、2% 起飞、4% 巨物命中）；每次冲击只写一次主震，之后"回稳/衰减"；摄影机震动要有物理来源（风压、冲击波），在整体基准里声明"摄影机反馈集中在冲击抵达时"。

## 6. 尺度量化

巨大或极小的东西，用**占画面比例 + 参照物**：

| 场景 | 写法 |
|---|---|
| 极小人物 | `实际人身高度约画高0.3%，衣发只构成一个极小直立轮廓` + `镜头保留两秒，使一个微小人影与数千米地形的比例被完整读到` |
| 巨型动物 | `躯体占画宽约六成`、`俯伏身躯约占画宽三分之一、画高近四成`、`直立时比姜颜高半个头` |
| 与参照物比 | `整头烤牛约为熊躯体长度的一半` |
| 巨型特效 | `弧形刀气的跨度约三千米…投影跨幅约画宽80%…亮刃及其半透明流动刃面覆盖画面约三成，近端较大、远端受透视压缩` |
| 远去 | `身影由画高约两成缩至不足一成`，并"建筑边缘留作尺度" |
| 护罩包人 | `球罩直径约为姜颜身高的1.8倍，头顶、脚下和左右都留出可见空隙，姜颜始终全身处于球体内部` |
| 环境高差 | `数百米高差的阶状岩壁`、`沟底数千米长的岩层` |
| 速度 | `约每秒一米三的步速走完最后三米多距离` |

要点：**同一量化数字在同一段内保持一致**，写进整体基准，镜头里引用。

## 7. 特效物的物理

刀气、护罩、鱼群这类资产要给出：

- **形状**（有薄厚的月牙刃面，凸刃朝向，两尖向上）
- **材质与分层**（刃芯青白、外缘青蓝、内弧通透）
- **内部流动方向**（发光颗粒沿刃芯快速流向凸刃；尾流逆运动方向向上剥离）
- **遮挡关系**（刃面先后被凸起岩脊遮住局部，随深入重新显露）
- **对环境的作用**（岩面与悬粒先被照亮；命中后岩层错动、崩碎、悬沙、水体冲击）
- **唯一性**（整体基准写"为同一击，只产生一次"）

## 8. 视线与空间

- 视线用画外方位词：`画外下方 / 上方 / 前方 / 侧后方 / 斜前方 / 身侧`。
- 对话双方的高低差固定：高位者"看向画外下方"，低位者"看向画外上方"。
- 距离一律给可测量单位：步、臂、人宽、米。
- 远近关系用层级写：近层 / 中层 / 后层，或前景 / 中景 / 后景。
- 空间中的"画外声"方位要写：`从画外高处落下`、`从面前方向连续传来`。

## 9. 固定手势与姿态模板

范本中反复出现的姿态，沿用同一写法以保持一致：

| 姿态 | 固定写法 |
|---|---|
| 直立飞行 | 双手收至背后/背负，脊背挺直，肩线放松，身形直立；一腿自然垂直伸展、另一腿微弯膝 |
| 起飞 | 先写"双脚缓缓离开木地板"→"脚底高于栏杆横木"→0.2 秒窗口掠出 |
| 太空/水下悬浮 | 直立悬浮，一腿垂下、另一腿微弯；衣发缓慢承接动作惯性 |
| 叉手礼 | 写双手形状与高度，同一角色每次一致 |
| 拔刀 | 左手稳住鞘口，右手握柄，刀柄沿鞘轴斜前移 |

新增手势模板时，写进本段整体基准，下一段继续引用同一写法。
