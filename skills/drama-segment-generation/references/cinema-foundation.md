# 影视基础速查（写分段前的判断依据）

这一页管"为什么这样拍"；"怎么写成句子"见 `shot-grammar.md`。AI 适用性标签：**可平移** = 直接套用；**需改写** = 简化或换实现方式。

## 1. 导演意图卡（每场戏先答，不写进提示词正文）

1. **目的**：这场戏要观众感到什么？（紧张/心疼/爽/恐惧/期待）
2. **欲望**：谁想要什么？谁在阻挡？
3. **情绪关键词**：这一段的情绪落点是什么？

答完再选景别、角度、运镜、光。每个视听选择都要有叙事理由，杜绝"为美而美"。

- Show don't tell：不写"他很紧张"，写反复点烟、手抖（落到物理细节，见 `physics-and-scale.md`）。
- 潜台词靠表情差、站位距离、道具外化，不靠旁白解说。
- 情绪曲线要有起伏：铺垫 → 升温 → 爆发 → 回落。全程高潮 = 没有高潮。范本的做法是用 0.5~1.5 秒的快切堆叠，再用一个 3~8 秒的长镜头给尺度或余波。

## 2. 景别

越近越私密/压迫，越远越疏离/宏大。景别跳跃本身就是叙事：全景硬切特写 = 心理冲击；中景缓推特写 = 情绪递进。

| 景别 | 作用 | AI 适用性 |
|---|---|---|
| 大远景 | 人物极小或无人，交代地理、气势、孤独 | 可平移 |
| 全景 | 全身 + 环境，空间关系、动作全貌 | 可平移 |
| 中景 | 腰部以上，对话主力 | 可平移 |
| 近景 | 胸部以上，强调表情 | 可平移 |
| 特写 | 面部填满，放大情绪 | 可平移，脸部易漂移 |
| 大特写 | 只取眼、手指、道具局部 | **需改写**，手指和眼睛畸变高危 |

## 3. 角度

| 角度 | 含义 |
|---|---|
| 平视 | 中立客观，默认 |
| 俯视 | 弱小、无助、被审视 |
| 仰视 | 高大、权威、威胁（范本里只"强调他坐在高处的压迫"，不夸张变形） |
| 过肩 | 双人对话默认，建立空间与攻守 |
| 荷兰角 | 失衡、疯狂、不安 |
| 鸟瞰 | 抽象化，人如棋子 |

## 4. 运镜（AI 安全等级）

静止镜头让观众思考，运动镜头把观众拽进情绪。

- **安全，可直接用**：固定、轻推、缓推、升降（无人脸时）。
- **需简化**：推拉摇移跟环绕——连续大幅运动容易让人物漂移，用**切镜 + 景别变化**替代，或写成短距离（"半步""短弧"）。
- 范本的 202 次"切镜头"说明：快节奏靠切，不靠长运镜。每个镜头的运镜尽量不同，连续重复同一运镜是模型偷懒的信号。

## 5. 组接

目标是"隐形"，让观众沉浸于故事。

- **180° 轴线**：对话双方连线的同一侧机位，保证 A 永远在左、B 永远在右。AI 拼镜必须自己核对朝向，【本段初始空间】里声明轴线。
- **正反打**：对话主力手法（见 `shot-grammar.md`）。
- **视线匹配**：A 看向右侧 → 下一镜切到他所看的对象（在画面左侧出现）。要自己设计视线方向。
- **动作匹配**：AI 建议动作**完成后**再切，避免切点错位；范本里用"刀尖完全脱出时立即切走"这类完成点做切点。
- **30° 规则**：同一主体相邻两镜机位至少变化约 30°，否则像跳切。
- **跳切**：同机位同景别硬切，压缩时间、制造焦躁。快节奏短剧天然适合，不必追求无缝。

## 6. 场面调度

- **走位外化关系**：走近 = 亲近/施压，走远 = 疏离/退缩。AI 难精确走位，用定机位 + 定姿态替代，位移终点在初始空间写明。
- **纵深分层**：前景（虚化）+ 中景（主体）+ 后景（环境），一帧讲多层信息。AI 强项。
- **留白**：主体占画面小部分，周围大量空，表孤独、渺小。
- **框架构图**：门框、窗、走廊框住主体，暗示囚禁、窥视。AI 对"透过门洞"效果好。
- **道具叙事**：关键道具写进提示词，并在【本段现场生成】定死尺寸。

## 7. 光

光是摄影机的画笔：亮着拍是喜剧，暗着拍是惊悚，逆着拍是诗意。

- **三点布光**：主光（决定阴影方向）、辅光（阴影深浅）、轮廓光（把主体从背景剥离）。
- **光比**：1:1 平光温馨，8:1 以上高反差戏剧。
- 常用光法：高调（喜剧爱情）、低调（悬疑压抑）、伦勃朗光（45° 侧上方，阴影侧出三角亮斑）、**逆光剪影**（AI 非常稳定，离别/神秘）、侧光（半脸亮半脸暗，双重性）、蝴蝶光（正前上方）。
- 光源在【本段整体基准】写一次，所有镜头沿用；写法和铁律见 `seedance-25-rules.md` 第 4 节。

## 8. 色彩

- 红 = 危险/激情，蓝 = 冷静/孤独，黄 = 温暖/警告，绿 = 自然/不安。
- 互补色（蓝橙、红绿、黄紫）冲击最强；冷暖对比：人物冷 + 背景暖 = 人与环境对抗；暖房间里手机冷光照脸 = 危险入侵。
- 常用调色：青橙调、低饱和、莫兰迪、霓虹。
- **同场景色彩统一**：同一场戏内所有镜头色温色调一致，这是 AI 最大难点——靠场景参考图 + 整体基准里锁死色调关键词。
- **跨场景色彩演变**：按集或阶段定主色调弧线（前半冷蓝压抑 → 后半暖橙救赎）。

## 9. 节奏（红果短剧快节奏）

- 开场 1~2 个镜头内进入核心冲突；动作连续、台词短促、不拖沓。
- 该有的细节必须保留（回忆闪回、标志道具特写、环境氛围），用 0.5~3 秒的短镜头承载，不单独拆段。
- 单集总时长由各段时长相加决定，不预设固定值；合计后核对与剧本叙事体量相符。
