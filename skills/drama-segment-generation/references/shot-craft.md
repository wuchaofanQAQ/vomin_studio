# 镜头工艺（4.2 实操）

> 母版规则的可执行版。写每个镜头前扫一遍；每条都给出"错 → 对"的对照。

## 1. 画面坐标系

所有位置、朝向、运动都用**画面**做基准，不用世界方位：

- 水平：画左 / 画右 / 画面中央 / 贴近画框边缘
- 垂直：画上 / 画下
- 纵深：前景 / 中景 / 后景
- 关系：遮挡、进入方向、离画方向

| 错 | 对 |
|---|---|
| 他朝她走过去 | R02陈诚从画左中景走到画面中央，停在 R01沈幼怡右前方半步 |
| 她抬头看前方 | R01沈幼怡在画面中央抬起下巴，视线落向画右上方画外 |
| 镜头跟着他 | 镜头从画左后景跟拍 R02陈诚，随他横移到画面右前景停住 |
| 他转身离开 | R02陈诚上半身先向画右转，重心移到右脚，从画右下角离画 |

**只有 A、B 同时可见且位置已建立**，才写"A 看向 B"，并保留画面关系：
`R02陈诚位于画左前景，侧身看向画右中景的 R01沈幼怡`。
B 在画外时，只写 A 看的方向，**不写 B 的动作**。

过肩：写清谁的肩背在前景、另一人在哪侧中后景。
`R02陈诚的右肩虚化占据画右前景，R01沈幼怡位于画左中景，正面朝向画右。`

## 2. 可见边界：先问摄影机能不能同时拍到

写之前自问三件事：**景别够不够、角度对不对、遮挡挡不挡**。拍不全就拆镜，不硬塞。

| 错 | 问题 | 对 |
|---|---|---|
| 近景里的女主听见门外妖怪咆哮，画面写"妖怪张口挥爪" | 妖怪在画外，近景拍不到 | 只写她的反应 + `画右画外传来一声低沉咆哮`；妖怪的动作切到下一镜 |
| 一个镜头里 A 在门外、B 在门内，还要同时看清两人表情和门内客厅 | 纵深和遮挡不支持 | 拆三镜：门外近景 / 过肩看门内 / 门内反打 |
| 中景写"她握紧拳头，脚趾抓紧地砖" | 中景看不到脚趾 | 只写手与肩；脚趾改特写或删除 |

画外信息只有四种合法形式：**声音（带方向）、目线、影子/反光、气流或光线变化**。
画外台词写 `R02陈诚画外音（门内压低地说）：谁啊？`，并在镜头段写 `声音来自画左门后`。
**不写**画外角色的姿态、表情、受力、特效。

## 3. 切镜后状态重建

切镜只换观察位置，动作不重开。新镜头第一句必须重新交代：位置、朝向、姿势、速度趋势、持握、视线。

| 错 | 对 |
|---|---|
| 切到近景，她继续跑 | 切到侧面近景：R01沈幼怡在画面中央偏左，身体前倾，右臂仍向后摆到极限，左脚刚离地，速度未减 |
| 他仍然站着 | 切到中景：R02陈诚站在画面右侧，背靠门板，右手仍搭在门把上，肩膀随呼吸起伏 |
| 剑还在飞 | 切到仰拍：P01寒汐剑在画面上方前景，剑尖朝画右下方，拖出一道向左衰减的白色尾迹 |

**描述范围服从景别**：全景写站姿、重心、双腿、衣发；近景只写头肩、手、表情、视线，不写腿脚。

动作变化要写**原因与时点**：
`冲击抵达胸口的瞬间，R02陈诚上身先向画右后仰，重心越过右脚，左脚被惯性拖离地面半寸。`

## 4. 受力—环境—摄影机反馈链

有碰撞/速度变化才写，按顺序取必要环节，不逐项凑：

`发力准备 → 方向/轨迹/速度 → 接触部位与瞬间 → 惯性/重心传导 → 衣发道具延迟 → 地面空气水体反应 → 摄影机反馈与回稳`

例（一记耳光）：
> R02陈诚右手从画右下方向画左上抡出，掌根先接触 R01沈幼怡的左颊；接触瞬间她的头向画右偏转约二十度，颈部先动、肩膀随后跟，发丝甩向画右并延迟半拍落下；R02陈诚的手掌在接触后继续向画左带出五厘米才收力，重心压到左脚；镜头在接触帧向画右短促低幅震动一次，随即回稳。

要点：
- 先受力部位先动，躯干四肢**延迟跟随**；
- 脚底摩擦/离地、重心移动要写；
- 环境反馈有方向、范围、衰减，不写"周围剧烈变化"；
- 摄影机只有力量传到机位才抖，**文戏不抖**。

## 5. 特效生命周期

`出现（从画面哪里）→ 增强 → 传播（方向/速度/密度）→ 接触或影响环境 → 余波/消散`

| 错 | 对 |
|---|---|
| 雷电大作，天地变色 | FX01雷光从画面上方中央劈下，占据中景一层，落点在 R01凌霜脚前三米，地砖向四周炸开一圈碎屑，尘浪向画左右两侧推开，两秒后光衰减成细碎电弧沿地面爬行 |
| 剑气纵横 | P01寒汐剑向画右横斩，一道月牙形剑气从画面中央向画右扩张，边缘亮、中心透，掠过处空气扭曲，撞上石柱后向两侧炸开，尾迹在两秒内衰减 |

## 6. 题材强度

| 类型 | 镜头策略 |
|---|---|
| 文戏 | 稳定中景/近景/过肩；缓慢推进、轻微横移、焦点转移；写目光、呼吸、停顿、手指/嘴角、两人间距。不环绕、不甩镜、不抖 |
| 动作/仙侠 | 可用速度、规模、受力层次、特效生命周期；但一个短镜头仍只做**一个核心动作或一次信息揭示** |
| 大场面 | 先保证路径、接触、反馈、屏幕分布清楚，再谈宏大；一个镜头里不要同时铺三条以上的力线 |

## 7. 台词、画外音、音效

```text
R02陈诚（压着火、短促地说）：你爸呢？
R01沈幼怡（垂下眼、很轻地说）：我可以走。
R02陈诚画外音（门内压低地说）：谁啊？      ← 镜头段写"声音来自画左门后"
```

- 括号里必须是**可表演的情绪/语气/状态**，且必须有"说"字；
- 不用"有感情地说""平静地说"这类空泛词，用"压着火""断续""咬着字"；
- 台词逐字，不改写、不合并、不删；
- 音效写归属与方向：`门轴干涩的摩擦声从画左传来`，不写"紧张的音效"。

## 8. 停点与段尾

- 切点**不强制**：多数镜头收在动作结果上即可；只有运镜镜头必须写落幅（`到位` / `收稳` / `停住`），切点本身是决定时才写。
- 段尾最后一镜必须**自成结束画面**，不靠下一段补完动作或解释信息。
- 一段内的镜头用动作承接：`承接同一次抬手`、`门还在回弹`，但**不写"继续/仍然"了事**。

## 9. 高频病灶自查

| 病灶 | 症状 | 修法 |
|---|---|---|
| 裸名 | 正文写"沈幼怡"而不是"R01沈幼怡" | 全文搜名称，逐个补编号 |
| 越界 | 画外人物有表情/动作 | 改成声音/目线/影子，或拆镜 |
| 重开 | 切镜后角色重新蓄力、重新站起 | 从上一镜结束状态接着写 |
| 纸片人 | 全身同步平移、无延迟 | 加"先……随后……"的传导顺序 |
| 空词 | 史诗、震撼、极致、电影感 | 换成可见的规模/速度/数量/材质 |
| 堆运镜 | 一镜里推、摇、移、环绕全上 | 只留一个主要运镜 + 一个落幅 |
| 无停点 | 镜头写到动作一半就断 | 补落幅或切镜点 |
| 装饰音效 | "紧张的音乐""压抑的氛围" | 只留能判断因果与方向的声源 |
