# 剧集分段生成（剧本转提示词 4.2）

## 定位

B1 阶段的默认执行者：分集剧本 + 现有资产 → 先做资产绑定 → 按难度分段（项目上限 30 秒）→ 每段一份可直接提交的导演级视频提示词 → 依赖清单 + 可写入飞书分镜表的结构化数据。

- 母版是《剧本转提示词 4.2》：`references/mother-prompt-42.md`（原文，冲突时以它为准）。
- 旧 `docs/director-segment-prompt` 的工艺细节已吸收进 `references/`（13 篇），另有 1 篇运镜手册 `camera-movement-and-lens.md`（吸收自公众号《视听语言》教程）；与 4.2 冲突处一律按 4.2。
- 本 skill 只产出文字；`write` / `generate` / `push` 都要先列清单、拿到用户明确确认。
- **项目约定优先于母版的两处**：①时码统一写 `[19.9s]` / `[0s-30s]`（母版是 `00:00—00:XX.XX`）；②资产引用统一写 `图N =【名称】{资产库：…}`（母版是 S01/R01 编号）。其余仍以母版为准。

## 六条铁律

1. **只写摄影机拍得到的东西。** 当前镜头拍不到的动作、表情、受力、画外状态一律不写；要写就拆镜、改景别，或让摄影机摇移"揭示"。每镜先列当前可见主体，正文里出现的名字必须真的以实体、局部、反射或可辨投影进入画框。
2. **先取料、再绑资产、最后写段。** 取料顺序固定：剧本表（含 `涉及资产`、`对应原小说章节`）→ 小说表对应章节 → 资产库（`描述` / `备注` / `文件路径`，**先打开图看**）。外观**以真实图片为准**（`描述` 只是当初的出图提示词，会跑偏）；`备注` 是参考、大概率正确，用来校正空间理解，**不是照抄模板**；本段的机位与构图由戏决定，不由参考图决定。有行有图=可绑；有行无图=标待出图；库里没有=**【待补，未读取】**，不许自编名称或编号充数。资产表不是出场名单，每段只锁真正参与本段的。
3. **一段 = 一次独立生成。** 每段重新锁定资产、重新建立空间，时间码从 00:00 起、镜头从 01 起；禁止"延续上一段/接上一镜/同上"。段长按难度取 6~30 秒（30 秒是项目上限），参考图张数不设上限（API 没有这个限制），该用几张用几张。
4. **名称即身份。** 资产在【本段资产锁定】里写成 `图1 =【沈幼怡】  {资产库：沈幼怡}；`（需要固定音色时，在该条目后加 `音频参考：{音色库：音色名}`）；正文每次出现都写 `【沈幼怡】`，必须带【】、不写裸名，也不用编号。
5. **台词逐字、写在真正发声的位置。** 行首就是时间窗：`[4s-5.5s]，内心独白，【陈诚】（压着火，低声自问，问句不上挑，嘴唇闭合）：「台词」`。**括号两个槽位：先状态/动作（可演），再声音与语流（可听）**；下笔前心里过四件事——音量、语速、停顿、尾音——但写成 8~13 字的自然语，不写成参数表。**台词的字逐字不动，标点按情绪调**：剧本不会写到这个颗粒度，而模型靠标点读情绪——`！`一口气砸完、`？！`先惊后骂、`……`话没说完/余味、`。。`越说越急、`。`关门判死、`~`拖软。

**不写情绪词**（紧张、生气、高兴、委屈）：情绪由动作与声音推导。**OS 一律写「内心独白，」**，并在【本段整体基准】统一声明「内心独白一律嘴唇闭合」，防模型让角色张嘴。**标点就是发声指令**：！=落重；？=上挑或落平；……=拖住；？！=先升后砸；~=拖软上扬（详见 `references/dialogue-and-audio.md`）。需要固定音色的角色，在锁定区条目后加 `音频参考：{音色库：音色名}`，CLI 会把它作为参考音频传给模型（本项目不再走 TTS）。
6. **正向表达，不改剧情。** 不写 NEGATIVE 段和"不要/禁止"式纠错，一律改写成期望出现的画面；只补机位、景别、调度、表演、受力、光影、声音、终态，不新增人物、台词、事件、结果、专名。

## 唯一合法格式

下面是**简单档**（单场景、两人、无特效），吃满 30 秒；复杂内容按 Step 2 缩短。

````text
【第01段｜[0s-30s]｜陈诚公寓门口·门铃】

【本段资产锁定】
【参考图映射】图1=【沈幼怡】；图2=【陈诚】；图3=【陈诚公寓走廊】；图4=【行李箱】；图5=【手机】
角色：
图1 =【沈幼怡】  {资产库：沈幼怡}；
图2 =【陈诚】  {资产库：陈诚}；
场景：
图3 =【陈诚公寓走廊】  {资产库：陈诚公寓走廊}；
取用与重建：只取门扇、门牌、猫眼、门框、地砖与尽头那扇窗；门铃面板在门框右缘墙面正向重建，不改门的样式。
道具：
图4 =【行李箱】  {资产库：行李箱}；
图5 =【手机】  {资产库：手机}；

【本段现场生成】
1. 屏幕上的字：聊天软件会话界面里一行被调到最大的字——「我是沈幼怡」，末尾一个句号。

【本段整体基准】
16:9，24fps，真人电影质感，中国都市八月末午后。走廊 40℃白炽直射、硬光比，浅米灰地砖上硬边光斑；角色脸、发型、服装与体态以本段图为准。全段实速、无慢镜，十镜按下列时码依次硬切。【沈幼怡】紧张只在睫毛和指节；【陈诚】嘴冷手软。物理顺序：指腹压到底才有铃声。声音：蝉声底噪、门轴与锁舌、指尖敲屏。内心独白一律嘴唇闭合。画面内除指定屏幕文字外，不显示任何字幕、水印与台标。

【本段初始空间】
【陈诚公寓走廊】：净宽约 1.6 米、地砖通铺；入户门在画左、门扇宽约 0.9 米、向室内开；【沈幼怡】站在门前约 0.8 米、正对门，【行李箱】立在她右脚边；【陈诚】在门内一步、只入半个身位。开镜机位在她右后方约 1.6 米、35mm、与胸口平齐。

【镜头01｜[0s-2s]｜门铃上的指腹】
[0s] 门外贴墙的 85mm 特写，固定机位，画框里只有墙、门铃面板和从画右伸入的手指。[0.55s]【沈幼怡】的食指探入，指腹悬在圆钮上方半寸停半拍；[0.95s] 压到底，钮面陷进约两毫米又回弹；[1s] 一声短促的“叮”贴着门板散开。铃声尾音还没散，手指还悬在钮上没收回。

【镜头02｜[2s-4s]｜门缝】
[2s] 门内贴门板的 50mm 中近景，摄影机随门扇拉开极轻推近半寸。[2.1s] 门轴先响一声，【陈诚】把门拉开约十厘米；[2.6s] 眼球先落在她脸上，[3.4s] 扫完才抬眼。推到位时，缝宽正好一掌。
[4s-5.5s]，内心独白，【陈诚】（低声自问，问句上挑）：「来投奔亲戚的？」

…… 其余镜头同法，直至 [30s]。

【本段终态】同一性锁定：画面里只有一位【沈幼怡】、一台【手机】、一只【行李箱】。【沈幼怡】仍在门外原位，【手机】端在胸前；【陈诚】半身卡在门缝、门开一掌宽；【行李箱】立在她右脚边、拉杆拉出。
````

格式细则：

| 元素 | 规则 |
|---|---|
| 段头 | `【第NN段｜[0s-结束s]｜场景·事件】`；结束时码 = 本段总时长（6~30 秒，按难度取）；镜头 01 起 |
| 资产锁定 | 固定以 `【本段资产锁定】` 开头；分类行只写本段真正参与的资产；没有的分类整行省略 |
| 资产条目 | `【编号｜名称：补充内容】`；场景/角色**必须**带 `{资产库：名}`；道具**有参考图时**带 `{资产库：名}`，没有就只写外形/尺度/数量；补充写在锚点前 |
| 待补 | 库里没有、本段确需的，写 `待补：【旧怀表】`，不许编锚点 |
| 现场生成 | `【本段现场生成】` 只列**本段要重建的元素**，用 `1.` `2.` `3.` 每条一行：屏幕字、临时道具、回忆里的物件、没有独立资料板的空间局部、手部/形制这类补充说明。**不写"取自参考图/不再重建/取用层/重建层"这类说明**；没有要重建的就写「无」 |
| 整体基准 | `【本段整体基准】` **五样、一整段、150~200 字**：①规格与题材环境（16:9/24fps/质感/城市或朝代）②环境与光（天气、光色、光比、反光）③「角色脸、发型、服装与体态以本段图为准」④节奏一句（实速/无慢镜/几镜硬切/情绪走向）⑤声音一句（4 个以内的具体声源）。人物状态只留**一句话**（"【陈诚】毒舌傲娇、嘴冷手软"）。**不写**：整段表演提纲、逐镜流程清单、声音清单、物件形制（手/材质/尺寸归现场生成） |
| 初始空间 | `【本段初始空间】` 必写：世界轴、每个可见主体的画面位置与朝向、支撑点、开镜机位、遮挡关系 |
| 参考图映射 | 锁定区有带图资产时写一行 `【参考图映射】图1=【陈诚公寓走廊】场景名；图2=【沈幼怡】角色名`；编号从 1 连续，顺序 = 锁定区出现顺序，无图资产不列 |
| 编号 | 提示词正文**不用编号**，一律 `图N =【名称】`；S/R/P 这类编号只出现在结构化 JSON 的 `asset_ids` 里 |
| 镜头头 | `【镜头NN｜起-止｜标题】`，0.5 秒格、首尾相接、末镜终点 = 段长 |
| 镜头正文 | **一个完整自然段**，按发生顺序融合：景别+机位/运镜 → 空间与可见主体位置 → 姿态/动作 → 画面变化/物理反馈/环境 → 停止点；禁止拆成"景别：""运镜："多行栏目 |
| 台词 | 单独成行：`[4s-5.5s]，内心独白，【陈诚】（火气上顶，短促砸出）：「台词」`；行首是时间窗，不用【对白】前缀；台词一律用「」；台词逐字，每句只在实际发声位置出现一次。**括号 8~13 字**，先状态/动作、再声音与语流；嘴唇状态在整体基准统一声明 |
| 画外音 | `[9s-10.5s]，画外音，【陈诚】（画左门板后、压着嗓子、问句上挑）：「台词」`；方向与发声方式都写进括号，字逐字不改 |
| 终态 | `【本段终态】` 是给下一段重建用的**坐标**，不是剧情收尾。三条判据：①只写下一段需要的量（位置/朝向/持握/道具/门窗开合/姿态/伤势/特效）；②**变化锁死**——段尾和段初不同的用「已…／从 X 到 Y」，相同的用「仍」；③**句法即状态**——名词短语、不写施力动词，不贴「这不是镜头」之类的元标签。取景落点（"最后画面为…"）可单独一句，可选。不写动作、不写「下一段…」 |
| 音效 | 只写有助于判断动作因果与空间方向的音效，带归属与方向；不写装饰清单 |
| 音色 | 需要固定音色时直接写 `{音色库：音色名}`（建议单起一行 `音频参考：【【沈幼怡】：{音色库：沈幼怡-清冷少女}】`）；CLI 收集该音频作为 `reference_audio`；音色库里没有这一行就不要写（本项目不做 TTS） |

## 工作流

### Step 0 — 取料（只读，无需确认）

设当前集为 **N**。**顺序不能变**：先剧本、再原文、后资产图。

```bash
# 1) 剧本：本集正文 + 涉及资产 + 对应原小说章节
python cli.py read $WS --table 剧本表 --episode N --context 1

# 2) 原文：只读这一集用到的章节（对应原小说章节，如 "1,2"）
python cli.py read $WS --table 小说表 --chapter 1,2

# 3) 资产：按 涉及资产 里的名字，从资产库取 描述 / 备注 / 文件路径
python cli.py read $WS --table 资产库

# 4) 全局设定 + 本集已有分镜（重写时避免叠写）
python cli.py read $WS --table 剧本设定
python cli.py read $WS --table 剧本分镜表 --episode N
```

**三个信息源，各管一件事，冲突时按下面的优先级处理：**

| 来源 | 管什么 | 冲突时 |
|---|---|---|
| 剧本表 `初版剧本` | 事件、台词、节奏 —— **台词逐字照抄，不改** | 与小说冲突 → 以剧本为准 |
| 小说表对应章节 | 人物情绪、关系、潜台词、生活细节、场景质感 | 与剧本冲突 → 剧本优先，但情绪按原文演 |
| 资产库 **真实图片** | 外观事实：长相、服装、家具位置、光线 | 与 `描述` 冲突 → **以图为准** |

### 关于资产图与备注（三条）

1. **图是外观事实，但图只是一张静帧。** 长相、服装、家具的**样子**以图为准；但**图里的机位、焦段、构图不是本段的机位**——不能因为参考图是广角全景，就把整段都写成广角。外观照图，镜头照戏。
2. **备注是参考，不是抄写模板。** 备注（反打关系、同源图、近中远景）大概率是对的，用来**校正你对空间的理解**；但它不是逐字照搬的台词。发现备注与图或剧本对不上时，以你自己的空间判断 + 图为准，并在交付说明里写出依据。
3. **先建立对场景的完整理解，再动镜头。** 写段之前在心里（或草稿上）过一遍：
   - 门在哪、窗在哪、光从哪来、有几条可行走的路线
   - 主要家具的朝向，人坐下/站起/转身会挡住什么
   - 轴线在哪一侧，哪几个机位是同一侧、哪个会跳轴

   对不上、或图里看不全的，标 `待补` 或先问，**不许凭一张图猜空间关系**。

### 理解在前，镜头在后

动笔前先用剧本 + 原文把这三件事想清楚，再排镜头：

- **这场戏在争什么**：谁想要什么、谁在挡、最后谁退了一步（冲突落点决定切点）
- **人物此刻在藏什么**：嘴上说的和心里想的差在哪（表情/手部/呼吸/躲视线，就是镜头该给的地方）
- **空间的戏在哪**（门、窗、茶几、拖鞋的位置决定走位和机位）

想不清就不要写镜头；先回去读原文那一段。

排到具体某一镜时，再补一句**镜头目的**：观众在这个镜头**结束时**，比开始时多知道什么？（看见收紧的表情 / 发现门后有人 / 意识到空间很大。）这句话写不出来，说明这一镜还没有功能——先退回固定镜头把表演看清楚，别用运镜掩盖没想明白的设计。

### Step 1 — 资产绑定（写段之前必须完成）

把本集剧本里出现的**角色、场景、道具**逐一对上「资产库」（按 `类型` 区分）：

| 情况 | 处理 |
|---|---|
| 表里有这行、`文件路径` 有图 | 可绑：锁定区写锚点，参考图映射里占一个图号 |
| 表里有这行、还没出图 | 可绑描述：锚点照写，参考图映射里**不占号**，并在依赖清单标「待出图」 |
| 表里没有 | 标 `待补：【编号｜名称：待补，未读取】`；依赖清单进 `missing`，不许自编名称/锚点/编号充数 |

规则：

- **绑定前必须先看图**：逐个打开 `文件路径` 指向的图片确认外观（长相、服装、家具位置、光线），再决定这个资产能不能用在本段；不看图不许写分镜。**汇报时必须写清"读了哪几张图"；没读的标 `未读取`，不许用 `描述` 或正文推断冒充看图**。图片读不出来（格式与扩展名不符等）同样标 `未读取`，不许跳过不提。
- **备注与图一起读**：备注写了反打关系、同源图、近景/中景/远景内容，空间层次照它写。
- **资产表不是出场名单**：只把本段真正参与（入画或发声）的资产锁进本段。
- 画外只出声的角色：不锁成画面资产，只在台词行标画外音与方向。
- 同名不同版本（`陈诚` / `陈诚 12岁`）、光影变体（`出租屋（日）` / `（夜）`）按表里的**精确名**绑定，不合并、不改写。
- 绑定结果登记在 `workspace/{剧名}/drafts/asset_ids.json`，跨段跨集复用；新资产取当前类别最大号 +1。

```json
{"assets": [
  {"id": "S01", "category": "场景", "name": "陈诚公寓门口", "table": "资产库", "has_image": true},
  {"id": "R01", "category": "角色", "name": "沈幼怡", "table": "资产库", "has_image": true},
  {"id": "P01", "category": "道具", "name": "行李箱", "table": "资产库", "has_image": true}
]}
```

### Step 2 — 按难度分段（30 秒是上限，不是目标）

模型一次最多出 30 秒。**先判断这段有多难，再决定段长**：场景、人数、参考图、动作量任何一项变重，硬塞进 30 秒都会掉质量。

先算**参考图预算**：本段随请求发出的图片 = 场景图 + 角色图（群像算 1 张；没出图的资产不占号）。

| 影响因素 | 轻 | 中 | 重 |
|---|---|---|---|
| 场景 | 1 个空间 | 同空间换时段/光线 | 换地点、跨场景连续动作 |
| 人物 | 1~2 人 | 3 人 | ≥4 人 / 群像 |
| 参考图 | 1~2 张 | 3~4 张 | ≥5 张 |
| 动作/特效 | 无或单一动作 | 有对抗、有受力 | 打斗连招、大特效、群战 |
| 剪辑 | 常规正反打 | 换轴、插入特写 | 多线交叉、闪回 |

| 档 | 典型内容 | 段长 |
|---|---|---|
| 简单 | 单场景、1~2 人、对白为主 | 20~30 秒 |
| 中等 | 3 人 / 有动作或情绪转折 / 4~5 张参考图 | 12~20 秒 |
| 复杂 | 换场景、≥4 人、群像、打斗、大特效 | 6~12 秒 |

硬规则：

- **参考图不设上限**：场景图、角色图、道具图该挂都挂；拆段只看空间变化与动作密度。
- **一段尽量只用一个场景**：跨场景会让场景图数量翻倍，优先在场景交界处断开。
- **人数突变就是切点**：2 人→5 人、屋里→楼下、文戏→打斗，都在变化处断。
- **简单戏可以吃满 30 秒**，但不许为凑 30 秒加镜头；复杂戏也不许为整齐压进 30 秒。
- 断开点选在动作间歇、对白停顿、进出场处；前段最后一镜自成结束画面。
- 段内必须严格覆盖 `00:00 → 本段时长`；段 ID `ep{两位集号}_p{两位段序}`，与飞书分镜表主键一致。
- 校验脚本按同一套标准兜底：复杂度只按人数/特效/群像评分（0→30 秒上限，1~2→24，3~4→20，≥5→15）；参考图不设上限，换场景不降上限。

### Step 2.5 — 先定这一场的情绪线（一句话）

每场（每段）动笔前，先用一句话写出「他怎样、她怎样」，把基调钉住。格式：

```text
本场情绪：他的烦躁一开门就没处落，转成打量与不安；她的怯在门口冻成一层壳。
本段情绪：她给自己找退路，他被这句退路卡住，只能用难听的话把她留下。
```

要求：**两个人各一个状态，用分号隔开；写变化，不写形容词堆叠**（写"从烦躁转成打量"，不写"很复杂"）。这句话进剧本的场头、也进分镜的整体基准，后面所有镜头都为它服务。

### Step 3.0 — 导演阐述（必做，先于动笔）

每一镜动笔前先写一块。**填不满、或者答不出「表达什么」，这镜就不该拍**（删、并、换机位）。

```text
【镜头0X｜时长｜标题】
· 交给观众：  这一镜结束后，观众多知道了什么（人物/关系/空间/物件）
· 情绪落点：  观众该被推到哪一下（不安、打量、打发、惊、僵、暴、空）
· 机位景别：  焦段 + 景别 + 机位在哪 + 动不动（动的话，动因是四条中的哪条）
· 构图：      主体在画框的哪个位置、什么充当遮幅/前景、画面被切成几块、为什么这样切
· 光影：      光从哪来、光比多大、哪块亮哪块暗、光怎么随动作变化
· 环境：      风、热、尘、水、声源在空间里的位置；什么东西在动
· 音效：      这一镜真正该听见的 2~3 个声音，谁发出的、从哪个方向来
· 为什么：    以上六项合起来表达什么；为什么非得这么拍（写「好看」就是没理由）
```

四条硬要求：

1. **「为什么」必须是观众的理由**：让观众多知道一件事 / 多感觉到一下 / 保住上一个信息不被挡住。
2. **运镜必须有动因**，四条至少占一条：①主体在动 ②信息在转移 ③情绪在收紧 ④空间要交代。都不占 → 固定。
3. **构图为内容服务**：遮幅、分割、留白、前景压边，都要能说出「它替我表达了什么」（例：门缝遮幅＝他被自己的门框困住）。
4. **光影与环境不是背景板**：光比要说明这一刻的关系（门外过曝／门内全黑＝两个世界）；环境要具体到「什么在动」。

**分工**：机位、构图、光影、环境、音效五项**要写进提示词**（都是拍得到、听得见的）；「情绪落点」和「为什么」**不进提示词**，那是给自己和审片用的判断依据。

**设计数据必须落盘**：每集建一份 `drafts/epNN_director_brief.md`，逐镜写这些块；**先有这份文件，再动笔写提示词**。提示词里不出现这些分析，但分析必须存在、可复查——审片时对不上，就回这张表看是哪一步想错了。交付时连同提示词一起给。

### Step 3 — 写段（按 4.2 顺序，一次写完）

1. **【本段资产锁定】**：场景 / 角色 / 群像 / 道具 / 动物 / 载具 / 特效，只锁本段真正参与的；待补项单独一行。紧随其后写 `【参考图映射】`。
2. **【本段现场生成】**：没有独立图、本镜确需的可见内容；写清取用层与重建层。
3. **【本段整体基准】**：本段差异（时段、光比、冷暖、身份状态、尺度、声音）。
4. **【本段初始空间】**：世界轴 + 每个可见主体的位置、朝向、支撑、遮挡 + 开镜机位。
5. **逐镜**：一镜一段，景别/机位先起笔，按"位置 → 动作 → 变化/反馈 → 停点"融合；相邻镜头用动作承接，不重开。
6. **台词行**：落在真正发声的镜头里，逐字，带情绪和"说"。
7. **【本段终态】**：写成下一段的起点坐标——只给重建需要的量，变化点用「已…／从 X 到 Y」锁死，没变的写「仍」；不写动作、不写下段指令、不贴元标签。模型读的是句子形态，不是标签。

写镜头前必读 `references/shot-craft.md`（坐标系、可见集合、切镜重建、受力链、尺度、台词/音效）；定运镜前读 `references/camera-movement-and-lens.md`（拍法判据、景别画面边界、条件冲突）。

### Step 4 — 亲自通读 + 两轮自检 + 机器校验

**必须亲自从头到尾读一遍全稿，不许用脚本代替。** 脚本只查机械项；「这句话拍不拍得出来、和前一句冲不冲突」只能读出来。

顺序不能颠倒：

1. **通读全稿**：从第 1 段第 1 镜读到末段终态，逐句问「这个景别拍得到吗、和前一句矛盾吗、时间够吗」。
2. **第一轮：材料与覆盖**（段界/时长/原切镜/事件/台词/身份/资产名/待补/用户最新要求/字数/平台/材料是否真读到/旧项目残留）。
3. **第二轮：逐镜模拟拍摄**（机位与可见/遮挡、动作时间线、接触先于结果、摄影机反馈、特效传播、群像、光影声音、切镜终态、动作密度、文戏目线与受光）。
4. **修正闭环**：改实际提示词 → 复检受影响镜头与相邻衔接 → 空间轴/身份/资产替换/世界尺度改动回查全场 → 高风险项定向第三轮。
5. 最后才跑脚本：

```bash
python skills/drama-segment-generation/scripts/check_segment_prompt.py workspace/{剧名}/drafts/ep01_storyboard_v4.md
```

完整清单、检查表、高风险回归类型、武戏专项与失败反馈处理见 `references/self-check.md`。

**脚本任一 ✗ 不许交付；但脚本全 ✓ 也不等于自检通过——必须报「通读了几段几镜、发现并改了什么」。**

### Step 5 — 交付

1. 草稿文件 `drafts/ep{NN}_storyboard_v4.md`（段头用 `## ` 前缀，便于阅读与校验）。
2. 资产绑定表（编号/名称/表/有无图/待补）+ 依赖清单。
3. 结构化 JSON（写入用）：

```json
{
  "shots": [{
    "shot_id": "ep01_p01", "episode": 1,
    "timeline": "[0s-30s]",
    "prompt": "【第01段｜[0s-30s]｜场景·事件】\n\n【本段资产锁定】…（完整段文本）",
    "status": "待生成"
  }],
  "dependencies": {"scenes": [{"name": "陈诚公寓门口"}], "characters": ["沈幼怡", "陈诚"],
                   "props": ["行李箱"],
                   "missing": [{"type": "道具", "name": "旧怀表", "reason": "库里没有，标待补"}],
                   "pending_images": [{"type": "场景", "name": "陈诚童年家厨房（日）"}]},
  "asset_ids": [{"id": "S01", "name": "陈诚公寓门口"}]
}
```

4. 2~4 行说明：段数、总时长、绑定资产数、待补资产、待出图资产。

**自检通过才写 `自检：PASS`；不写 PASS 的稿子不算交付。** 文本自检 ≠ 出片实测，没出片不写"实测通过"。

### Step 6 — 写入与生成（harness 调用时）

先列清单、后执行：

```bash

python cli.py preflight $WS --episode 1       # 生产态闸门：资产真实存在且格式正确
```

## 写法密度（硬指标，吸收自参考稿）

写的不是字数，是**可执行信息**：位置、比例、材质、受力、切点。低于下表直接退回重写。

| 块 | 最低字数 | 必含 |
|---|---|---|
| 【本段整体基准】 | **≥150** | 技术规格 + 光色 + 主体保持 + 尺度 + 剪辑执行 + 速度/接触反馈 + 声音层次 + 重建声明 |
| 【本段现场生成】 | **≥60**（确实没有写「无」） | 形制、材质、物理规则、与主体的关系 |
| 【本段初始空间】 | **≥90** | 世界轴 + 各主体位置/朝向 + 历史状态 + 开镜机位 |
| 单镜正文 | **≥70** | 硬切起 + 前景/中景/后景 + 动作链 + 接触 + 切点 |
| 【本段终态】 | **≥40** | 姿态/持握/承力/残留/朝向清单 |

九条规律、整体基准配方、单薄↔密度对照见 `references/prompt-density.md`。

## 【】的用法（容易写错）

`【】` 只表示**引用本段锁定的那张参考图**：

- 角色名一律带：`【陈诚】`、`【沈幼怡】`
- 道具/场景**只有指锁定资产时**才带：`【手机】`＝沈幼怡那部顶配苹果
- 泛指同类物件**不带**：`陈诚掏出自己的手机`、`桌上的杯子`、`路边的车`——它们不是那张参考图

写错会污染参考图绑定：把陈诚的旧手机写成 `【手机】`，模型会拿沈幼怡那部顶配机的参考图去生成他的手机。

## 情节零改动，情绪转动作

**事件、因果、台词、人物关系、数字（三个月房租、一个小时、两下门铃）一个字都不能改。** 能做的只有一件事：把原文里的情绪，翻译成观众看得见的动作。

| 原文写的情绪 | 不许做 | 要做的（可见动作） |
|---|---|---|
| 她在门口至少站了一个小时 | 加一句台词说"等了一小时" | 后背的裙子被汗浸出深色一片、发尾汗黏在颈侧 |
| 那手机比他三个月房租还贵 | 加旁白解释收入 | 三摄、钛边框反光、机身干净没有指纹 |
| 妈？她还知道自己是妈 | 加事件（摔手机） | 低声冷笑、牙关咬着、喉结滚一次 |
| 她局促 | 加台词"我紧张" | 双手交叠握手机、脚趾在瓷砖上缩 |
| 她被说中心事 | 加闪回 | 眨一次眼、呼吸停半拍、视线垂下去 |

**禁止清单**：新增物件（原厂膜、照片、信件）、新增事件（摔东西、接电话）、新增台词、改数字、改人物动机。

## 小说式描写必须转成可拍动作

小说写"感受"，镜头只能拍"动作"。以下这类句子**一律不许出现在镜头正文里**：

| 小说写法 | 为什么不能拍 | 改成 |
|---|---|---|
| 字小得要凑近才看清 | 是叙述者的判断，不是画面 | 他把手机往眼前送了送，屏幕离鼻尖只剩一掌 |
| 她心里一酸 | 情绪不可见 | 她抿住嘴、鼻翼动了一下，睫毛垂下去 |
| 热气逼人 | 是体感 | 地面上的热气蒸得直抖、她的额头沁出汗 |
| 空气凝固了 | 比喻 | 两个人都没动，只剩空调外机在响 |
| 脚步轻得像只猫 | 比喻，模型可能真给你加猫或猫步 | 脚掌先落地、脚跟再慢慢压下，鞋底与瓷砖之间几乎没有响声 |
| 拉杆烫得跟烙铁似的 | 比喻 | 指尖刚碰上就缩回来、掌心发红 |
| 整个人像往裙子里缩了一寸 | 比喻＋推断 | 肩膀往内收，下巴往领口里压低半寸 |
| 像在门口已经站了很久 | 推断，观众才知道的事 | 每个动作之间都停半拍 |

## 环境音必须有声源

「热浪的嗡鸣」「阳光的声音」这类**没有物理声源**的拟声一律不写。要写声音，先能指出是谁在响：

- ✅ 空调外机的低频嗡声、蝉声、电流底噪、冰箱压缩机、楼下小孩跑过、车轮压过井盖
- ❌ 热浪的嗡鸣、光的响声、沉默在响

画面里可以拍"热"，但声音只能来自具体物件。

## 屏幕文字规则（手机/屏幕/打字）

屏幕上的字是**画面内容**，不是字幕：

- 必须写进镜头正文：「聊天软件会话界面里一行被打到最大的字——“妈妈说，给你发过信息了。”，末尾一个句号，光标还在闪」
- **禁止**另起一行 `（字幕·手机）……`
- 社恐角色不说话，靠"打完字 → 翻转手机 → 屏幕对着对方"完成对话，这个动作链要写全
- 需要观众看清字时，单独给一个屏幕正面的特写镜头

## 场景锁定（防穿帮）

**只要本段有镜头能看见另一个空间，就必须把那个空间的场景图一起锁进本段**，宁可多挂一张，也不要让模型自由补空间：

| 可能看见相邻空间的镜头 | 必须额外锁定 |
|---|---|
| 门内/门外过肩、开门瞬间 | 门另一侧的场景 |
| 从阳台/窗户反打室内 | 室内场景 |
| 猫眼、镜子、玻璃反射 | 被反射的空间 |
| 走廊尽头的门、楼梯口 | 门后空间 |

场景图还没出图的，先出图再写段；不能拿"文字描述"顶场景一致性。
跨空间但属于人物连续位移（从客厅走到阳台）的段，两个空间都要锁。

## 官方模型规则（2.5 实测）

四条固定动作，每段都要做到：

1. **台词只出现一次**：`[5s-6s]，【沈幼怡】（…地说）：「…」`，后面不再复述这句话；复述+追加情绪最容易诱发字幕。
2. **画面声明**：`【本段整体基准】` 末尾固定加一句 `画面内除指定屏幕文字外，不显示任何字幕、水印与台标。`
3. **一镜一种运镜**：推、拉、摇、移、跟、环绕、固定任选其一；要复合运动就拆镜。确有叙事目的的组合（推近+摇摄、升降+俯仰）写成"先…再…"并各给落点，且确认时长做得完；判据见 `references/camera-movement-and-lens.md`。
4. **情绪写外化动作**：不写"悲伤/愤怒"，写"肩膀微颤、眼眶泛红、手指攥紧衣角"（见 `prompt-density.md` 第八节、`seedance-official.md` 第三节）。

其余：单段 30 秒上限、单次最多 50 个参考素材、角色按首次出场顺序绑定；屏幕文字只写一次并声明无其他字幕。

## 运镜：先定拍法，再写起点/触发/终点

完整判据、12 种拍法的写法示例、条件冲突改法见 `references/camera-movement-and-lens.md`。这里只放写段时最常踩的几条。

**两件事分开写**：人物从哪走到哪、朝向哪、视线落在哪；摄影机从哪开始、走哪条路径、最后看向什么。不能混成一句"向前移动"。

**12 种拍法，先认机位动没动**：

| 机位固定 | 一句话判据 | 机位位移 | 一句话判据 |
|---|---|---|---|
| 固定 | 位置、朝向、取景范围都不变；云台一转就不是固定 | 推近 | 机位靠近，人变大且前后比例变 |
| 摇摄 | 原地转、看起止对象；背景滑动不能证明是横移 | 拉远 | 机位远离；新露出的内容必须提前存在 |
| 甩镜 | 快速摇/俯仰 + 方向性模糊 + 明确落点、不回摆 | 横移 | 机位侧移，看前景与远景的相对位置变化 |
| 俯仰 | 只改角度、不改高度；上摇拿不到"越过遮挡"的新位置 | 升降 | 改高度；摇臂是弧线 ≠ 直线升降 |
| 变焦 | 机位不动改焦距，透视基本不变 | 跟拍 | 写清谁在动、摄影机跟在前后侧、距离是否稳定 |
| 移焦 | 清晰区在距离层之间转，场景必须有前后层次 | 环绕 | 绕弧线并持续转向主体；可只绕一小段 |

**三组最容易写混**：摇摄 vs 横移（机位转 / 机位移）、俯仰 vs 升降（角度 / 高度）、变焦 vs 推近（改焦距 / 改机位）。写完回头看一眼自己写的是哪一种，别让模型替你选。

**景别写画面边界**：`腰部以上中景`、`胸部以上近景`、`面部特写`。机位高度与角度分开写——`低机位、向上仰拍`，别让"低机位"默认等于仰拍。景深写"谁清晰、谁虚"，不写光圈值。

**四种会打架的组合，写完必须自查**：

| 不同时写 | 改法 |
|---|---|
| 推近 + 人物大小不变 | 让人物同步远离，或反向变焦，并另写清楚 |
| 跟拍 + 距离不断缩短 | 分阶段：先追近，再等速跟随 |
| 环绕 + 机位朝向固定 | 保留焦距/高度固定，写"持续转向人物使其居中" |
| 移焦 + 两人都清晰 | 改深景深构图，或用表演/光线/剪辑转移注意力 |

**参考图模式只写增量**：参考图已经固定的长相、服装、家具位置、光线方向，不要用文字另写一套；文字只管动作、机位路径、焦点、终态。要从首帧拉远露出环境，得先在场景图或【本段现场生成】里把环境定义好。

## 交付前自检（人工项，脚本替代不了）

**脚本只覆盖机械项**（结构/时间/资产锚点/台词引号与语速/密度/景别与切点词/可见性关键词/运镜条件冲突）。**必须先亲自通读全稿**，再按下表逐镜过，任何一条没做就等于没自检（完整版见 `references/self-check.md`）：

1. **可见性三分**：每镜在心里列「可见集 / 可听集 / 画外因果集」，正文里每个名字、物件、身体部位都要在可见集里；画外只写方向（画左/画右/画外上/画外下），**不写画外人物的名字**。
2. **轴线一致**：同一段内同一人物的目线方向要一致；「别开视线」要写明往哪边躲，不能和对方所在方向撞上。**指向画外要两样东西**：画面方向（画左/画右/画外上/画外下）+ **空间参照**（"门槛外她站的那一侧""走廊尽头那扇窗""阳台外"）——只写"画外"等于没给方向，只写"画左"模型仍不知道画面外是什么；她在画左，就不能写他往画右别开。
3. **机位反算**：这个景别 + 角度 + 遮挡，能不能同时拍到写的全部内容？不能就拆镜。
4. **过肩**：确实有后肩/耳侧/后脑进画才写「过肩」，否则写「干净反打」。
5. **景别精度**：远景不写表情与手指，特写不写三层空间。
6. **起幅/落幅**：镜内有运动时，写清哪些元素是后来才入画的，不能写成从头可见。
7. **一镜一动作**：动作分句数 ÷ 秒数，超过约 3 就拆镜或加时长。
8. **台词只出现一次**：台词后再复述一遍最容易诱出字幕。
9. **运镜成立**：起幅景别与落幅景别真的不同吗？**推近/摇向的目标在起幅真的存在吗**（不能对着还在包里的手机推）？人物和摄影机是不是各走各的路径？推拉有没有退化成平面缩放？焦点落在该看的信息上吗？接下一镜时走向、视线、光线方向、轴线对得上吗？
10. **条件不打架**：推近不锁人物大小、跟拍不锁距离、环绕不锁朝向、移焦不锁双方都清晰；方向有起止参照（"从正面移到左侧脸"），不拿"稳定器/无人机"代替路径。
11. **台词括号可演可听**：括号里只有气息/语速/音量，或说话人在画内时可见的动作与视线；不写"心里咯噔""心想""暗想"，也不写"急了""慌了"这类情绪判断。他在画外时，不写只有画面才看得见的喉结、眼神、手势。

自检结论要逐条报「过了 / 改了什么」，不能只报「校验 0 错」。

## 镜头写法速查

| 维度 | 要做 | 不要 |
|---|---|---|
| 景别/机位 | 每个镜头第一句写清景别 + 固定机位/推进/拉远/横移/升降/跟拍/跟摇/环绕/焦点转移 | 不写机位；一个短镜头堆三种无因运镜 |
| 景别写法 | 写画面边界："腰部以上中景""胸部以上近景""面部特写" | "近一点""大一点"；只写 MS/MCU/CU |
| 机位高度与角度 | 分开写："低机位、向上仰拍" | 默认"低机位"就是仰拍、"俯拍"就是高机位 |
| 摇与移 | 摇＝原地转（写起止对象）；移＝机位侧移（写前景/远景相对位移） | 笼统写"扫过""划过"，让模型自己选 |
| 变焦与推近 | 变焦＝机位不动只改取景；推近＝机位靠近、前后比例变 | 把"人变大"当成推近，或推近同时锁人物大小 |
| 切点 | **能不写就不写**——参考稿三份里写切点的镜头只占 28% / 45% / 2%；只在切点本身是决定时才写：切在动作没做完、切在声音、切在出门框、切在眼神冷下来；其余靠下一镜开头的「硬切」承接 | 每镜都以「切在…」收尾，43 镜 43 个同一句式 |
| 镜内时间点 | 与镜头头同一种写法：`[19.9s] 手抓起碗`、`[20.45s] 砸在地砖上`；一个镜头 3~4 个点，标出起势、接触、切点 | 用 `00:19.90` 这种另一套时码，段内格式不统一 |
| 晃动 | 写**幅度、频率、方向、来源**："画面随呼吸上下浮动约画高的百分之一、每秒一次"、"门板合拢的震动传到机位、画面短促后坐约半个指宽再回稳" | 只写"手持""轻晃""轻微抖动"——模型读不出幅度，只能自己编 |
| 参考图增量 | 只写动作、路径、焦点、终态 | 用文字另写一套与图冲突的服装/位置/光线 |
| 位置 | 画左/画右/画面中央/画上/画下/前中后景 + 距离/遮挡 | "看向前方""朝他走去" |
| 景深分层 | **只在真有纵深时**写前景/中景/后景，用来交代遮挡与距离（门缝、过肩、走廊纵深） | 特写、插入镜也硬套"前景…中景…后景…"，等于编 |
| 后景方向 | 先确认机位在哪：机位在门外 → 后景是门内；机位在门内 → 后景是走廊 | 把机位背后的空间写成后景（站在门外却写"后景是门内那片黑"） |
| 主体称呼 | 主体用【名】+画面位置（"她在画左、脚边是行李箱"） | 把主体叫"中景"——中景是景别/景深层，不是人 |
| 朝向 | 绑定画面："上半身朝画右偏转，视线落向画右上方画外" | 孤立写"转身""回头" |
| 环境声 | 只写**这个空间里真实存在**的声音：走廊=蝉、空调外机、门轴、楼道回声；客厅=冰箱低频、拖鞋、衣料；不确定就不写。**禁止否定式填充**（「没有风」「很安静」——这不是声音） | 二楼公寓走廊里写「远处车辆」、为了凑环境写「没有风」×13 处 |
| 主观镜头 | **点名主人**：`【陈诚】主观视角的 35mm 中景，机位在【陈诚】眼睛的高度`、`【陈诚】透过猫眼看到的主观视角`；标题也写「【陈诚】的视角」，不写「他的眼睛」 | 只写「主观视角」「猫眼视角」，模型不知道是谁的眼睛，可能挂到别人身上或拍成第三人称 |
| 眼神变化 | 写**可拍的四件事**：瞳孔（缩/放）、眼睑（收窄/抬起）、视线落点（从 A 移到 B）、眨眼（停/加速），可加呼吸变浅、喉结滚动 | 写「眼神变了」「不再是看陌生人」「像看一笔账」——观众看不见「不再」和「像」 |
| 视线移动 | 观众看不见的东西不能靠"眼球扫过去"交代：要么**镜头跟着移**（随目光横移/摇到目标），要么**让画框里的东西自己变**（门扇张开、缝隙变宽、人走进画面），要么**切到他的主观** | 在门缝/半脸这种受限画框里写"眼球先落在她脸上、再扫到肩带"——观众只看他半张脸不动 |
| 切镜 | 重新写位置/朝向/姿势/速度/持握/视线 | "继续飞""仍然站着" |
| 动作 | 发力→方向/轨迹→接触→惯性传导→衣发延迟→环境→摄影机反馈 | 整个人同步平移、无因抖动 |
| 暴力动作 | 写清：谁·抓什么·往哪个方向抡·砸在什么上·冲击与碎裂的可见结果·声音强度（"一把抓起白瓷碗，前臂往上一抡又狠狠往下砸，砸在地砖上炸开，一声脆响顶着画面炸响"） | 写成"扫下桌沿""碰掉了""碗掉在地上"——模型只能演出失手；也别把冲击放到画框外 |
| 特效 | 阶段（形成/持续/发射/命中/消散）→位置→方向/速度→影响 | 光效名词堆叠、每镜重演全流程 |
| 巨物 | 先定尺度，再写当前可见部位与占画幅比例 | 编造"300 米"这类绝对数字 |
| 文戏 | 稳定中景/近景/过肩/缓推/微横移/焦点转移；目光、呼吸、停顿、手指嘴角 | 环绕、甩镜、爆炸特效 |
| 表演 | 用可拍动作写情绪：捧脸、抹泪、唇角发颤、眼神稳住；台词前后都带准备与余势 | 写"难过""愤怒""很感动" |
| 切点 | 只在切点本身是决定时才写（动作未完/声音/出门框/眼神变化）；其余靠下一镜的「硬切」承接 | 每镜都以「切在…」收尾 |
| 机位 | 写上「随…下摇/上摇/轻推」，机位跟着表演走 | 全段只写「镜头固定」 |
| 结尾 | 收在动作结果上即可；运镜镜头要写落幅（到位/收稳/停住） | 每镜硬凑一个停点 |

## 与本项目 CLI / 飞书的对接

| 项 | 约定 |
|---|---|
| 一行 = 一段 | `剧本分镜表` 一行，`镜头编号` = `shot_id`，`视频提示词` = 段文本（含段头） |
| 时长 | `时间线` 写本段真实时长（6~30 秒）；`generate` 按它出片，上限 30 秒 |
| 素材锚点 | `{资产库：名}` 写在资产锁定条目里；`expand` 会收成 `【R01｜沈幼怡】` 并把图挂上 |
| 台词 | 4.2 写法：`[5s-6s]，【沈幼怡】（…地说）：「…」`，行首即时间窗；不用 `【对白】` 前缀 |
| 音色 | 需要固定音色的角色写 `音频参考：{音色库：音色名}`；CLI 收集音频文件作为 `reference_audio` 传给模型，本项目不开 TTS |
| 画风 | 全局风格由 `剧本设定` 在生成时追加；【本段整体基准】只写差异 |
| 已有分镜 | 重写本集时先读 `剧本分镜表 --episode N`，不要在旧段上叠写 |

**已知边界**：角色/场景的补充信息不要写在带锚点的那一行（`：】` 会被收干净），需要时写进镜头段。

## 不做的事

- 不写"延续上一段/同上/保持之前"，不跨段继承状态。
- 不写 NEGATIVE 段、不写英文胶片参数、不写镜头参数清单。
- 不写画外角色的姿态/表情/受力，只写声音、目线、影子、反光、气流。
- 不写"史诗/震撼/极致/炸裂"这类不可执行的形容词；不写比喻、瞳色、剧情原因。
- 不写**导演意图与解释**："为了让观众…""让这几下动作成为唯一运动""纹丝不动""手持＝记忆不稳"——这些是写给自己看的理由。固定机位就写"固定机位"，晃动就写幅度频率，理由留在设计里。
- 不新增台词、人物、事件、结果、专名；不改剧本顺序。
- 不把资产表当出场名单；不给库里没有的资产编名字、编号、锚点。
- 不写空的"音频参考："；音色只在需要固定时写 `{音色库：音色名}`，没有就不写。
