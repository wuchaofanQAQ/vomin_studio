# 角色 Character Sheet 提示词蓝图

用于豆包 seedream 文生图。每个角色产出 **1 条四视图 Character Sheet prompt**，1 张 16:9 横版图内：**左侧 40% 为大幅正脸端正面部特写，右侧 60% 并列三个全身三视图（正面 / 90°侧面 / 180°背面，各占 20%）**。

**语言规则**：提示词内容全部使用中文输出，标签名（如 `<HEADER>`、`<DESC>`、`<PANELS>`、`<STYLE LOCK>`）保持英文字母。

---

## 标签区块结构

整条提示词由 5 个标签区块组成，按固定顺序排列，标签之间换行分隔：

```
<HEADER>
16:9横版四视图角色设定图，浅灰纯色商业影棚背景；左侧占画面约40%为同一人物大幅正脸端正面部特写，右侧并列三个全身三视图共占60%。
</HEADER>

<STYLE LOCK>
统一画风锁定（中文）
</STYLE LOCK>

<DESC>
角色外貌、身材、服装、配饰的纯物理描述
</DESC>

<PANELS>
四个面板的逐一描述
</PANELS>

<STUDIO>
棚拍设置 + 禁止清单 + 质量约束（中文）
</STUDIO>
```

## 各标签区块详细规则

### 1. `<HEADER>` — 开头声明

固定内容，不需要改动：

```
<HEADER>
16:9横版四视图角色设定图，浅灰纯色商业影棚背景；左侧占画面约40%为同一人物大幅正脸端正面部特写，右侧并列三个全身三视图共占60%（正面全身、标准90°侧面全身、标准180°背面全身，每个各占20%）。
</HEADER>
```

### 2. `<DESC>` — 角色外貌描述

**只写物理形态，禁止表情、动作、姿态、心理状态、影视参考。**

按以下顺序组装（中文）：

1. **身份行**：年龄、性别、职业/身份、民族
2. **面部特征**：**按 7 个维度逐一细腻刻画，禁止泛化**——眼睛（眼型/双眼皮/瞳色/眼神）、眉毛（眉形/浓淡/眉峰）、嘴巴（唇形/唇色）、脸型（具体形状/下颌线/颧骨）、发型（发色/长度/发质/发量/刘海与发尾细节）、皮肤（肤色/质感/光泽）、腿型（腿长/笔直/纤细/脚踝）。脸型、眼型(双眼皮/单眼皮/大眼/细长眼)、鼻型、唇型、肤质肤色，保留 hex 色号
3. **记忆点**：提炼 1~2 个标志性记忆点（痣/下垂眼尾/三白眼/下颌线/唇珠等），用【记忆点】标注
4. **身材**：身高(cm)、**量化头身比**（成年男性/高个=九头身，成年女性/修长=8.5头身，少年/娇小=8头身）、体型(客观描述如偏瘦/壮实/纤细/匀称偏健整体型)、**下半身明显长于上半身、腰节偏高、双腿修长、躯干紧凑**
5. **服装**：上装/下装/鞋，每件含颜色(hex)和材质
6. **标志配饰**：饰品/道具/独特穿着细节 — 视觉锚点

**禁止词汇表**：
- 表情类：微笑、咧嘴笑、冷笑、皱眉、平静、温柔、凶狠、冷漠、淘气
- 动作类：重心偏移、驼背、前倾、双臂交叉、手插口袋、倚靠
- 心理类：自信姿态、紧张体态、放松站姿

## Seedance 锁脸引用方式（附在输出说明中）

- 裁切**左侧 40% 大幅正脸特写** → Seedance 图片 1（大头照/面部特征参考）
- 裁切**右侧第 1 格正面全身（20%）** → Seedance 图片 2（妆造身形参考）
- 提示词写法："主体的面部特征参考图片 1（大头照），妆造参考图片 2（全身照）"
- **不要**把整图直接当参考——四个视图会被识别成多个主体，造成 ID 漂移

## 修正规则

- 用户改某要素 → 替换对应 `<DESC>` 或 `<PANELS>` 段落，重新输出整条 prompt
- 若角色是非人类（动物、怪物等），调整右侧三视图站姿描述（如四脚站立），但保持"左 40% 大特写 + 右 60% 三视图"的 16:9 布局不变
- 色卡 hex 值改动时，prompt + 角色档案的色卡需同步更新
- 下装若为短裙/短裤/紧身款，背面视图必须显式写入"后片长度与覆盖范围必须符合设定，不允许任何裸露"的约束
