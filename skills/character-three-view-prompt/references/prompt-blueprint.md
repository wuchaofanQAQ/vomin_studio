# 角色 Character Sheet 提示词蓝图

用于豆包 seedream 文生图。每个角色产出 **1 条四宫格 Character Sheet prompt**，1 张图内 2x2 grid 排列 4 个面板。

**语言规则**：提示词内容全部使用中文输出，标签名（如 `<HEADER>`、`<DESC>`、`<PANELS>`、`<STYLE LOCK>`）保持英文字母。

---

## 标签区块结构

整条提示词由 5 个标签区块组成，按固定顺序排列，标签之间换行分隔：

```
<HEADER>
四面板角色设定图，1×4 横排布局，每个面板 9:16 竖向比例。
</HEADER>

<STYLE LOCK>
统一画风锁定（中文）
</STYLE LOCK>

<DESC>
角色外貌、身材、服装、配饰的纯物理描述
</DESC>

<PANELS>
四个面板的逐一描述
</PANELS>

<STUDIO>
棚拍设置 + 禁止清单 + 质量约束（中文）
</STUDIO>
```

---

## 各标签区块详细规则

### 1. `<HEADER>` — 开头声明

固定内容，不需要改动：

```
<HEADER>
四面板角色设定图，1×4 横排布局，每个面板 9:16 竖向比例。
</HEADER>
```

### 2. `<DESC>` — 角色外貌描述

**只写物理形态，禁止表情、动作、姿态、心理状态、影视参考。**

按以下顺序组装（中文）：

1. **身份行**：年龄、性别、职业/身份、民族
2. **面部特征**：脸型、眼型(双眼皮/单眼皮/大眼/细长眼)、鼻型、唇型、肤质肤色，保留 hex 色号
3. **发型**：发色(hex)、长度、造型/质感
4. **身材**：身高(cm)、九头身比例、体型(客观描述如偏瘦/壮实/纤细)
5. **服装**：上装/下装/鞋，每件含颜色(hex)和材质
6. **标志配饰**：饰品/道具/独特穿着细节 — 视觉锚点

**禁止词汇表**：
- 表情类：微笑、咧嘴笑、冷笑、皱眉、平静、温柔、凶狠、冷漠、淘气
- 动作类：重心偏移、驼背、前倾、双臂交叉、手插口袋、倚靠
- 心理类：自信姿态、紧张体态、放松站姿

### 3. `<PANELS>` — 四面板描述

逐面板写内容（中文），统一站姿，禁止表情和动作：

**面板1 — 正面脸部：**
头肩特写，正面直视镜头。[五官物理形态全量描述] — 完整且权威的面部参考，该角色唯一的五官标准。

**面板2 — 侧面脸部：**
同比例头肩，干净侧面轮廓，同发型。[侧面五官与骨相物理形态]。

**面板3 — 正面全身：**
全身正面图，标准直立站姿，双臂自然下垂，九头身比例，面部刻意模糊低细节（预留后期编辑）。[服装身形全套描述]。

**面板4 — 背面全身：**
全身背面图，标准直立站姿，与面板3同一站位，九头身比例。[背面造型：发型背面、服装背面、鞋跟]。

**非人类角色**（动物/怪物）：面板3/4 站姿调整为四脚站立等适配姿态，但保持 2×2 网格结构不变。

### 4. `<STYLE LOCK>` — 统一风格锁定

从剧本设定的画面风格字段读取，翻译为中文后填入，锁定全角色统一画风。**标签名保持英文字母，内容使用中文**：

```
<STYLE LOCK>
明亮干净的现代都市风格，饱和度略高于现实并带有微妙的漫画/动漫美感，以暖白色和奶油色为主色调，橙色点缀高光，自然光照，温馨温暖的氛围，不要暗黑或赛博朋克风，日剧的温暖感与动漫的清透感融合。
</STYLE LOCK>
```

### 5. `<STUDIO>` — 棚拍设置 + 禁止清单 + 质量约束

此段内容全角色统一，只有"禁止"中的"面部"和"身体"部分按角色特有防偏需要微调。**内容使用中文**：

```
<STUDIO>
无缝中性灰色(#606570)纯色背景。单个硬质主光源位于相机左侧45°角，冷钢蓝色调。无补光灯，无道具装饰，无摆设。仅地面有自然接触阴影。

禁止 — 面部：[角色特有面部防偏]，无面部表情，无微笑，无皱眉，无任何情绪表现。身体：[角色特有身形/服装防偏]，无姿势，无手势，无动作，无短小或矮胖比例。灯光：无补光灯，无暖色调，无背景色溢出，无边缘光效果，面板间无色温跳跃。格式：面板标签外无文字块，无水印，面板间身份保持一致，无美颜滤镜皮肤，无光泽电视剧妆容，无偶像妆容，无皮肤平滑处理。

1:1正方形格式，2×2网格，四个等大面板，细边框间距。影视制作级摄影角色设定图，曝光均匀，织物纹理准确，哑光肤色，真实毛孔，无光泽感。干净、专业、适合影视制作使用。
</STUDIO>
```

## 关键句式（必须包含，中文）

- `<HEADER>` 中：**"四宫格角色设定图，2×2 网格布局"**

- `<PANELS>` 面板1 中：**"完整且权威的面部参考，该角色唯一的五官标准"**
- `<PANELS>` 面板3 中：**"面部刻意模糊低细节（预留后期编辑）"**
- `<PANELS>` 面板3/4 中：**"标准直立站姿，双臂自然下垂"** + **"九头身比例"**
- `<DESC>` 面部描述末尾：**"不含任何表情、情绪、动作描述"**

- `<STUDIO>` 末尾：**"影视制作级摄影角色设定图"**

## Seedance 锁脸引用方式（附在输出说明中）

- 从四宫格裁切上排左面板（正面脸部）→ Seedance 图片 1（大头照/面部特征参考）
- 从四宫格裁切下排左面板（正面全身）→ Seedance 图片 2（妆造身形参考）
- 提示词写法："主体的面部特征参考图片 1（大头照），妆造参考图片 2（全身照）"
- **不要**把四宫格整图直接当参考——多角度会被识别成多个主体，造成 ID 漂移

---

## 修正规则

- 用户改某要素 → 替换对应 `<DESC>` 或 `<PANELS>` 段落，重新输出整条 prompt
- 若角色是非人类（动物、怪物等），调整站姿描述（如四脚站立），但保持 2×2 网格结构不变
- 色卡 hex 值改动时，prompt + 角色档案的色卡需同步更新
