# Character Three-View Prompt

把一个剧本/设定里的角色文字描述，转成 **1 条可直接投喂豆包 seedream** 的四视图 Character Sheet 提示词（16:9 横版布局：左侧 40% 大幅正脸端正面部特写，右侧 60% 并列正面全身 / 90° 侧面全身 / 180° 背面全身三个三视图，各占 20%）。内容全中文，标签名保持英文字母。

**本 skill 仅用于人物三视图生成，不包含场景、背景。**

## 标签区块结构

整条提示词由 4 个标签区块组成，按固定顺序，标签采用行内写法 `<标签> … </标签>`：

| 顺序 | 标签 | 职责 |
|---|---|---|
| 1 | `<STUDIO>` | 布局 + 背景 + 布光（固定模板） |
| 2 | `<STYLE LOCK>` | 画风锁定（固定，禁止修改） |
| 3 | `<DESC>` | 角色外貌描述（从角色档案提取） |
| 4 | `<PANELS>` | 四个视图逐一描述（基于 DESC 组装） |

## 固定模板（原样照抄，禁止增删改）

`<STUDIO>` 与 `<STYLE LOCK>` 为固定模板，输出时一字不改照抄。

### `<STUDIO>`

```
<STUDIO> 16:9横版四视图角色设定, 同一人物，正面、侧面、背面，全身设定稿，左侧占画面约40%为同一人物大幅正脸端正面部特写，右侧并列三个全身三视图共占60%（正面全身、标准90°侧面全身、标准180°背面全身，每个各占20%）,干净浅灰纯色背景,柔和均匀布光 </STUDIO>
```

### `<STYLE LOCK>`（画风锁定，禁止修改）

```
<STYLE LOCK> 电影感仿真人像，单反人像质感，写实皮肤纹理，柔和均匀布光，原生皮肤质感，低饱和灰调，氛围感，高清8k，柔和暖侧光 </STYLE LOCK>
```

**画风锁定规则（硬性）**：
- `<STYLE LOCK>` 内容为固定锁定画风，**禁止修改、替换、增删**。
- 不读取剧本"画面风格"字段，不随剧本或角色改变画风。
- **禁止私自修改风格**：不得改成真实毛孔、美颜滤镜、偶像磨皮、动漫风、高饱和、冷硬高对比等任何其他风格。画面风格一律以本模板为准。

## `<DESC>` — 角色外貌描述

只写物理形态，禁止表情、动作、姿态、心理状态。从角色描述中提取：

1. **身份**：年龄、性别
2. **面部**：脸型、眼、眉、鼻、唇、肤色肤质、发型（发色 / 长度 / 造型）
3. **身材**：身高、体型、量化头身比（成年男 / 高个 = 9 头身，成年女 / 修长 = 8.5 头身，少年 / 娇小 = 8 头身），并写"下半身明显长于上半身、腰节偏高、双腿修长、躯干紧凑、头小身正"
4. **服装**：上装 / 下装 / 鞋，含颜色与材质
5. **配饰**：饰品 / 包 / 头饰等

缺失项标"未指定"，不臆造。可提炼 1~2 个标志性记忆点（痣、唇珠等）保证辨识度。

## `<PANELS>` — 四视图描述

先写一句跨视图一致性总锁定，再按"左侧特写 → 右侧三视图"逐视图描述，统一直立站姿，禁止表情和动作：

- **一致性锁定（开头必写）**：四个视图必须严格为同一人物，脸型、五官、肤色、妆容、发型、发长、服装结构、配色、配饰与鞋子全部 1:1 一致，禁止不同视图自行改变。
- **左侧特写（40%）**：完整刻画五官物理形态 + 头部定位（正对镜头、双眼连线水平、不歪头、视线平视）。
- **正面全身（20%）**：身体正对镜头，双手自然垂落，双腿自然直立，写量化头身比与腿长描述，从头到脚完整不裁切。
- **90° 侧面全身（20%）**：严格 90° 侧身，头 / 肩 / 胸 / 腰胯 / 腿 / 鞋保持真实侧面结构，写头身比，禁止上长下短、服装层缺失。
- **180° 背面全身（20%）**：严格 180° 正背面，肩背水平，写头身比，完整展示发型背面、服装背部、腰带、下装后片与鞋跟。

## 核心规则

1. **禁止表情和动作**：所有 4 个视图不写微笑、皱眉、情绪、姿态、手势；统一标准直立站姿。
2. **禁止修改风格**：见 `<STYLE LOCK>` 锁定规则，画风固定不可改。
3. **中文输出**：内容全中文，标签名保持英文字母，hex 色号保留英文格式。

## When to Use

触发："给这个角色生成三视图 / 参考照片提示词"、"角色 Character Sheet prompt"。本 skill 只写人物提示词，出图由文生图工具执行。

## Workflow

1. 从角色描述提取要素，填入 `<DESC>`。
2. 原样输出固定 `<STUDIO>`、`<STYLE LOCK>`。
3. 基于 `<DESC>` 组装 `<PANELS>`。
4. 按 `<STUDIO>` → `<STYLE LOCK>` → `<DESC>` → `<PANELS>` 顺序输出整条 prompt，末尾附：抽取了哪些要素、哪些未指定需确认。

<PANELS>
四个视图必须严格为同一人物，脸型、五官、肤色、妆容、发型、发长、服装结构、配色、配饰与鞋子全部1:1一致，禁止不同视图自行改变。
