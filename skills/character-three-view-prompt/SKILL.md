# Character Three-View Prompt（四视角角色锁定图）

把一个剧本/设定里的角色文字描述，转成 **1 条可直接投喂豆包 seedream** 的四视角角色锁定图提示词。一个角色 = 一条提示词 = 一张图。不做多选角方案（不出 5 张 5 张脸），不多角色同屏。**本 skill 仅用于人物，不含场景。**

## 版式（所有风格统一：9:16 竖版 2700×4800，非平均四宫格）

```
┌───────────────┬───────────────┐
│  正面面部近景  │  侧面面部近景  │   上半区：头部锁定区，约占整图高度 1/3
├───────────────┼───────────────┤
│               │               │
│   全身正面     │   全身背面     │   下半区：全身结构区，约占整图高度 2/3
│               │               │
└───────────────┴───────────────┘
```

两个区域内左右各占一半宽度，分割线极细、浅灰。四个视角锁定：正脸与五官（左上）、侧脸轮廓（右上）、身高比例与服装正面结构（左下）、后脑发型与服装背面结构（右下）。

**版式硬规则**：上半区约 1/3、下半区约 2/3，不平均分成四格；不得让头部区过大或全身区过小；四个视角缺一不可。

## Step 0 — 判定风格分支（只决定 STYLE LOCK）

读剧本设定（只读：`python cli.py read $WS --table 剧本设定`），取「人物风格」，没有则取「画面风格」：

| 命中 | 分支 | `<STYLE LOCK>` |
|---|---|---|
| 含「真人」「仿真人」「真人写实」「电影真人」「实拍」「单反人像」等**真人影视**线索 | **A｜电影真人** | 固定模板（含 85mm），禁止修改 |
| 动漫 / 国漫 / 二次元 / 3D / 插画 / 手绘 / 水墨等**非真人**线索 | **B｜非真人** | 取设定「人物风格」原文 |

判不出来（设定缺失或含糊）时，不要臆断，向用户确认一句"本项目角色是电影真人风格吗"再继续。分支判定结果在末尾说明里写明。

## 标签区块结构

整条提示词由 4 个标签区块组成，按固定顺序，标签采用行内写法 `<标签> … </标签>`：

| 顺序 | 标签 | 职责 |
|---|---|---|
| 1 | `<STUDIO>` | 画幅 + 版式 + 背景 + 布光 + 画内无文字（固定模板，两分支仅"真人"二字不同） |
| 2 | `<STYLE LOCK>` | 画风锁定（A 固定禁改；B 取设定原文） |
| 3 | `<DESC>` | 角色外貌描述（从角色档案提取） |
| 4 | `<PANELS>` | 四个视角逐一描述（基于 DESC 组装） |

## 固定模板

### `<STUDIO>`（原样照抄，禁止增删改）

分支 A：

```
<STUDIO> 9:16竖版2700×4800真人角色锁定图，同一人物四视角设定稿，干净浅灰纯色棚拍背景，柔和均匀布光，极细浅灰分割线；非平均四宫格：上半区约占整图高度1/3，左右并列正面面部近景与侧面面部近景，各占上半区一半宽度；下半区约占整图高度2/3，左右并列全身正面与全身背面，各占下半区一半宽度；画面内只有人物与背景，无任何文字、标签、水印、logo </STUDIO>
```

分支 B（仅把"真人角色锁定图"换成"角色锁定图"，其余一字不改）：

```
<STUDIO> 9:16竖版2700×4800角色锁定图，同一人物四视角设定稿，干净浅灰纯色棚拍背景，柔和均匀布光，极细浅灰分割线；非平均四宫格：上半区约占整图高度1/3，左右并列正面面部近景与侧面面部近景，各占上半区一半宽度；下半区约占整图高度2/3，左右并列全身正面与全身背面，各占下半区一半宽度；画面内只有人物与背景，无任何文字、标签、水印、logo </STUDIO>
```

### `<STYLE LOCK>`

**分支 A（固定模板，禁止修改、替换、增删）：**

```
<STYLE LOCK> 电影感仿真人像，单反人像质感，85mm人像镜头质感，写实皮肤纹理，柔和均匀布光，原生皮肤质感，低饱和灰调，氛围感，高清8k，柔和暖侧光 </STYLE LOCK>
```

- 镜头统一为 **85mm 人像镜头质感**（不写 50mm，也不写"50mm/85mm"二选一）。
- 该行比剧本设定「人物风格」多了「85mm人像镜头质感」，这是有意统一，不要回退成与设定逐字相同。
- 不得私改成美颜磨皮、动漫风、高饱和、冷硬高对比等。

**分支 B：** 取剧本设定「人物风格」原文（没有则取「画面风格」）一字不改写入，不自行发明画风；A 分支的固定 STYLE LOCK 与 85mm 镜头词**不用于**本分支。

## `<DESC>` — 角色外貌描述

只写物理形态，禁止表情、动作、姿态、心理状态。从角色描述中提取：

1. **身份**：年龄、性别
2. **面部**：脸型、眼、眉、鼻、唇、肤色肤质、发际线与刘海、发型（发色 / 长度 / 造型）
3. **身材**：身高、体型、量化头身比（成年男 / 高个 = 9 头身，成年女 / 修长 = 8.5 头身，少年 / 娇小 = 8 头身），并写"下半身明显长于上半身、腰节偏高、双腿修长、躯干紧凑、头小身正"
4. **服装**：上装 / 下装 / 鞋，含颜色与材质；有背面结构（后片、披风、绑带、腰封）的要写
5. **配饰**：饰品 / 包 / 头饰 / 耳饰等

缺失项标"未指定"，不臆造。可提炼 1~2 个标志性记忆点（痣、唇珠等）保证辨识度。

## `<PANELS>` — 四视角描述

先写一句跨视角一致性总锁定，再按"左上 → 右上 → 左下 → 右下"逐视角描述，统一直立站姿，禁止表情和动作：

- **一致性锁定（开头必写）**：四个视角必须严格为同一人物，脸型、五官、肤色、妆容、发型、发色、发长、服装结构、配色、配饰、鞋子、身高比例、年龄感全部 1:1 一致，禁止不同视角自行改变；面部近景与全身图是同一张脸，正面与背面是同一套服装与发型。
- **左上 — 正面面部近景（上半区左半宽）**：锁定正脸、脸型、五官、眼神、妆容、刘海、发际线、耳饰、颈部服饰细节。头部正对镜头居中，双眼连线水平、不歪头、视线平视；眼睛、五官、发型、妆容清楚；肩颈上半部分可见；脸部清晰不模糊。完整写 `<DESC>` 的五官物理形态。
- **右上 — 侧面面部近景（上半区右半宽）**：锁定侧脸轮廓。严格 90° 纯侧脸（不是三分之二侧脸，不能和正面图相似）；鼻梁轮廓、嘴唇形状、下颌线、耳朵与耳饰位置、发型侧面厚度与结构、颈部与衣领清楚。
- **左下 — 全身正面（下半区左半宽）**：锁定身高比例、体态、服装正面结构、鞋子。身体正对镜头，双手自然垂落，双腿自然直立，标准直立站姿；写量化头身比与腿长描述（下半身明显长于上半身，禁止上长下短）；头到脚完整入画、不裁掉头 / 手 / 脚；服装正面结构与鞋子清楚。
- **右下 — 全身背面（下半区右半宽）**：锁定后脑发型与服装背面结构。严格 180° 正背面，背对镜头，肩背水平；写头身比；完整展示后脑发型、背部服装结构、腰部、后侧裙摆 / 披风 / 外套后片 / 绑带 / 腰封、鞋子背面；下装覆盖符合设定。不得换发型、换服装。

## 核心规则

1. **禁止表情和动作**：四个视角不写微笑、皱眉、情绪、姿态、手势；统一标准直立站姿，不摆拍、不夸张。
2. **画风按分支**：A 固定 `<STYLE LOCK>` 禁改；B 取设定「人物风格」原文，两者都不自行发明画风。
3. **画面内无文字**：`<STUDIO>` 已声明；`<DESC>` 与 `<PANELS>` 中不得要求生成姓名、年龄、身高、版本名、"正面/侧面/背面"字样等任何画内文字（这些信息只作描述，不会显示）。
4. **中文输出**：内容全中文，标签名保持英文字母，hex 色号保留英文格式。
5. **一次一角色一张图**：不输出多版本、多选角方案，不多角色同屏。

## When to Use

触发："给这个角色生成三视图 / 角色锁定图 / 参考照片提示词"、"角色 Character Sheet prompt"、"出角色三视图"。本 skill 只写人物提示词，出图由文生图工具执行。

## Workflow

1. **Step 0 判定风格分支**（见上），读剧本设定「人物风格」。
2. 从角色描述提取要素，填入 `<DESC>`。
3. 输出对应分支的固定 `<STUDIO>` 与 `<STYLE LOCK>`。
4. 基于 `<DESC>` 组装 `<PANELS>`（左上 → 右上 → 左下 → 右下）。
5. 按 `<STUDIO>` → `<STYLE LOCK>` → `<DESC>` → `<PANELS>` 顺序输出整条 prompt，末尾附：**所走分支及判定依据**、抽取了哪些要素、哪些未指定需确认。
6. 出图画面比例统一选 **9:16**（生图工作台「画面比例」下拉；`cli.py generate` 的角色图不传尺寸，竖版靠提示词版式，必要时在工作台指定 9:16 与 2K 以上分辨率）。

## 示例（分支 A：电影真人）

```

<PANELS>
四个视角必须严格为同一人物，脸型、五官、肤色、妆容、发型、发色、发长、服装结构、配色、配饰、鞋子、身高比例、年龄感全部1:1一致，禁止不同视角自行改变；面部近景与全身图为同一张脸，正面与背面为同一套服装与发型。

</PANELS>
```

分支 B 的版式、`<PANELS>`、`<DESC>` 写法与上例完全相同，只有 `<STUDIO>` 去掉"真人"二字、`<STYLE LOCK>` 换成设定「人物风格」原文。
