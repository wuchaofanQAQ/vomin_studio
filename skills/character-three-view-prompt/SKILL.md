# Character Three-View Prompt

## Overview

把一个剧本/设定里的角色文字描述，转成 **1 条可直接投喂豆包 seedream** 的四视图 Character Sheet 提示词（16:9 横版布局：左侧 40% 为大幅正脸端正面部特写，右侧 60% 并列正面全身 / 90°侧面全身 / 180°背面全身三个三视图，每个三视图占 20%）。提示词内容全部使用中文输出，标签名（如 `<HEADER>`、`<DESC>`、`<PANELS>`、`<STYLE LOCK>`、`<STUDIO>`）保持英文字母。提示词由 5 个标签区块组成，标签之间换行分隔。

**本 skill 仅用于人物三视图生成，不包含场景、背景、灯光等内容。**

## 标签区块结构

| 顺序 | 标签 | 职责 | 语言 | 内容来源 |
|---|---|---|---|---|
| 1 | `<HEADER>` | 开头声明 | 中文 | 固定文本 |
| 2 | `<DESC>` | 角色外貌描述 | 中文 | 从角色档案提取 |
| 3 | `<PANELS>` | 四视图逐一描述 | 中文 | 基于 DESC 组装 |
| 4 | `<STYLE LOCK>` | 统一画风锁定 | 中文 | 从剧本设定读取 |
| 5 | `<STUDIO>` | 棚拍设置 + 禁止清单 + 质量约束 | 中文 | 全角色共享模板 |

## 16:9 横版 4 视图布局（左特写 + 右三视图）

整图为 **16:9 横版**，浅灰纯色商业影棚背景。左侧一个大幅面部特写占 **40%**，右侧并列三个全身视图共占 **60%**（每个 **20%**）。

| 位置 | 占比 | 视图 | 内容 | 用途 |
|---|---|---|---|---|
| 左侧 | 40% | 正脸端正面部特写 | 完整展示头顶发型、面部、妆容、耳环/耳饰、肩颈与上胸部；头部正对镜头，无左右旋转，双眼连线水平，不歪头，下巴轻微内收约 2°-3°，视线平视镜头，颈部自然竖直，头部稳定位于双肩中心 | 锁面部 ID（唯一五官标准） |
| 右侧第1格 | 20% | 正面全身 | 身体正对镜头，双手自然垂落身体两侧，双腿自然直立，从头顶到脚底完整可见不裁切 | 锁正面服装身形 |
| 右侧第2格 | 20% | 标准 90° 侧面全身 | 严格 90° 侧身站立，头/肩/胸腔/腰胯/双腿/鞋子均保持真实侧面结构，完整展示服装各层与侧面装饰 | 锁侧面骨相与剪裁 |
| 右侧第3格 | 20% | 标准 180° 背面全身 | 严格 180° 正背面，肩背保持水平，完整展示发型背面、服装背部拼接、腰带、下装后片与鞋跟结构 | 锁背面造型 |

四个视图必须严格为同一人物，脸型、五官、肤色、妆容、发型、发长、服装结构、配色、耳饰、腰带、金属配件与鞋子全部 1:1 保持一致，禁止不同视图自行改变发型、服装或配饰。

## 核心规则

### 1. 禁止表情和动作

**所有 4 个视图**都不得出现任何表情、情绪、动作描述：
- **禁止**：微笑、咧嘴笑、冷笑、皱眉、平静、温柔、凶狠、冷漠、淘气等
- **禁止**：重心偏移、驼背、前倾、双臂交叉、手插口袋、倚靠、摆拍手势等
- **正确做法**：只在 `<DESC>` 中描述五官的物理形态，不加情绪修饰
- 人物站姿统一为：标准直立站姿，双臂自然下垂，双手自然垂落身体两侧，双腿自然直立

### 2. 身材比例约束（强约束，必须量化）

`<DESC>` 和 `<PANELS>` 右侧三个全身视图必须**强烈**包含身材比例约束，避免大头娃娃、上半身长下半身短、腿短矮胖的即视感：

- **头身比必须写具体数字**，按角色分档：
  - 成年男性 / 高个角色：**九头身比例**（约 9 个头高）
  - 成年女性 / 匀称偏修长：**8.5 头身比例**（约 8.5 个头高）
  - 少年 / 娇小体型：**8 头身比例**
- 写明角色身高（如 178cm / 168cm）
- 体型用客观描述（偏瘦/壮实/纤细/匀称偏健整体型）
- **必须额外写**：下半身（腿长）明显长于上半身，腰节位置偏高，双腿修长，躯干紧凑，头小身正，禁止大头娃娃、头大身小、上长下短、腿短、五短身材
- 该句同时进入 `<STUDIO>` 禁止清单："禁止大头娃娃比例，禁止头大身小，禁止上半身长下半身短，禁止腿短，禁止五短身材"

### 3. STYLE LOCK 统一风格段

`<STYLE LOCK>` 标签内只放风格描述（中文），内容从剧本设定的画面风格字段读取并翻译为中文，锁定全角色统一画风。标签名保持英文字母。

### 4. 人脸与视图分工规则

- **左侧大特写（40%）**：完整刻画五官物理形态，是该角色唯一的五官标准；头部定位约束（正对、双眼水平、下巴内收 2°-3°）必须写入
- **右侧正面全身（20%）**：面部与左侧特写严格同一人，五官/肤色/妆容不漂移；身体正对镜头，完整展示服装正面结构
- **右侧 90° 侧面全身（20%）**：严格 90° 侧身，所有解剖部位（头/肩/胸/腰胯/腿/鞋）保持真实侧面结构；禁止服装层突然缺失
- **右侧 180° 背面全身（20%）**：肩背水平，完整展示发型背面、服装背部、腰带、下装后片与鞋跟；下装后片覆盖范围必须符合设定，不允许任何裸露
- 四个视图跨区必须用同一句"严格同一人物，脸型/五官/肤色/妆容/发型/服装/配色/配饰/鞋子全部 1:1 一致"锁定

### 5. STUDIO 段全角色共享

`<STUDIO>` 段包含 16:9 浅灰影棚设置、禁止清单、质量约束（中文），全角色共享模板。只有"禁止"中的"面部"和"身体"部分按角色特有防偏微调。

### 6. 中文输出规则

- 提示词所有描述内容使用中文（包括 `<STYLE LOCK>` 内的画风描述）
- hex 色号保留英文格式（如 #1A1A1A）
- 标签名保持英文字母（`<HEADER>`、`<DESC>`、`<PANELS>`、`<STYLE LOCK>`、`<STUDIO>`）

## When to Use

触发场景：
- "给这个角色生成三视图/参考照片提示词"
- "角色 Character Sheet / 角色一致性照片的 prompt"
- 短剧制作流程中需要为某角色产出一致性参考图 prompt

本 skill 只负责**写人物提示词**。出图由文生图工具执行。不处理场景图。

## Workflow

### Step 1 — 抽取角色核心要素

从角色描述中提取结构化要素，填入 `<DESC>` 段。缺失项标记"未指定"，不臆造：

1. **身份/性别/年龄**
2. **面部特征**：脸型、五官物理形态（不含表情）、发型（发色/长度/造型）
3. **身材体型**：身高、胖瘦、体态（客观描述，禁止姿态词）
4. **服装**：上装/下装/外套、颜色(hex)、材质
5. **配饰**：饰品/眼镜/帽子等
6. **标志性特征**：伤疤、纹身、道具、独特穿着细节 — 视觉锚点
7. **色卡**：从服装/发色/标志性道具提取 3-5 个主色 hex 值

**★ 五官细腻描写维度清单（必写，逐项刻画，禁止泛化）**：`<DESC>` 面部描述必须按以下 7 个维度逐一写清物理形态，缺一不可：

| 维度 | 写法要求 | 示例（非模板，按角色实际写） |
|---|---|---|
| 眼睛 | 眼型（杏眼/丹凤/下垂眼/细长眼/三白眼…）、双眼皮形态、瞳色、眼神特征 | 圆润杏眼、眼尾自然下垂，瞳仁黑亮 |
| 眉毛 | 眉形（剑眉/柳叶眉/平直眉…）、浓淡、眉峰位置 | 剑眉压眼，眉骨立体、眉尾略上扬 |
| 嘴巴 | 唇形（薄唇/M唇/唇珠/樱桃小口…）、唇色 | 上唇有唇珠，唇色浅粉 |
| 脸型 | 具体形状 + 下颌线/颧骨特征 | 圆润鹅蛋脸，下颌线条柔和收尖 |
| 发型 | 发色、长度、发质、发量、刘海/发尾细节 | 黑长直及腰，发质垂顺，空气刘海微遮眉 |
| 皮肤 | 肤色（冷白/暖白/暗沉…）、质感（通透/哑光/粗糙…）、光泽 | 冷白通透瓷感，细腻无瑕疵 |
| 腿型 | 腿长占比、笔直/纤细/匀称、脚踝/小腿特征 | 双腿笔直纤细，脚踝细，小腿线条干净 |

**★ 记忆点规则（必写，拒绝大众脸/网红脸）**：每个角色必须提炼 **1~2 个标志性记忆点**（如左眉尾小痣、下垂眼尾、三白眼+胡茬、清晰下颌线、唇珠、眼尾微垂等），写入 `<DESC>` 用【记忆点】标注，并在 `<PANELS>` 左侧特写与 `<STUDIO>` 禁止清单中重复锁定（"左眉尾小痣不丢失"等），确保出图有辨识度。

### Step 2 — 按标签模板组装提示词

读取 `references/prompt-blueprint.md`，按 5 个标签区块顺序组装（中文）：

1. `<HEADER>` — 固定开头声明（16:9 横版，左 40% 特写 + 右 60% 三视图）
2. `<DESC>` — Step 1 提取的外貌描述（中文，禁止表情/动作/姿态/心理状态/影视参考）
3. `<PANELS>` — 左侧大特写 + 右侧三个全身视图逐一描述（中文），并在开头写跨视图一致性锁定句
4. `<STYLE LOCK>` — 从剧本设定读取画面风格，翻译为中文填入
5. `<STUDIO>` — 16:9 浅灰影棚设置 + 禁止清单 + 质量约束（中文，禁止的面部/身体按角色微调）

### Step 3 — 输出与说明

输出 1 条带标签区块的四视图 prompt。末尾附说明：

1. 抽取了哪些要素、哪些项未指定需确认
2. **Seedance 锁脸使用指引**：
   - 不要把整图直接当 Seedance 参考图
   - 正确用法：裁切**左侧 40% 大幅正脸特写**作为图片 1（大头照/面部特征参考），裁切**右侧第 1 格正面全身**作为图片 2（妆造身形参考）

## Automated Mode (Harness Integration)

当被 `ai-drama-harness` 调用时，额外输出结构化 JSON，供 harness 通过 `python cli.py write --table 角色库` 更新角色的 `gen_prompt` 字段。

### 读取输入

```bash
python cli.py read $WS --table 角色库
python cli.py read $WS --table 角色档案
python cli.py read $WS --table 剧本设定
```

### JSON 输出格式

````
```json:structured-output
[
  {
    "name": "林砚",
    "gen_prompt": "<HEADER>\n16:9横版四视图角色设定图，浅灰纯色商业影棚背景；左侧占画面约40%为同一人物大幅正脸端正面部特写，右侧并列三个全身三视图共占60%（正面全身、90°侧面全身、180°背面全身各占20%）。\n</HEADER>\n\n<DESC>\n...\n</DESC>\n\n<PANELS>\n...\n</PANELS>\n\n<STYLE LOCK>\n...\n</STYLE LOCK>\n\n<STUDIO>\n...\n</STUDIO>"
  }
]
```
````

`gen_prompt` 为带标签区块的四视图 Character Sheet 提示词（中文）。harness 写入后通过 `python cli.py generate $WS --target 角色库:林砚` 触发出图。
