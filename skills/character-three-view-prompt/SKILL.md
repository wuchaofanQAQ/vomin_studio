# Character Three-View Prompt

## Overview

把一个剧本/设定里的角色文字描述，转成 **1 条可直接投喂豆包 seedream** 的四面板 Character Sheet 提示词（1×4 横排布局，每个面板 9:16 竖向比例）。提示词内容全部使用中文输出，标签名（如 `<HEADER>`、`<DESC>`、`<PANELS>`、`<STYLE LOCK>`、`<STUDIO>`）保持英文字母。提示词由 5 个标签区块组成，标签之间换行分隔。

**本 skill 仅用于人物三视图生成，不包含场景、背景、灯光等内容。**

## 标签区块结构

| 顺序 | 标签 | 职责 | 语言 | 内容来源 |
|---|---|---|---|---|
| 1 | `<HEADER>` | 开头声明 | 中文 | 固定文本 |
| 2 | `<DESC>` | 角色外貌描述 | 中文 | 从角色档案提取 |
| 3 | `<PANELS>` | 四面板逐一描述 | 中文 | 基于 DESC 组装 |
| 4 | `<STYLE LOCK>` | 统一画风锁定 | 中文 | 从剧本设定读取 |
| 5 | `<STUDIO>` | 棚拍设置 + 禁止清单 + 质量约束 | 中文 | 全角色共享模板 |

## 1×4 横排 4 面板布局

| 位置 | 面板 | 内容 | 用途 |
|---|---|---|---|
| 第1格 | 正面脸部 | 头肩特写，正面直视镜头 | 锁面部 ID（唯一五官标准） |
| 第2格 | 侧面脸部 | 同比例头肩，干净侧面轮廓 | 补侧面骨相 |
| 第3格 | 正面全身 | 正面全身站姿，从头顶到脚底完整可见不裁切，**面部刻意模糊低细节** | 锁服装身形 |
| 第4格 | 背面全身 | 背面全身站姿，从头顶到脚底完整可见不裁切 | 锁背面造型 |

每个面板为 9:16 竖向比例，横向平铺排列。

## 核心规则

### 1. 禁止表情和动作

**所有 4 个面板**都不得出现任何表情、情绪、动作描述：
- **禁止**：微笑、咧嘴笑、冷笑、皱眉、平静、温柔、凶狠、冷漠、淘气等
- **禁止**：重心偏移、驼背、前倾、双臂交叉、手插口袋、倚靠等
- **正确做法**：只在 `<DESC>` 中描述五官的物理形态，不加情绪修饰
- 人物站姿统一为：标准直立站姿，双臂自然下垂

### 2. 身材比例约束

`<DESC>` 和 `<PANELS>` 面板3/4 必须包含身材比例约束：
- 写明 **"九头身比例"**
- 写明角色身高（如 178cm）
- 体型用客观描述（偏瘦/壮实/纤细）

### 3. STYLE LOCK 统一风格段

`<STYLE LOCK>` 标签内只放风格描述（中文），内容从剧本设定的画面风格字段读取并翻译为中文，锁定全角色统一画风。标签名保持英文字母。

### 4. 人脸分工规则

- 第1/2格面板（正面脸部 / 侧面脸部）：**完整刻画五官物理形态**
- 第3格面板（正面全身）：**面部刻意模糊低细节**
- 第4格面板（背面全身）：无需人脸

### 5. STUDIO 段全角色共享

`<STUDIO>` 段包含棚拍设置、禁止清单、质量约束（中文），全角色共享模板。只有"禁止"中的"面部"和"身体"部分按角色特有防偏微调。

### 6. 中文输出规则

- 提示词所有描述内容使用中文（包括 `<STYLE LOCK>` 内的画风描述）
- hex 色号保留英文格式（如 #1A1A1A）
- 标签名保持英文字母（`<HEADER>`、`<DESC>`、`<PANELS>`、`<STYLE LOCK>`、`<STUDIO>`）

## When to Use

触发场景：
- "给这个角色生成三视图/参考照片提示词"
- "角色 Character Sheet / 角色一致性照片的 prompt"
- 短剧制作流程中需要为某角色产出一致性参考图 prompt

本 skill 只负责**写人物提示词**。出图由文生图工具执行。不处理场景图。

## Workflow

### Step 1 — 抽取角色核心要素

从角色描述中提取结构化要素，填入 `<DESC>` 段。缺失项标记"未指定"，不臆造：

1. **身份/性别/年龄**
2. **面部特征**：脸型、五官物理形态（不含表情）、发型（发色/长度/造型）
3. **身材体型**：身高、胖瘦、体态（客观描述，禁止姿态词）
4. **服装**：上装/下装/外套、颜色(hex)、材质
5. **配饰**：饰品/眼镜/帽子等
6. **标志性特征**：伤疤、纹身、道具、独特穿着细节 — 视觉锚点
7. **色卡**：从服装/发色/标志性道具提取 3-5 个主色 hex 值

### Step 2 — 按标签模板组装提示词

读取 `references/prompt-blueprint.md`，按 5 个标签区块顺序组装（中文）：

1. `<HEADER>` — 固定开头声明
2. `<DESC>` — Step 1 提取的外貌描述（中文，禁止表情/动作/姿态/心理状态/影视参考）
3. `<PANELS>` — 四面板逐一描述（中文）
4. `<STYLE LOCK>` — 从剧本设定读取画面风格，翻译为中文填入
5. `<STUDIO>` — 棚拍设置 + 禁止清单 + 质量约束（中文，禁止的面部/身体按角色微调）

### Step 3 — 输出与说明

输出 1 条带标签区块的四面板 prompt。末尾附说明：

1. 抽取了哪些要素、哪些项未指定需确认
2. **Seedance 锁脸使用指引**：
   - 不要把横排整图直接当 Seedance 参考图
   - 正确用法：裁切第1格面板（正面脸部）作为图片 1（大头照），裁切第3格面板（正面全身）作为图片 2（妆造身形参考）

## Automated Mode (Harness Integration)

当被 `ai-drama-harness` 调用时，额外输出结构化 JSON，供 harness 通过 `python cli.py write --table 角色库` 更新角色的 `gen_prompt` 字段。

### 读取输入

```bash
python cli.py read $WS --table 角色库
python cli.py read $WS --table 角色档案
python cli.py read $WS --table 剧本设定
```

### JSON 输出格式

````
```json:structured-output
[
  {
    "name": "林砚",
    "gen_prompt": "<HEADER>\n四面板角色设定图，1×4 横排布局，每个面板 9:16 竖向比例。\n</HEADER>\n\n<DESC>\n...\n</DESC>\n\n<PANELS>\n...\n</PANELS>\n\n<STYLE LOCK>\n...\n</STYLE LOCK>\n\n<STUDIO>\n...\n</STUDIO>"
  }
]
```
````

`gen_prompt` 为带标签区块的四面板 Character Sheet 提示词（中文）。harness 写入后通过 `python cli.py generate $WS --target 角色库:林砚` 触发出图。
