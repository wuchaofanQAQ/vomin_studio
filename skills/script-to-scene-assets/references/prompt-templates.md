# 场景提示词模板（七段式）

## 一、标准结构（七段固定顺序，缺一不可）

| 模块 | 写什么 | 作用 |
|---|---|---|
| ① 作用标注 | 这张图干什么用、给哪些场号/片段挂、不用于什么 | 防止误用 |
| ② 图的性质 | 空间参考图/无人/视角/景别 | 告诉 AI 这不是剧照 |
| ③ 关联声明 | 继承哪张图、咬合哪张图、共享什么锚点、是否独立 | 防止各画各的 |
| ④ 空间锚点 | 入口、地面、功能区、门窗、固定陈设、通道，逐条写死 | 空间一致性 |
| ⑤ 光线与色调 | 主光方向、明暗关系、色温、氛围 | 视觉统一 |
| ⑥ 排除项 | 无人物、无文字、无 logo、无水印、不要什么 | 减少抽卡污染 |
| ⑦ 参考图句 | 挂哪张参考图、保持什么不变、只改变什么 | 派生约束 |

落库位置：整条七段提示词写入场景库 `gen_prompt`；负向提示统一放在提示词包末尾，不逐条重复，也不写进 `gen_prompt`（出图时由 harness 追加）。

**画风与画幅**：每条提示词在②之前或②内带上"画风锁定"（取剧本设定"画面风格"）和画幅（取"平台调性"，竖屏短剧通常 9:16），见 `camera-and-style.md`。

## 二、模板库

### 模板 A：总空间母版图（`view_angle=母版`）

> 【作用】空间母版，定义[空间名]整体骨架，给[派生图ID]做派生参考；不直接挂分镜生成。
>
> 【性质】空间参考图，无人，[画幅]，[斜俯视/平视]全景，用于定义空间关系。
>
> 【关联】本图派生[图ID列表]；约束[锚点列表]。[派生图]生成时必须挂本图做参考。
>
> 【锚点】[逐条列：入口在哪、地面材质与分界、各功能区方位、固定陈设、通道关系]。
>
> 【光线色调】[主光从哪来、明暗关系、色温、整体氛围]。
>
> 【排除】无人物，无文字，无 logo，无水印。不要[豪华装修/杂乱/过曝等]。
>
> 【参考图】无（母版首图）。

### 模板 B：主场景图（`view_angle=主场景`）

> 【作用】[场景名]主场景图，用于[场号/片段]挂参考；不用于[排除用途]。
>
> 【性质】空间参考图，无人，[画幅]，[平视中全景/全景]，[场景名]主角度。
>
> 【关联】继承[母版ID]；与[图ID]共享[入口/地面/光源]；派生/咬合[图ID]。
>
> 【锚点】与[母版ID]保持同一空间：[逐条重复母版锚点，写死左右方位]。
>
> 【光线色调】[光源方向、明暗、色温、氛围]。
>
> 【排除】无人物，无文字，无 logo，无水印。不要改变[入口/功能区/门窗]的相对位置。
>
> 【参考图】`{场景库：[空间名]·母版} 图1：[空间名]空间母版。保持参考图中的[锚点列表]不变，只改变视角和取景范围。`

> 单一独立空间没有母版时：删除【关联】里的继承与【参考图】，改写"本图为该空间唯一定义，自带完整锚点"，并把模板 A 的锚点逐条写入【锚点】。

### 模板 C：局部补充图（`view_angle=局部·部位`）

> 【作用】[场景名]局部补充图，用于[具体镜头/片段]挂参考；不用于[主场景全景等]。
>
> 【性质】空间参考图，无人，[画幅]，[斜 45 度中景/俯拍近景]，[场景名]局部。
>
> 【关联】继承[母版ID/主场景ID]；必须与[主场景ID]咬合：[写清哪一侧对哪一侧、哪个开口对哪个开口]。
>
> 【锚点】[写死从哪看向哪：入口在画面哪侧、地面材质、开口位置、可见的相邻空间元素]。
>
> 【光线色调】[局部光从哪来、与相邻空间的明暗对比]。
>
> 【排除】无人物，无文字，无 logo，无水印。不要[杂乱物品/多余家具]。
>
> 【参考图】`{场景库：[空间名]·母版} 图1：[空间名]空间母版。{场景库：[空间名]·主场景} 图2：[空间名]主场景。保持参考图中的[锚点列表]不变，只取[局部视角]。`

### 模板 D：闪回/特殊色调场景图（`view_angle=闪回`）

> 【作用】[场景名]闪回/特殊场景图，用于[场号]挂参考；不用于现实时空。
>
> 【性质】空间参考图，无人，[画幅]，[平视全景]，[场景名]，[低饱和褪色/冷青/暖黄]回忆感。
>
> 【关联】本图独立，不与[现实场景图]共用空间锚点；仅[色调]统一。
>
> 【锚点】[逐条列空间结构、关键道具、固定陈设方位]。
>
> 【光线色调】整体[低饱和/褪色/压抑/陈旧]，不要[温馨/现代装修]。
>
> 【排除】无人物，无文字，无 logo，无水印。
>
> 【参考图】无，独立生成；只做色调检查，不做空间一致性比对。

### 模板 E：外景/走廊场景图（`view_angle=外景`，或走廊作为主场景）

> 【作用】[场景名]主场景图，用于[场号]挂参考。
>
> 【性质】空间参考图，无人，[画幅]，[平视/微仰]，[外景/走廊]主角度。
>
> 【关联】与[室内图ID]共享[入口/门框/门牌]；与[母版ID]共享[入口位]。
>
> 【锚点】[宽度、入口位置和开门方向、门牌、墙面材质、地面、尽头关系]。
>
> 【光线色调】[时间光、强光/热浪/阴天、色温]。
>
> 【排除】无人物，无文字，无 logo，无水印。
>
> 【参考图】`{场景库：[室内空间名]·主场景} 图1：[室内空间名]主场景。保持参考图中的[入口位/门框/门牌]不变。`

## 三、统一负向模板

> 负向：人物，人脸，文字，字幕，logo，水印，多余家具，豪华装修，过曝，过饱和，广角畸变，空间关系混乱，入口位置不一致，地面颜色不一致。

每个项目可在此基础上增删，但统一放在提示词包末尾。

## 四、参考图句的写法（与 `expand_prompt` 配合）

场景引用 `{场景库：名·视角}` 在 `expand` / `generate` 时会：
1. 从正文**移除**该标记
2. 把该场景行的图片作为**参考图**传给出图 API

所以：
- 标记要紧跟 `图N：说明` 写，移除后留下的文字仍是完整、可读的句子
- "保持什么不变、只改变什么"要写在标记之外，不能依赖标记本身表达
- 多张参考图按 `图1`、`图2` 依次编号
- 引用目标必须已出图（有 `ref_image`），否则展开时会提示"没有关联素材文件"——这是母版必须先出图的原因，`generate` 同空间多行时会自动先出母版

## 五、变量与复用规则

| 变量 | 填写说明 |
|---|---|
| `[空间名]` | 场景库 `name`（不含 `·`） |
| `[画幅]` | 取剧本设定"平台调性"，如竖屏 9:16 |
| `[母版ID]` | 有母版才填，没有则删关联与参考图模块 |
| `[派生图ID]` | 列出继承本图的图 |
| `[锚点列表]` | 入口、地面、功能区、门窗、固定陈设、光源等 |
| `[色调]` | 按场景情绪写 |
| `[排除用途]` | 写清"不用于什么" |

复用原则：
1. **结构不变**：七段顺序固定，换项目只换内容
2. **母版句可继承**：母版锚点段可整段复制到派生图的【锚点】里，只改视角描述
3. **参考图句模板化**：每张派生图只改中括号
4. **负向统一**：全项目共用一条
