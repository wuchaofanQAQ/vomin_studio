# 相机、画风与方位规范

本文件承接旧 `scene-image-prompt` 中仍然有效的规则，并统一了画幅口径。

## 一、相机参数标准

每张场景图按类型选机位，**机位要在 `description` 的【基准图机位】里写定**（含选用的角落/朝向），提示词直接采用。

**室内场景（占短剧场景的绝大多数：客厅、卧室、书房、病房、办公室）**
- 机位高度：**1.5 米**，成年人平视高度（不仰不俯；仰俯留给分镜镜头）
- 水平角度：**45° 斜角**，站在房间一个角落外侧，看向对角。例：矩形客厅四角 A/B/C/D，相机靠近 A 角看向对角 C；画面里同时看见 A 相邻的两面墙，沙发、茶几、门窗这些核心陈设都落在画面内
- 镜头焦距：**35mm**（小广角）

**室外场景（街道、别墅大门、停车场、医院门口）**
- 常规外景：平视，45° 斜侧，35mm，略微拉开距离，拍到主体建筑 + 周边环境。例：别墅大门斜着拍，同时拍到一部分院墙和门前空地，不是正对着大门
- 狭长外景（走廊、地下通道）：稍微偏 **30°**，不要正对通道深处（正对容易产生隧道视觉，机位很难复用）

**特殊固定机位场景（监控视角、固定窗边机位）**：才单独改相机，其余一律用上面的默认标准。

**各层图的机位差异**
- 母版：可用斜俯视，目的是看清整套空间的骨架与各区域相对位置
- 主场景：平视中全景，取主要使用角度
- 局部：斜 45° 中景或俯拍近景，必须写明"从哪看向哪"

## 二、方位写法（北/南/东/西 + P0/P1/M）

方位用**世界坐标**（北/南/东/西），不随机位改变，**不写"摄影机身后""画面左侧"这类相对说法**去定义空间。

【摄影主轴】必须包含：
- **P0**：站位端锚点（通常选主入口/门洞，角色最常进出处）
- **P1**：朝向端锚点（通常选主背景墙/主窗，空间纵深的终点）
- **M**：主体锚点（场景中心主体，角色互动最多的物件/区域）
- 轴线方向（从北指向南等），以及"面朝 P1 时，左手侧墙是哪面、右手侧墙是哪面"
- 剧本有明确镜头方向暗示（如"从门口望去"）时优先采用

示例：
```
【摄影主轴】P0=入户门（北墙） → P1=窗台（南墙） M=书桌与办公椅。轴线从北指向南。面朝 P1 时，左手侧墙是西墙，右手侧墙是东墙
```

派生图（主场景/局部）写左右时，必须带上墙名和物件：
`画面左侧是面朝 P1 时的左手侧墙【西墙·书桌】；画面右侧是右手侧墙【东墙·单人床】`

## 三、description 的结构（写入场景库「场景描述」）

紧凑文本，`\n` 分隔模块。母版/独立主场景写全套，派生图在此基础上追加视角与锚点：

| 模块 | 内容 |
|---|---|
| 【场景基础】 | 类型(室内/室外)、地点、风格(继承设定)、氛围(光线/天气/色调)、材质体系 |
| 【功能区】 | A/B/C 区各是什么功能区、方位、面积比例、空间关系 |
| 【摄影主轴】 | P0 → P1、M、轴线方向、左右手侧墙 |
| 【物件清单】 | 逐一列出物件的区域、相对主轴方位、邻近关系 |
| 【门窗】 | 每个门/窗的位置、开向、铰链侧/朝向 |
| 【光源】（必填） | 数量、位置、类型、色温、照射方向、光影关系 |
| 【画面分层】（必填） | 前景 / 中景 / 远景分别有什么，前后遮挡关系——供分镜设计站位与调度 |
| 【空间锚点】 | 本图的入口、地面、功能区、门窗、固定陈设、主光，逐条写死 |
| 【基准图机位】（必填） | 选定的机位角落/朝向，按上节标准 |

校验底线（出图前自检）：
- 【摄影主轴】含 P0、P1、M 三个锚点
- 【物件清单】至少 3 个物件及方位
- 【光源】至少 1 个光源含位置和色温
- 【画面分层】含前景/中景/远景
- 【基准图机位】写明机位

缺项就补，补不出的标"未指定"，不替编剧脑补。

## 四、画风锁定（STYLE LOCK）

取剧本设定「画面风格」的内容，翻译成中文写入每张图，**同一项目所有场景图共享同一段画风锁定**，保证全剧画风统一。

示例（现代都市）：
> 现代都市风格（真人影视剧质感）：场景干净明亮，全画面清晰，墙体门窗与家具边界可读，禁止浅景深背景虚化，空间比例真实，材质精致真实，自然光与柔和布光，轻微胶片颗粒不过度锐化，色彩明快通透低饱和。

画风以剧本设定为准；设定与上例冲突时按设定写，不照搬示例。

## 五、画幅

**以剧本设定「平台调性」为准**，不在文档里写死。竖屏短剧通常为 9:16。

> 旧 `scene-image-prompt` 在同一份文档里同时出现过 16:9 与 9:16，已作废。本技能所有提示词的画幅一律由 `[画幅]` 变量带入，取自剧本设定。

出图质量约束（写入【排除】或质量段）：纯空镜无人物，无文字、水印、标注线框；全画面清晰，墙体、门窗与家具边界可读，禁止浅景深背景虚化；光影方向与色温和锚点一致；透视准确，禁止夸张透视与鱼眼畸变。

## 六、跨场景共享锚点

同一部短剧里多个场景常共享同一套空间与物件（同一公寓的走廊与室内、同一扇入户门的内外两面、同一套墙面/地板/家具）。共享部分必须一致，否则成片会"门不对版、装修割裂、材质跳变"。

硬规则：
1. **写死、逐字一致**：共享物件/材质在**每个场景各自写一份具体规格**（颜色/材质/五金/纹理），文字逐字一致。例：入户门统一写"深灰黑(#2A2A2A)系哑光深色金属门，单扇，配深灰色金属门把手、猫眼、金属门牌号，门扇表面哑光深色金属、无明显花纹"
2. **禁止关系引用**：不要写"本场景与『X场景』同属那套公寓""与Y场景为同一扇门"——画图模型只看得到具体描述，关系引用无效。一致性靠具体规格的一致文字保证，不靠场景名关联
3. **共享物即锚点**：在设计阶段就标记为共享锚点，出图提示词以它为中心做材质锁定；多个场景共用同一段锚点规格文字
4. **补一条一致性条款**：凡跨场景共享物件，在【锚点】追加（仍写具体规格，不点名其他场景）——"本场景的X物件与同剧其他场景所见为同一物件/同一套装修，材质、颜色、五金、纹理完全一致"

适用：同空间多场景、同一物件多场景出现、同户型多集复用。

> 与派生关系的区别：**同一空间内**的母版→主图→局部靠 `{场景库：…}` 参考图挂接；**跨空间**（走廊与室内）的共享物件靠逐字一致的规格文字。
