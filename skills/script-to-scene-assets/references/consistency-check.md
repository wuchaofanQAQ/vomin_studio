# 出图后一致性检查

场景图出图后、进入分镜视频生成前的**门禁**。任一硬指标不通过，停止后续片段生成，先修场景图。

## 一、什么时候检查

- 同一空间的母版/主场景/局部**全部出图后**，逐张派生图对照母版比对
- 重抽或局部重绘后**重新比对**，不沿用上次结论
- 只出了母版时不需要检查（没有可比对的派生图）；单独的闪回图只做色调检查

## 二、硬指标

| 检查项 | 通过标准 | 不通过处理 |
|---|---|---|
| 入口位置和开门方向 | 相关图看到的是同一入口、同一方向 | 重抽，不将就 |
| 地面材质与分界 | 材质、颜色、分界线一致 | 重抽或局部重绘 |
| 主要功能区和门窗方位 | 左右/前后关系不反转 | 重抽 |
| 光源方向 | 主光方向一致 | 调整提示词重抽 |
| 色调统一 | 同组场景统一；特殊时空按设定统一 | 调色或重抽 |

附加（有对应关系时检查）：

| 检查项 | 通过标准 |
|---|---|
| 咬合 | 局部图与主场景图连接处：哪一侧对哪一侧、开口方向一致，能拼进同一空间 |
| 共享锚点 | 共享的门/窗/外墙在两张图里外观一致 |
| 无人无字 | 无人物、无文字、无水印 |
| 独立图 | 闪回/特殊时空仅检查指定色调，不比对空间 |

## 三、检查报告格式

逐图打勾，并标注涉及图：

| 图（name·view_angle） | 对照图 | 入口/开门 | 地面 | 功能区/门窗 | 光源 | 色调 | 咬合/共享 | 结论 |
|---|---|---|---|---|---|---|---|---|
| 出租屋（夜）·主场景 | 母版 | ✓ | ✓ | ✓ | ✓ | ✓ | — | 通过 |
| 出租屋（夜）·局部·厨房 | 母版、主场景 | ✓ | ✗ 地面分界缺失 | ✓ | ✓ | ✓ | ✓ | **不通过：重抽** |
| 旧出租屋·闪回 | — | — | — | — | — | ✓ | — | 通过（仅色调） |

## 四、不通过的处理流程

1. 在报告里写明**哪一条不通过、涉及哪几张图**
2. 优先改提示词：把没遵守的锚点在【锚点】里写得更具体，在【参考图】句里把"保持不变"的项目点名
3. **重抽**（`generate` 属写入/花预算动作，须先列清单拿到用户确认）
4. 重抽后重新比对，直到全部硬指标通过
5. 修场景图期间，**不得**对依赖这些图的分镜执行视频生成

## 五、放行条件

同一空间内：所有派生图硬指标全部通过 → 该空间放行 → 分镜里引用该空间的镜头才可进入视频生成（确认点 3 之后的 `generate`）。

不同空间互相独立放行，一个空间未通过不阻塞其他空间。
