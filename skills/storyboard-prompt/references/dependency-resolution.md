# 分镜依赖解析规则（场景 / 角色）+ 一致性自查

分镜拆完后，必须解析每个镜头依赖的**角色**与**场景**，产出去重依赖清单，并在提示词阶段把依赖转成素材引用（见 `asset-reference.md`）。

## 一、角色依赖解析（Step 3）

1. **逐镜头清点出镜角色**：画面中出现的每个角色都登记角色名（含群演身份，如"保镖甲"）；无人物空镜标"无人物"。
2. **引用必须可解析**：角色名必须能在角色库/角色档案中找到。
   - 找不到 → 标记"需补角色档案"，进依赖清单 `new_characters`。
   - 名称以角色库主键为准（别名/称呼统一映射到正式角色名）。
3. **多人镜头**：列出全部出镜角色（如"张三 + 李四"），不得遗漏背景中正在动作的角色。
4. **跨镜头一致性**：同一角色在不同镜头里的造型、年龄段、标志性特征（伤疤/纹身/道具）必须与角色档案一致；状态变化（受伤/湿身/换装）要在镜头描述中显式延续。
5. **音色归属**：有台词的镜头，台词归属角色 = 该镜头人物锁定中的说话人；TTS 配音按引用顺序的第一个角色匹配音色。

## 二、场景依赖解析（Step 2）

1. **逐镜头标注所在场景**：每个镜头都要有环境锁定（场景名），地点变化必须切新镜头。
2. **引用必须可解析**：场景名必须能在场景库中找到。
   - 找不到 → 标记"需补场景"，进依赖清单 `new_scenes`。
   - 同一场景的不同时段/天气（如"出租屋·夜·雨"）视为独立场景行，不得混用。
3. **跨镜头一致**：同一场景连续镜头的空间结构、光线方向、天气、色调保持一致。
4. **空镜也算依赖**：无人物的建立镜头同样引用场景素材。

## 三、依赖清单格式（交 harness 比对资产库）

```json
{
  "scenes": ["出租屋", "写字楼大堂"],
  "characters": ["张三", "李四"],
  "new_scenes": ["重生前出租屋"],
  "new_characters": ["保镖甲"]
}
```

- `scenes` / `characters`：本集全部依赖（去重）。
- `new_*`：现有库中不存在、**必须先补资产**才能生成提示词的项。
- harness 比对规则：新增角色 → 走角色档案 + 三视图补生成；新增场景 → 走场景空镜补生成；素材就绪前，相关镜头的提示词不得进入生成队列。

## 四、从依赖到锚定（Step 4）

依赖解析通过后，在每个 CLIP 的**锚定段**（正文之外、STYLE LOCK 之后）逐行声明，每行"引用 + 编号 + 身份说明"：

| 锁定类型 | 锚定段写法 | 锚定素材 |
|---|---|---|
| 人物 | `{角色库：张三} 图1：张三，男主角，28岁外卖员，黑发、左眉伤疤，黑色冲锋衣` | 角色形象图 |
| 环境 | `{场景库：出租屋} 图2：出租屋，张三住处，筒子楼一居室，室内·夜·雨，冷蓝调` | 场景空镜图 |
| 动作衔接 | `{剧本分镜表：ep01_s01} 视频1：上一镜成片，张三门口动作衔接` | 上一镜成片视频 |

**正文（逐秒拆解等）中只写"张三""出租屋"等名字，不出现任何 `{}`。**

完整语法规则见 `asset-reference.md`。

## 五、出稿前自查清单

- [ ] 时间线连续覆盖整集，无断档；镜头时长合计 ≈ 单集总时长
- [ ] 每个镜头人物锁定可解析到角色库；空镜标"无人物"
- [ ] 每个镜头环境锁定可解析到场景库
- [ ] 依赖清单已去重，新增角色/场景已列入 `new_*`
- [ ] 每个出镜角色在锚定段都有一行 `{角色库：…}` 引用，且写清了"是谁/定位/关键特征"
- [ ] 每个场景在锚定段都有一行 `{场景库：…}` 引用，且写清了"是什么场景/时空/色调"
- [ ] 锚定段按 图1/图2/视频1 顺序编号，与引用顺序一致
- [ ] 正文（STYLE LOCK 场景子段/逐秒拆解/微动作）无残留 `{}`，角色场景只用名字
- [ ] 引用的素材均已生成（库中存在文件路径）；未生成的已挂起等待补资产
- [ ] 同角色跨镜头造型/状态一致，同场景跨镜头光影/色调一致
- [ ] V8 提示词 12 子段完整、Preflight 全部通过（见 `video-continuity.md`）
