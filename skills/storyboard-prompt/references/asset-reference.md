# 素材锚定与引用语法（提示词 → API 参考素材）

分镜提示词分两层：**锚定段**（声明参考素材是谁/是什么）+ **正文**（写画面，直接用名字）。
CLI 在生成前解析锚定标记：把标记对应的素材文件随 API 发送，标记本身从文本中移除，锚定段保留为素材映射说明。

## 一、语法总览

```
{表名：行标识}
```

- 冒号**中文 `：`、英文 `:` 均可**（推荐中文冒号）。
- `表名` = 飞书表名；`行标识` = 该行主键（`rowId`，match key 的值）。
- 通用形式：`{sheetName:rowId}`。
- **标记只允许出现在 CLIP 开头的「参考素材锚定」段，正文（STYLE LOCK / 逐秒拆解）中一律不写标记**，直接用角色名/场景名。

## 二、锚定段写法（★ 必须指明"是谁/是什么"）

锚定段每个引用**独占一行**，格式：

```
{引用标记} <编号>：<名字>，<是谁/是什么角色/什么场景> + <关键控制属性>
```

- **编号**：图片按出现顺序编号 `图1、图2、图3…`；视频编号 `视频1、视频2…`。编号顺序必须与引用顺序一致（CLI 按此顺序组装素材）。
- **角色行必须写清**：名字 + 角色定位（主角/反派/配角身份）+ 关键特征（年龄/发型/标志性特征）+ 服装。
- **场景行必须写清**：场景名 + 这是什么场景（功能/地点）+ 时空（日夜/内外景/天气）+ 结构与色调关键词。
- 只写一个光秃秃的 `{角色库：张三}` 而不做任何说明，是**不合格**的。

标准示例：

```
## [参考素材锚定]
{角色库：张三} 图1：张三，男主角，28岁外卖员，黑色短发、左眉骨伤疤，黑色冲锋衣
{角色库：李四} 图2：李四，反派，张三前老板，50岁，深色西装、金丝眼镜
{场景库：出租屋} 图3：出租屋全景基准图，张三重生前的住处，老旧筒子楼一居室，室内·夜·雨，冷蓝调
{剧本分镜表：ep01_s01} 视频1：上一镜 ep01_s01 成片，张三站在门口的动作与姿态衔接
```

场景引用说明（**每个场景只有一个全景基准图**）：
- `{场景库：出租屋}` → 取该场景的全景基准图（每个场景只生成一张，不再有多视角图）
- 场景一致性由全景基准图 + 正文按场景 `description` 的【摄影主轴】/【画面分层】描述共同保证

CLI 展开后发送给模型的文本（标记移除，说明保留）：

```
## [参考素材锚定]
图1：张三，男主角，28岁外卖员，黑色短发、左眉骨伤疤，黑色冲锋衣
图2：李四，反派，张三前老板，50岁，深色西装、金丝眼镜
图3：出租屋全景基准图，张三重生前的住处，老旧筒子楼一居室，室内·夜·雨，冷蓝调
视频1：上一镜 ep01_s01 成片，张三站在门口的动作与姿态衔接
```

图1/图2/图3/视频1 与 API 请求中素材的传入顺序一一对应。

## 三、正文写法（直接用名字，不写花括号）

锚定段完成身份映射后，**正文（STYLE LOCK 场景物理、⑨首帧声明、⑩逐秒拆解、⑪微动作）直接用角色名和场景名**，不再出现任何 `{}`：

```
### Shot 1（建立·近景·手持跟拍）
【首帧】深夜出租屋，冷蓝调，暖橙台灯。张三站在门口，雨水顺发梢滴落。
【0s-2s】张三右手扶住门框（主动），肩膀微微起伏喘气（不自主）……
李四背对镜头坐在桌前。
```

- 模型通过"图1 = 张三"的映射知道名字对应的脸/服装，无需在正文重复锚定。
- 正文中**不描写长相、瞳色、服装细节**（由参考图控制）；但要写动作、表情、运镜、光影、物理细节。
- 同一场景正文统一用锚定段的标准场景名（"出租屋"，不写"张三的家"等别名）。

## 四、可引用的表

| 表名 | 行标识（主键） | 收集的素材字段 | 素材类型 |
|---|---|---|---|
| `角色库` | 角色名，如 `张三` | `ref_image` | 图片 |
| `场景库` | 场景名，如 `出租屋`（取该场景的全景基准图） | `ref_image` | 图片 |
| `生图工作台` | 任务名 | `result_path` / `ref_image` | 图片 |
| `素材库` | 素材ID | `file_path` | 图片或视频（按扩展名自动分类） |
| `剧本设定` | 设定项名，如 `画面风格` | `ref_image_path` | 图片 |
| `剧本分镜表` | 镜头ID，如 `ep01_s01` | `ref_image` / `result_path` / `file_path` / `video_path` | 图片或视频 |

- 图片素材以 `reference_image` 角色传入；视频素材以 `reference_video` 角色传入。
- 支持图片格式：png / jpg / jpeg / webp / bmp / gif；视频格式：mp4 / mov / webm / mkv / avi。
- 同一张图在 CLIP 中只声明一次；多个镜头共用同一角色时，每个 CLIP 的锚定段都要重新声明（每个 CLIP 独立投喂）。

## 五、不能引用的表

`角色档案`、`剧集表` 是**文字表**，不携带素材文件：

- 引用角色形象一律用 `{角色库：名字}`，不要写 `{角色档案：名字}`。
- 角色档案中的性格/音色/外貌文字，在生成提示词前由 `read --table 角色档案` 读入作为写提示词的上下文，不写进锚定段。

写错表名/找不到行/素材文件不存在时 CLI 会直接报错，不静默跳过。

## 六、使用铁律

1. **每个出镜角色都必须在锚定段列出**：有几个角色列几行，多人镜头不遗漏；无人物空镜不写角色行。
2. **每个场景都必须在锚定段列出**（含纯空镜）：场景图锁场景结构与色调。
3. **每行引用必须带身份说明**：角色写"是谁+定位+关键特征+服装"，场景写"是什么场景+时空+结构色调"。
4. **正文禁止出现 `{}`**：正文只用角色名/场景名；锚定段外出现任何花括号都算错误。
5. **引用必须可解析**：名字与库中主键完全一致；库中不存在 → 列入依赖清单"新增待补"，不得编造引用。
6. **素材未生成不得引用**：新增角色/场景先补出图，`ref_image` 就绪后才进锚定段；否则 CLI 报错。
7. **编号连续不重不漏**：图1…图N、视频1…视频N 按引用顺序编号；同素材不重复声明。
8. **动作衔接用上一镜视频**：需要姿态/动作严格衔接时，锚定段加 `{剧本分镜表：上一镜ID} 视频1：…`，正文说明"起始姿态与视频1结尾一致"。

## 七、预览与自查

- 写入/生成前用 `python cli.py expand <workspace> --shot ep01_s01` 预览：检查标记是否全部解析、锚定段映射文字是否完整、正文是否残留 `{}`、素材清单是否齐全。
- 脱机手工投喂 Seedance 网页端时，把锚定段的"图1/图2/视频1"按编号顺序上传对应文件即可。
