# 镜头连续性 + 参考素材纯净度 + 一致性自查

## 参考素材纯净度规则（Seedance 2.5 铁律）

harness 环境通过「锚定段 + 引用标记」锚定素材（规则见 `asset-reference.md`）：

- 锚定段在 STYLE LOCK 之后，每行 `{引用} 图N：身份/场景说明`；正文只用名字，不出现 `{}`。
- 以下规则对引用素材与手工 @Image 同样适用：

1. **每个素材只控制指定属性**：角色图控制 identity/outfit/关键特征，场景图控制结构/材质/基础色调；不让参考素材控制光影/色调/动作。
2. **一个 CLIP 只在锚定段声明一次**：按 图1/图2/视频1 编号，CLI 自动去重；正文不再重复引用。
3. **每行必须有身份说明**：角色写"是谁+定位+特征"，场景写"是什么场景+时空+色调"，不允许光秃秃的标记。
4. **参考图上不带文字**：参考图应干净，不包含标注文字。
5. **多主体每人一个引用**：不要把多个角色合并到一张参考图，每人独立一行。
6. **特写参考独立**：人脸特写用"正面人头细节照"单独存为素材（素材库/工作台），不与全身图混用。
7. **素材未就绪不引用**：引用解析失败（找不到行/文件不存在）时必须先补资产，不得删引用硬生成。

## 参考素材锁定规则

| 锁定类型 | 锚定段写法（示例） | 素材来源 | 控制范围 |
|----------|----------|----------|----------|
| 人物锁定 | `{角色库：张三} 图1：张三，男主角，黑发、伤疤，黑色冲锋衣` | 角色三视图/形象图 | identity + outfit + 关键特征 |
| 环境锁定 | `{场景库：出租屋} 图2：出租屋，一居室，室内·夜·雨，冷蓝调` | 场景空镜 | 场景结构 + 材质 + 基础色调 |
| 动作衔接 | `{剧本分镜表：ep01_s01} 视频1：上一镜成片，门口动作衔接` | 上一镜成片视频 | 动作/姿态/运镜衔接 |
| 战斗特效 | `{素材库：特效素材ID} 图N：暗金色能量冲击特效` | 特效参考素材 | 特效颜色 + 形态 |

## 反 CG 感锁定

STYLE LOCK ④必须写明：
- Live action, not animation/CGI/game
- Physical camera + anamorphic lens
- Real film stock characteristics
- Camera movement description

## 光源铁律

1. **所有光源必须有真实物理来源**——禁止凭空出现光
2. **角色不能独立打光**——角色光照必须来自场景中可见或可推断的光源
3. **多光源=多色温区**——写明哪个部位偏冷、偏暖
4. **反射光必须写**——地面/墙壁/水面的反射光
5. **阴影 never pure black**——总有 ambient bounce

## 动作连续性规则

1. **上一段结束状态 = 下一段起始状态**：前 Shot 末尾的角色姿态/位置/光影 = 后 Shot 开头
2. **不跳变**：同一角色连续镜头，姿态/服装/位置连贯，不瞬移、不换装
3. **时间顺序**：镜头按分镜时间线顺序输出
4. **全身动力学链贯穿**：不自主反应（呼吸/眨眼/微晃）不因切 Shot 而中断

## 时长与单集匹配

- 单集总时长**不预设固定值**（红果短剧不固定 2 分钟），由分镜总时长决定
- 所有分镜时长合计 = 单集最终时长；每分镜 5~10s（整数），最长 15s
- 节奏校验：开场 1~2 分镜内进入核心冲突；分镜内动作连续无拖沓；细节场景（闪回/道具特写/环境氛围）以微段保留
- 与剧本叙事体量严重不符（过短/超长）→ 提示用户增删分镜或调整微段

## 跨 Shot 一致性规则

1. **色调统一**：同场景内所有 Shot 的 STYLE LOCK ②色调必须一致
2. **光源统一**：同场景内光源位置/类型/色温不变
3. **材质统一**：同场景内地面/墙壁/天花板材质一致
4. **角色状态连续**：受伤/脏污/湿润等状态在后续 Shot 中持续
5. **环境动态连续**：风向/雾/灰尘等环境动态在同场景各 Shot 中方向一致
