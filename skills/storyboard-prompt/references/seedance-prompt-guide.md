# Seedance 提示词速查（2.0 + 2.5）

## 版本差异速查

| 维度 | Seedance 2.0 | Seedance 2.5 |
|------|-------------|-------------|
| 时长 | 最长 10s | 单段直出 30s |
| 参考素材 | 有限 | 最多 50 个（图/视频/音频） |
| 执行模式 | **推理型**：写大概它帮你补 | **执行型**：你写什么给什么，不写=没有 |
| 情绪词 | 可用，模型自行演绎 | **禁用**，必须分解为可见肌肉动作 |
| 环境 | 自动补充环境细节 | **不补**，每 Shot 至少 3-4 个环境动态 |
| 光影 | 自动打光 | **不自动**，必须写明光源-角色皮肤交互 |
| 提示词长度 | 建议简洁 | 不限，每个字必须描述可见/可听内容 |

> **当前默认面向 Seedance 2.5。** 以下规则为 2.5 标准；需兼容 2.0 时删除物理细节段、情绪词可直接使用。

## 任务类型（2.5）

| 任务 | 触发词 | 锁定行为 |
|------|--------|---------|
| 参考生视频 | 参考`<图片/视频N>`中的`<属性>` | 不锁定宽高比/时长 |
| 编辑视频 | 编辑/增加/删除/修改/替换`<视频N>` | 锁定宽高比+时长 |
| 延长视频 | 向前/向后延长`<视频N>` | 锁定宽高比，时长可自定义 |
| 首帧/首尾帧 | content.role=first_frame/last_frame | 锁定宽高比，时长可自定义 |
| 多宫格分镜 | 分镜图参考 | 不严格对齐画面细节 |
| 关键帧 | 多张独立分镜图 | 相对严格对齐输入图 |

## 素材输入上限

- 图片：最多 30 张 4K
- 视频：最多 10 段，总时长 ≤ 30s
- 音频：最多 10 段，总时长 ≤ 30s
- 主体数量：1-5 较好，6-10 可尝试但需抽卡
- 宫格分镜：15 个以下效果好

## 提示词基本结构（2.5）

```
1. 素材指代 — 明确每个图/视频/音频编号与用途
2. 一句话概述 — 主体+地点+事件+风格+特殊运镜
3. 具体情节描述 — 时间戳或镜头N切分，逐段描述
4. 结尾 — 贯穿全程的画面细节补充
```

## 素材映射规则

1. 多主体逐一列清映射：`图1的侠客`、`img1-2 是人物1，对应音频1`
2. 分工具体到"参考什么"：`参考视频1中施法的动作，视频2的环绕式运镜`
3. 素材足够精准时只做指代、减少画面复述
4. **编辑/延长任务**：直接用`<视频N>`指代，不加"参考"前缀
5. Asset ID 不能替代`<图片/视频N>`

## 提示词核心原则

### 正向描述优先
告诉模型"画面中有什么"比"不要什么"更稳定。反向描述仅用于字幕/音频控制。

### 动作描写规则
- **时间锚定**：使用时间戳 `[0-3s]` 或镜头号 `镜头1`
- **动作拆解**：大动作拆成可执行子步骤
- **空间关系**：通过参考图表达优先，减少复杂文字描述
- **运镜与动作同步**：每段写明镜头如何跟随动作

### 进阶公式（2.0 兼容，2.5 同适用）
```
精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件
```

## 常见坑与避坑

| 坑 | 避法 |
|----|------|
| 多主体混淆 | 每个主体绑定编号，全程统一指代 |
| 素材映射丢失 | 开头先写映射清单再写情节 |
| 编辑任务被误判为参考 | 编辑/延长不加"参考"前缀 |
| 2.5 情绪过度 | 删除情绪词→物理分解（详见 `seedance-25-execution-model.md`） |
| 2.5 画面空 | 补环境动态+四层画面枚举（详见 `seedance-25-execution-model.md`） |
| 2.5 人物像人偶 | 补全身动力学链（详见 `seedance-25-execution-model.md`） |
| 分镜图文字干扰 | 宫格分镜用线稿/火柴人，不在图上写文字 |
| 时长控制不稳 | 2.5 用时间戳精确控制；2.0 靠分镜切分 |
| 视频延长音画不衔接 | 输入输出都用 mov 格式 |
