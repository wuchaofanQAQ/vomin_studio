# 迭代修复手册

## 迭代医生原则

- 失败后一次只改 1-2 个变量
- 保留成功部分，不全重写
- 每轮修改后必须重新过 preflight，不能跳过

## 常见问题修复表

| 问题 | 修复方案 |
|------|----------|
| 掉帧 | 加 motion blur 锁定 + 负面限制 no frame skipping/stutter/choppy motion → 降手持摇晃幅度 |
| 角色复制 | STYLE LOCK 锁角色数 + 负面限制 no character duplication → 每 Shot 开头写角色数量 |
| 动作被跳过 | 优先保证核心 Shot 完整性，合并次要 Shot |
| 能量颜色偏蓝紫 | 明确"暗金色+深红底色" + 负面限制 no blue-purple energy |
| 格挡没有物理反馈 | 加推退/飞溅/震动描述 |
| 角色表情过多/不对 | 加 no excessive emotion/screaming + 根据人设推演 |
| 翻滚方向错误 | 明确写方向词如 "backward" |
| 演出不匹配人设 | 写提示词前必须通读人物设定 |
| 色调不一致 | 同一场景统一色调，跨 Shot 检查色温/光源一致性 |
| 景别与描述不匹配 | 逐 Shot 检查：镜头拍不到的不写 |
| 比喻污染 | 删除所有"像XX""如XX"，直接写视觉事实 |
| **画面假/没活人感** | 环境动态缺失，每 Shot 补 3-4 个环境动态元素 |
| **皮肤与环境颜色不匹配** | 光照-表面交互缺失，补写每个光源照到角色哪个部位、色温混合、反射光来源 |
| **表情过度** | 情绪词导致 2.5 字面执行，删除所有情绪词替换为可见肌肉动作 |
| **动作僵硬/像人偶** | 只写了一个身体部位，补全全身动力学链 |
| **画面空/元素太少** | 四层画面枚举缺失，补写前景/中景/背景/空气层 |
| **角色与环境没物理交互** | 接触面物理缺失，补写脚踩/手扶等接触面反应 |

## 成功 CLIP 经验

### 方法论

1. 用户/导演给详细镜头设计时，执行者角色是把指示翻译成 Seedance 能吃的提示词，不是自己编镜头
2. 多轮迭代，每轮只改 1-2 个变量
3. 冲突自查是硬门——每次修改后必须重新过检

### 写作技术

4. 每镜运镜必须全不同——重复运镜=模型偷懒的信号
5. 动词要狠——"猛然翻起"不是"缓慢起身"
6. 物理细节每镜不重复有递进
7. 负面限制针对性极强——每条都是实际迭代踩过的坑

### 角色演出

8. 角色演出是导演推演的结果，不是死规矩——同一角色不同场景演出不同
9. 角色间演出必须分化不雷同——三人面对同一事件应有不同反应

### 写作前确认

- [ ] 用户/导演是否已给出镜头设计？没有先问要
- [ ] 每镜运镜是否全不同？
- [ ] 动词是否够狠？
- [ ] 物理细节是否每镜不重复有递进？
- [ ] 角色演出是否匹配人设？角色间是否分化？
- [ ] 负面限制是否每条针对具体坑？
- [ ] 导演推理是否在 paste-ready 之前完成？
