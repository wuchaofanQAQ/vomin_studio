# 镜头连续性 + @Image 纯净度 + 一致性自查

## @Image 纯净度规则（Seedance 2.5 铁律）

1. **每张 @Image 只控制指定属性**：identity/outfit/关键特征。不让 @Image 控制光影/色调/动作。
2. **全局锁定一次声明**：@Image 在 STYLE LOCK 之后声明一次，后续 CLIP 中不再重复 @声明。
3. **不在 @Image 上写文字**：参考图应干净，不包含标注文字。
4. **多主体每人一张**：不要把多个角色合并到一张参考图，每人独立 @Image。
5. **特写参考独立**：人脸特写用"正面人头细节照"单独一张，不与全身图混用。

## 参考图锁定规则

| 锁定类型 | 来源 | @Image 控制范围 |
|----------|------|----------------|
| 人物锁定 | 角色三视图 | identity + outfit + 关键特征 |
| 环境锁定 | 场景空镜 | 场景结构 + 材质 + 基础色调 |
| 战斗特效 | battle-fx-storyboard 状态标注 | 特效颜色 + 形态 |

## 反 CG 感锁定

STYLE LOCK ④必须写明：
- Live action, not animation/CGI/game
- Physical camera + anamorphic lens
- Real film stock characteristics
- Camera movement description

## 光源铁律

1. **所有光源必须有真实物理来源**——禁止凭空出现光
2. **角色不能独立打光**——角色光照必须来自场景中可见或可推断的光源
3. **多光源=多色温区**——写明哪个部位偏冷、偏暖
4. **反射光必须写**——地面/墙壁/水面的反射光
5. **阴影 never pure black**——总有 ambient bounce

## 动作连续性规则

1. **上一段结束状态 = 下一段起始状态**：前 Shot 末尾的角色姿态/位置/光影 = 后 Shot 开头
2. **不跳变**：同一角色连续镜头，姿态/服装/位置连贯，不瞬移、不换装
3. **时间顺序**：镜头按分镜时间线顺序输出
4. **全身动力学链贯穿**：不自主反应（呼吸/眨眼/微晃）不因切 Shot 而中断

## 时长与单集匹配

- 所有镜头时长合计 ≈ 单集总时长（从剧本设定取）
- 不合 → 提示用户：时长偏短/超长，建议增删 Shot 或调整节奏

## 跨 Shot 一致性规则

1. **色调统一**：同场景内所有 Shot 的 STYLE LOCK ②色调必须一致
2. **光源统一**：同场景内光源位置/类型/色温不变
3. **材质统一**：同场景内地面/墙壁/天花板材质一致
4. **角色状态连续**：受伤/脏污/湿润等状态在后续 Shot 中持续
5. **环境动态连续**：风向/雾/灰尘等环境动态在同场景各 Shot 中方向一致

## Preflight 自查清单

- [ ] 12 子段完整（STYLE LOCK 8 + CLIP 3 + NEGATIVE 1）
- [ ] 三反原则（无比喻/无衣物描写/无瞳色）
- [ ] 情绪词全部替换为物理动作
- [ ] 每角色每时间段有全身动力学链
- [ ] 每 Shot ≥3 个环境动态
- [ ] 每可见角色有光照-皮肤交互
- [ ] 四层画面枚举完整
- [ ] @Image 全局锁定一次且纯净
- [ ] 逐秒拆解连续（上一段末 = 下一段初）
- [ ] 每镜运镜全不同
- [ ] NEGATIVE 针对具体问题（3-8 项）
- [ ] 角色演出匹配人设且分化
- [ ] 同场景色调/光源/材质统一
- [ ] 时长合计匹配单集总时长
