# Storyboard Generator

## Overview

把一集文字剧本拆成**逐镜头分镜脚本**。每个分镜是"可直接出画面"的最小单元，且**明确锁定**它依赖的人物（用角色档案保证一致）和环境（用场景空镜保证一致）。同时产出**分镜依赖清单**（本集用到的场景 + 角色），供 harness 去重补资产。

## 分镜条目格式（每镜头）

```
时间线(秒) | 镜头焦点调度 | 描述 | 构图提示 | 光影/色调提示 | 人物锁定 | 环境锁定
```

| 字段 | 含义 |
|---|---|
| **时间线(秒)** | 该镜头在单集中的起止秒（如 00:00–00:03）|
| **镜头焦点调度** | 景别（大远景/远景/全景/中景/近景/特写/大特写）+ 角度（平视/俯视/仰视/过肩/荷兰角）+ 运镜（推/拉/摇/移/升降/固定/环绕/手持/慢镜）+ 焦点 |
| **描述** | 画面内容：人物动作、表情、环境、氛围 |
| **构图提示** | 构图方式：三分法/框架构图/引导线/对称/留白/纵深分层 |
| **光影/色调提示** | 光影方向（高调/低调/伦勃朗光/逆光剪影/侧光）+ 色调方向（青橙调/低饱和/莫兰迪/霓虹）|
| **人物锁定** | 引用角色名（必须来自角色档案）|
| **环境锁定** | 引用场景名（必须来自场景资产）|

## Workflow

### Step 1 — 加载输入

读齐：**分集剧本** + **角色档案**（出场角色）+ **场景资产**（本集场景）。缺任一则要求提供。

### Step 2 — 拆镜头

**导演意图 → 视听转译**：拆镜头前，先逐场标注导演意图卡——这场戏要观众**感到什么**？谁想要什么？情绪关键词是什么？再据此选择景别/角度/运镜/构图/光影来服务该目的。杜绝"为美而美"，每个视听选择都要有叙事理由。详见 `references/cinema-foundation.md`。

把剧本的场次按叙事节奏拆成镜头。短剧铁律：
- 单镜头 2~5 秒为主，动作/高潮镜头可更短
- 每场至少拆出"建立镜头 + 主体镜头"，对话用正反打
- 时间线从 0 开始连续分配，覆盖整集时长

### Step 3 — 逐镜头产出 + 锁定

对每个镜头输出完整条目（见格式表）。

> 景别/运镜/构图/光影的专业词表及 AI 适用性标注见 `references/shot-template.md`；完整影视理论速查见 `references/cinema-foundation.md`。

**锁定规则（核心）**：
- **人物锁定**：镜头里出现的每个角色都标注角色名；无角色空镜标"无人物"
- **环境锁定**：每镜头标注所在场景名；必须能对上已建场景资产
- 景别/运镜调度要服务叙事焦点（情绪镜头用近景/特写，环境交代用全景/远景）
- **构图提示**：根据镜头意图选构图方式（对话用三分法/过肩，囚禁用框架构图，孤独用留白）
- **光影/色调提示**：根据场景情绪选光影和色调方向，同场景内保持统一

### Step 4 — 产出依赖清单

输出本集分镜**依赖清单**：
- **场景清单**：本集所有镜头用到的场景名（去重）
- **角色清单**：本集所有镜头用到的人物（去重）

> 此清单交 harness 比对，新增场景/角色才补生成。

### Step 5 — 输出与说明

输出完整分镜表 + 依赖清单，附 2–3 行说明：拆了几个镜头、时间线分配、哪些依赖是新增需补。

## Automated Mode (Harness Integration)

当被 `ai-drama-harness` 调用时，额外输出结构化 JSON，供 harness 通过 `python cli.py write --table 剧本分镜表` 写入飞书。

### 读取输入

```bash
python cli.py read $WS --table 角色库
python cli.py read $WS --table 角色档案
python cli.py read $WS --table 场景库
python cli.py read $WS --table 剧本设定
```

### JSON 输出格式

````
```json:structured-output
{
  "shots": [
    {
      "shot_id": "ep01_s01",
      "episode": 1,
      "shot_number": "S01",
      "dialogue": "这不可能...",
      "description": "近景，林砚震惊看手机",
      "prompt": "{角色库:林砚}震惊表情，近景",
      "status": "待生成"
    }
  ],
  "dependencies": {
    "new_scenes": ["场景名1"],
    "new_characters": []
  }
}
```
````

harness 读取 `dependencies` 比对现有资产，新增的场景/角色调对应 skill 补生成。
