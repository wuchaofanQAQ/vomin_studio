# 人物/环境锁定规则 + 一致性自查

## 人物锁定规则

1. **引用必须可解析**：每个镜头的人物锁定，必须能在角色档案中找到该角色。找不到 → 标记"需补角色档案"，列入依赖清单。
2. **一致性**：同一角色在不同镜头里，外形须符合角色档案（发型/服装/标志性特征不漂移）。
3. **空镜标注**：无人物镜头标"无人物"，不强行填。
4. **多人镜头**：列出所有出现角色（如"阿城 + 反派·老K"）。

## 环境锁定规则

1. **引用必须可解析**：环境锁定必须能对上已建场景资产。找不到 → 标记"需补场景"，列入依赖清单。
2. **跨镜头一致**：同一场景的连续镜头，环境细节（光线/天气）须一致。
3. **换场景必须换镜头**：地点变化时开新镜头，环境锁定随之更新。

## 依赖清单格式（交 harness）

```
场景清单（去重）：废弃厂房、警局审讯室…
角色清单（去重）：阿城、老K…
新增待补：新角色 X / 新场景 Y
```

- [ ] 每镜头环境锁定都能解析到场景资产
- [ ] 同角色跨镜头外形一致
- [ ] 同场景跨镜头环境一致
