## 5. 分段分镜与视频提示词（script-to-prompt-30 → 剧本分镜表）

**match key**: `shot_id`（= 段 ID，格式 `ep{两位集号}_p{两位段序}`，如 `ep10_p05`）

一段 = 一次生成任务 = 剧本分镜表一行。`script-to-prompt-30`（剧本转提示词 3.0）一次产出分段提示词 + 依赖清单 + 资产编号表：

```json
{
  "shots": [
    {
      "shot_id": "ep10_p05",
      "episode": 10,
      "timeline": "00:00-00:30",
      "prompt": "【第05段｜00:00-00:30｜大殿质问】\n\n【资产锁定】\n场景：【S01｜隋朝皇宫大殿：{场景库：隋朝皇宫大殿}】\n角色：【R01｜杨广：{角色库：杨广 中年版}】【R02｜姜颜：{角色库：姜颜}】\n\n【本段风格】……\n【本段初始空间基准】……\n\n【镜头01｜00:00-00:02｜抬眼】\n近景固定机位，R01杨广位于画面中央……落幅停在他的眼睛。\n【对白 00:00.5-00:02】R01杨广（压着怒气、缓慢地说）：人有南北，国有南北吗？",
      "status": "待生成"
    }
  ],
  "dependencies": {
    "scenes": [{"name": "隋朝皇宫大殿"}],
    "characters": ["杨广 中年版", "姜颜"],
    "new_scenes": [],
    "new_characters": []
  },
  "asset_ids": [
    {"id": "S01", "name": "隋朝皇宫大殿"},
    {"id": "R01", "name": "杨广"}
  ]
}
```

`prompt` 字段是带换行的完整段文本，以段头 `【第NN段｜00:00-00:30｜标题】` 开头；多段即 `shots` 数组里多个对象。

### 段文本的固定骨架

```text
【第NN段｜00:00-00:30｜标题】

【资产锁定】
场景：【S01｜场景名：{场景库：场景名}】
角色：【R01｜角色名：{角色库：角色名}】【R02｜角色名：{角色库：角色名}】
道具：【P01｜道具名：外形、尺度、数量】

【本段风格】只写本段差异（时段/光比/表演基调/画幅），不重复全局画风词。
【本段初始空间基准】画面位置（画左/画右/中央/前中后景）、朝向、距离、遮挡、开镜机位。

【镜头01｜00:00-00:02｜标题】
景别＋机位/运镜起笔，融合写：位置 → 动作 → 画面变化/物理反馈 → 停点。
【对白 00:00.5-00:02】R01角色名（情绪/语气地说）：台词。
```

### 素材锚点语法

角色和场景条目里带锚点，CLI 展开时移除标记、收集素材，并把 `：】` 收干净：

| 写法 | 展开结果 | 收集的素材 |
|---|---|---|
| `【R01｜沈幼怡：{角色库：沈幼怡}】` | `【R01｜沈幼怡】` | 角色形象图 |
| `【S01｜陈诚公寓门口：{场景库：陈诚公寓门口}】` | `【S01｜陈诚公寓门口】` | 该场景那一张图 |
| `【P01｜行李箱：24 寸硬壳】` | 原样保留 | 无（道具没有库表） |
| `{剧本分镜表：ep10_p04}` | 移除 | 该段已生成的图片/视频（动作衔接，能不用就不用） |
| `{素材库：素材ID}` / `{生图工作台：任务名}` | 移除 | 对应素材文件 |

规则：角色/场景**必须**带锚点且名称与库内逐字一致；带锚点的条目里不写补充内容（会被 `：】` 清理影响）；正文一律写"编号+名称"（`R01沈幼怡`），不写裸名。

### 台词的机器格式

```text
【对白 00:01-00:02】R02陈诚（压着火、短促地说）：你爸呢？
【对白 00:09-00:10.5】R02陈诚画外音（画右门板后、压低地说）：谁啊？
【对白 00:18.5-00:20】R02陈诚（内心独白、嘴唇不动地说）：沈幼怡。这三个字，
```

- 前缀 `【对白 起-止】` 供配音与对白窗口校验；时间窗必须落在所在镜头内；
- 说话者 `编号+名称`，括号里必须有"说"；
- 画外音写 `…画外音（…地说）`，并在镜头段写明声音来自画左/画右/画上/画下；
- 内心独白写 `（内心独白、嘴唇不动地说）`；
- 配音时 CLI 会剥掉括号表演提示、编号前缀与"画外音"，按名称去 `角色档案` 取音色。

### 提示词里的其它约定

- `【本段风格】` 只写差异；全局画风由 `剧本设定` 在生成时追加，重复会稀释指令。
- 时长以 `时间线` 字段为准（`generate` 按真实秒数出片，上限 30 秒）。
- 分镜表不单独存台词字段；`【对白】` 行是唯一台词来源。

harness 流程：
1. 读 `dependencies`，**差分比对场景库**：逐条检查 `scenes` / `new_scenes` 中每个场景名是否已存在、场景图素材是否已生成且一致性检查已通过
   - 缺失的场景 → 汇总待补清单，交 `script-to-scene-assets` 补出（一个场景一张图）
   - `new_characters` → 调对应 skill 补角色档案 + 三视图
2. 素材就绪后用 `python cli.py expand $WS --shot <id>` 预览锚点映射、确认 `【R01｜…】` 已收干净、素材齐全
3. 跑 `python skills/script-to-prompt-30/scripts/check_segment_prompt.py <草稿> --target 30`，错误必须为 0
4. 用户确认 → `write --table 剧本分镜表` → `generate --tts-only` → `generate` → `push`
5. 只有 `preflight` 全过、进入生产态，才在交付摘要里写 `12 项自检：PASS`
