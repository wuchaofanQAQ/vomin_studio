# Vomin Studio · AI 短剧制作技术方案

> **项目定位**：两人团队（内容 + 技术）的 AI 短剧制作流水线工具。用 Python 封装方舟视频/图片生成 + 豆包 TTS 三大 API，配合飞书多维表格做内容协作，支撑「剧本分镜 → 批量生成 → 审核 → 成片」全流程。
>
> **关联文档**：《AI 短剧制作流程操作手册》PRD

---

## 0. 与原方案的差异说明

原技术方案（《方舟 API 开发技术方案》）存在以下问题，本方案做了修正：

| 原方案问题 | 本方案处理 |
|---|---|
| 飞书对接假设有企业自建应用权限 | 个人账号需先注册免费企业版；同时设计 workspace 本地存储兜底，飞书断开也能跑 |
| TTS 混用方舟 API Key | 豆包音频生成（Seed-Audio 1.0）独立产品，域名 `openspeech.bytedance.com`，鉴权用 `X-Api-Key` 单头，非方舟 Key |
| Files API file_id 与视频生成 API 混淆 | 视频/图片生成接受的是公网 URL / Base64 / `asset://`，不接受 file_id；Files API 定位为素材归档 |
| workspace 概念缺失 | 新增 workspace 机制：所有素材路径存相对路径，换电脑改根目录即可 |
| 缺少 TTS API 实现 | 新增豆包音频生成模块（Seed-Audio 1.0 HTTP 非流式接口，已验证连通） |

## 1. 架构总览

### 1.1 数据流

```
飞书剧本分镜表 ──同步──→ workspace/storyboard.json（本地镜像）
       │                         │
       │                    Python 脚本读取
       │                         │
       ├──────────────────────────┤
       │                         ▼
       │              ┌──── 批量调度引擎 ────┐
       │              │                      │
       │         ┌────┴────┐  ┌────┴────┐  ┌─┴──────┐
       │         │ 图片生成 │  │ TTS配音 │  │视频生成 │
       │         │Seedream │  │豆包语音  │  │Seedance│
       │         └────┬────┘  └────┬────┘  └─┬──────┘
       │              │           │          │
       │              ▼           ▼          ▼
       │         ref/characters  audio/    video/
       │              │           │          │
       │              └─────┬─────┘──────────┘
       │                    │
       │               素材落盘到 workspace
       │                    │
       │              状态回写飞书（待审核）
       │                    │
       └────── 媳妇在飞书审核 ◄──┘
                    │
               通过 → 剪映成片
               返工 → 重新生成
```

### 1.2 关键设计决策

| 决策 | 选择 | 原因 |
|---|---|---|
| 分镜数据主存储 | 飞书多维表格 + 本地 JSON 镜像 | 媳妇在飞书操作，脚本读本地 JSON；断网也能跑 |
| 素材路径 | workspace 内相对路径 | 换电脑改 `workspace_root` 一个配置即可 |
| 视频生成传参 | 公网 URL（参考图上传 CDN / 对象存储） | 方舟视频生成 API 不接受 file_id |
| TTS 鉴权 | 独立 AppId + AccessToken | 豆包语音合成是独立产品，非方舟 Key |
| Files API | 素材归档 + 未来视频理解 | 不参与生成环节的素材传递 |

### 2.3 路径解析逻辑

```python
# workspace.py 核心逻辑
import os
import yaml
import json

class Workspace:
    """一个 workspace = 一部剧的所有数据和素材。
    所有路径存相对路径，运行时拼接 root 得到绝对路径。"""

    def __init__(self, root: str):
        self.root = os.path.abspath(root)
        self._config = self._load_config()

    def _load_config(self) -> dict:
        with open(self.abs("workspace.yaml"), "r", encoding="utf-8") as f:
            return yaml.safe_load(f)

    def abs(self, rel_path: str) -> str:
        """相对路径 → 绝对路径"""
        return os.path.join(self.root, rel_path)

    def rel(self, abs_path: str) -> str:
        """绝对路径 → 相对路径（存入 JSON/飞书时用）"""
        return os.path.relpath(abs_path, self.root)

    def episode_dir(self, ep: int, sub: str = "") -> str:
        """ep01/audio, ep01/video 等"""
        d = self.abs(f"ep{ep:02d}/{sub}" if sub else f"ep{ep:02d}")
        os.makedirs(d, exist_ok=True)
        return d

    @property
    def config(self) -> dict:
        return self._config

    # 分镜 JSON 读写
    def load_storyboard(self) -> list[dict]:
        path = self.abs("storyboard.json")
        if not os.path.exists(path):
            return []
        with open(path, "r", encoding="utf-8") as f:
            return json.load(f)

    def save_storyboard(self, data: list[dict]):
        with open(self.abs("storyboard.json"), "w", encoding="utf-8") as f:
            json.dump(data, f, ensure_ascii=False, indent=2)

    def update_budget(self, cost: float):
        self._config["budget"]["spent"] = round(
            self._config["budget"].get("spent", 0) + cost, 2
        )
        if self._config["budget"]["spent"] > self._config["budget"]["total_limit"]:
            raise RuntimeError(
                f"预算超限！已花费 {self._config['budget']['spent']} 元，"
                f"上限 {self._config['budget']['total_limit']} 元"
            )
        with open(self.abs("workspace.yaml"), "w", encoding="utf-8") as f:
            yaml.dump(self._config, f, allow_unicode=True)
```

## 3. 飞书多维表格对接

### 3.1 前置准备（一次性）

由于个人账号无法直接使用飞书开放平台 API，需要做以下准备：

1. **注册免费企业版飞书账号**：用新邮箱注册一个飞书企业版（无需认证），你自己就是管理员
2. **创建自建应用**：在 [飞书开放平台开发者后台](https://open.feishu.cn/) 创建企业自建应用
3. **申请权限**：`bitable:app:read`、`bitable:app:write`
4. **拿到凭证**：App ID + App Secret → 换取 `tenant_access_token`
5. **把应用添加到多维表格**：确保应用有对应表格的读写权限

> **降级方案**：如果飞书对接暂时搞不定，可以纯用本地 `storyboard.json` 工作。媳妇直接编辑 JSON（或你提供简单 CLI 命令帮她录入），后续再补飞书同步。

### 3.2 飞书表结构设计

**剧本分镜表（核心）**

| 字段名 | 字段类型 | 说明 |
|---|---|---|
| episode | 数字 | 集号 |
| shot_id | 文本 | 镜头编号，如 `ep01_s03` |
| scene | 文本 | 场景名（关联场景库） |
| characters | 文本 | 出场角色（逗号分隔） |
| dialogue | 文本 | 台词 |
| scene_desc | 文本 | 场景描述 / 镜头动作 |
| prompt | 文本 | 视频生成提示词（你填或 LLM 生成） |
| status | 单选 | `待生成` / `生成中` / `待审核` / `通过` / `返工` |
| audio_path | 文本 | 配音文件相对路径（如 `ep01/audio/ep01_s03.mp3`） |
| video_path | 文本 | 视频文件相对路径 |
| task_id | 文本 | 方舟视频生成任务 ID（追踪用） |
| ref_image | 附件 | 参考图（可选） |
| notes | 文本 | 审核备注 |

> **路径字段存的都是 workspace 内的相对路径**，换电脑后 workspace 根目录变了，相对路径不变，直接能用。

### 3.3 本地 JSON 镜像结构（storyboard.json）

```json
[
  {
    "episode": 1,
    "shot_id": "ep01_s01",
    "scene": "写字楼大堂",
    "characters": ["男主"],
    "dialogue": "这一次，我不会再输了。",
    "scene_desc": "近景固定机位，男主从旋转门走进大堂，表情坚定",
    "prompt": "近景固定机位，都市写字楼大堂，年轻男性穿深蓝西装从旋转门走入，步伐坚定，镜头跟随",
    "status": "待生成",

    "video_path": null,
    "task_id": null,
    "notes": ""
  }

```

### 3.4 飞书 ↔ 本地同步策略

```
飞书表 ──pull──→ storyboard.json（覆盖本地）
            ← push── storyboard.json（回写状态和路径字段）
```

- **pull**（飞书 → 本地）：媳妇在飞书改完剧本后执行，拉最新分镜数据覆盖本地 JSON
- **push**（本地 → 飞书）：脚本生成完素材后执行，把 `status`、`audio_path`、`video_path`、`task_id` 回写飞书
- **冲突处理**：以飞书内容字段为准（剧本、台词、描述），以本地状态字段为准（生成状态、路径）

## 4. 方舟 API 封装（ark 模块）

### 4.1 HTTP 基础客户端（`ark/client.py`）

```python
import os
import time
import requests

ARK_BASE = "https://ark.cn-beijing.volces.com/api/v3"


class ArkError(Exception):
    def __init__(self, code: str, message: str, status_code: int = 0, request_id: str = ""):
        self.code = code
        self.message = message
        self.status_code = status_code
        self.request_id = request_id
        super().__init__(f"[{code}] {message}")


class ArkClient:
    def __init__(self, api_key: str | None = None, timeout: int = 300):
        self.api_key = api_key or os.environ.get("ARK_API_KEY", "")
        if not self.api_key:
            raise ValueError("缺少 ARK_API_KEY")
        self.session = requests.Session()
        self.session.headers["Authorization"] = f"Bearer {self.api_key}"
        self.timeout = timeout

    def request(self, method: str, path: str, **kwargs) -> requests.Response:
        url = f"{ARK_BASE}/{path.lstrip('/')}"
        kwargs.setdefault("timeout", self.timeout)
        resp = self.session.request(method, url, **kwargs)
        if resp.status_code >= 400:
            try:
                err = resp.json().get("error", resp.json())
            except Exception:
                err = {"code": "Unknown", "message": resp.text[:200]}
            raise ArkError(
                code=err.get("code", "Unknown"),
                message=err.get("message", str(err)),
                status_code=resp.status_code,
                request_id=resp.headers.get("x-request-id", ""),
            )
        return resp

    def poll_task(self, task_id: str, *, timeout_sec=600, interval=10) -> dict:
        """轮询视频生成任务直到终态。"""
        deadline = time.time() + timeout_sec
        while time.time() < deadline:
            resp = self.request("GET", f"/contents/generations/tasks/{task_id}")
            task = resp.json()
            if task["status"] in ("succeeded", "failed", "cancelled"):
                return task
            print(f"  任务 {task_id} 状态: {task['status']}，等待 {interval}s...")
            time.sleep(interval)
        raise TimeoutError(f"任务 {task_id} 轮询超时 ({timeout_sec}s)")
```

### 4.2 视频生成（`ark/video.py`）

```python
import os
import requests as req
from .client import ArkClient


class VideoClient:
    def __init__(self, client: ArkClient):
        self.c = client

    def create(self, *, model: str, content: list[dict],
               resolution="720p", ratio="9:16", duration=10,
               generate_audio=True, watermark=False,
               seed: int | None = None, draft=False,
               callback_url: str | None = None) -> str:
        """创建视频生成任务，返回 task_id。"""
        body = {
            "model": model,
            "content": content,
            "resolution": resolution,
            "ratio": ratio,
            "duration": duration,
            "generate_audio": generate_audio,
            "watermark": watermark,
        }
        if seed is not None:
            body["seed"] = seed
        if draft:
            body["draft"] = True
        if callback_url:
            body["callback_url"] = callback_url
        resp = self.c.request("POST", "/contents/generations/tasks", json=body)
        return resp.json()["id"]

    def get(self, task_id: str) -> dict:
        return self.c.request("GET", f"/contents/generations/tasks/{task_id}").json()

    def cancel(self, task_id: str) -> dict:
        return self.c.request("DELETE", f"/contents/generations/tasks/{task_id}").json()

    def create_and_download(self, *, model, content, save_dir, **kwargs) -> dict:
        """创建任务 → 轮询 → 下载视频到本地。"""
        task_id = self.create(model=model, content=content, **kwargs)
        print(f"视频任务已提交: {task_id}")
        task = self.c.poll_task(task_id)
        if task["status"] != "succeeded":
            raise RuntimeError(f"视频任务失败: {task.get('error')}")
        video_url = task["content"]["video_url"]
        os.makedirs(save_dir, exist_ok=True)
        path = os.path.join(save_dir, f"{task_id}.mp4")
        with req.get(video_url, stream=True) as r:
            r.raise_for_status()
            with open(path, "wb") as f:
                for chunk in r.iter_content(1 << 20):
                    f.write(chunk)
        print(f"视频已下载: {path}")
        return {**task, "local_path": path}
```

**content 构造说明（互斥铁律）**

三种场景只能选一种，不可混用：

| 场景 | content 构造方式 |
|---|---|
| **图生首帧**（短剧主力） | `text` + `image_url(role=first_frame)` |
| **图生首尾帧** | `text` + `image_url(role=first_frame)` + `image_url(role=last_frame)` |
| **全模态参考** | `text` + `image_url(role=reference_image)` + 可选 `video_url` + 可选 `audio_url` |

短剧流水线主力用「图生首帧」：把角色形象图作为 first_frame，确保人物一致性。

### 4.3 图片生成（`ark/image.py`）

```python
import os
import json
import requests as req
from .client import ArkClient


class ImageClient:
    def __init__(self, client: ArkClient):
        self.c = client

    def generate(self, *, model: str, prompt: str, size="2K",
                 n=1, image=None, response_format="url",
                 watermark=False, seed: int | None = None,
                 stream=False) -> dict | req.Response:
        body = {
            "model": model,
            "prompt": prompt,
            "size": size,
            "n": n,
            "response_format": response_format,
            "watermark": watermark,
        }
        if image is not None:
            body["image"] = image
        if seed is not None:
            body["seed"] = seed
        if stream:
            body["stream"] = True
        resp = self.c.request("POST", "/images/generations", json=body, stream=stream)
        return resp if stream else resp.json()

    def generate_to_dir(self, *, model, prompt, save_dir, size="2K", n=1, **kw) -> list[str]:
        """生成图片并下载到本地目录，返回本地路径列表。"""
        data = self.generate(model=model, prompt=prompt, size=size, n=n, **kw)
        os.makedirs(save_dir, exist_ok=True)
        paths = []
        for i, item in enumerate(data.get("data", [])):
            url = item.get("url")
            if not url:
                continue
            path = os.path.join(save_dir, f"img_{i}.png")
            with req.get(url, stream=True) as r:
                r.raise_for_status()
                with open(path, "wb") as f:
                    f.write(r.content)
            paths.append(path)
        return paths

    def generate_stream(self, *, model, prompt, on_image=None, on_error=None, **kw) -> int:
        """流式生成（仅 4.0 / 4.5 / 5.0-lite 支持）。"""
        resp = self.generate(model=model, prompt=prompt, stream=True, **kw)
        count = 0
        for line in resp.iter_lines():
            if not line:
                continue
            text = line.decode("utf-8")
            if not text.startswith("data:"):
                continue
            payload = json.loads(text[5:].strip())
            etype = payload.get("type")
            if etype == "image_generation.partial_succeeded":
                count += 1
                if on_image:
                    on_image(payload)
            elif etype in ("image_generation.partial_failed", "error"):
                if on_error:
                    on_error(payload)
        return count
```

### 4.4 Files API（`ark/files.py`）

> 定位：素材归档管理 + 未来接入视频理解/智能体。**不参与**视频/图片生成的素材传递。

```python
from .client import ArkClient


class FilesClient:
    def __init__(self, client: ArkClient):
        self.c = client

    def upload(self, file_path: str, purpose="user_data") -> dict:
        with open(file_path, "rb") as f:
            files = {"file": (file_path.split("/")[-1], f)}
            data = {"purpose": purpose}
            return self.c.request("POST", "/files", files=files, data=data).json()

    def get(self, file_id: str) -> dict:
        return self.c.request("GET", f"/files/{file_id}").json()

    def list(self, limit=100, order="desc", purpose=None) -> dict:
        params = {"limit": limit, "order": order}
        if purpose:
            params["purpose"] = purpose
        return self.c.request("GET", "/files", params=params).json()

    def delete(self, file_id: str) -> dict:
        return self.c.request("DELETE", f"/files/{file_id}").json()
```

## 5. 豆包音频生成（tts 模块）—— Seed-Audio 1.0

### 5.1 接口说明

| 项 | 值 |
|---|---|
| 端点 | `POST https://openspeech.bytedance.com/api/v3/tts/create` |
| 鉴权 | `X-Api-Key: {api_key}`（单头鉴权，豆包语音控制台获取） |
| 模型 | `seed-audio-1.0` |
| 返回 | JSON，音频在 `audio` 字段里 Base64 编码，另有 `url`（2h 有效） |
| 单次上限 | 最长 120 秒，`text_prompt` 最大 3000 字符 |
| 核心能力 | 纯文本描述即可控制角色声线、情绪、音效、BGM；支持多角色对白、环境音 |
| 连通性 | **已验证通过**（2026-10-10） |

> **与方舟的区别**：域名 `openspeech.bytedance.com`，鉴权用 `X-Api-Key`（非方舟 API Key）。

> **短剧配音优势**：Seed-Audio 1.0 可以在 `text_prompt` 中用自然语言描述角色声线和情绪，不需要预定义 voice_type。例如 `男子（青年男性，声音沉稳）用坚定语气说道："这一次，我不会再输了。"`

### 5.2 互斥规则

| 场景 | 传参 | 说明 |
|---|---|---|
| 纯文本生成 | 只传 `text_prompt` | 按描述自动生成声线和音效 |
| 指定音色 | `references[].speaker` | 使用豆包 TTS 2.0 音色或声音复刻音色 |
| 参考音频克隆 | `audio_data` 或 `audio_url` | 克隆参考音频的声线 |
| 参考图片生成 | `image_data` 或 `image_url` | 用图片辅助生成 |

> `speaker` / `audio_data` / `audio_url` **三者互斥**；图片参考不能与音频参考混用。

### 5.3 实现（`tts/doubao.py`）

```python
import os
import base64
import requests

TTS_URL = "https://openspeech.bytedance.com/api/v3/tts/create"


class DoubaoTTS:
    def __init__(self, api_key: str | None = None):
        self.api_key = api_key or os.environ.get("DOUBAO_TTS_API_KEY", "")
        if not self.api_key:
            raise ValueError("缺少 DOUBAO_TTS_API_KEY")

    def create(self, text_prompt: str, *,
               speaker: str | None = None,
               fmt: str = "mp3", sample_rate: int = 48000,
               speech_rate: int = 0, pitch_rate: int = 0,
               enable_subtitle: bool = False) -> dict:
        """音频生成，返回完整响应 dict（含 audio/duration/url 等）。"""
        body = {
            "model": "seed-audio-1.0",
            "text_prompt": text_prompt,
            "audio_config": {
                "format": fmt,
                "sample_rate": sample_rate,
                "speech_rate": speech_rate,
                "pitch_rate": pitch_rate,
                "enable_subtitle": enable_subtitle,
            },
            "watermark": {},
        }
        if speaker:
            body["references"] = [{"speaker": speaker}]

        resp = requests.post(
            TTS_URL,
            headers={
                "Content-Type": "application/json",
                "X-Api-Key": self.api_key,
            },
            json=body,
            timeout=300,
        )
        resp.raise_for_status()
        data = resp.json()
        if data.get("code", 0) != 0:
            raise RuntimeError(f"TTS 失败: code={data.get('code')}, message={data.get('message')}")
        return data

    def create_to_file(self, text_prompt: str, save_path: str, **kwargs) -> dict:
        """生成音频并保存到文件，返回响应 dict。"""
        data = self.create(text_prompt, **kwargs)
        if data.get("audio"):
            os.makedirs(os.path.dirname(save_path) or ".", exist_ok=True)
            with open(save_path, "wb") as f:
                f.write(base64.b64decode(data["audio"]))
        return data
```

## 7. 批量调度引擎（pipeline）

### 7.1 主流程伪代码

```python
from vomin.workspace import Workspace
from vomin.ark.client import ArkClient
from vomin.ark.video import VideoClient
from vomin.ark.image import ImageClient
from vomin.tts.doubao import DoubaoTTS

def run_pipeline(workspace_root: str):
    ws = Workspace(workspace_root)
    cfg = ws.config

    ark = ArkClient()
    video = VideoClient(ark)
    image = ImageClient(ark)
    tts = DoubaoTTS()

    # 加载角色库（拿声线描述和参考图）
    characters = ws.load_json("characters.json")
    char_map = {c["name"]: c for c in characters}

    # 读取待生成的分镜
    shots = [s for s in ws.load_storyboard() if s["status"] == "待生成"]

    for shot in shots:
        ep = shot["episode"]
        shot_id = shot["shot_id"]
        print(f"\n=== 处理镜头 {shot_id} ===")

        # 1. TTS 配音（Seed-Audio 1.0，用自然语言描述角色声线）
        if shot["dialogue"]:
            char_name = shot["characters"][0] if shot["characters"] else "男主"
            char = char_map.get(char_name, {})
            voice_desc = char.get("voice_desc", "青年男性，普通话标准")
            # 拼接 text_prompt：角色声线描述 + 台词
            text_prompt = f'{char_name}（{voice_desc}）说道："{shot["dialogue"]}"'
            audio_rel = f"ep{ep:02d}/audio/{shot_id}.mp3"
            tts.create_to_file(text_prompt, ws.abs(audio_rel), speaker=char.get("speaker"))
            shot["audio_path"] = audio_rel
            print(f"  配音完成: {audio_rel}")

        # 2. 视频生成
        content = [{"type": "text", "text": shot["prompt"]}]
        # 如果角色有参考图且已上传到公网 URL
        char_name = shot["characters"][0] if shot["characters"] else None
        ref_img = char_map.get(char_name, {}).get("ref_image_url") if char_name else None
        if ref_img:
            content.append({
                "type": "image_url",
                "image_url": {"url": ref_img},
                "role": "first_frame",
            })

        task_id = video.create(
            model=cfg["ark"]["video_model"],
            content=content,
            resolution=cfg["ark"]["default_resolution"],
            ratio=cfg["ark"]["default_ratio"],
            duration=cfg["ark"]["default_duration"],
        )
        shot["task_id"] = task_id
        shot["status"] = "生成中"

        # 3. 轮询 + 下载
        task = ark.poll_task(task_id)
        if task["status"] == "succeeded":
            video_rel = f"ep{ep:02d}/video/{shot_id}.mp4"
            # 下载视频
            import requests as req
            video_url = task["content"]["video_url"]
            os.makedirs(ws.abs(f"ep{ep:02d}/video"), exist_ok=True)
            with req.get(video_url, stream=True) as r:
                r.raise_for_status()
                with open(ws.abs(video_rel), "wb") as f:
                    for chunk in r.iter_content(1 << 20):
                        f.write(chunk)
            shot["video_path"] = video_rel
            shot["status"] = "待审核"
            print(f"  视频完成: {video_rel}")
        else:
            shot["status"] = "生成失败"
            shot["notes"] = str(task.get("error", ""))
            print(f"  视频失败: {task.get('error')}")

        # 4. 预算累加（按时长估算）
        ws.update_budget(cfg["ark"]["default_duration"] * 0.6)  # 约 0.6 元/秒

        # 5. 实时保存进度
        ws.save_storyboard(ws.load_storyboard())  # 更新当前 shot

    print("\n批量生成完成")
```

### 7.2 参考图的公网 URL 问题

视频生成 API 的 `image_url.url` 需要**公网可访问的 URL**。解决方案：

| 方案 | 适用场景 | 成本 |
|---|---|---|
| **火山 TOS 对象存储** | 推荐，方舟同生态 | 极低（几毛/月） |
| **图床服务**（SM.MS、路过图床） | 临时测试 | 免费 |
| **Base64 内联** | 小文件（<5MB） | 免费但请求体大 |
| **ngrok 临时公网** | 本地开发调试 | 免费 |

> 推荐：先用 Base64 跑通，正式出片前上 TOS 对象存储。

## 11. 关键约束速查

| 坑 | 正确做法 |
|---|---|
| 方舟 Key 调 TTS | **错误**。TTS 用豆包语音控制台的 `X-Api-Key`，域名 `openspeech.bytedance.com` |
| 视频生成传 file_id | **错误**。传公网 URL / Base64 / `asset://` |
| 首帧/全模态混用 | 三选一，`role` 不能混 |
| 结果 URL 只存不下载 | **24h 过期**，必须立即下载到 workspace |
| 任务创建成功后重复创建 | 只轮询 `GET`，别再 `POST` |
| 路径存绝对路径 | 存 workspace 内**相对路径** |
| 真人人脸参考图 | 不支持直接上传，用虚拟角色或 `asset://` |
| 飞书无企业应用 | 注册免费企业版，或降级到纯本地 JSON |
| TTS url 只存不下载 | 返回的 `url` 有效期仅 **2 小时**，及时下载落盘 |
| TTS speaker/audio_data/audio_url 混传 | 三者**互斥**，仅传其一 |
