# 单镜头句式与词库

## 句式

```
[切镜头，]{景别}{机位/角度}，{主体【资产】}{动作链}；{后景}；{运镜与落幅}。
```

六个要素的顺序固定，前面的先建立"看什么、从哪看"，后面的才写"怎么动"：

1. **开头**：首镜头"开镜，"；其余"切镜头，"。承接上一镜动作时在景别后写"承接同一次拔刀"。
2. **景别+机位**：`固定正面中景`、`过姜颜肩向丹陛上拍的全景`、`俯拍超大远景，镜轴朝下约六十度`。
3. **主体**：一律写【资产名】，**禁止代词**（他/她/自己/前者/后者/那个人）。首次与之后都一样，模型不该靠上下文猜"他"是谁。多主体写清画面位置（偏右、近侧、居龙椅两侧）。
   - **身体部位与局部同样要归属**：`半张脸` `指尖` `手背` `下颌线` `脚背` `喉结` 这类，必须写 `【沈幼怡】的指尖`、`随后露出【陈诚】的半张脸`；不能只写"随后是半张脸"
4. **动作链**：按时间先后一口气写完，每个动作用"先…随后…"或分号串联，见 physics-and-scale.md。
5. **后景**：一句话，交代背景是什么、是否虚化、与初始空间一致。
6. **运镜与落幅**：`镜头轻推`、`摄影机短促前推并顺去路急摇`、`落幅完整看见她双脚缓缓离开木地板`；固定镜头写"固定"或"收稳"。

## 篇幅

| 镜头时长 | 参考字数 | 内容量 |
|---|---|---|
| <1 秒 | 约 90 | 一个动作或一个反应 |
| 1~2 秒 | 约 115 | 一个动作 + 一个落幅 |
| 2~3 秒 | 约 125 | 一句台词 + 表情 |
| 3~5 秒 | 约 150 | 一段完整动作或一句长台词 |
| 5~8 秒 | 约 190 | 运镜 + 多个递进动作 |
| 8 秒以上 | 290 以上 | 仅奇观/尺度镜头，分前后两个时间段落写（"前两秒固定静场…随后…末两秒…"） |

不要为凑字数加形容词；加的是**空间关系、物理反馈、后景**。镜头明显短于上表时，先查是否缺了前/中/后景分层、运镜落幅、承接句、本镜光线、微表情——这五项见 `shot-richness-and-pitfalls.md`。

## 经验法则：段长、镜头数与时长分配

> 统计自范本 27 段（第十集）。这是**经验区间，不是硬规则**，校验脚本不检查；偏离时要有叙事理由。

### 段类型 → 镜头数

| 段类型 | 段长 | 镜头数 | 平均每镜 | 范本例子 |
|---|---|---|---|---|
| 单一奇观（一击、坠落、尺度） | 6~15s | 1~3 | 4~8s | 第14段 6s/1镜，第11段 15s/3镜 |
| 过渡、入场 | 8~10s | 3~5 | 2~3s | 第03段 10s/3镜，第26段 10s/5镜 |
| 叙事加动作混合 | 15~20s | 5~10 | 2~3s | 第05段 20s/7镜，第17段 20s/8镜 |
| 对白戏 | 25~30s | 17~20 | 1.5~1.8s | 第20段 30s/20镜，第27段 30s/19镜 |
| 快节奏打斗 | 30s | 约 29 | 约 1.0s | 第22、23段 30s/29镜 |

估算：镜头数 ≈ 段长 ÷ 平均每镜时长。对白越多、冲突越快，平均每镜越短。

### 镜头功能 → 单镜头时长

| 镜头功能 | 时长 |
|---|---|
| 动作接触、命中瞬间 | 0.5~1.5s |
| 听话反应、短特写 | 0.5~1.5s |
| 一句台词 | 台词有效汉字数 ÷ 4.5，再加 0.3~0.5s 余量 |
| 建立空间、展景 | 1.5~4s |
| 尺度、情绪、余波 | 3~8s |

范本分布：<1s 占 29%，1~2s 占 32%，≥5s 仅 8%。快冲突用短镜头堆叠，尺度和情绪才用长镜头。

### 分配步骤

1. 先定对白镜头：每句台词按 4.5~5.2 字/秒算窗口，上限 5.3。
2. 再给动作、反应镜头各分 0.5~1.5s。
3. 剩余时间分给建立镜头和收束镜头。
4. 全部镜头时长相加 = 段长；时间码最小单位 0.5s，首尾相接。

### 自检

- 平均每镜时长明显偏离同类型段的区间时，先问：镜头是否都有**独立信息**？碎而无信息的镜头合并进相邻镜头，不是简单删。
- 镜头多不等于碎：18s/10 镜（平均 1.8s）属于对白戏与混合戏之间的正常范围。
- 单一奇观段若切成 5 个以上镜头，通常说明尺度感被切散了。

## 节奏规则（短剧快节奏）

- 开场 1~2 个镜头内进入核心冲突，不做慢热铺垫。
- 动作连续、台词短促；停顿只给一次，用静场或长镜头一次性给出。
- 快冲突用 0.5~1.5 秒短镜头堆叠，尺度、情绪、余波用 3~8 秒长镜头。
- 细节（回忆闪回、标志道具特写、环境氛围）用短镜头保留，不为此单独拆段。
- 每镜运镜尽量不同；连续重复同一运镜说明镜头设计偷懒。
- 景别选择、角度含义、组接规则的"为什么"见 `cinema-foundation.md`。

## 景别词

**景别要能被画面边界核对**：写 `腰部以上中景`、`胸部以上近景`、`面部特写`，比只写 MS/MCU/CU 更少歧义；"近一点""大一点"这类相对词一律不用（模型只能猜）。术语与边界的对应见 `cinema-foundation.md` 第 2 节。

| 词 | 用法 |
|---|---|
| 超大远景 / 大全景 | 建立尺度；人物占画高 0.3%~2% 时直接写百分比 |
| 全景 / 中全景 | 双人/多人关系、空间位置 |
| 中景 / 中近景 | 对白主镜头，腰部以上 |
| 近景 | 听话反应、表情递进，胸部以上 |
| 特写 / 近特写 | 手、眼、道具、脚步；"画面只取手、磨旧袖口与麻绳" |
| 贴地特写 | 道具落地、滚动 |

## 机位词

**机位高度与拍摄角度是两件事**：低机位可以平视也可以仰拍，高机位不一定俯拍。要两个都说才不歧义——`低机位、向上仰拍`、`高机位、略俯视`。

| 词 | 用法 |
|---|---|
| 正面 / 干净正面 | "干净"= 前景没有他人肩头，纯人物 |
| 过肩 | "真实过姜颜后肩"，前景只保留后肩与衣领，虚焦 |
| 反打 | 对话轴另一侧；见下文正反打 |
| 主观 | `姜颜眼高的主观全景，从门内望向低案`；姿态与眼高要写 |
| 高位斜俯 / 低机位仰 | 压迫感：`略低机位…仰角只强调他坐在高处的压迫` |
| 贴地 / 栏外斜前方 / 殿门内侧侧后方 | 用空间位置描述机位，不只写角度 |

## 运镜词（先判机位动没动）

摇和移、俯仰和升降、变焦和推近，是三组最容易写混的动作。**判据是机位有没有位移**：机位只转 = 摇/俯仰；机位侧移或升降 = 横移/升降；机位不动只改焦距 = 变焦。判断横移不能只凭"背景往左滑"（摇摄也会让背景滑），要看前景与远处门窗的相对位置变化。完整 12 种拍法与写法示例见 `camera-movement-and-lens.md`。

**机位基本固定**

| 词 | 含义与注意 |
|---|---|
| 固定 / 收稳 | 不动；情绪承接用，"镜头固定让这个反应完整发生"。云台一转就不再是固定构图 |
| 摇摄 / 急摇 / 俯摇 / 下摇 / 甩镜 | 机位原地转，先写方向再写起止对象；`从桌后向右摇到门口，最后停在【陈诚】身上` |
| 俯仰 / 上摇 / 下摇 / 抬镜 | 只改角度不改高度；上摇拿不到"越过前景遮挡"的新位置；`抬镜`＝由近景抬到远景交代尺度 |
| 变焦 / 拉近 | 机位不动改焦距，透视关系基本不变；交代"取景从腰部以上收紧到面部特写" |
| 移焦 / 焦点转移 | 清晰区在距离层之间转；场景必须有前中后层次与足够浅的景深 |

**摄影机位移**

| 词 | 含义与注意 |
|---|---|
| 轻推 / 缓推 / 短促前推 | 机位沿直线靠近；推幅写"半步""短距离"；人变大的同时前后比例要变 |
| 后拉 / 等速后退 | 机位远离；要露出的内容必须提前定义在场景里，否则模型自己补 |
| 横移 / 平移 | 机位侧移；跟随走动时写速度更好（"约每秒一米三的步速"） |
| 升降 | 机位竖直升降；摇臂是弧线，不等于直线升降 |
| 跟拍 / 跟摇 / 伴飞 | 写清谁在动、摄影机在前/后/侧、距离是否稳定；背后跟拍 ≠ 过肩 |
| 环绕 / 短弧绕行 | 绕弧线并持续转向主体；可只绕一小段；"顺时针"要写观察基准，改写成"从正面移到左侧脸"更可核对 |

> 升格不是运镜，是速度处理：全集只在个别揭示镜头使用，并在【本段整体基准】声明（见 `physics-and-scale.md`）。


## 起幅与落幅

动作镜头同时写**起幅**和**落幅**，让剪辑点明确：

- `正面近景起幅…镜头迅速拉开到全景，带出他仍踩在土路上的双脚`
- `落幅完整看见她双脚缓缓离开木地板`
- `刀尖从鞘口完全脱出时立即切走`（用动作完成点作为切点）
- `末幅只见远去的小背影与宽阔天空，建筑边缘留作尺度`

## 常用镜头类型

| 类型 | 写法要点 | 范本位置 |

## 动作链衔接

多个镜头拍同一个连续动作时：

- 后一镜写 `承接同一次…`（范本"承接"出现 25 次）：`承接同一次拔刀`、`姜颜承接同一次疾飞`、`承接同一只杯子的下坠末段`。
- 前一镜以动作的**完成点**收，后一镜以**同一动作的下一帧**开始。
- 连续快动作整体时长在整体基准里写死（"约四秒的连续快动作"），各镜头时长之和必须等于它。
- 微观到宏观：先在人物近景发力，再切大远景写后果（斩 → 三千米弧刃轰入海沟）。

## 正反打（对话）

1. 在初始空间声明对话轴与机位所在一侧。
2. 说话人镜头：说话人面对画外对面略高/低处；写眼神方向。
3. 听话人镜头：写不开口的细节；声音"从画外高处落下""从面前方向连续传来"。
4. 双方的画面左右、视线高低在所有镜头里不变（例：杨广在高位，姜颜永远"看向画外上方"，杨广永远"看向画外下方"）。
5. 偶尔回到双人纵深全景刷新空间关系，间隔不要超过约 6~8 个镜头。
