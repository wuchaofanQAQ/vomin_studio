# Seedance 官方提示词规则（2.5 / 2.0 合并）

> 来源：官方《2.5 提示词文档》《2.0 提示词文档》。**模型能力以本文为准；剧本格式仍以 4.2 / SKILL.md 为准。**

## 一、2.5 的硬事实

| 项 | 数值 |
|---|---|
| 单段直出 | **30 秒** |
| 单次参考素材 | 最多 **50 个**（图片 ≤30 张 4K、视频 ≤10 段总 30s、音频 ≤10 段总 30s） |
| 参考任务 | **无锁定**：宽高比、时长由我们指定（编辑/首尾帧/延长才锁定） |
| 主体数量 | 1~5 个最稳；6~10 个可试但易抽卡；>5 个时多视图要拆成多张单视图上传 |
| 多宫格分镜 | ≤15 格；推荐线稿 |
| 视频编辑 | 20s 内更稳 |

## 二、提示词结构（官方推荐）

```text
① 素材指代：图1 是谁、图2 是谁（文字绑定，不要只在图上写字）
② 一句话概述：主体 + 地点 + 事件 + 题材/风格 + 特殊运镜
③ 具体情节：按镜头或时间戳逐段写画面、运镜、动作、台词、音效，尽量正向
④ 结尾：贯穿始终的细节（机位、环境、声音、氛围）
```

- 时间戳以**秒**为单位、区间连续；不要用时间戳控制频率（「一秒摇头 3 次」）。
- 素材足够精准时**只指代、少复述**（"严格参考视频1的动作与运镜"即可）。
- 负向只支持两类：**字幕**（不要字幕）与**音频**（无 bgm / 不要任何声音）。

## 三、动作与表情（2.0 官方公式，2.5 仍适用）

- **肢体细化 + 量化**：写到手/腿/头/肩背，带幅度、速度、力度（缓慢抬手、快速转头、用力蹬地、微微低头）。
- **过渡衔接**：写前后动作的惯性（借着转身惯性顺势抬手）。
- **情绪外化**（禁止写"很悲伤/非常愤怒"）：

| 抽象情绪 | 外化成动作 |
|---|---|
| 悲伤 | 低头、肩膀微颤、眼眶泛红、手指无意识攥衣角、泪在眼眶里打转没落下 |
| 喜悦 | 嘴角抑制不住上扬、眉眼舒展、脚步变轻、忍不住原地转半圈 |
| 紧张 | 频繁看表、手指敲桌面、呼吸急、眼神闪躲 |
| 愤怒 | 双拳紧握、下颌线绷紧、胸口起伏、从牙缝里挤话 |
| 释然 | 长舒一口气、肩膀松下来、淡淡的笑、抬头望远处 |

- **一个镜头只写一种运镜**：推、拉、摇、移、跟、环绕、固定，任选其一；写多种会增加不稳。

## 四、字幕与文字（最容易翻车）

- **字幕诱发因素**：台词后复述词语、再追加语气/表情/动作，最容易让模型叠字幕。
  - 推荐格式：`角色台词（情绪）：内容`
  - 我们的写法 `00:05-00:06，R01沈幼怡（…地说）：「…」` 已符合，**不要**在台词后再复述一遍。
- 需要在画面里出现的文字（聊天界面、字幕、招牌）：**只写一次**、写明位置与字号；同时声明「画面内除该处文字外不显示任何字幕」。
- 文字要绝对准确时：把文字做成图片当参考素材，或在提示词中拆字母逐字出现。

## 五、角色对应错误

- 参考素材按**人物首次出场顺序**上传，提示词里的编号与上传顺序一一对应。
- 多主体逐一列清映射（图1=谁、图2=谁），不要只在图上写名字。
- 我们的做法：`【参考图映射】图1=S01…；图2=R01…` + 资产锁定，属于官方推荐的"文字绑定"，保留。

## 六、情绪过度响应（眼睛发光）

- 避免"狂热/极度震惊"这类强情绪词，改成"惊叹"等常规描述。
- 必要时加一句「人物为正常人眼，不发光」。
- 情绪靠第四节的外化动作表达，不靠眼部特效。

## 七、我们提示词里要固定的四条

1. **台词只出现一次**，行内只带情绪与「说」，后面不再复述。
2. **画面声明**：`画面内除指定屏幕文字外，不显示任何字幕、水印与台标。`
3. **一镜一种运镜**；要复合运动就拆镜。
4. **情绪写外化动作**，不写抽象形容词（与 `prompt-density.md` 第八节互补）。
