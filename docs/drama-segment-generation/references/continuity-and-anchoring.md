# 一致性锚定与段间衔接

## 1. 同一性锚定

同一个物体、生物、特效在**多个镜头/多段**出现时，每次都用"同一…"句式锚定，并附形制基准。

| 对象 | 写法 |
|---|---|
| 道具 | `【程咬金的巨斧】在画面中为同一把单面宽弧形铁斧，钝厚斧背，约1.4米直木柄与铁箍。` |
| 生物 | `北极熊是一头成年巨型白毛北极熊…【北极熊，披风版】与【北极熊】是同一头熊的前后状态，面部、耳朵、体型始终一致。` |
| 特效 | `刀气为同一击，只从本段右手下斩产生一次。` |
| 重复建筑 | `数百艘大型战船按同一战船的楼舱、桅杆和船体复用` |

规则：

1. 形制基准包含：**外形特征 + 尺寸 + 材质/细节**（弧刃、斧背厚度、柄长、铁箍）。
2. 在**本段现场生成**或**整体基准**里写一次，不在每个镜头重复，只在需要时用"同一…"。
3. 资产未出图时，列入文档头"待补资产"，并保证正文已写形制基准；补图后按同名绑定。

## 2. 资产版本区分

同一角色/动物有多个阶段时，**每个版本一个资产名**，并在整体基准里写明本段用哪一个：

- `皇帝全段使用【杨广 中年版】`
- `姜颜只使用【姜颜】身份`
- `姜颜本段全程以既有老者外貌行动，身法却轻快精确`
- `李靖为【李靖二】深袍阶段；李世民为【李世民】便服阶段`
- `源文李一按同场药师称呼统一为李靖，身份外形绑定【李靖二】`

不同版本如在同段共存或前后变化（披风版 → 飞走外袍后的裸露版），在整体基准写：

> 衣袍与熊毛分别接受气流，外袍飞离后延续裸露白毛身份。

并在资产锁定里同时列出两个版本。

## 3. 终态 = 下一段初态

每段末尾的【本段终态】与下一段的【本段初始空间】逐项对应：

| 终态要写 | 下一段初态要对得上 |
|---|---|
| 主体位置与姿态（"直立姿态飞向街外天空并远去"） | 世界轴与站位 |
| 手持物/道具（"右手持出鞘刀、刀鞘在左腰"） | 同一手、同一状态 |
| 环境残留（悬沙与碎块仍翻涌） | 空间中的持续元素 |
| 尚未发生的事（"尚未再次挥斩"） | 下一段从什么动作开始 |
| 未入画者的状态（"熊仍留在后部食案，继续进食"） | 之前出现过的角色不凭空消失 |

同一场景拆成连续两段时，**第二段的初始空间必须复述第一段的终态**，并用"开镜机位"重新声明机位。

## 4. 左右轴与方位

- 在初始空间里一次性声明：世界轴、对话轴、机位侧。
- 所有镜头沿用；越轴时在镜头里显式写"摄影机回到…"、"从右后侧绕到右前侧"。
- 人物的相对左右在群体镜头中保持："座位与此前左右关系一致"、"画左【大熊猫】…画右【黑熊】…"。
- 对话双方的**视线高低**固定（见 physics-and-scale.md 第 8 节）。

## 5. 场景光与风的一致

- 光源方向在整体基准写一次，所有镜头"光源方向承接前镜"（`脸部的光源方向承接前镜`）。
- 风向写主方向，所有软物（衣、发、草、帘、雾）"具有一致主方向"。
- 夜景写两类光源并存（冷月光 + 门廊暖灯），刃/杯面"反射真实光源"。

## 6. 群体与数量

群体用"取某资产形制扩为 N 个"，并注明**是否包含某个具名角色**：

- `取【八名隋代男女劳役】体貌衣料扩为十六名役夫，人数包含【隋末跛脚男性役夫】`
- `取【官差】服装形制生成另外五名不同面孔的官差，皆持短直刀；【隋末押役官差首领】为发问的官差A`
- `提取【宫廷美女】中的两名不同女性，分别坐在龙椅两侧、稍前的低坐席`

数量固定后，镜头里提到"两名""十六名"必须一致。

## 7. 跨段尺度与状态的延续

- 巨型动物的体型数字（"站起时比姜颜高半个头"）写在每个出现它的段的整体基准里，**数字不变**。
- 受伤、湿身、换装、道具位置变化，写入终态并在下一段整体基准里延续。
- 同一人物在不同段的"身份/年龄/外貌"若有规则（老者外貌、黑发），每段整体基准重申。
