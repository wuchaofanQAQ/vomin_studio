# 动作、撞击、特效、群战与巨物

> 来源：《剧本转提示词》3.0 的「受力—环境—摄影机反馈链 / 题材强度」与 4.2 的「快动作 / 撞击 / 群战 / 特效 / 巨物 / 关键帧变速 / 唯美连续变化」。仅在本段确有这类内容时读；文戏、轻动作段不要硬套。已有的 0.2 秒爆发窗口、短震量化、尺度占比写法见 `physics-and-scale.md`，本文件补它没覆盖的部分。

## 0. 先按题材控制强度

- **仙侠、奇幻、战争、动作**：可强调速度、规模、受力、环境层次、特效生命周期；但每个短镜头仍只承担**一个核心动作或一个信息揭示**。先保证路径、接触、反馈、屏幕分布清楚，再追求宏大。
- **文戏**：克制，见 `camera-space-and-visibility.md` 第 7 节。
- 受力与特效**不是每镜必写**：没有碰撞、速度变化或环境影响就不加；事件需要力量感时，用最短文字补全关键因果，不用同义词重复强调。
- 精简标准：一句话若不新增可见信息、空间关系、动作因果、表演细节或生成约束，就删。

## 1. 受力 — 环境 — 摄影机反馈链

动作镜头按必要程度写：

```
发力来源与身体准备 → 动作/能量的方向、轨迹、速度 → 接触部位与接触瞬间
  → 受力者的惯性、重心、身体传导 → 衣发/道具的次级延迟
  → 地面、空气、水体、云雾、建筑的反应 → 摄影机受到的反馈与回稳
```

- **真人受力**符合惯性与人体力学：先受力的部位、躯干与四肢如何延迟跟随、脚底摩擦或离地、重心往哪侧移、停止或落地如何缓冲。避免整个人像纸片同步平移，也避免无依据的夸张布娃娃。
- **环境互动**只写本次动作真正影响的介质，并给**方向、范围、先后、衰减**：气流推开尘土与云雾，脚步压陷或震裂地面，冲击掀动水面、草木、衣摆、散落物。不写"周围发生剧烈变化"。
- **摄影机也是环境的一员**：只有爆炸、撞击、重踏、极速掠过、强声压足以影响机位时才加抖动，并写方向、幅度、频率、持续、恢复：`冲击从画左撞向画右，镜头同步向右短促低幅震动一次，轻微反弹后迅速回稳`。晃动不是全画面长期随机游走。

## 2. 快动作与武戏

- 打戏用**连续、迅疾、干净**的动作句。每一招写明：当前姿态与支撑、持握手、最关键的身体或兵器路径、准确接触点、主要结果、下一招如何接上。详细度用来消除歧义，不把一次爆发拆成逐步等待的慢演示。
- **先定空间路径，再选镜头**。出手方向、身体移动方向、镜头运动方向可以不同，但必须能同时成立。
- 轻盈潇洒来自重心、身法弧线、衣发惯性、落点；**力量感来自速度骤变、命中、目标受力位移、环境结果**。特效亮度、火花数量、震幅数字不能替代目标后挫、肢体偏折、支撑受压、地面翻裂。
- **旋转给轴和姿态**：沿伸展身体长轴滚转、水平面转髋、手腕带兵器走小弧，是三种动作。悬空、单掌支撑、踏在兵器或动物上时，写实际接触部位、承重物、持续支点；"剑插地支撑"与"持剑攻击"分开写。
- **一攻一防**可用全景与特写的利落硬切展示，所有切镜保留同一动作进度。连续战斗里下一名敌人的进入与主角的后续动作要有承接，避免"打完等一会儿再重新启动"。
- **接触后的分离、扣抓、卸力、再接触**要真实承接，不能一面弹开一面仍在原处扣住。
- 快武戏优先短促前推、同速跟拍、甩镜接动作、低位掠行、快速横移、有目的的短弧绕行。镜头紧张但**主体、打击路径、结果都能辨认**。
- **速度词要有可见证据**：身体迅速跨过明确距离、近景地纹掠走、刃锋抵达接触点、衣发向后绷展。不要只堆"猛烈、瞬间、疾掠"，也不要把所有快动作都写成慢动作。
- **飞行**：先锁本镜的高度、姿态、速度、来去方向，只写实际发生的加速、转向、制动、悬停或落地；衣发与饰带随后响应身体惯性。雨中飞行需要排水时，写迎面雨线被贴体气流沿头肩与四肢外缘分向两侧、后方，离开扰动区后重新下落。没有起飞/落地的镜头不补这些事件。
- **重要交锋**须让观众辨认：威胁怎么逼近、招式怎么命中或被化解、力量怎么改变对手与环境、下一动作怎么接上。这些信息可跨原有切镜连续完成，不要求每镜重演全过程；沿同一攻击路径压缩起势、突出爆发，并留足看清主结果的瞬间。

## 3. 撞击与环境反馈

一次重要撞击围绕**来势、撞点、主结果**组织，不套固定八阶段流水线。每镜只写它覆盖的阶段；已经命中的下一镜承接结果，已形成的屏障或火焰直接进入当前状态。

- **接触先于**碎裂、扬尘、震动与声响尾部。写清目标受力位置、位移方向、停止状态；攻击方也要减速、偏折、停住或穿透。用一两个最强证据表现力度（木端撞停后回摆、盾面断裂带动手臂后挫、脚下泥土被犁开）。
- 摄影机反馈由地面震动、承载结构、近掠风压、抵达机位的冲击触发，写主方向、峰值、回稳。**远处撞击允许光、声、机位反馈先后抵达**，不把极远特写与近处振动混成同一距离。只在有执行价值时写震幅数字，不给每镜套同一百分比。
- 环境随实际作用响应：落脚后起尘、刀刃接触后断裂、气浪前沿抵达后草木倾伏；碎片、火星、尘土、衣发有一致的主方向与后续惯性。减少无关的同时响应，让主撞点清楚。
- **屏障**的空间顺序是：来袭物 → 受击面 → 被保护者。写清屏障覆盖头顶、身体侧面、脚下的范围，受击区域在主体外侧，外壳/内部人影/地面的前后遮挡成立。不要用一句"保护罩"代替完整包覆关系。
- **布幔、绳索、兵器、盾牌**有实际连接与承力方式：固定点、松弛余量、受击方向、回弹状态相互一致，反馈只保留当前镜头能看见的部分。

## 4. 群战与大场面

- 先区分**战役范围、局部交战区、当前镜头取景范围**。局部围攻嵌在持续推进的大军里；城外攻城、城头交锋、主角身边战团同时发生时，各自保持行动职责。
- 人数、密度、占画幅描述**绑定当前景别**：近层清楚的攻击与反应，中层队列接续逼近，远层持续推进/攀登/撤退；道路、门洞、通路保持真实宽度。剧情没要求的巨大空地、整齐圆环、围观队列，不作默认设计。
- 群体运动靠**交替落脚、支撑、身体越过承重点**：近景读得到鞋底或马蹄接触，远景用头肩起伏、队列参差、旗杆节拍、贴地尘带。大军在地面上真实前进，不用整片剪影匀速平移。
- **围攻**按来向与抵达时序组织：前排交战、侧方补入、后排向缺口接续推进。角色每次击退的数量与剧本一致，被击者让出空间，后续敌人持续进入。背景动作有任务、有路径，不抢主动作。
- **攻城器械**先交代接近的具体城墙段、车轮落地、登城平台与墙沿的高差，再写搭桥、落桥、通过；俯拍必须能看见通道连到哪里，人员的进入、拥挤、跌落、交锋发生在同一几何关系内。
- **撤退**沿远离威胁的明确路线，队伍缩小来自距离增加，尘带与步频保持。动物或同伴有剧情职责时，写它实际完成的攻击/保护/搬运/行走，不用"跟着主角"替代。

## 5. 特效：从资产外观转成空间事件

特效资产提供轮廓、色相、材质、密度、纹理、峰值形态。**先定本镜处于哪个阶段**（形成 / 持续 / 发射 / 命中 / 消散），只写这一个阶段的运动，不要求每镜重演全流程。大招生命周期是：出现 → 增强 → 传播 → 接触/影响环境 → 余波/消散。

- 写清特效**发出或依附的位置、前进方向、变化范围、当前可见尺度**，以及从画面哪里出现、占前/中/后哪一层、向哪流动/扩张/冲击、速度与密度、闪烁/连续/脉冲/旋转、如何影响云雾尘土水体与光影、最后怎样衰减。
- 用少量**最有证明力的体积证据**：近远表面视差、实体遮挡、内部物质流动、对场景的局部投光、接触处的扰动。**颜色变化不能代替运动过程。**
- **云雾包裹主体**：云丝沿具体部位流动、翻卷、脱离并被后续云流补入，主体轮廓在流云间时显时隐。**火柱**有持续供给的源头，火舌沿喷射主方向卷走。**环、漩涡、太极**等分阶段资产共享同一圆心、平面、尺度衔接，阶段变化发生在同一实体上。
- **剑气**与实际剑路同向，从刃口或规定位置生成，离身后沿固定斩面前进；弧刃的薄厚、凸刃、尖端、透明内侧、拖尾各有职责。要提取参考图某一部分时，说明保留的形态，以及其余边缘怎样逐渐收细、疏散、消融。
- **多道剑气 / 多次落击 / 分批攻击**：内部给每次发射建一个**实例标识**，记录来源、产生时刻、切出位置、目标、命中、消耗。外观共用资产 ≠ 同一个实体。按剧本写清"前一道在飞行/命中/散开时，下一道处于何处"，不要只写"多道同时出现"让模型自行排列。
- **地面裂痕、火流文字、阵图**是场景内的结构与运动：裂痕始终沿已定地面路径延伸，与人物的空间关系可在俯拍中核对；火流沿真实沟槽逐段燃起，多个火头各走各的通路，连通处才分叉或汇合；字形来自路径整体，不另放悬浮文字层；关键字形需稳定复现时，优先用经确认的布局参考。
- **特效收尾要登记**：每次消耗、碎裂、消失后，在终态记录残留、战损、剩余阶段。无需特效的普通动作不额外添加法术、爆炸、受伤、死亡。

## 6. 巨物与镜头尺度

- 先以**剧情给定体型、角色比较或资产比例**建立稳定尺度，再按每镜距离和景别推占画幅。巨兽、法相、浪潮、大特效每次入画，都写当前可见部位和大致占画高/画宽，或给同框参照。
- 绝对数字（"300 米级"）必须来自本次剧本或明确指令，**不从旧案例复制**。没有绝对数字时，用与人、树、城墙、山脊、船只的可见比较建立尺度，不编精确物理值。
- 分清**全身、头胸、局部**：巨大头颅占满近景 ≠ 全身缩小；全景需要树冠、脚边建筑、地平线作比例；超大全景里的普通人保持可信小轮廓；与巨物同框的人物不能同时清楚呈现五官。
- 占比写明**对象与分母**（"全身约占画高六成""头胸铺满画宽"），不混用高度、面积、宽度。随摄影机推进/拉远，起止占比对应变化，连续运镜中不能锁死互相矛盾的比例。
- 重量靠迟滞、地面承重、遮挡、空气透视、环境位移呈现；极速巨物仍保持躯干惯性与落足节拍。

## 7. 关键帧与变速

- 关键帧先识别为**起始 / 途中经过 / 动作峰值 / 终态**，记录主体数量、姿态、接触部位、支撑点、朝向、构图。把真实动作**连续带入**它，再由它继续发展；不能跳切成静止参考图。
- 踏物、借力、横展、空中滚转：写进入路径、真实支撑或接触、到达关键姿态的瞬间、下一步动作。关键帧里的背景底色只用于展示，成片按本次场景重建光照与地面关系。
- 需要展示完整关键帧构图时，给一个**明确抵达、可辨保持的窗口**；随后环绕必然改变观察角度，按同一三维姿态展开前后遮挡，而不是要求所有角度都与原平面构图相同。
- **子弹时间 / 超慢升格**只在剧情或创作者指定时触发，写清开始点、持续窗口、结束点、恢复正常速度；主体放慢时摄影机仍按设计移动，衣发、尘粒、动势保持连续。慢动作服务美感、关键接触或情绪，激烈段落的主要攻防保持利落节拍。

## 8. 唯美画面与连续变化

- 独处、情绪、辞别镜头从人物位置、负空间、背景层次、具体光源设计美感。主体脸部可读，发丝与衣料由真实风向、转身、行进带动。
- **变色、衰老、伤势、形态显化**：指定发生位置、传播方向、变化前沿、结束状态；同时锁定不变的面容、姿势、空间和已有伤势。例：发色沿同一批实际发丝由根至梢推进，已变与未变部分在同一镜中可辨。摄影机沿变化路径平顺跟随，焦点接住交界，再回面部表演；用身体/发束/镜头移动与变化同时连续发生，**不用整幅换色代替局部演进**。
- 人物、背景、特效接受**同一光源逻辑**：方向、强弱、颜色、持续时段与受光面相符；太阳位置、火光、闪电、动态特效变化时，受光面随之连续变化。
- **出招后的静场**按剧情保留：动作已结束，角色收势，尘埃、花瓣、雨、光仍在空间里运动。需要俯拍大全景时，让人物、裂痕、景物关系清楚，并给足可读的停留时间。
