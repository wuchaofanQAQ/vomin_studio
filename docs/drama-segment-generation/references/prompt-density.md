# 提示词密度：照着参考稿学

> 来源：拆解《你的两千年修行之路》第 4 集 14 个独立单元（73 镜 / 90 秒）的成稿。
> 结论一句话：**并不是字多，而是每句话都带可执行信息**——位置、比例、材质、受力、切点。

## 单镜六层（缺一层就是废镜，正文 ≥120 字）

写每一镜前先回答六个问题，答不全就回去想，不要动笔：

| # | 层 | 要回答的问题 | 反例 → 正例 |
|---|---|---|---|
| 1 | **景别** | 从多远看？ | 「近景」→「门外机位、与【陈诚】眼平齐的近景」 |
| 2 | **调度** | 人和机位怎么动？ | 「他走到窗边」→「镜头随【陈诚】横移半步，他经过【沈幼怡】身边时脚步慢半拍，走过去才加快」 |
| 3 | **表演** | 他在忍什么？身体哪里泄漏？ | 「他皱眉」→「拇指按了两次没按准，第三次才亮；指甲压进掌心压出四个印」 |
| 4 | **环境** | 空间里有什么在动？ | 热浪把墙线晃软、地砖被晒出白亮、柜子轮廓浮在暗里 |
| 5 | **环境音** | 这一镜观众听到什么？ | 门轴先响、水声、杯底磕茶几、话筒漏音、冰箱嗡鸣、忙音、风扇声 |
| 6 | **光影** | 光从哪来、怎么变？ | 「逆光勾出下颌线」「屏光从下往上照鼻底」「门合上把走廊的白切掉一半」 |

**收尾**：能不写切点就不写；只在切点是决定时写（「切在铃声尾音还没散」）。运镜镜头必须给落幅。

### 三条禁令

1. **禁止只写动作**：只有「谁做了什么」的镜头＝废镜，必须带表演与环境。
2. **禁止只写前中后景**：三层是构图，不是全部；缺环境音与光影同样不合格。
3. **禁止一镜同构**：连续三镜以上用同一句式（如都以「切镜头，X景，」开头）视为偷懒，必须换写法。

## 单镜四层（每镜缺一不可，正文 ≥150 字）

一条合格的镜头正文，至少四层信息：

| 层 | 写什么 | 示例 |
|---|---|---|
| **光位** | 主光从哪来、明暗比、有没有反光/逆光 | 「夕阳从画右斜切进来，他半边脸压在暗部」 |
| **表演** | 动作怎么发力 + 表情/呼吸/视线的变化 | 「指节先发白，随后整只手下意识收紧」 |
| **层次** | 前景 / 中景 / 后景分别有什么，虚实关系 | 「前景是虚化的窗帘边，中景是他的侧脸，后景是过曝的天」 |
| **运动与切点** | 固定还是微推/手持，起幅落幅，切在哪一帧 | 「固定机位微推半寸，切在他眼皮落下的瞬间」 |

低于 150 字的镜头基本只写了动作，模型只能自由发挥，成片会"空"。

## 一、参考稿的九条硬规律

| # | 规律 | 参考稿怎么写 | 反例（我们常犯） |
|---|---|---|---|
| 1 | **段首不写「硬切」；切点不强制** | `侧面全景，完整球体占画高60%……外壳已裹成燃烧火球时强制硬切。` | 每镜都以「硬切」起、以「切在…」收，43 镜一个句式 |
| 2 | **画面三层 + 量化** | `前景岩峰沿下缘急速扫开；中景干裂谷底向深处延伸；后景300米级兽体占画高70%、画宽80%` | `画面中有陈诚和门`（无层无比例） |
| 3 | **动作链写全** | `兽口骤张→火柱轰出→喷吐反力把前胸压下去→前爪扣入岩层→掌缘石块翻起` | `陈诚生气了`（只有结果没有过程） |
| 4 | **接触先于结果** | `刃与巨角同时骤顿，护甲先挤凹，兽头才被压低` | `一剑砍中，怪物倒下` |
| 5 | **一镜一个主动作，时长 0.6~1.7 秒** | 每单元 5~7 镜、5~6.5 秒 | 一镜 3 秒堆三件事 |
| 6 | **整体基准是技术卡** | `16:9，24fps，真人电影质感……主体保持资产面容/结构……七镜各自硬切……风声、金属出鞘、矛断爆响与巨足低频踏震……各资产在真实场景中重建材质、体积、透视、投光与动态身份` | `八月末正午，硬光比`（只有一句环境） |
| 7 | **现场生成写形制与物理** | `护盾为完整透明球体：球心位于躯干中心，初始半径为身高1.5倍；头顶双足双掌发梢衣摆全部在球内，离内壁留半个前臂宽` | `手机屏幕上的字，按剧本生成`（只有一句交代） |
| 8 | **初始空间带历史状态** | `旧摔击深坑保留在谷深后方，巨兽已冲至原标高的岩地，本轮新圆坑将在这块前方岩地受击形成` | `门在画右，人物在画中`（无前史） |
| 9 | **终态是状态清单** | `右掌已抬至胸前、身体面向谷深、火柱保持斜向上前进、巨兽前爪扣紧岩层` | `下一段接着门口` |

## 二、字数基线（参考稿实测）

| 块 | 参考稿区间 | 我们的最低要求 |
|---|---|---|
| 【本段整体基准】 | 200~300 字 | **≥150 字** |
| 【本段现场生成】 | 80~150 字 | **≥60 字**（确实没有写「无」） |
| 【本段初始空间】 | 100~150 字 | **≥90 字** |
| 单镜正文 | 60~200 字 | **≥70 字** |
| 【本段终态】 | 40~80 字 | **≥40 字** |
| 单元总字数 | 1200~2200 字 | 同 |

## 三、整体基准的固定配方（照写就够 200 字）

```text
1) 技术规格：16:9，24fps，真人电影质感，<时段/天气>
2) 光与色：主光方向 + 色温 + 局部动光源（火光/屏幕光/台灯）+ 受光面
3) 主体保持：<角色> 保持角色资产的面容、发型、服装；<场景> 保持结构
4) 尺度：主体在画面里的量级（巨物写高度级与占画比例；室内写空间尺度）
5) 剪辑执行：本单元 N 个独立镜头，按下列时码依次硬切；前一镜切出状态是后一镜动作起点
6) 速度与接触：速度由什么证据表现；接触/受力谁先谁后；机位怎么反馈
7) 声音：环境底声 + 动作声 + 远近层次（"远处爆响晚于可见闪光到达"）
8) 重建声明：各资产在真实场景中重建材质、体积、透视、投光与动态身份，周围环境连续完整
```

## 四、现场生成的写法

只写**没有独立参考图、但本单元确需**的东西，写它的：

- 形制（几块、什么形状、多大）
- 材质（石材/金属/布料/发光膜）
- 物理规则（怎么承力、怎么变形、怎么消散）
- 与主体的关系（在谁身上、占多大、离多近）

例：`青白剑阵在人物身后展开，外圈基环与内层剑纹有空间厚度；内层凝成全长300米的透明剑形法相，柄端、剑格、厚刃根、直剑脊与尖端连续可辨。`

## 五、镜头的写法顺序

```text
硬切 + 景别 + 机位/运镜（一句）
→ 画面构成：前景… / 中景… / 后景…（带比例）
→ 动作链：起势 → 路径 → 接触 → 结果 → 反作用（谁先动、谁后动）
→ 光与材质落在接触处
→ 声音（只在有信息时写）
→ 切点：…时强制硬切
```

| 单薄版 | 密度版 |
|---|---|
| `陈诚坐在电脑前敲字，眉头一拧。` | `中景固定机位：陈诚坐在圆桌旁的餐椅上，笔记本电脑屏幕占画左三分之一，冷白屏光从下往上照亮他的下颌与手指；他敲字的右手在第四个键上停住，眉峰压下去；前景是桌上半杯凉掉的水，后景是虚焦的开放式厨房；画外门铃第一声响起时，他的手指还停在键上。` |
| `沈幼怡站在门外，背着书包。` | `全景固定机位：沈幼怡站在门槛外半米，浅蓝碎花裙的后背被汗浸出深色一片；双肩书包鼓囊囊压着右肩，肩带把裙子勒出两道褶；行李箱立在她右脚边、拉杆拉出；门外白炽日光从她头顶压下来，在脚下投出一小片短影；镜头固定，落幅停在她垂着的肩线。` |

## 七、别学的地方

- 他们用【名称】直接指代资产，我们用 `编号+名称`（4.2/项目要求）。
- 他们单元 5~6.5 秒、每段拆 5 个单元；我们按难度 6~30 秒一段，一段即一个生成单位。
- 他们的台词单独成行格式不同；我们用行首时间窗。


## 八、第五集参考稿补充的十条（文戏尤其有用）

| # | 规律 | 参考稿原句 | 我们要怎么写 |
|---|---|---|---|
| 1 | **表演靠可见动作，不靠形容词** | `母亲双臂先接住扑来的孩子，再捧起他的脸仔细端详，拇指抹过眼角泪水` | `她忍住不哭` → `她唇角发颤，先抿了一下，才把话说完` |
| 2 | **台词前后都要有戏** | `她朝前景方向深深鞠躬，脸随俯身转向下方，话语从低头姿态中清楚送出` | 说话前写准备动作，说话时写姿态，说完写余势 |
| 3 | **语气括号写可表演的状态** | `（忍住哭腔，重复时稍松一口气）`、`（平稳笃定，承诺处落字清楚）` | 不要写`（难过地说）`，写`（声音发紧、把最后一个字压下去）` |
| 4 | **切点写成"切在…时"** | `切在母子即将相拥时`、`切在她仍躬身、孩子站在身侧时` | 不要只写`落幅停在他脸上`，要写切出瞬间谁在什么状态 |
| 5 | **机位随动作微调** | `镜头随她蹲下轻轻下摇`、`再随站直上摇回面部` | 写"随…下摇/上摇/轻推"，机位跟着表演走 |
| 6 | **过肩写虚实** | `前景保留姜颜虚焦肩背与发缘` | 过肩镜头要写前景是谁的哪个部位、虚到什么程度 |
| 7 | **尺度用相对参照** | `肩背最高处比同地面、同纵深直立的姜颜头顶高约半米` | 不写"300米"，写"比他头顶高半个头""只到他腰" |
| 8 | **群像里指定个体** | `由【马匹群像】最左黑马绑定为姜颜坐骑` | 群像入场要指名用哪一个，不然模型每镜换人 |
| 9 | **光为可读性服务** | `门外柔和正侧光照亮两人的眼睛和嘴唇`、`照清正脸眼神、鼻梁和嘴唇` | 不只写"暖光"，要写光照亮了什么表演信息 |
| 10 | **声音带距离与回声** | `对白、衣料、脚步和物件接触声具有同一室内距离与回声` | 写清远近层次，室内写回声，室外写扩散 |

### 文戏镜头的推荐句式

```text
<景别>，<硬切/固定机位/随…微调>。<前景：谁虚焦的哪个部位>；<中景：谁在做什么，
手/眼/呼吸怎么动>；<后景：环境与光>。<台词前的准备动作>，<说话时的姿态>，
<说完的余势>。切在<谁仍处于什么状态>时。
```

### 对照：我们的镜头 → 按第十条改写

```text
（原）硬切近景固定机位：R01沈幼怡低下头，拇指一个字一个字地敲，比刚才慢得多；
她的嘴唇抿成一条线；前景是她的拇指与机身边缘，中景是低垂的睫毛，后景是门外过曝的白。

（改）硬切近景固定机位，镜头随她低头轻轻下压。前景是她握着手机的拇指与机身边缘，

还没按下去的那一瞬。
```


## 九、两条最容易写错的硬约束

### 1. 景别决定可见集合

- **近景**只装得下头肩，**特写**只装得下局部（眼睛、手指、汗珠、屏幕）。
- 近景/特写的后景只能写**光、虚焦色块、同一个人身上的部位**；写「地砖/走廊纵深/厨房/客厅」就是拍不出来。
- 要写全「前景—中景—后景」三层，就换**中景/中全景/全景**。

| 错误 | 为什么错 | 改法 |
|---|---|---|
| 近景 + 后景是地砖 | 站着的近景看不到脚底 | 后景改「门外过曝的白」或「虚焦的走廊」 |
| 近景里写「汗珠坠到行李箱拉杆」 | 拉杆在她腰以下，近景不入画 | 改成**特写**：下巴+拉杆+虚焦地砖，拍那滴汗 |
| 特写手机 + 后景是地砖 | 手机举在胸前，背景是衣料/走廊 | 后景改「她衣料的暗部」 |

### 2. 动作句必须有执行人

「门从内侧拉开」「箱子被拎起」这类没有主语的句子，模型会让物体**自己动**。

- ✗ `门从内侧拉开，【陈诚】站在门内`
- ✓ `【陈诚】右手先拧动门把，把门从内侧拉开；他站在门内`

写动作时固定三件事：**谁**（【名称】）+ **哪个部位**（右手/双手/肩膀）+ **怎么发力**（拧、拽、推、拎）。
