# 迭代修复手册 + 成功CLIP经验复盘

## 迭代医生原则

- 失败后一次只改1-2个变量
- 保留成功部分，不全重写
- 每轮修改后必须重新过质检，不能跳过
- 多处修改文件时用write_file整体覆盖，不用edit_file（并发问题已确认）

## 常见问题修复表

| 问题 | 修复方案 |
|------|----------|
| 掉帧 | 加motion blur锁定+负面限制no frame skipping/stutter/choppy motion→降手持摇晃幅度 |
| 角色复制 | STYLE LOCK锁角色数+负面限制no character duplication→每Shot开头单独写角色数量 |
| 动作被跳过 | 优先保证核心Shot完整性，合并次要Shot |
| 暗金能量偏蓝紫 | 明确"暗金色+深红底色"+负面限制no blue-purple energy |
| 格挡没有物理反馈 | 加推退/飞溅/震动描述 |
| 角色表情过多/不对 | 加no excessive emotion/screaming + 根据人设推演 |
| 翻滚方向错误 | 明确写方向词如"backward" |
| 演出不匹配人设 | 写提示词前必须通读人物设定 |
| 色调不一致 | 同一场景统一色调，跨Shot检查色温/光源一致性 |
| 镜头景别与描述不匹配 | 逐Shot检查：镜头拍不到的不写（如背影镜头不写正面微表情） |
| 比喻污染 | 删除所有"像XX""如XX""仿佛XX"，直接写视觉事实 |
| **画面假/没有活人感（2.5）** | 环境动态缺失。每个Shot补3-4个环境动态元素：风/灰尘/雾/光焰/水/生物。2.5不自动补环境运动，不写=死画面。详见 `seedance_25_execution_model.md` 第三节 |
| **角色皮肤与环境颜色不匹配（2.5）** | 光照-表面交互缺失。补写每个光源照到角色哪个部位、色温混合、反射光来源。不写=角色像在影棚独立打光。详见 `seedance_25_execution_model.md` 第四节 |
| **表情过度/不对（2.5）** | 情绪词导致2.5字面执行。删除所有情绪词（笑/怒/悲等），替换为可见肌肉动作。"嘴角抬起2mm"不写"微笑"。详见 `seedance_25_execution_model.md` 第一节 |
| **角色动作僵硬/像人偶（2.5）** | 只写了一个身体部位，其他部位不动。补全全身动力学链：主动件+稳定件+补偿件+不自主反应。即使"不动"也要写呼吸/微晃/眨眼。详见 `seedance_25_execution_model.md` 第二节 |
| **画面空/元素太少（2.5）** | 四层画面枚举缺失。补写前景层/中景层/背景层/空气层。2.5不补充你没写的元素。详见 `seedance_25_execution_model.md` 第五节 |
| **角色与环境没有物理交互（2.5）** | 接触面物理缺失。补写脚踩地面/手扶墙壁等接触面的物理反应（水被挤开/灰尘被带起/表面变形） |

## 成功CLIP经验复盘

### A. 迭代方法论

1. **用户给详细镜头设计 = 执行的基座** — 当用户/导演给出具体镜头指示时，质变转折点出现。执行者的角色是把镜头指示翻译成Seedance能吃的提示词，不是自己编镜头
2. **多轮迭代，每轮只改1-2个变量** — 每轮只解决一个具体问题。唯一例外是用户指示驱动的结构重写
3. **冲突自查是硬门** — 每次修改后必须重新过检，不能跳过

### B. 提示词写作技术

4. **每镜运镜必须全不同** — 重复运镜=模型偷懒的信号。9镜9种运镜，不给模型重复模板的机会
5. **动词要狠** — "猛然翻起"不是"缓慢起身"，"极速"不是"快速"，"撕裂空气"不是"挥动"。模型对动词强度敏感
6. **物理细节每镜不重复有递进** — 每击/每镜有独特物理细节，不是模板化重复
7. **负面限制针对性极强** — 每条负面限制都是实际迭代中踩过的坑，不写泛泛的通用spam
8. **导演推理在paste-ready之前完成** — 没有导演推理直接写提示词=无根之木

### C. 角色演出

9. **角色演出是导演推演的结果，不是死规矩** — 同一角色不同场景演出不同。每次写CLIP都要根据当前场景+角色人设重新推演
10. **角色间演出必须分化不雷同** — 三人面对同一事件应有不同反应（如一人慌/一人评估/一人沉默）

### D. 写作前方法论确认

写每个新CLIP前对照（质量/格式/2.5专项检查详见 SKILL.md 生成前质检清单）：
- [ ] 用户/导演是否已给出镜头设计？如果没有，先问要
- [ ] 每镜运镜是否全不同？
- [ ] 动词是否够狠？
- [ ] 物理细节是否每镜不重复有递进？
- [ ] 角色演出是否严格匹配人设？角色间是否分化？
- [ ] 负面限制是否每条针对具体坑？
- [ ] 导演推理是否在paste-ready之前完成？
