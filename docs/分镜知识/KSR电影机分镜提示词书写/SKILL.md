# Seedance视频提示词编写

将用户的镜头调度/剧本段落转化为Seedance 2.5可执行的视频生成提示词（CLIP）。核心原则：提示词是纯视觉指令，只写"长什么样"+"怎么变的"，不写剧情原因和抽象情感。

## 工作流程

1. **读取剧本段落** — 确认当前CLIP在剧本中的位置、时长、内容
2. **读取角色人设** — 涉及的角色必读人设档案，演出必须匹配性格
3. **导演推理** — 时间铰链/Shot Function/张力曲线/角色演出弧线/站位推演（此段不复制给Seedance）
4. **编写提示词** — 按V8标准结构编写，详见 `references/v8_structure_template.md`
5. **道具锚定检查** — 只锚定实际出镜的参考图和道具，不出镜不提及
6. **生成前质检** — 过preflight checklist（见下方）
7. **交付** — 上传文件，不贴全文
8. **迭代修复** — 按迭代医生原则一次只改1-2个变量，详见 `references/iteration_manual.md`

## V8格式结构（SD 2.5融合版）

每个CLIP提示词文件结构：

```
## 使用方式
（上传参考图顺序 + 复制粘贴说明）

## 导演推理（不复制此部分给Seedance）
（时间铰链/Shot Function/张力机制/演出弧线/站位/质检）

## [STYLE LOCK]（风格段·全局锁定）
（8个子段，详见references/v8_structure_template.md）

## [参考图锚定]（主体段·全局声明）
（每个@Image锁定属性和职责，后续不重复）

## CLIP — 标题（时长·N镜）
### Shot N（镜头类型·景别·运镜）
【0s-3s】起始状态 + 主体动作 + 镜头拍法 + 结束状态

## [BGM & 声音设计]
（BGM/对白/关键音效独立段）

## [限制]
（3-8项精准限制，非通用spam）
```

### 顺序铁律
- 视觉母版（STYLE LOCK）放开头，但镜头核心内容占60%+字数
- 时间段不重叠不留空：上一段结束状态 = 下一段起始状态
- 参考图锚定一次性声明，后续Shot不写任何@Image引用

## 12子段模板（小薇拉标准）

每次写CLIP必须包含全部12子段，缺一不可。写之前先翻项目中最接近的同类已完成CLIP对齐结构。完整模板见 `references/v8_structure_template.md`。

**STYLE LOCK段（8子段）**：①一句话风格锁定 ②色调（色卡融入叙述一段压完）③质感（Kodak胶片模拟）④电影质感锁定 ⑤物理照明锁定 ⑥人物运动物理锁定 ⑦场景特定物理规则 ⑧严格N人声明

**CLIP段（3子段）**：⑨首帧声明 ⑩逐秒拆解 ⑪微动作全程

**结尾（1子段）**：⑫[NEGATIVE] 场景特定否定指令

## 核心规则

### 三反原则（最高优先级）
1. **反比喻** — 所有"像XX""如XX""仿佛XX"全删，直接写视觉事实
2. **反衣物描写** — 服装已由@Image锚定，除特写外禁止重复描写衣物（但衣物随动作/风的运动可以写）
3. **反眼色** — 禁止写瞳孔/虹膜颜色，统一写"视线看向XX"

### @Image纯净度规则
1. 画面不出现的角色不在提示词中提及（写了角色名=Seedance认为需要生成→角色复制根因）
2. 每个Shot只引用画面焦点角色的@Image，背景虚焦角色不引用不提名字，只写"虚焦人影"
3. 提示词=纯视觉指令，不写"敬佩恐惧劫后余生"等抽象情感词
4. 绝对不写剧情原因（"她选择召回它等于解除抽取"是注释不是视觉指令）
5. "朝向"≠"位置"：面朝左≠在画面左侧

### CLIP V2写法规则
1. **台词嵌入SHOT时间线**，不分开写
2. **禁暗示性描述** — Seedance不需要知道的不写
3. **锚定段只写"作为xxx的视觉锚定"**，不写穿着
4. **画面中每秒每个人物和物体都有形容**
5. **情绪→物理分解** — 禁用所有情绪/感受词（笑/怒/悲/犹豫等），替换为2-3个可见肌肉动作+身体动作。写"嘴角抬起2mm"不写"微笑"。详见 `references/seedance_25_execution_model.md` 第一节
6. **全身动力学链** — 每个角色每个动作写全四层面：主动件+稳定件+补偿件+不自主反应。不能只写一个身体部位。详见 `references/seedance_25_execution_model.md` 第二节
7. **环境动态必须写** — 每个Shot至少3-4个环境动态元素（风/灰尘/雾/光焰/水/生物等）。2.5不会自动补环境运动，不写=死画面。详见 `references/seedance_25_execution_model.md` 第三节
8. **光照-表面交互必须写** — 每个可见角色写明：主光源方向+照射部位+色温混合+反射光+阴影来源。不写=角色皮肤与环境脱节。详见 `references/seedance_25_execution_model.md` 第四节
9. **四层画面枚举** — 每个Shot写全前景层/中景层/背景层/空气层。详见 `references/seedance_25_execution_model.md` 第五节
10. **声线锚定** @Audio
11. **CLIP段落零比喻**
12. **只出现声音的角色用声音特征描述**，不写角色名
13. **导演推理段中的角色名和比喻保留**（该段不复制给Seedance）
14. **镜头景别与画面描述匹配** — 镜头拍不到的不写
15. **色调一致性** — 同一场景统一色调，跨Shot不混色

### 声音设计规则
- BGM/对白/关键音效独立成段管理
- 台词全英文写（包括语气词）
- 脚步声需明确角色步态特征（重踩/轻踩/碎步拖拽/稳健步等）
- J-Cut：声音可从上一场景延续到画面切换后

### 反CG感三锁定
1. Live action not animation/CGI/game
2. Physical camera + anamorphic lens, real film stock characteristics
3. 所有运动有惯性和重量，fabric follows mass and air resistance

### 光源铁律
- 所有光源必须有真实物理来源，禁止凭空出现暖光
- 暗色物体需边缘光勾勒轮廓避免变成flat hole
- DARK AREAS not pure black

## Seedance 2.5 执行模型（必读）

2.0会推理、会加戏、你写个大概它帮你补。2.5不推理——你写什么它给什么，你不写=画面里没有。完整规律详见 `references/seedance_25_execution_model.md`。

核心升级点（K哥实战总结，从具体问题推理到通用规律）：
1. **情绪→物理分解**：不写"笑"，写"嘴角抬起2mm+紧跟下一个动作"。所有情绪词都有同样问题——2.5字面执行且往往过度。把每个情绪分解为2-3个可见肌肉动作+身体动作
2. **全身动力学链**：每个动作都是全身协调。写"转头"要写颈椎旋转+肩膀跟转+重心微移+眨眼。2.5只执行你写的部位，没写的部位不动=恐怖片
3. **环境动态必须写**：风/灰尘/雾/光焰/水/生物——2.5不会自动补。不写=死画面=假。每个Shot至少3-4个环境动态元素
4. **光照-表面交互**：角色不是独立打光的。写明环境光怎么照到角色皮肤上（主光源方向+照射部位+色温混合+反射光+阴影来源）。不写=角色皮肤与环境脱节
5. **四层画面枚举**：前景/中景/背景/空气层都要写。空气永远有内容（至少灰尘和温度效果）
6. **字数不再受限**：2.5支持50个参考素材，放心写长。但每个字必须描述画面中可见或可听的内容

## 生成前质检（preflight）

- [ ] 参考角色：所有图明确角色和controls
- [ ] 首帧状态：嵌入开场beat
- [ ] 动作物理：每beat有movement construction
- [ ] 时间：beat分配合理，时间段不重叠不留空
- [ ] 材质/光：material stack + dark object edge light
- [ ] 负面限制：针对性，非通用spam
- [ ] 连续性：全局锁定
- [ ] 每拍一个主动作
- [ ] 相机：每镜一个主运镜，无矛盾，每镜运镜不同
- [ ] 相邻拍不重复
- [ ] 角色演出：匹配人设，不叫喊不站桩，角色间分化不雷同
- [ ] 站位：空间关系清晰，不混乱
- [ ] **情绪词清零**：搜索提示词正文，零情绪/感受/抽象状态词
- [ ] **全身描写覆盖**：每个角色每个秒都有四层面动力学描写
- [ ] **环境动态≥3-4项**：每个Shot有空气/光/水/物体等动态元素
- [ ] **光照-皮肤交互**：每个可见角色都有光源方向+照射部位+色温区
- [ ] **四层画面枚举**：前景/中景/背景/空气层都有内容
- [ ] **丁达尔效应**（有光源+有粒子的场景）
- [ ] **角色-环境接触面物理**：脚踩/手扶/身体靠的表面有物理反应
- [ ] **不自主反应持续**：呼吸/眨眼/微晃贯穿全Shot
- [ ] **动作无空白**：每个动作紧跟下一个动作，不留情绪空白让2.5自己填

## 迭代修复

失败后一次只改1-2个变量，保留成功部分，不全重写。常见问题（掉帧/角色复制/动作跳过/色调偏移等）的修复方案详见 `references/iteration_manual.md`。

打斗CLIP有额外专用规则（急速运镜/压迫感镜头/物理反馈/荷兰角等），详见 `references/fight_clip_rules.md`。

## 注意事项

- Seedance 2.5支持30s输出但十分贵，提示词必须检查检查再检查
- 2.5支持50个参考素材，提示词长度不再是限制——放心写长，但每个字必须描述画面中可见或可听的内容
- 15s能搞定就不拆成多个CLIP
- 每镜必须改变≥2项（shot function/size/angle/move）
- 绝不站桩：角色必须有持续动作行为（2.5不会帮你补"活着"的感觉——呼吸/微晃/眨眼都要写）
- 多处修改文件时用write_file整体覆盖，不用edit_file（并发问题）
- **写每个CLIP前必读 `references/seedance_25_execution_model.md`**
