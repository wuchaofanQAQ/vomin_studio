# 交付前自查清单

逐段过一遍，未通过的先改再交付。

## A. 结构

- [ ] 段标题含"第NN段  标题"，下一行有"本段总时长 X秒  时间范围 0-Xs"
- [ ] 六块齐全且顺序固定：资产锁定 → 现场生成 → 整体基准 → 初始空间 → 镜头 → 终态
- [ ] 资产锁定里的名称与参考图/库内名称**逐字一致**（含版本后缀，如"中年版""披风版"）
- [ ] 正文中出现的所有【】资产都已在资产锁定中列出；资产锁定里的都在正文用到
- [ ] **正文没有代词**（他/她/自己/前者/后者），所有人物指称都写成【资产名】
- [ ] **身体部位写清归属**（`【沈幼怡】的指尖`、`【陈诚】的半张脸`），没有孤立的"指尖/半张脸/下颌线"
- [ ] **屏幕文字写进正文**（界面 + 气泡方向 + 「」原文），没有"内容留白""后期贴字"
- [ ] 缺图资产已写入文档头"待补资产"，且正文已写形制基准
- [ ] 【资产锁定】按 场景/角色/道具/特效 分组，每条写成 `【名称：{表：行}】`，行标识与库主键逐字一致、与名称同名
- [ ] 【资产锁定】**只写名称与引用**，没有重复描述场景内容或角色外貌（图和档案已涵盖）
- [ ] **`{}` 只出现在【资产锁定】块内**，正文无残留花括号
- [ ] **【本段现场生成】引用图时写了【资产名】**，且都在资产锁定里；没有"走廊图""厨房图"这类泛称
- [ ] 锁定引用的素材均已出图；未出图的只在"待补资产"，不进锁定块
- [ ] 锁定条目名与正文用的名字逐字一致

## B. 时间

- [ ] 镜头时间码从 `0` 开始、**全部落在 0.5 秒格上**（`0-0.5s`、`0.5-1.5s`），首尾相接，无重叠、无空隙
- [ ] 最后一个镜头终点 = 本段总时长
- [ ] 每个镜头窗口内的动作量可信（<1 秒只一个动作；1~2 秒一个动作+落幅）
- [ ] 0.2 秒爆发窗口、"约四秒连续动作"等写死的时间与镜头时间码吻合
- [ ] 镜头数与平均每镜时长落在同类型段的经验区间内（`shot-grammar.md` 经验法则），偏离时有叙事理由

## C. 对白

- [ ] 每条对白的起止都落在其镜头窗口内
- [ ] 语速 = 去标点汉字数 ÷ 时长 ≤ 5.3 字/秒（中位约 4.5）
- [ ] 台词与剧本**逐字一致**，未润色
- [ ] 画外声写了方位；听话人镜头写了声音来向
- [ ] 内心独白的画面里人物不开口，整体基准声明"内心独白清楚"
- [ ] 有对白的段，整体基准末尾带固定的"连续声桥"句
- [ ] 长句拆分在逗号处，收尾镜头标"收尾"

## D. 空间与一致性

- [ ] 初始空间写了世界轴、主体距离/朝向、未入画者位置、开镜机位、对话轴与机位侧
- [ ] 所有镜头的左右、视线高低与初始空间一致
- [ ] 光源与风向在整体基准定下，镜头不自相矛盾
- [ ] 同一物体（道具/特效/生物）用"同一…"锚定并有形制基准
- [ ] 同一角色的版本在本段内一致，整体基准已点明
- [ ] 群体数量与具名角色的包含关系前后一致
- [ ] 本段终态与下一段初始空间逐项对应（位置、姿态、手持物、环境残留、未发生的事）

## E. 写法质量

- [ ] 每个镜头按"景别机位 → 主体 → 动作链 → 后景 → 运镜落幅"写，六要素齐
- [ ] 没有"震撼""史诗""情绪饱满""很愤怒"这类无法拍出来的词；情绪都已物理化
- [ ] 动作写成先后因果，且物体有承重/支撑
- [ ] 软物（衣摆、发尾）有惯性滞后，且方向与风/运动方向一致
- [ ] 冲击/起飞/撞地后有一次带幅度、方向与衰减的短震
- [ ] 巨大/极小的物体有占画面比例与参照物
- [ ] 连续动作的相邻镜头用"承接同一次…"，并以动作完成点收镜
- [ ] 没有 NEGATIVE 段、英文胶片参数、STYLE LOCK 编号子段
- [ ] 画面描写里没有比喻（"像…""如…"）、瞳色、剧情原因、衣物重复描写
- [ ] 每个镜头扫过 `seedance-25-rules.md` 五项：情绪物理化、全身动力学链、环境动态≥3~4、光-表面交互、四层画面
- [ ] 相邻镜头运镜尽量不同；物理细节递进不重复

## E2. 镜头写厚与块间一致（详见 `shot-richness-and-pitfalls.md`）

- [ ] 每个镜头有前景/中景/后景三层（特写可压缩为各一句），过肩/过门缝镜头写了遮挡关系
- [ ] 运镜写了"起点→落幅"；一段里没有大半镜头都是"镜头固定"
- [ ] 连续动作的相邻镜头有"承接……"句，且从上一镜完成点起
- [ ] 每个主要角色全段至少 3~4 处物理化微表情；人设（社恐/内向等）在表演里有体现
- [ ] 机位换边（过肩/门内/反打）的镜头补了本镜光线来向
- [ ] 尺度用数字写（厘米、占画比例、距离），没有"很近""很大"
- [ ] 锚点身份说明（如"未露脸"）与镜头里的露脸/露出部位不冲突
- [ ] 内心独白对白行标了"嘴唇不动，画外声"，镜头正文没有嘴部动作
- [ ] 终态每一项都能在最后几镜里找到来源动作
- [ ] 道具交接处每镜写清持握者，终态写最后持握者
- [ ] 整体基准声音层次里的每种声音都在某镜头作为声音事件出现；镜头标题里提到的声音正文有写
- [ ] 1~2 秒镜头只有一个动作 + 落幅，过程性动作已写成结果态
- [ ] 没有"没有独立信息"的碎镜头（已合并进相邻镜头）

## E3. 镜头空间与可见性（详见 `camera-space-and-visibility.md`、`action-impact-vfx-crowd.md`）

- [ ] 每镜都能回答：摄影机在哪、看见什么、动作如何连续、结果落在哪、下一镜从什么状态继续
- [ ] 主体位置与朝向用画左/画右/前中后景表达，没有孤立的"看向前方""朝他走去"
- [ ] 每镜可见集核对过：正文里每个人名/物名/身体部位都真在画框内；画外角色只以声音/目线/影子/气流出现，没有写其姿态与表情
- [ ] 切镜后主体状态已重建（位置、朝向、姿势、速度、持握、视线），描述范围服从景别
- [ ] 运镜写了起幅、路径、落幅；稍后才入框的内容没写成从头可见
- [ ] 剧本要求"看见"的事件都在具体镜头窗口里可见，没有挪进画外/基准/终态
- [ ] 正文没有"不要/禁止/无……"式负向句（剧本台词里的自然否定词除外）
- [ ] 动作戏：受力—环境—摄影机链完整，接触先于结果；特效写了所处阶段与空间路径；多道攻击有各自起点/方向/时序
- [ ] 仅作画外声的角色未进锚点与资产锁定
- [ ] 单段字数 ≤ 12000
- [ ] 文本自检结论没有冒称"实测通过"

## E4. 导演级逐镜改写已完成（详见 `director-self-review.md`）

- [ ] 已逐镜过 16 项，修正直接写进镜头正文，没有另列"自检说明/修改报告"，没有因此拆出分行栏目
- [ ] 每个运镜有起点、路径、方向、落点，且在镜头时长内做得完；环绕/跟拍写成"与主体共同前进的同时改变相对方位"
- [ ] 高速镜头有视差、相对速度、方向性环境反馈，而不是人物在背景上平移
- [ ] 动作链完整（接近→接触→受力→形变→释放→后续），反馈强度与力量一致，环境反馈只在受影响区域
- [ ] 镜头里没有当前景别/机位拍不到的元素，也没有上下场景或无来源的额外主体（靠删改解决，不靠加否定句）
- [ ] 0.5 秒镜头只有一个动作；切镜点继承上一镜的运动方向、惯性、速度等级
- [ ] 慢镜写明看什么并明确恢复正常速度
- [ ] 同一连续场景的光向/天气/时间没跳变；人物、武器、载具、数量连续
- [ ] 最后一镜写出了真正停下的那一帧（位置、占比、层次、光向、机位最终位置）并与终态一致

## F. 交付

- [ ] 文档头：用法、资产绑定、待补资产、分段索引完整
- [ ] 附资产映射表（【资产名】→ 库内名称/来源/状态）
- [ ] 附依赖清单（scenes/characters/new_scenes/new_characters），已去重，新增项已列入 `new_*`
- [ ] 段 ID 为 `ep{集号}_p{段序}`，结构化 JSON 的 `prompt` 为完整段文本
- [ ] 同角色跨段造型/状态一致，同场景跨段光影色调一致
- [ ] `timeline` 为 `MM:SS-MM:SS` 且等于该段真实时长（≤30 秒）；`dialogue` 每行 `角色：台词`，说话人都在角色档案且有音色
- [ ] 写文件、写入飞书、generate 前，已向用户列出清单并得到明确确认
