# Seedance 2.5 执行规则（中文版）

> 2.5 不推理：你写什么它给什么，不写就没有。所以每个镜头要把"看得见、听得见"的东西写够；但范本镜头只有 90~290 字，所以下面五条是**检查项**——逐镜头扫一遍有没有漏，不是每镜都要逐项展开成长文。

## 1. 情绪 → 物理

2.5 会对情绪词字面执行且过度："笑"就真笑，"愤怒"就暴怒。正文里**不出现情绪、感受、抽象状态词**，一律换成 2~3 个可见的肌肉与身体动作，且动作后紧跟下一个动作，不留情绪空白。

禁用词（遇到同类一律替换）：笑、微笑、怒、愤怒、悲伤、犹豫、轻蔑、紧张、恐惧、惊讶、疑惑、不屑、欣慰、失落、痛苦、得意、尴尬、满足、疲惫、期待、失望、警惕、放松、困惑、厌恶。

| 禁用 | 替换写法 |
|---|---|
| 微微一笑 | 嘴角上提约两毫米，随即落回，紧接着转入下一个动作 |
| 愤怒 | 眉骨下压，下颌咬紧，颈侧肌肉绷出，双拳在身侧收紧 |
| 悲伤 | 眼睑下垂，嘴角微降，喉头吞咽一次，肩膀向内收 |
| 犹豫 | 视线向左再向右扫约半秒，嘴唇微张不出声，右脚半步迈出又停住 |
| 紧张 | 喉结滑动，手指蜷成拳再松开，重心移到左脚 |
| 恐惧 | 眼睛睁大，鼻翼张开，上身后仰约三厘米，双手停在半空 |
| 惊讶 | 双眉上扬，嘴张开约一厘米，身体微微后晃 |
| 疲惫 | 肩膀下沉，眼睑半垂，从嘴里长呼一口气，脊背略微前弯 |
| 警惕 | 头迅速转向声源，肩膀绷直，呼吸变浅变快 |

对白的语气标注（`得意地`、`压着怒意`）是范本允许的，因为它描述的是**说话方式**；但画面描写里仍不能出现这类词。更多写法见 `physics-and-scale.md`。

## 2. 全身动力学链

只写一个部位，2.5 就只动那一个部位——像恐怖片。每个动作要覆盖四层：

1. **主动件**：做核心动作的部位。
2. **稳定件**：维持平衡的部位（重心腿、核心）。
3. **补偿件**：配合的联动（肩跟转、手臂摆动）。
4. **不自主反应**：呼吸、眨眼、重心微移、衣物随动。

例：转头看——颈部向右转约三十度，双脚不动、重心微移左脚，右肩跟着转几度、下巴微抬，呼吸不变、眨眼一次。

使用方式：
- 每个角色每个时间窗口都有全身交代，**即使站着不动**（写重心、手位、呼吸）。
- 短镜头（<1 秒）可压缩成"主动件 + 一个补偿 + 一个不自主反应"一句话；长镜头才展开四层。
- 不自主反应贯穿整个镜头。

## 3. 环境动态

2.5 不会自动补环境运动，不写就是死画面。每个镜头至少 3~4 个环境动态，且融进动作时间线（"脚步带起灰尘，灰尘在光里飘散"）。

| 类别 | 例子 |
|---|---|
| 空气 | 风的方向和强度及影响对象；灰尘被脚步带起；雾、蒸汽、烟随气流 |
| 水 | 涟漪扩散、倒影扭曲、水滴溅起、积水被踩出波纹 |
| 光 | 火焰摇曳、光斑跳动、影子随光源摆动、丁达尔光柱里粒子流动 |
| 物体 | 布料旗帜被风吹、松动物件被震得微颤、碎屑从接触面脱落 |
| 生物 | 飞虫绕灯、远处人影走动 |
| 可视温度 | 冷天呼吸雾气、热气蒸汽、皮肤凝汗 |

- 要有时间维度："风从左侧来，衣角每秒摆动约两次"。
- 有光源又有粒子的场景写丁达尔光柱。
- 整体风向在【本段整体基准】写一次，镜头里只补充具体对象，避免每镜重复整段环境。

## 4. 光与表面交互

2.5 不会让环境光自动影响肤色；不写，人物就像在影棚里独立打光。每个可见角色要交代：

1. 主光源从哪来；
2. 照到身体哪个部位；
3. 反射光从哪来（地面、墙、水面）；
4. 阴影落在哪（眉骨在眼窝投影、下颌下方暗）；
5. 色温混合（冷天光 + 暖火光 = 头顶冷蓝灰、侧面暖橙、下颌暗灰）；
6. 边缘光（冷天光在肩与头顶勾出冷灰轮廓）。

写法示例：`冷蓝灰天光从上方落下，头顶、肩与上胸偏冷；右侧两米外火把把暖橙光打在右脸、右臂；潮湿地面把暗冷灰光反向托到下颌。肤色顶部冷灰、右侧暖橙、下方暗灰。`

**光照铁律**：
1. 光必须有物理光源（太阳、月、灯、火），不写"氛围光""戏剧光"。
2. 不给角色单独打光，人物与场景用同一套光。
3. 多光源 = 多色温区，写明哪个部位偏冷、哪个偏暖。
4. 反射光必须写；材质决定反射（湿石强反光、干石哑光、金属高光）。
5. 阴影永远不是纯黑，写成"暗灰""深褐"。

位置：光源方向和主色温在【本段整体基准】写一次；每个镜头只写**这一镜相对前一镜变了什么**（逆光、侧光、反光落点）。

## 5. 四层画面

不写某一层，画面里那一层就是空的。每个镜头逐层检查：

- **前景（0~2 米）**：物体、碎片、虚化的肩缘；材质、光、运动、表面细节。
- **中景（2~8 米，角色层）**：全身动力学链、情绪物理化、光-肤交互、与环境的接触面、随动元素。
- **背景（8 米外）**：建筑、人群、远处光源及其动态，空气透视（雾让远处偏冷偏糊）。
- **空气层（贯穿全画面）**：灰尘、雾、烟、蒸汽、风，光在空气里的传播，可视温度。

要点：
- 角色与环境的**接触面**必须写（脚踩水地水被挤开、手扶墙带下灰）。
- 空气永远有内容——至少灰尘与温度效果。
- 范本把后景压成"一句话"：前景一句、人物一句、后景一句。这是可以的，只要四层各有着落。

## 6. 三条反规则与其他禁止

1. **反比喻**：删掉"像……""如……"，直接写视觉事实。
2. **反衣物描写**：服装由参考图锁定，正文不重复；衣物**随动**可以写（衣摆迟半拍飘起）。
3. **反瞳色**：不写瞳孔、虹膜颜色，统一写"视线看向某处"。
4. **反剧情原因**：不写"因为她想起了过去"，只写看得见的。
5. **反暗示**：Seedance 不需要知道的信息不写。
6. 不写 NEGATIVE 段；用正向描述把画面写对（见 `iteration-manual.md` 里对 2.5 的修复写法）。

## 7. 篇幅

- 参考素材可多（图最多 30、视频 10、音频 10），提示词长度不是限制。
- 每个字都要描述画面里**可见或可听**的内容。
- 范本镜头 90~290 字，一段 6~30 秒；不要为控制字数省空间关系和物理反馈，也不要为凑字数加形容词。

## 8. Seedance 平台速查

| 任务 | 触发词 | 锁定 |
|---|---|---|
| 参考生视频 | 参考图片/视频N中的某属性 | 不锁定宽高比和时长 |
| 编辑视频 | 编辑/增加/删除/修改/替换 视频N | 锁宽高比 + 时长 |
| 延长视频 | 向前/向后延长 视频N | 锁宽高比，时长可自定 |
| 首帧/首尾帧 | role=first_frame/last_frame | 锁宽高比，时长可自定 |
| 多宫格分镜 | 分镜图参考 | 不严格对齐细节；15 格以内效果好 |
| 关键帧 | 多张独立分镜图 | 相对严格对齐输入图 |

- 编辑/延长任务直接用"视频N"指代，不加"参考"前缀；Asset ID 不能替代"图片/视频N"。
- 宫格分镜图用线稿或火柴人，不在图上写字，文字会干扰。
- 视频延长要音画衔接，输入输出统一用 mov。
- 2.5 单段直出最长 30 秒，精确控时用时间码（范本做法）。
- 正向描述优先：告诉模型"画面里有什么"比"不要什么"更稳；反向描述只用于字幕和音频控制。
